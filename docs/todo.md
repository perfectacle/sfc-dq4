# 남은 일

트랙마다 아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../.agents/skills/tracks/SKILL.md) 를 봅니다.

## dq5

SFC DQ5 엔진 분석. 시작점은 [dq5-handoff.md](dq5-handoff.md). 결과 문서: [dq5-map-format.md](dq5-map-format.md), [dq5-field-format.md](dq5-field-format.md).

- **인물 대화 번호 → 대사, 텍스트 형식**: DQ4 대사를 넣으려면 가장 먼저 필요합니다.
- **보물상자**.
- **인물**: 인라인 스크립트, 기타·이동·추가 값, 숨은 인물 목록 9개.
- **맵별 루틴(`15:F907`)의 남은 것**: 01/05 (51,20)·04/05 (4,66) 처럼 조건 없이 빈 곳에 둔 출구 셀과 짝이 되는 계단을 무엇이 만드는지(04/06 (4,5) 계단을 밟으면 04/05 빈 곳 (3,66) 에 섬). 맵을 옮길 때 `00:A8CC` 가 `7E:21A0` 을 지우는데도 03/02·06/05 루틴이 그 플래그를 보는 이유(켜진 채 루틴이 도는 경로). 표의 둘째 루틴(`$1AA6`)의 쓰임.
- **필드 마을 입장을 실제로 걸어 확인**: 조작 가능한 필드 장면이 필요합니다(지금 세이브스테이트는 강제 전투 뒤 조작이 막힘). 바다 위에 찍힌 입구 몇 개의 정체, `23:EA44` 조우 계수 패치 효과도 함께.
- **필드 영역 이동**(`01:94B4`, `01:9635`, `9642`, `9667`)과 다른 필드(`$BC` = `$50`~`$54`).
- **맵 머리 `+0` bit3-5**(`$1A33`)를 읽는 곳. 셀 `+1` bit4-6, `+0` bit3 의 쓰임.
- **필드 팔레트** 4번 줄과 팔레트를 고르는 루틴.

## dq4

FC DQ4(Rev A) 원작 데이터 분석. 이식할 데이터가 어디에 어떤 형식으로 있는지 찾습니다. 시작점은 [dq4-handoff.md](dq4-handoff.md).

- **롬 구조**: 뱅크 `00`~`07`(부팅·보행에서 실행 안 됨)의 내용, 뱅크별 `$8000` 함수 표의 길이와 역할, `BRK` 특수 형식(`x3` 인자 길이, `$627B` 플래그 형식), 고정 뱅크 `0F`·`1F` 가 다른 6548바이트.
- **출구 표**: `$05A0` 7바이트 항목의 +2·+3·+6, 목적지 맵 번호를 정하는 곳, 표를 채우는 롬 데이터. `$0028` 이 필드·다른 마을에서도 맵 번호인지.
- **대사 텍스트**: 문자 표, 압축(사전) 방식, 대사 번호에서 본문을 찾는 표.
- **실내 맵과 필드**: 맵 데이터 형식, 인물 배치, 출구.
- **몬스터·아이템·주문·경험치 표**.
- **이벤트·스크립트**: 플래그, 장(章)마다 바뀌는 데이터.
