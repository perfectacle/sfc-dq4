## dq4

FC DQ4(Rev A) 원작 데이터 분석. 이식할 데이터가 어디에 어떤 형식으로 있는지 찾습니다. 시작점은 [dq4-handoff.md](dq4-handoff.md).

- **롬 구조**: 뱅크 `00`~`07`(부팅·보행에서 실행 안 됨)의 내용, 뱅크별 `$8000` 함수 표의 길이와 역할, `BRK` 특수 형식(`x3` 인자 길이, `$627B` 플래그 형식), 고정 뱅크 `0F`·`1F` 가 다른 6548바이트.
- **대사 텍스트 나머지**: 제어 바이트 `ED`·`EE`·`F1`·`F4`·`FE`·`FF` 의 뜻, `F5`~`F8`·`EF` 치환 값, 메뉴·상점 창 문구, 맵·인물이 부르는 메시지 번호(뱅크 15 스크립트 해석기, 왕 → `060A` 실측).
- **맵 나머지**: 블록 번호 → 그래픽·통행(맵 종류별 블록 정의), 해제 뒤 BRK 뒤처리, 연결 끝점 플래그 위 비트, 인물 레코드 나머지 바이트·블록(움직임·대화 스크립트)·대체 목록(`1C:$9D0E`), 필드 타일 → 그래픽·통행, 필드 1·2 의 정체, 조우 표.
- **표 나머지**: 몬스터 레코드 나머지 바이트·HP 무작위, 아이템 수치 화면 확인과 플래그 비트, 주문(MP·효과), 레벨별 능력치·경험치, 상점 목록, 보물상자.
- **이벤트·스크립트**: 플래그, 장(章)마다 바뀌는 데이터.
- **스프라이트 나머지**: [스프라이트 규격](dq4-sprite-format.md)의 9명 중 라이안 정면만 사용자 확인. 나머지 8명과 측면·후면·보행의 확인, 복장 색 대조(크리프트·주인공 모자, 미네아 띠), `_step` 보행 자세를 손으로 그리기. 마을 인물·몬스터(슬라임 외)는 아직 없음.
- **포팅용 그래픽 나머지**: 타이틀·일러스트 보존([그래픽 핸드오프](dq4-graphics-handoff.md)). DQ5 인물 그래픽 압축·포인터·VRAM·CGRAM 배치와 장면 전환 검증(dq5 트랙과 협의), 채택 미확인인 샘플 맵의 재검토·원작 배치·통행·출구·이벤트 연결, 타이틀 삽입과 일러스트의 게임 내 사용 여부 결정.

## nds

NDS DQ4 리메이크와 그 한글 팬패치를 참고 자료로 분석합니다. 패치의 바탕이 아닙니다. 시작점은 [nds-handoff.md](nds-handoff.md).

- **롬 구조**: 파일 시스템을 풀고 일본판·한글판을 파일 단위로 비교해 팬패치가 바꾼 파일(대사·폰트·그래픽 위치)을 찾기. 압축·묶음 형식 확인.
- **대사와 명칭 대조표**: 대사 파일 디코더, 인물·지명·몬스터·아이템·주문·특기·장 제목을 FC 일본어·DS 일본어·DS 한글 팬패치·채택 이름으로 대조. 채택 이름은 사용자 확인.
- **늘어난 내용 목록**: 6장, 피사로 동료, 이민 마을, 파티 대화, 새 몬스터·아이템·주문, 카지노·작은 메달. 롬 확장을 전제로 DQ5 엔진에 필요한 기능과 추가 용량을 적고 「옮긴다 / 나중에 / 안 옮긴다」 를 제안.
- **맵·스프라이트 참고**: DS 맵 배치(건물·인물·출구)를 FC 맵과 장소 단위로 짝짓기, 인물 스프라이트 렌더링 스크립트(결과는 `work/` 에만).
- **툴킷 보강**: `krpatch xdelta apply` 가 VCDIFF 2차 압축(LZMA)을 못 읽음(한글패치 v1.1 이 이 형식). 위에서 필요한 게임 무관 형식(NARC, NDS 폰트·그래픽 등)을 kr-patch-toolkit 에 넣기.
