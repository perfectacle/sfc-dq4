# 남은 일

트랙마다 아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../.agents/skills/tracks/SKILL.md) 를 봅니다.

## dq5

SFC DQ5 엔진 분석. 시작점은 [dq5-handoff.md](dq5-handoff.md). 결과 문서: [dq5-map-format.md](dq5-map-format.md), [dq5-field-format.md](dq5-field-format.md), [dq5-text-format.md](dq5-text-format.md), [dq5-data-format.md](dq5-data-format.md), [dq5-graphics-format.md](dq5-graphics-format.md).

- **상점의 남은 것**: 여관 값의 일행 수 곱셈과 bit7(`$0F36`), 교회·코인 판매·맡기는 곳 값 실측(돈·상태 이상이 있는 세이브스테이트 필요), 슬라임 레이스(`03:A1EE`)·격투장(`26:8E38`·`04:E391`) 배당과 상품.
- **주문·몬스터 표의 남은 것**: 주문 실행 때 대상 수를 정하는 곳(`26:8765` bit5-6 을 바꿔도 그대로)과 플레이어 명령 입력(`20:8700`)의 범위 비트, 상태 주문 루틴(`20:AE41`·`AEC6`·`AEFF`)에 넘기는 값, 내성 50·51·57 밖의 실측. 몬스터 필드 `68`·`69`·`6D`·`6E`·`76`·`77`(`76`·`77` 은 동료가 되는 것으로 보임)과 시작 상태 `39`. 물건 표 k1~k4 플래그(`21:A49D`~`A61F` 를 부르는 곳), 장비 비트 `21:A632` 의 인물 번호 ↔ 동료, `23:AED1` 레코드.
- **전투**: 전투 모드 메시지(`24:8C39`). 몬스터 그림의 남은 것: 머리 `+0`~`+4` 의 뜻, 여러 마리 배치·OAM 만드는 루틴(`7E:5800` →), 그림 `15` 뒤 3바이트, `EA` 에 `EB` 를 더하는 곳, 전투 배경.
- **조우의 남은 것**: 필드 구역 격자(`23:F1FC`~)·지형 조우율(`23:F1E0`) 실측(조작 가능한 필드 세이브스테이트 필요), `$1948`·`$1949` 가 고르는 것, 실내 조우율 20(`01:8526`)과 `$7E21C9` 처리, 고정 무리 하위 4비트(`$1009`~)·레코드 `+0`·`$1000`·`$1010`·맵 항목 `+3`~`+5` 의 쓰임, 큰 몬스터 마릿수를 줄이는 곳.
- **인물**: 인라인 스크립트 명령 중 처리 루틴만 읽은 것(`05`·`20`·`41`·`43`·`4F`~`53` 등) 실측, 인물 표 `32A0`·`33A0` 의 나머지 비트를 쓰는 곳.
- **맵별 루틴(`15:F907`)의 남은 것**: 04/05 (4,66) 빈 곳 출구 셀과 짝이 되는 계단을 무엇이 만드는지(04/06 (4,5) 계단을 밟으면 04/05 빈 곳 (3,66) 에 섬. 01/05 는 파파스 스크립트가 놓음). 매 프레임 루틴(`$1AA6`) 각각이 하는 일(`02:AE55` 의 `21A1` bit0, `03:D4B5` 의 `7E:1ECE`).
- **필드 마을 입장을 실제로 걸어 확인**: 조작 가능한 필드 장면이 필요합니다(지금 세이브스테이트는 강제 전투 뒤 조작이 막힘). 바다 위에 찍힌 입구 몇 개의 정체도 함께(`23:EA44` 를 0 으로 하면 실내 조우가 꺼지는 것은 확인).
- **필드 영역 이동**(`01:94B4`, `01:9635`, `9642`, `9667`)과 다른 필드(`$BC` = `$50`~`$54`).
- **맵 머리 `+0` bit3-5**(`$1A33`)를 읽는 곳. 셀 `+1` bit4-6, `+0` bit3 의 쓰임.
- **필드 팔레트** 4번 줄과 팔레트를 고르는 루틴.
- **보물상자의 남은 것**: `D001`·`D002` 의 `$1948` 조건, `D003`·`D006`·`D008` 이 만드는 계단, `D005` 가 놓인 곳, `D009` 플래그, `01:868B` 에 넘기는 값(`0C`~`0F`)이 몬스터를 고르는 표.
- **텍스트의 남은 것**: 끝 코드 `1001`·`1010`·`1018` 의 차이, `1100` 번대 몸짓의 화면 모양(`7E:31E0`·`3260`·`33A0`). 이름 변수 `1013`·`100F`·`101B`·`1009`·`100C` 실측과 `$F5` 대기열을 채우는 쪽. `BRK 88`·`89`·`8B` 조회와 조건 코드 `03`·`11`·`13`·`20`·`14` 의 뜻(동료가 있는 세이브스테이트 필요). 대화 번호 `000` 인물의 실제 대사, 네이티브 호출 142곳의 나머지. 창 레코드(`04:EB48`) 머리와 숫자 자리가 있는 창(상태 창 등)의 형식.
- **장면 이동 도구의 남은 것**: 시대(`$1949`)·동료·탈것 상태를 바꾼 장면 만들기, 롬 밖 뱅크(`30`~`3F`) 실행 감시를 어른 시절·탈것·동료·미니게임 장면에서도 돌리기, 이벤트 전투 무리 플래그(`23:D757 +0`)와 무리 `30`~`3F` 를 부르는 곳.

## dq4

FC DQ4(Rev A) 원작 데이터 분석. 이식할 데이터가 어디에 어떤 형식으로 있는지 찾습니다. 시작점은 [dq4-handoff.md](dq4-handoff.md).

- **롬 구조**: 뱅크 `00`~`07`(부팅·보행에서 실행 안 됨)의 내용, 뱅크별 `$8000` 함수 표의 길이와 역할, `BRK` 특수 형식(`x3` 인자 길이, `$627B` 플래그 형식), 고정 뱅크 `0F`·`1F` 가 다른 6548바이트.
- **대사 텍스트 나머지**: 제어 바이트 `ED`·`EE`·`F1`·`F4`·`FE`·`FF` 의 뜻, `F5`~`F8`·`EF` 치환 값, 메뉴·상점 창 문구, 맵·인물이 부르는 메시지 번호(뱅크 15 스크립트 해석기, 왕 → `060A` 실측).
- **맵 나머지**: 블록 번호 → 그래픽·통행(맵 종류별 블록 정의), 해제 뒤 BRK 뒤처리, 연결 끝점 플래그 위 비트, 인물 레코드 나머지 바이트·블록(움직임·대화 스크립트)·대체 목록(`1C:$9D0E`), 필드 타일 → 그래픽·통행, 필드 1·2 의 정체, 조우 표.
- **표 나머지**: 몬스터 레코드 나머지 바이트·HP 무작위, 아이템 수치 화면 확인과 플래그 비트, 주문(MP·효과), 레벨별 능력치·경험치, 상점 목록, 보물상자.
- **이벤트·스크립트**: 플래그, 장(章)마다 바뀌는 데이터.
- **포팅용 그래픽 재검토**: [그래픽 핸드오프](dq4-graphics-handoff.md) 기준으로 타이틀·일러스트를 보존하고, 최종 16×24까지 반려된 스프라이트는 제작 방법부터 다시 결정. 원작과 같은 배경·배율에서 정면 한 장을 비교해 채택한 뒤 보행 제작. 로컬 DQ5 Lua 보행 실험은 영구 삽입이 아니며 새 복제본에서 재현되지 않음. 이후 DQ5 압축·포인터·VRAM·CGRAM 배치와 장면 전환 검증, 채택 미확인인 샘플 맵의 재검토·원작 배치·통행·출구·이벤트 연결, 타이틀 삽입과 일러스트의 게임 내 사용 여부 결정.
