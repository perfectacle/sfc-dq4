# 남은 일

트랙마다 아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../.agents/skills/tracks/SKILL.md) 를 봅니다.

## dq5

SFC DQ5 엔진 분석. 결과 문서: [dq5-map-format.md](dq5-map-format.md), [dq5-field-format.md](dq5-field-format.md).

- **출구 셀보다 목적지 항목이 많은 맵 4개**: 01/05·04/05·06/05 는 남는 항목(맵의 마지막 항목, 첫 바이트 bit7)이 상대 맵과 짝을 이룹니다(01/04 출구 1 → 01/05 출구 2, 04/0C 출구 0 → 04/05 출구 5, 06/04 출구 0 → 06/05 출구 1). 정적 맵에 없는 출구 셀이 이벤트로 생기는 것으로 보입니다. 03/02 는 출구 셀 없이 종류 `60` 항목 하나만 있습니다. 실험: 배 선실 세이브스테이트에서 사다리 항목(파일 오프셋 `156FF5`)을 `E40C2C0101` 로 덮으면 01/04 (7,42) 에 도착하고, (12,47) 계단 칸에서 아래로 눌러도 맵이 바뀌지 않았습니다. 계단 셀 좌표·층 마스크부터 다시 봅니다. 18/00 은 셀이 항목보다 많습니다(쓰이지 않는 셀로 보임).
- **종류 `60` 목적지 좌표**: `E40C2C0101`(x=12, y=44)로 덮었는데 01/04 의 (7,42) 에 도착했습니다. 좌표 변환을 확인합니다.
- **필드 마을 입장을 실제로 걸어 확인**: 조작 가능한 필드 장면이 필요합니다(지금 세이브스테이트는 강제 전투 뒤 조작이 막힘). 바다 위에 찍힌 입구 몇 개의 정체, `23:EA44` 조우 계수 패치 효과도 함께.
- **필드 영역 이동**(`01:94B4`, `01:9635`, `9642`, `9667`)과 다른 필드(`$BC` = `$50`~`$54`).
- **보물상자**.
- **맵 머리 `+0` bit3-5**(`$1A33`)를 읽는 곳. 셀 `+1` bit4-6, `+0` bit3 의 쓰임.
- **인물**: 기타·이동·추가 값, 인라인 스크립트, 대화 번호와 대사의 연결, 숨은 인물 목록 9개.
- **필드 팔레트** 4번 줄과 팔레트를 고르는 루틴.

## dq4

FC DQ4(Rev A) 원작 데이터 분석. 이식할 데이터가 어디에 어떤 형식으로 있는지 찾습니다.

- **롬 구조**: MMC1 PRG 뱅크 배치, 뱅크 전환 루틴, 고정 뱅크의 공통 루틴.
- **대사 텍스트**: 문자 표, 압축(사전) 방식, 대사 번호에서 본문을 찾는 표.
- **실내 맵과 필드**: 맵 데이터 형식, 인물 배치, 출구.
- **몬스터·아이템·주문·경험치 표**.
- **이벤트·스크립트**: 플래그, 장(章)마다 바뀌는 데이터.
