# 2026-10-25-20: 실행 루틴 표와 저주 장비

[2026-10-25-19](2026-10-25-19-target.md) 에서 「대상 펼치기 표」라고 적은 `26:8865` 가 행동마다의 실행 루틴 표라는 것, 저주 장비 비트(k2 bit3)가 장비할 때 실제로 쓰이는 것, 몬스터 필드 `69` 의 갈래를 확인했습니다.
결과는 [dq5-data-format.md 「주문과 행동」](../../dq5-data-format.md#주문과-행동-268765)·[「물건 표」](../../dq5-data-format.md#물건-표-23b081) 에 있습니다.

## 1. 실행 루틴 표

`26:8865` 의 값 171개를 같은 값끼리 묶으니 71가지였습니다. 공통 루틴 다섯 개를 여러 주문이 같이 쓰고, 나머지는 ザオラル(`9865`), 숨(`DB2B`), パルプンテ(`E282`)처럼 행동 하나 또는 몇 개만 씁니다.

```
975F  メラ メラミ メラゾーマ ヒャド …         9824  ホイミ ベホイミ ベホマ …
9771  ギラ ベギラマ ベギラゴン ヒャダルコ バギ …  9829  ベホマラー ベホマズン …
97BC  イオ イオラ イオナズン マヒャド ライデイン …
```

`9824`·`9829` 는 대상마다 `20:EF8F` 를, 적 쪽 셋은 `20:EF4C` 를 부르고, 둘 다 `20:AA8C` 로 처리 루틴 표(`20:B7F9`)에 들어갑니다.
파파스의 メラ 칸(`26:8867`)을 `9824`·`9829` 로 바꾸자 적이 아니라 우리 편에게 걸고 「キズが かいふくした」(`094`)가 떴습니다. `9829` 는 메시지가 세 번 나왔습니다.

```
9824: 070 094          9829: 070 094 094 094
```

## 2. 플레이어가 주문을 쓰는 장면

일행 레코드 `+23` 을 `FF` 로 하면 주인공이 ホイミ 등을 배운다는 것을 [2026-10-25-17](2026-10-25-17-encounter3.md) 에서 알았습니다. 장면 이동 도구의 `SET` 으로 `+23`·MP 를 넣고 전투를 만들었지만, 전투 명령 창은 그대로 たたかう·にげる(창 `57`)였습니다.
어른 일행의 창은 `13`(たたかう·さくせん·にげる)이고, 어느 쪽을 고르는지는 찾지 못했습니다. 그래서 플레이어 쪽 범위 비트는 코드만 읽었습니다. `20:86E8`~ 는 범위 0·1 이면 한 명, 2 면 그룹을 다시 고르고 3 이면 그대로 둡니다.

## 3. 저주 장비

필드 메뉴 そうび 에서 방패 단계까지 가면 주인공이 장비할 수 있는 はめつのたて(`80`, 장비 비트 bit7 켜짐)가 목록에 나옵니다. 가진 물건 셋째 칸(`7E:2058`)에 넣고 골랐습니다.

```
k2 = 0A (bit3 켜짐): f00396 25:FD00 A=0223, 다음 칸(かぶと)으로 넘어가기까지 더 걸림
k2 = 02 (bit3 끔)  : 25:FD00 호출 없음, 바로 かぶと 단계
```

`25:FD00` 은 `24:FE91` 등 소리 쪽으로 보이는 루틴을 부릅니다. 그래서 k2 bit3 을 저주 장비 비트로 정리했습니다. 저주 메시지와 벗을 수 없는 것은 아직 화면으로 보지 못했습니다.

## 4. 몬스터 필드 69

슬라임·ドラキー 의 바이트10 bit5-7 을 0~7 로 바꿔 같은 입력으로 싸웠습니다. 0~4 는 메시지 흐름이 똑같았고, 5·6·7 은 저마다 달랐습니다.
코드와 맞습니다. `21:AFD5` 는 7 이면 행동 표 처리를 건너뛰고, `21:AD8F` 는 5 이상(7 제외)이면 행동할 때 다시 고르지 않습니다. 슬라임은 공격만 해서 고른 행동이 어떻게 다른지는 보이지 않았습니다.

## 남은 것

- 행동 전용 실행 루틴 60여 개의 뜻
- 플레이어 명령 입력의 범위 비트(어른 일행 장면 필요), 전투에서 k2 bit7 물건 쓰기
- 저주 메시지·벗을 수 없음, 진짜 마을 상점에서 k1 bit3 물건 팔기
- 몬스터 필드 `68`·`6D`·`6E`, `69` 가 고르는 행동의 차이(행동이 여럿인 몬스터로), 시작 상태 `39`
