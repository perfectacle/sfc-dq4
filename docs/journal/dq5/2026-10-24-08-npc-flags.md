# 2026-10-24-08: 이벤트 플래그로 바뀌는 인물

[2026-10-24-03 일지](2026-10-24-03-npc.md) 에서 인물 목록을 풀 때 건너뛴 두 표를 확인했습니다. 이야기가 진행되면 같은 맵에도 다른 사람이 서는데, 그 장치입니다.
결과는 [dq5-map-format.md 의 「이벤트 플래그에 따른 목록」](../../dq5-map-format.md#이벤트-플래그에-따른-목록-1282fb-128357) 에 있습니다.

## 1. 두 표

인물을 놓는 `12:8009` 는 기본 목록을 찾기 전에 두 루틴을 부릅니다. 이번 실험에서 실행되지 않은 갈래는 정적으로 읽었습니다.

- `12:8357`: `12:839C` 의 4바이트 항목 `[$BC][$BD][플래그 번호][마스크]` 가 참이면 인물을 하나도 놓지 않습니다.
- `12:82FB`: `12:8449` 의 6바이트 항목에 포인터가 더 붙어, 참이면 인물 목록을 뱅크 `$10` 의 그 목록으로 바꿉니다. 표 순서대로 처음 참인 항목이 이깁니다.

플래그는 `7E:2190 + 번호` 의 마스크 비트이고, 번호의 bit7 이 1 이면 「꺼졌을 때 참」으로 뒤집힙니다.

## 2. 대체 목록 293개

표가 가리키는 목록 284개를 기존 인물 파서로 읽으니 `10:8000`~`10:DDB1` 이 거의 이어졌고, 틈 8곳이 남았습니다.
틈 자리를 목록으로 읽자 모두 다음 목록 시작에 정확히 닿았습니다. 표가 가리키지 않는 목록이 9개 숨어 있었고(이벤트 스크립트가 직접 가리키는 것으로 보임),
인물은 모두 1,366명입니다.

## 3. 플래그를 켜고 띄우기

첫 맵 02/06 에 걸린 「플래그 `$1D` 마스크 `$10` → `10:9B57`」 을 보려고 `atpc.lua` 의 `POKE` 로 `7E:21AD` 를 `$10` 에 고정해 부팅했습니다.

```
  slot 08: ours (36, 11, 23) game (36, 11, 23) OK
  ...
  slot 0C: ours (68, 35, 123) game (68, 35, 123) OK
```

인물 없애기는 배 선실 17/00 의 「플래그 `$02` 마스크 `$80`」 으로 봤습니다. `walk.lua` 에 `POKE` 를 넣고 사다리로 내려갔다 올라왔습니다.
플래그가 없으면 다시 들어온 17/00 에 목록대로 인물(그림 `2C 2E 2E 2C A6`)이 놓였고, 플래그를 켜면 인물 표에 앞 맵의 값이 그대로 남았습니다. 로더가 아예 돌지 않은 것입니다.

처음엔 도착 자리에서 바로 출구를 다시 밟으려 했는데, 도착 자리가 곧 출구 위치라 발동하지 않았습니다. 두 칸 위로 갔다가 돌아오자 넘어갔습니다.

## 틀렸던 것들

- 도착한 자리에서 출구를 다시 밟기: 한 번 벗어났다 들어와야 한다.
