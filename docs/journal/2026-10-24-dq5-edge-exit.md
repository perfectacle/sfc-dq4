# 2026-10-24 (5): 가장자리 출구와 필드로 나가기

[앞 일지](2026-10-24-dq5-exits.md)에서 「목적지 표의 여분 항목은 맵 가장자리로 걸어 나가는 출구」라는 가설을 세웠습니다.
이번에는 실제로 가장자리로 걸어 나가 확인했고, **가설은 틀렸습니다.** 결과는
[dq5-map-format.md 의 「가장자리 출구와 필드로 나가기」](../dq5-map-format.md#가장자리-출구와-필드로-나가기-2af425) 에 있습니다.

## 1. 걸어 나갈 맵이 없다

조작할 수 있는 곳은 배 안(17번 그룹)뿐인데, 배의 맵들은 가장자리 출구가 없습니다.
이야기를 진행해 항구·마을까지 가는 대신, 사다리 출구가 읽는 목적지 표 항목을 **실험 중에만 메모리에서 바꿔** 원하는 곳으로 보내기로 했습니다.

`walk.lua` 에 `ROMPATCH` 를 넣어 시작할 때 ROM 바이트를 덮어쓰게 했습니다(원본 롬 파일은 그대로).
배 사다리 항목(`2A:EFF5`, 파일 오프셋 `156FF5`)을 종류 `60`(좌표 직접 지정)으로 바꿨습니다.

```
E0 25 3C 01 03   = 종류 60 + 끝 표시, $BD=00, X=37, Y=60, 방향 1, $BC=03
```

목적지 03/00 은 출구 셀이 0개이고 끝 표시 `80` 만 있는 맵입니다. 맵을 그려 보니 성 앞뜰이었고 아래 줄이 열려 있었습니다.

## 2. 걸어 나가니 전투

```sh
STATE=$PWD/work/state/ship.mss PRE="b:4,wait:40,b:4,wait:40" ROMPATCH="156FF5=E0253C0103" \
  WAYPOINTS="3,11;3,24;7,24;7,22;37,66;37,72;down:90" CHANGES=2 AFTER=150 MAXF=2500 SHOT_DIR=$PWD/work/edge1 \
  "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/walk.lua"
```

```
f00362 map 17/00 -> 03/00 at x=7 y=23
f00693 reached 37,72
f00694 press down:90 at 37,72
f02500 end map 03/00 x=251 y=216
```

사다리를 밟자 03/00 으로 날아갔고, 아래로 걸어 나가자 필드로 나가 곧바로 슬라임 셋과 전투가 붙었습니다.
`$BC`/`$BD` 는 03/00 그대로였고 좌표만 (251, 216) 으로 바뀌었습니다.

## 3. 출구 표를 거치지 않았다

그 순간의 뱅크 `$2A` 실행 리스팅에는 목적지 표를 읽는 `2A:F6B8` 이 없었습니다. 대신 `2A:F234 → 2A:F425` 가 돌았고,
호출한 곳은 필드 보행 코드 `00:CC0F` 였습니다.

`2A:F425` 는 맵 그룹으로 필드 좌표를 정합니다. `04:FD97` 표(47항목)에서 `$BC` 를 찾고, 없으면 `04:FE83` 표(14항목)에서 찾습니다.
03 은 두 번째 표에 `03:(251,215)` 로 있었고, Y 에 1 을 더한 (251, 216) 이 실제로 선 자리와 같습니다.

## 4. 여분 항목의 정체

그럼 목적지 표의 「여분」 항목은 무엇이었을까요. 다시 세어 보니 여분이 종류 `00` 인 83개 맵은 **모두 출구 셀이 0개이고 항목이 `80` 하나뿐**이었습니다.
맵마다 목록이 bit7 항목으로 끝나야 하므로, 출구가 없는 맵에도 끝 표시 하나가 필요했던 것입니다.
출구 셀이 있는 맵 가운데 종류 `00` 항목을 가진 맵은 하나도 없습니다.

이것을 빼면 셀 수와 항목 수가 맞지 않는 맵은 5개(01/05, 03/02, 04/05, 06/05, 18/00)만 남습니다. 이벤트로 출구가 생기거나 막히는 곳으로 보이지만 확인하지 않았습니다.

종류 `00` 을 실제 출구로 밟는 경우(`2A:F7B2`)도 리스팅으로 봤습니다. `2A:F80A` 가 몇몇 맵만 따로 처리하고(예: 12/07 이면 53/52 의 정해진 자리),
나머지는 같은 `2A:F425` 로 필드에 나갑니다.

## 틀렸던 것들

- 여분 항목 = 가장자리 출구: 아니었다. 출구 없는 맵의 끝 표시. 가장자리 출구는 출구 표를 쓰지 않는다.
