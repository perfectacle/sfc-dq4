# 2026-10-25-05: 필드(세계 지도)

필드의 타일 배치를 롬에서 푸는 디코더를 만들었습니다. 결과는 [dq4-field-format.md](../../dq4-field-format.md) 에 있습니다.

## 1. 필드에서 읽는 곳

[앞 일지](2026-10-25-04-data.md) 에서 만든 필드 세이브스테이트에서 걸으며 `probe/reads.lua` 를 돌리니 `0F:$D336` 이 뱅크 0B 의 `$8F9D`~`$9281` 을 1892번 읽었고, `$D2E6` 이 `0B:$8000` 의 두 바이트를 읽었습니다. `$D259` 는 X·Y 레지스터의 좌표를 받아 타일 번호를 돌려주는 함수였습니다.

## 2. 줄 RLE

줄마다 4바이트 레코드(데이터 포인터, X=80 이 시작되는 바이트, 줄 끝 바이트)가 있고, 줄 데이터는 위 3비트가 타일·아래 5비트가 길이인 RLE 였습니다. X 가 40~7F, C0~FF 이면 다음 기준점에서 거꾸로 읽습니다. 디코더로 앞에서부터 다 풀었을 때 250줄 모두 기준점이 표와 같았습니다.

## 3. 게임 조회와 맞추기

`$D259` 진입 때 X·Y 와 `$D269` 의 결과 A 를 적는 `tools/lua/fc/fieldlookup.lua` 로 147번을 모아 비교했습니다.

```
조회 147번 중 0 다름
```

## 틀렸던 것들

- `$D2AA` 가 좌표에서 3 을 빼므로 지도도 3칸 밀려 있다고 봤는데, 뺀 값은 범위 검사에만 쓰고 찾을 때는 원래 좌표를 썼습니다. 처음 비교에서 80번이 달랐습니다.

## 남은 것

- 타일 번호 → 그래픽·통행, 필드 1·2 의 정체, 필드 위 입구 표, 조우 표.
