# 2026-10-25-09: 포팅용 스프라이트·맵·타이틀 제작

라이안과 호이미 슬라임의 스프라이트, 성·마을용 블록과 샘플 맵, 한글 타이틀, 모험 일러스트를 만들었습니다. 제작 원본과 출력 규격은 [DQ4 포팅용 그래픽 제작물](../../dq4-graphics.md)에 정리했습니다. 이번 작업은 롬 분석이나 삽입 실험이 아니라 그래픽 제작과 변환 검사입니다.

## 1. 스프라이트와 블록을 코드로 그리기

FC·Nintendo DS DQ4 인물 자료와 SFC DQ5 화면을 보고 비율·윤곽·색 구분을 확인했습니다. `tools/dq4sprites.py` 에 색 번호 문자 행렬과 팔레트를 직접 작성했습니다. 두 인물은 16×24픽셀, 네 방향에 세 프레임씩입니다. `tools/dq4terrain.py` 에 성벽·돌바닥·지붕 가장자리·풀·해자 둑 등 49종 블록을 그리고 이름 격자로 성 안뜰과 마을을 배치했습니다. 벽의 높이와 성탑 윤곽, 벽돌과 불규칙한 돌바닥의 재질 차이를 표현했습니다. 이 배치는 원작 맵을 복원한 것이 아니라 블록의 연결과 인물 크기를 보는 샘플입니다.

![직접 그린 맵 위에서 두 인물의 남쪽 프레임을 합성한 미리보기](../../images/dq4-graphics-walk.webp)

## 2. 타이틀과 일러스트 만들기

타이틀은 사용자가 제공한 Nintendo DS DQ4 화면의 용·하늘·로고 색감을 참고해 이미지 생성 도구로 새로 구성했습니다. 부제는 「인도받은 자들」입니다. 모험 일러스트는 외부 참조 이미지 없이 생성했습니다. 생성 원본과 사용한 프롬프트는 `tools/dq4art/` 에 보관합니다. 이미지 생성 자체는 재현성이 없으므로, 저장한 원본부터 변환하는 과정을 재현 대상으로 삼았습니다.

타이틀은 256×224픽셀로 줄이고, 타일마다 8개 BG 팔레트 중 하나를 골라 최대 121색을 사용합니다. 공통 배경색을 제외하면 팔레트마다 15색입니다. 하늘과 적금색 로고의 색 구분을 살리는 대신 BG 팔레트 8개를 모두 사용하므로, 다른 화면 요소와의 배치를 정해야 합니다. 일러스트는 1536×1024픽셀 시안으로 남겨 두었으며 SFC 4bpp 변환에 포함하지 않았습니다.

## 3. SFC 타일로 내보내기

`tools/dq4graphics.py` 가 색 번호 그림을 SFC 4bpp CHR 과 BGR555 팔레트로 바꿉니다. 맵과 타이틀은 중복 타일을 합치고 BG 타일맵을 함께 출력합니다. 샘플 맵의 서로 다른 타일은 136개, 타이틀은 892개입니다. 타이틀의 BG 타일맵에는 팔레트 번호도 기록합니다.

```sh
uv run --locked python tools/dq4graphics.py --check
```

검사는 알려진 비트플레인 패턴, 타일·팔레트 왕복, BG 타일맵 재조립, 두 번 생성한 출력의 일치를 확인합니다. 세부 결과는 파일을 출력할 때 `work/dq4-graphics/verification.json` 에 기록합니다. 문서 그림은 `tools/dq4figures.py` 로 다시 만듭니다.

## 남은 것

DQ5 엔진에 넣거나 MesenCE 에서 실행하지는 않았습니다. 16×24 프레임의 OBJ 조합, 프레임·타일 순서, CGRAM 팔레트와 배경색, 압축·포인터·VRAM 배치를 맞춰야 합니다. 샘플 맵에는 통행·출구·이벤트가 없고, 타이틀 글자는 실제 크기에서 추가로 다듬어야 합니다. 일러스트의 게임 내 사용 여부도 남았습니다. 후속 작업은 [남은 일](../../todo.md#dq4)에 기록합니다.
