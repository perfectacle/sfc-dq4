# 2026-10-25-06: 필드에서 마을로 들어가기

필드 위 입구 표와 도착 표를 찾았습니다. 결과는 [dq4-field-format.md 「필드 → 마을 입구」](../../dq4-field-format.md#필드--마을-입구) 에 있습니다.

## 1. 들어갈 때 쓰는 곳

필드 세이브스테이트에서 오른쪽으로 걸어 바트랜드 성 마을로 들어가며 `$63`·`$64`·`$44`·`$45` 쓰기를 잡으니 `08:$AF13`·`$AF3E`·`$AF44`·`$AF49` 였습니다. 그 앞 `08:$AEE8` 은 `BRK 82 E7` 로 꺼낸 표에서 3바이트 레코드를 읽어 필드 좌표 `$42`·`$43` 과 비교했습니다. 처음에는 `E7` 을 뱅크 1E 로 읽어 엉뚱한 표를 봤는데, `b2` bit3 이 0 이라 뱅크 0E 입니다([BRK 형식](../../dq4-bank-format.md#brk-b1-b2)).

## 2. 실측

```
f00008 fx=A3 fy=2E g=02 k=00 x=FF y=1C
f00024 fx=A4 fy=2E g=02 k=00 x=FF y=1C
f00056 fx=A4 fy=2E g=02 k=00 x=00 y=1D
```

입구 `02 A4 2E`, 도착 `02 00 00 1D 01`(순번 0, (00,1D)) 그대로였습니다.

## 틀렸던 것들

- `BRK 82 E7` 의 뱅크를 1E 로 읽었습니다. `E7` 의 bit3 은 0 입니다.

## 남은 것

- 이벤트로 바뀌는 그룹(`45`·`18`·`0E`), 마을 가장자리로 나갈 때 필드에 서는 자리.
