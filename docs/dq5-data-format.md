# DQ5(SFC) 게임 데이터 형식

상점 품목과 물건 가격처럼 DQ4 데이터로 바꿔 넣을 표를 정리한 문서입니다. 찾아낸 과정은 일지에 있습니다.

- [2026-10-25-03: 상점과 물건 가격](journal/dq5/2026-10-25-03-shop.md)

기준과 검증:

- 기준 롬: `rom/dq5.sfc`([README](../README.md) 의 SHA-1). 주소 표기는 [dq5-map-format.md](dq5-map-format.md) 와 같습니다.
- 구현: [tools/dq5shop.py](../tools/dq5shop.py). 물건 이름은 [이름 문자열](dq5-text-format.md#이름-문자열-21955d) 5번 표입니다.
- 선실에서 무기점 처리기의 키를 바꿔 그룹 `00`·`01`·`21` 무기점 목록을 띄우니 품목과 가격 17개가 모두 표와 같았습니다.

## 가게 종류 (`06:DBD2`)

인물 대화 번호 `000`~`010` 은 `06:DBDB` 점프 표의 처리기로 갑니다([dq5-text-format.md 「대화」](dq5-text-format.md#대화-06af62)).
선실의 파파스 슬롯에 대화 번호를 넣고 말을 걸어 첫 메시지를 보았습니다.

| 대화 번호 | 가게 | 첫 메시지 | 목록 종류(`7E:0F20`) |
| --- | --- | --- | --- |
| `01` | 무기점 | 002「ここは　武器の店だ。」 | 2 |
| `02` | 도구점 | 000「ここは　道具屋。」 | 0 |
| `03` | 방어구점 | 001「ここは　防具屋でございます。」 | 1 |
| `04` | 맡기는 곳 | 0B9「お金と　持ち物の　預かり所です」 | |
| `05`·`0F` | 교회 | 07E·07F | |
| `06`·`10` | 여관 | 070·077 | |
| `07` | 몬스터 맡기기 | 0E9 | 7 |
| `08` | よろず屋 | 003「ここは　よろず屋だよ。」 | 3 |
| `09` | 작은 메달 | 482 | 4 |
| `0A` | ルイーダの店 | 470 | 0A |
| `0B` | 코인 판매 | 468 | 0B |
| `0C` | 코인 교환 | 461 | 5 |
| `0D` | 슬라임 레이스 | 10D | 0D |
| `0E` | 격투장 | 112 | 0E |

목록 종류 값은 처리기 첫머리의 `LDA #n / STA $0F20` 을 읽은 것입니다(코드 읽기, 무기점 2 는 실측).

## 상점 (`06:F49C`)

```
04:FBD5 + 종류 * 2 = 목록들의 시작(뱅크 04). 종류 0 도구, 1 방어구, 2 무기, 3 よろず屋
목록 = [키][물건 번호 …][FF] 가 이어짐. 06:F534 가 키가 7E:0F25 와 같은 첫 목록을 찾는다
```

- 무기·도구·방어구점의 키는 맵 그룹 `$BC` 입니다(`06:DC37` `LDA $BC / STA $0F25`). よろず屋 는 처리기마다 키를 고정합니다(예 `15`·`16`).
- 같은 키의 목록이 둘 이상이면 `06:F4CB` 가 뒤의 목록을 더 찾습니다. 그룹 `1A`·`01`·`22`·`21` 은 `7E:2190 & 40`(이야기 진행으로 보임),
  `21` 은 그다음 `7E:21A9 & 20`, 그룹 `19` 의 방어구점은 주인공 Y 좌표(`$C2 < 1D`)로 고릅니다(코드 읽기).
- 목록은 종류 0 이 11개, 1 이 15개, 2 가 17개, 3 이 5개이고 `04:FBDD`~`04:FD54` 에 빈틈없이 이어집니다.

## 물건 가격 (`21:A447`)

```
가격 = 23:B081[물건] × 21:A47B[23:B159[물건] & 3]
21:A47B = 1, 10, 100, 1000 (16비트 넷)
```

물건 표는 216개(`23:B081`~`23:B158`)이고, `23:B159` 와 `23:B231` 도 물건마다 1바이트입니다(`23:B231 & 07` 은 `21:A42A` 가 다른 곳에 쓰지만 뜻 미확인).
예: どうのつるぎ(`06`) = 27 × 10 = 270G, チェーンクロス(`1D`) = 12 × 100 = 1200G, やくそう(`A1`) = 8 × 1 = 8G.

## 남은 것

- 물건의 나머지 속성(공격력·수비력·장비 가능 인물). `21:8B00` 이 `21:8D96`·`21:8C86`·`21:8D6A` 표로 필드를 읽는다
- 목록 종류 4(`04:A11A`)·5(`04:A3A2`)의 형식, 여관·교회 값
- `23:B159` 의 위 비트와 `23:B231`
