# DQ4(FC) 필드(세계 지도)

필드 3개의 타일 배치입니다. 디코더는 [tools/dq4field.py](../tools/dq4field.py), 실험 과정은 [2026-10-25-05 일지](journal/dq4/2026-10-25-05-field.md) 에 있습니다. 필드에 있을 때 맵 종류 `$0028` 은 `00` 입니다([dq4-ram-format.md](dq4-ram-format.md#필드-상태)).

## 필드

RAM `$65` 가 필드 번호입니다. 크기는 `0F:$D2D6`(폭)·`$D2D9`(높이)에 있습니다.

| `$65` | 크기 | 내용 |
| --- | --- | --- |
| 0 | 250×250 | 세계 지도 |
| 1 | 61×61 | 모름 |
| 2 | 42×54 | 모름 |

## 좌표 → 타일

`0F:$D244`(뱅크 0B 를 끼우고 `$D259`)가 X·Y 레지스터의 좌표로 타일 번호(0~31)를 돌려줍니다.

1. X−3 이나 Y−3 이 폭·높이 이상이면 0(`$D2AA`). 아니면 원래 좌표 그대로 찾는다.
2. 줄 레코드: `0B:$8000 + 필드 × 2` 의 포인터 + Y × 4. 4바이트 = 줄 데이터 포인터, X=80 이 시작되는 바이트 위치, 줄 끝(X=100) 바이트 위치(`$D2DC`).
3. 줄 데이터는 바이트마다 RLE 입니다(`$D326`). X 가 40~7F 나 C0~FF 이면 다음 기준점(80, 100)에서 거꾸로 읽어 빨리 찾습니다(`$D37E`).

| 바이트 | 뜻 |
| --- | --- |
| 위 3비트 0~6 | 그 타일이 (아래 5비트 + 1)칸 |
| 위 3비트 7, 아래 5비트 0~7 | 타일 7 이 (아래 5비트 + 1)칸 |
| 위 3비트 7, 아래 5비트 8~31 | 타일 (아래 5비트) 한 칸 |

`$D516` 은 필드 0 의 (C2, 2E) 를 이벤트 플래그 `$62A1` bit7 이 켜져 있을 때 타일 2 로 바꿉니다(코드 읽기).

## 확인

- `tools/dq4field.py check`: 필드 0 의 250줄 모두, 앞에서부터 푼 위치가 X=80 기준점·줄 끝 바이트 위치와 표 값이 같음.
- `tools/lua/fc/fieldlookup.lua` 로 필드를 걸을 때 게임이 `$D259` 를 부른 147번의 (X, Y, 결과)를 기록해 `tools/dq4field.py compare` 로 비교: 0 차이.

## 남은 것

- 타일 번호(0~31) → 그래픽·통행·조우 지형.
- 필드 1·2 가 어디인지, 필드 위 마을·성 입구 표(필드 → 맵 연결).
- 필드 조우 표.
