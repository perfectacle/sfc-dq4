## 실험 출발점

준비(워크트리, `$MESENCE`, `$LIBDIR`)는 [analysis 스킬](../.agents/skills/analysis/SKILL.md#준비) 을 따릅니다.

- **세이브스테이트 `work/state/ship.mss`**: 배 선실(맵 17/00), 조작 가능. 사람마다 다시 만들어야 하면 `tools/lua/mkstate.lua` 로 만듭니다. 이 상태로는 필드에서 강제 전투 뒤 조작이 막혀, 필드 실험에는 새 세이브스테이트가 필요합니다.
- **순간이동**: 배의 사다리 출구 항목(CPU `2A:EFF5`, 파일 오프셋 `156FF5`)을 `ROMPATCH` 로 덮어 원하는 맵으로 갑니다. 사다리는 (3,11) → (3,24) → (7,24) 를 거쳐 위로 누르면 밟힙니다.

  ```sh
  STATE=$PWD/work/state/ship.mss PRE="b:4,wait:40" \
    WAYPOINTS="3,11;3,24;7,24;up:10;<새 맵에서의 경유점>" \
    ROMPATCH="156FF5=E40C2C0101" CHANGES=2 AFTER=150 MAXF=2500 \
    SHOT_DIR=$PWD/work/w1 "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/walk.lua"
  ```

  덮는 바이트는 목적지 표 항목 형식입니다([dq5-map-format.md 「출구」](dq5-map-format.md#출구-2af6b8)). `E0`/`E4` 의 bit7 은 「그 맵의 마지막 항목」 표시라 남겨 둡니다. 예: `E0253C0103` → 03/00, `E40C2C0101` → 01/04.
- **조우 끄기**: `ROMPATCH` 에 `11EA44=00…`(조우 계수 표 `23:EA44`)를 더합니다. 효과는 아직 실측하지 않았습니다.
- **전수 검사 틀**: 맵 목록은 그룹 표 `0F:8ED7` 앞의 그룹 포인터 54개 간격으로 구합니다(합계 346). `tools/dq5exit.py` 의 함수(`exit_cells`, `map_exits`)를 그대로 써서 모든 맵을 돌 수 있습니다.

## 다음에 할 일

[todo.md](todo.md) 의 `## dq5` 순서대로 합니다. 순서의 이유는 이렇습니다.

1. **출구 항목이 남는 맵 4개** — 실마리가 가장 뜨겁고 작습니다.
   - 확인한 것: 01/05·04/05·06/05 의 남는 항목은 상대 맵이 가리킵니다(01/04 출구 1 → 01/05 출구 2, 04/0C 출구 0 → 04/05 출구 5, 06/04 출구 0 → 06/05 출구 1). 정적 맵에는 그 번호의 출구 셀이 없습니다.
   - 실험 기록: 위 명령으로 01/04 에 가면 (7,42) 에 섭니다(패치 좌표 x=12, y=44 와 다름 — 종류 `60` 좌표 변환도 확인할 것). (7,46) → (12,46) → (12,47) 로 걸어 아래로 30프레임 눌렀는데 맵이 바뀌지 않고 y=50 까지 내려갔습니다. 01/04 의 출구 셀은 (5,7), (13,47) 입니다.
   - 다음 단계: (13,47) 셀의 `+1` 층 값과 출구 판정 루틴(`2A:FC16`)이 그 칸에서 실행되는지 `cover.lua` 로 봅니다. 출구 셀이 이벤트로 생기는 것이라면 맵을 바꾸는 스크립트를 찾아야 하고, 이것이 이벤트 스크립트 분석의 입구가 됩니다.
2. **인물 대화 번호 → 대사, 텍스트 형식** — DQ4 대사를 넣으려면 가장 먼저 필요합니다. 텍스트 부호는 [「ドラクエ命」 SFC 版ドラクエ 5](https://showa-yojyo.github.io/dqbook/dq5.html) 에 허프만 부호 설명이 있으니 주소 힌트로 쓰고, 롬에서 다시 확인합니다. 인물 엔트리의 대화 번호는 [dq5-map-format.md 「인물」](dq5-map-format.md#인물-128000) 에 있습니다.
3. **보물상자** — 맵마다의 상자 목록과 열림 플래그.
4. **인물의 인라인 스크립트·이동 값, 숨은 인물 목록 9개** — 이벤트 스크립트 형식으로 이어집니다.
5. **필드**: 조작 가능한 필드 세이브스테이트를 만든 뒤 마을 입장 실측, 바다 위 입구, 필드 영역 이동(`01:94B4`, `01:9635`), 다른 필드(`$BC` = `$50`~`$54`), 조우 패치 효과.
6. **나머지**: 맵 머리 `+0` bit3-5(`$1A33`), 셀 `+1` bit4-6, 필드 팔레트 4번 줄.

## 조심할 것

- [analysis 스킬의 「자주 밟는 함정」](../.agents/skills/analysis/SKILL.md#참고--자주-밟는-함정) 을 먼저 읽습니다. 특히 macOS 의 `timeout` 부재, zsh 단어 분리, `SHOT_DIR` 절대 경로.
- `walk.lua` 는 맵이 바뀐 직후 다음 경유점으로 넘어갑니다. 출구를 밟는 경유점이 출구 칸 바로 앞에서 끝나면(예: 사다리 (7,22) 대신 (7,23) 에서 바뀜) 그 경유점이 새 맵에 남아 엉뚱하게 걷습니다. 출구를 밟는 마지막 동작은 `up:10` 처럼 방향:프레임으로 씁니다.
- `tools/lua/` 와 `tools/figures.py` 는 dq4 트랙과 함께 씁니다([TRACK-02](../.agents/skills/tracks/SKILL.md#track-02--공유-파일)).
