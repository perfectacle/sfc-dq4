## 실험 출발점

준비(워크트리, `$MESENCE`, `$LIBDIR`)는 [analysis 스킬](../.agents/skills/analysis/SKILL.md#준비) 을 따릅니다.

- **세이브스테이트 `work/state/ship.mss`**: 배 선실(맵 17/00), 조작 가능. 사람마다 다시 만들어야 하면 `tools/lua/mkstate.lua` 로 만듭니다. 필드·다른 맵·전투 장면은 아래 「[장면 이동 도구](#장면-이동-도구)」(`tools/lua/dq5warp.lua`)로 이 상태에서 만듭니다.
- **순간이동**: 배의 사다리 출구 항목(CPU `2A:EFF5`, 파일 오프셋 `156FF5`)을 `ROMPATCH` 로 덮어 원하는 맵으로 갑니다. 사다리는 (3,11) → (3,24) → (7,24) 를 거쳐 위로 누르면 밟힙니다.

  ```sh
  STATE=$PWD/work/state/ship.mss PRE="b:4,wait:40" \
    WAYPOINTS="3,11;3,24;7,24;up:10;<새 맵에서의 경유점>" \
    ROMPATCH="156FF5=E40C2C0101" CHANGES=2 AFTER=150 MAXF=2500 \
    SHOT_DIR=$PWD/work/w1 "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/walk.lua"
  ```

  덮는 바이트는 목적지 표 종류 `60` 항목 `[E0|BD][X][Y][방향][BC]` 입니다([dq5-map-format.md 「출구」](dq5-map-format.md#출구-2af6b8)). bit7 은 「그 맵의 마지막 항목」 표시라 남겨 둡니다. 적힌 (X, Y) 에 그대로 섭니다. 예: `E0253C0103` → 03/00, `E40C2C0101` → 01/04 (12,44).
  `LIBDIR` 는 툴킷 Lua 폴더(`$(uv run --locked krpatch sfc lua)`)입니다. 다른 프로브와 함께 쓰려면 `tools/lua/seqlib.sh` 로 만든 폴더를 줍니다.
- **조우 끄기**: `ROMPATCH` 에 `11EA44=0000000000000000`(조우 계수 표 `23:EA44`)를 더합니다. 실내에서 320걸음 동안 조우가 없음을 확인했습니다.
- **무작위 전투 붙이기**: 사다리 출구를 `E2322B0121`(21/02 (50,43))로 덮고 `70,43;46,43` 을 왕복하면 수백 프레임 안에 전투가 붙습니다. `PRE` 의 `wait` 값을 바꾸면 다른 무리가 나옵니다. 무리를 고정하려면 구역 레코드(`23:96F3 + n*22`, 파일 오프셋 `1196F3 + n*22`)의 무게를 고칩니다([일지 2026-10-25-06](journal/dq5/2026-10-25-06-encounter.md)).
- **전수 검사 틀**: 맵 목록은 그룹 표 `0F:8ED7` 앞의 그룹 포인터 54개 간격으로 구합니다(합계 346). `tools/dq5exit.py` 의 함수(`map_exit_cells`, `map_exits`)를 그대로 써서 모든 맵을 돌 수 있습니다.
- **맵마다 게임 셀 버퍼 덤프**: 위 순간이동에 `atpc.lua` 를 끼워 `AT=15F7EE`(맵별 루틴이 끝난 직후) `FROM=300` 으로 덤프하면 맵을 푼 뒤의 최종 셀 버퍼(`7E:C000-`)를 얻습니다. 맵마다 1초쯤이라 346개를 8개씩 병렬로 돌리면 1분 반입니다(명령은 [일지 2026-10-24-12](journal/dq5/2026-10-24-12-exit-hook.md#5-표-전체를-훑고-346개-맵을-모두-확인)).
- **맵을 옮기면 `7E:219F`·`7E:21A0` 이 지워집니다**(`00:A8CC`). 이 두 바이트를 `POKE` 로 고정해도 맵별 루틴은 0 을 봅니다. 켠 채로 보려면 `ROMPATCH` 에 `28D2=EAEAEAEA` 를 더합니다.

## 장면 이동 도구

`tools/lua/dq5warp.lua` 는 위 사다리 순간이동을 감싼 드라이버입니다. 사다리를 밟아 게임의 맵 불러오기를 그대로 타므로 맵별 루틴·인물 목록이 정상으로 돕니다.
도착하고 `SETTLE`(기본 150) 프레임 뒤 `SHOT_DIR` 에 세이브스테이트(`SAVE`)와 그림을 저장합니다. 저장한 세이브스테이트는 `ROMPATCH` 없이 원래 롬으로 불러 쓰면 됩니다(덮은 롬 바이트는 세이브스테이트에 들어가지 않고, 바꾼 플래그는 WRAM 에 남습니다).
만든 세이브스테이트를 다른 세션과 함께 쓰려면 원래 체크아웃의 `work/state/` 에 새 이름으로 둡니다. `work/state/field-free.mss` 가 아래 (a) 명령으로 만든 필드 (341,56) 입니다(없으면 같은 명령으로 다시 만듭니다).

```sh
export LIBDIR=$(uv run --locked krpatch sfc lua)
# (a) 조작 가능한 필드: 필드 좌표($B6,$B8) (341,56). 걷기·마을 들어가기·무작위 조우 모두 됨
STATE=$PWD/work/state/ship.mss FIELD=341,56 SAVE=field-free.mss TEST="left:40,up:40" \
  SHOT_DIR=$PWD/work/warp "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/dq5warp.lua"
# (b) 아무 실내 맵: TO=$BC/$BD(16진),셀X,셀Y(10진)[,방향]. SET 은 시작할 때 한 번 WRAM 을 고침(= 값, | OR, & AND)
STATE=… TO=04/00,27,75 SET="2194|80" SAVE=0400.mss …
# (c) 전투: 첫 필드 이벤트 전투(23:D757 의 1번)의 무리를 몬스터:마릿수(16진:10진, 최대 4종)로 바꿈
STATE=… FIELD=341,56 BATTLE="0C:2,00:1" SETTLE=300 SAVE=battle.mss …
```

- 결과는 `warp.txt`(도착 맵, 셀 또는 필드 좌표, `$BE`, `7E:2190`~`21AF`)와 `end.png`. `TEST` 입력으로 좌표가 바뀌면 `moved=yes` 입니다.
- `FIELD` 는 01/00 (32,92) 로 간 뒤 아래로 걸어 나갑니다. 이때 쓰는 입구 표 `04:FD97` 의 그룹 01 항목(파일 오프셋 `27DC9`)을 그 좌표로 덮고, 첫 필드 이벤트를 끄려고 `7E:2194` bit7 을 켭니다.
  만든 세이브스테이트를 원래 롬으로 걸으면 그룹 01 입구는 원래 자리 (331,67) 입니다.
- 필드에서 조작이 막히던 까닭: `7E:2194` bit7 이 꺼져 있으면 필드 루틴(`15:F907` 의 `FE` 항목)이 `02:A94C` 를 골라 파파스와 슬라임 전투 이벤트(`02:A775` → `01:86A7`, 무리 1번)를 돌립니다. 이 bit 를 켜면 이벤트 없이 바로 조작됩니다([일지](journal/dq5/2026-10-25-08-warp.md)).
- 시대(`$1949`)가 다른 그룹(`0F:EA97` 첫 바이트 bit5-6 이 `40` 인 곳)에 들어가려면 `SET="1949=01"` 처럼 바꿉니다. 시대를 바꾼 장면은 아직 실측하지 않았습니다.
- 01/04 처럼 어두운 맵은 도착 화면이 검게 나옵니다(조작은 됨).

## 다음에 할 일

[todo.md](todo.md) 의 `## dq5` 순서대로 합니다. 순서의 이유는 이렇습니다.

1. **주문·몬스터 표** — 이름은 이름 문자열 3·4번 표입니다. 지금까지 확인한 것:
   - 몬스터: [dq5-data-format.md 「몬스터」](dq5-data-format.md#몬스터-238000) 에 HP·경험치·금화가 있습니다. 남은 필드는 같은 방법(레코드 바이트를 `ROMPATCH` 로 바꿔 전투 비교)으로 봅니다. 전투 메시지 번호는 `CALLS=248C39` 의 A 입니다.
   - 전투 재현: `STATE=…/ship.mss PRE="b:4,wait:40,b:4,wait:40" ROMPATCH="156FF5=E0253C0103" WAYPOINTS="3,11;3,24;7,24;7,22;37,66;37,72;down:90" CHANGES=2 AFTER=400 MAXF=2500` 이면 2,500프레임에 슬라임 셋과의 전투 명령 창이 뜹니다(이벤트 전투).
2. **전투** — 몬스터 그림은 [dq5-graphics-format.md](dq5-graphics-format.md)(아무 몬스터와 싸우기: 위 전투 재현에 `POKE="7E1001=<번호>;7E1005=1"`, 덤프는 `tools/lua/battledump.lua`). 남은 것은 전투 모드 메시지(`24:8C39`, 색인 `24:AECD`, 디코더 `24:9E47`). 조우 표는 [dq5-data-format.md 「전투 조우」](dq5-data-format.md#전투-조우-23e7c2). 남은 것은 필드 실측(조작 가능한 필드 세이브스테이트를 먼저 만들어야 함)과 todo 의 「조우의 남은 것」.
3. **인물의 인라인 스크립트·이동 값, 숨은 인물 목록 9개** — 대화 스크립트와 같은 바이트코드인지 확인합니다.
4. **맵별 루틴의 남은 것**, **필드**(마을 입장 실측, 필드 영역 이동, 다른 필드), **나머지**(맵 머리 `+0` bit3-5, 셀 `+1` bit4-6, 필드 팔레트), **텍스트의 남은 것**(`1100` 번대, `BRK 88`·`89`·`8B` 조회와 조건 `03`·`11`·`13`·`20`, 창 레코드 머리).

조사 실험 요령: 앞 칸을 보려면 몸을 돌리는 입력을 `right:8` 처럼 길게 주고, 명령 창은 `a:8;wait:60;down:6;wait:25;down:6;wait:25;down:6;wait:25;right:6;wait:25;a:8`(しらべる)로 엽니다.
상자 내용물을 바꿔 보려면 `ROMPATCH` 에 `F6E4E + 번호*2` 오프셋을 파일 바이트 순서로 줍니다.

대화 실험 요령: 선실 세이브스테이트에서 위를 보고 A 두 번(`PRE="b:4,wait:40,up:3,wait:20,a:4,wait:30,a:4,wait:150"`)이면 파파스(슬롯 `0B`)와 대화합니다.
`POKE="7E36EB=<하위>;7E370B=<상위>"` 로 대화 번호를 바꾸면 아무 스크립트·메시지나 띄울 수 있습니다. 메시지 번호는 `CALLS=248BAF` 의 A 값입니다.
아무 메시지나 띄우려면 파파스 스크립트의 메시지 `41 2D`(파일 오프셋 `30139`)를 `ROMPATCH="30139=6xyy"` 로 덮습니다(메시지 `xyy`). 조건 코드는 `ROMPATCH="3012D=07<조건>616B0B61293F"` 로 시험합니다(참 `16B`, 거짓 `129`). 여러 쪽은 `tools/lua/shots.lua` 로 찍습니다.

## 조심할 것

- [analysis 스킬의 「자주 밟는 함정」](../.agents/skills/analysis/SKILL.md#참고--자주-밟는-함정) 을 먼저 읽습니다. 특히 macOS 의 `timeout` 부재, zsh 단어 분리, `SHOT_DIR` 절대 경로.
- `walk.lua` 는 맵이 바뀐 직후 다음 경유점으로 넘어갑니다. 출구를 밟는 경유점이 출구 칸 바로 앞에서 끝나면(예: 사다리 (7,22) 대신 (7,23) 에서 바뀜) 그 경유점이 새 맵에 남아 엉뚱하게 걷습니다. 출구를 밟는 마지막 동작은 `up:10` 처럼 방향:프레임으로 씁니다.
- `tools/lua/` 는 dq4 트랙과 함께 씁니다. 그림은 dq5 몫인 `tools/dq5figures.py` 에 더합니다([TRACK-02](../.agents/skills/tracks/SKILL.md#track-02--공유-파일)).
