## 실험 출발점

준비(워크트리, `$MESENCE`, `$LIBDIR`)는 [analysis 스킬](../.agents/skills/analysis/SKILL.md#준비) 을 따릅니다.

- **세이브스테이트 `work/state/ship.mss`**: 배 선실(맵 17/00), 조작 가능. 사람마다 다시 만들어야 하면 `tools/lua/mkstate.lua` 로 만듭니다. 이 상태로는 필드에서 강제 전투 뒤 조작이 막혀, 필드 실험에는 새 세이브스테이트가 필요합니다.
- **순간이동**: 배의 사다리 출구 항목(CPU `2A:EFF5`, 파일 오프셋 `156FF5`)을 `ROMPATCH` 로 덮어 원하는 맵으로 갑니다. 사다리는 (3,11) → (3,24) → (7,24) 를 거쳐 위로 누르면 밟힙니다.

  ```sh
  STATE=$PWD/work/state/ship.mss PRE="b:4,wait:40" \
    WAYPOINTS="3,11;3,24;7,24;up:10;<새 맵에서의 경유점>" \
    ROMPATCH="156FF5=E40C2C0101" CHANGES=2 AFTER=150 MAXF=2500 \
    SHOT_DIR=$PWD/work/w1 "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/walk.lua"
  ```

  덮는 바이트는 목적지 표 종류 `60` 항목 `[E0|BD][X][Y][방향][BC]` 입니다([dq5-map-format.md 「출구」](dq5-map-format.md#출구-2af6b8)). bit7 은 「그 맵의 마지막 항목」 표시라 남겨 둡니다. 적힌 (X, Y) 에 그대로 섭니다. 예: `E0253C0103` → 03/00, `E40C2C0101` → 01/04 (12,44).
  `LIBDIR` 는 툴킷 Lua 폴더(`$(uv run --locked krpatch sfc lua)`)입니다. 다른 프로브와 함께 쓰려면 `tools/lua/seqlib.sh` 로 만든 폴더를 줍니다.
- **조우 끄기**: `ROMPATCH` 에 `11EA44=00…`(조우 계수 표 `23:EA44`)를 더합니다. 효과는 아직 실측하지 않았습니다.
- **전수 검사 틀**: 맵 목록은 그룹 표 `0F:8ED7` 앞의 그룹 포인터 54개 간격으로 구합니다(합계 346). `tools/dq5exit.py` 의 함수(`map_exit_cells`, `map_exits`)를 그대로 써서 모든 맵을 돌 수 있습니다.
- **맵마다 게임 셀 버퍼 덤프**: 위 순간이동에 `atpc.lua` 를 끼워 `AT=15F7EE`(맵별 루틴이 끝난 직후) `FROM=300` 으로 덤프하면 맵을 푼 뒤의 최종 셀 버퍼(`7E:C000-`)를 얻습니다. 맵마다 1초쯤이라 346개를 8개씩 병렬로 돌리면 1분 반입니다(명령은 [일지 2026-10-24-12](journal/dq5/2026-10-24-12-exit-hook.md#5-표-전체를-훑고-346개-맵을-모두-확인)).
- **맵을 옮기면 `7E:219F`·`7E:21A0` 이 지워집니다**(`00:A8CC`). 이 두 바이트를 `POKE` 로 고정해도 맵별 루틴은 0 을 봅니다. 켠 채로 보려면 `ROMPATCH` 에 `28D2=EAEAEAEA` 를 더합니다.

## 다음에 할 일

[todo.md](todo.md) 의 `## dq5` 순서대로 합니다. 순서의 이유는 이렇습니다.

1. **주문·몬스터 표** — 이름은 이름 문자열 3·4번 표입니다. 물건 표처럼 같은 크기 표가 나란히 있을 가능성이 크니, 알려진 값(예 スライム HP)으로 간격 검색을 해 봅니다. `21:8B00` 필드 읽기의 `21:8D6A` 기준 목록에 `23:8000`(크기 25)·`23:AED1`(크기 9) 같은 표가 있습니다.
2. **전투** — 조우 표, 몬스터 그림, 전투 모드 메시지(`24:8C39`, 색인 `24:AECD`, 디코더 `24:9E47`).
3. **인물의 인라인 스크립트·이동 값, 숨은 인물 목록 9개** — 대화 스크립트와 같은 바이트코드인지 확인합니다.
4. **맵별 루틴의 남은 것**, **필드**(마을 입장 실측, 필드 영역 이동, 다른 필드), **나머지**(맵 머리 `+0` bit3-5, 셀 `+1` bit4-6, 필드 팔레트), **텍스트의 남은 것**(제어 코드, 조건 코드).

조사 실험 요령: 앞 칸을 보려면 몸을 돌리는 입력을 `right:8` 처럼 길게 주고, 명령 창은 `a:8;wait:60;down:6;wait:25;down:6;wait:25;down:6;wait:25;right:6;wait:25;a:8`(しらべる)로 엽니다.
상자 내용물을 바꿔 보려면 `ROMPATCH` 에 `F6E4E + 번호*2` 오프셋을 파일 바이트 순서로 줍니다.

대화 실험 요령: 선실 세이브스테이트에서 위를 보고 A 두 번(`PRE="b:4,wait:40,up:3,wait:20,a:4,wait:30,a:4,wait:150"`)이면 파파스(슬롯 `0B`)와 대화합니다.
`POKE="7E36EB=<하위>;7E370B=<상위>"` 로 대화 번호를 바꾸면 아무 스크립트·메시지나 띄울 수 있습니다. 메시지 번호는 `CALLS=248BAF` 의 A 값입니다.

## 조심할 것

- [analysis 스킬의 「자주 밟는 함정」](../.agents/skills/analysis/SKILL.md#참고--자주-밟는-함정) 을 먼저 읽습니다. 특히 macOS 의 `timeout` 부재, zsh 단어 분리, `SHOT_DIR` 절대 경로.
- `walk.lua` 는 맵이 바뀐 직후 다음 경유점으로 넘어갑니다. 출구를 밟는 경유점이 출구 칸 바로 앞에서 끝나면(예: 사다리 (7,22) 대신 (7,23) 에서 바뀜) 그 경유점이 새 맵에 남아 엉뚱하게 걷습니다. 출구를 밟는 마지막 동작은 `up:10` 처럼 방향:프레임으로 씁니다.
- `tools/lua/` 는 dq4 트랙과 함께 씁니다. 그림은 dq5 몫인 `tools/dq5figures.py` 에 더합니다([TRACK-02](../.agents/skills/tracks/SKILL.md#track-02--공유-파일)).
