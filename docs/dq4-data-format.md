# DQ4(FC) 이름·아이템·몬스터 표

메뉴와 전투에 나오는 이름 목록, 아이템 수치, 몬스터 능력치 표입니다. 디코더는 [tools/dq4data.py](../tools/dq4data.py), 실험 과정은 [2026-10-25-04 일지](journal/dq4/2026-10-25-04-data.md) 에 있습니다. 글자 바이트는 [dq4-text-format.md](dq4-text-format.md#글자-바이트) 와 같습니다.

## 이름 목록

`0B:$B006` 에 목록 포인터 8개가 있습니다. 이름은 길이 바이트 + 글자 바이트이고, 목록은 다음 목록이 시작하는 곳에서 끝납니다. 각 목록의 0번은 빈 이름이라 **ID = 목록 순번 − 1** 입니다(아이템·몬스터 표가 이 ID 로 찾아짐).

| 순서 | 포인터 | 목록 | 개수 |
| --- | --- | --- | --- |
| 0 | `$B016` | 주문(メラ …) | 60 |
| 1 | `$B171` | 직업(ゆうしゃ, しんかん …) | 16 |
| 2 | `$B1E3` | 성별 | 2 |
| 3 | `$B1ED` | 아이템(무기·갑옷·방패·투구·도구) | 127 |
| 4 | `$B747` | 몬스터 | 195 |
| 5 | `$B634` | 장소(ルーラ 목적지로 보임) | 28 |
| 6 | `$B704` | 작전(みんながんばれ …) | 6 |
| 7 | `$B747` | 몬스터(4 와 같은 포인터) | |

## 아이템

뱅크 `10` 의 표들을 아이템 ID 로 찾습니다(`10:$8BAE`~`$8C9B` 의 함수들, 코드 읽기).

| 표 | 내용 |
| --- | --- |
| `$9E17` | 강도 1바이트. 무기는 공격력, 갑옷·방패·투구는 수비력으로 보임(ひのきのぼう 2, こんぼう 7, どうのつるぎ 12, ぬののふく 4, かわのたて 4 …) |
| `$8E19` | bit6-0 가격의 앞자리, bit7 플래그(뜻은 모름) |
| `$8D1B` | bit1-0 가격의 자릿수. 가격 = (`$8E19` & 7F) × 10^(`$8D1B` & 3)(`10:$8BED`). 위 비트는 다른 플래그 |
| `$8D9A` | bit7·bit6 플래그, bit5-0 값(뜻은 모름) |

예: ひのきのぼう 10G, こんぼう 30G, どうのつるぎ 100G, てつのつめ 1500G, くさりがま 550G.

## 몬스터

`18:$8046` 부터 22바이트씩, 몬스터 ID 순입니다.

| 바이트 | 내용 | 근거 |
| --- | --- | --- |
| 0-1 | 경험치(16비트) | 전투 두 번: おおみみず 둘 6, スライム+おおみみず 4 |
| 2-3 | 모름 | |
| 4 | 최대 HP. 전투에서는 이 값 이하로 정해짐 | 전투 RAM 의 몬스터 HP(`$727E`·`$728E`): おおみみず 11·9, スライム 8 |
| 5, 6 | 모름(공격력·수비력으로 보임) | |
| 7 | 골드 | 전투 두 번: おおみみず 둘 12, スライム+おおみみず 8(바이트 6 이면 11) |
| 8-21 | 모름(내성·행동 등) | |

예: スライム 경험치 1, HP 8, 골드 2. おおみみず 경험치 3, HP 11, 골드 6.

## 확인

- `tools/dq4state.sh` 가 만드는 전투 상태(`work/state/dq4-ch1-battle.mss`, スライム·おおみみず)와 그 전에 만난 おおみみず 둘 전투에서 이겨 RAM 의 골드(`$6157`)·경험치(`$60C5`) 변화를 읽음.
- 같은 전투의 몬스터 HP 를 RAM 에서 찾아(첫 타격 7 데미지로 9→2 가 된 바이트) 레코드 바이트 4 와 비교.

## 남은 것

- 몬스터 레코드 바이트 2-3, 5-6, 8-21. 몬스터 HP 를 정하는 무작위 규칙.
- 아이템 강도·가격을 게임 화면(가게, 장비)으로 확인. `$8D1B`·`$8D9A`·`$8E19` 의 나머지 비트(누가 장비할 수 있는지 등).
- 주문 표(소비 MP, 효과), 직업·레벨별 능력치·경험치 표, 상점 목록, 보물상자.
