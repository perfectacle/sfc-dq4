# NDS 판에서 늘어난 것과 이식 판단

FC 판에 없고 DS 판에 있는 이야기·즐길 거리·편의 기능을 모으고, 롬 확장을 전제로 DQ5(SFC) 엔진에 옮길지 판단합니다. 근거는 대사 파일·이름 표와 PARAM 표입니다([text-format.md](text-format.md), [glossary.md](glossary.md), [param-format.md](param-format.md)). 게임 화면으로 확인하지 않은 것은 「근거」 열에 대사만 적었습니다.

## 목록

「DQ5 엔진 이식 판단」 열은 SFC DQ5 롬을 확장한다는 전제의 판단입니다. DQ5 쪽 사실은 dq5 트랙 문서([dq5-data-format.md](../../../sfc/dq5/docs/dq5-data-format.md) 등)를 따릅니다.

## 이민 마을

맵 이름 `ss0`~`ss5` 가 단계이고 단계마다 바깥 맵이 따로 있습니다(`ss0out` → `ss5out`). `ss0out` 은 「砂漠のバザーは 終了しました」 팻말만 있는 빈터(`b0600`), `ss1`·`ss2` 는 `b0601`, `ss3` 은 `b0602`, `ss4`·`ss5` 는 `b0606` 을 부릅니다. `ss4` 에는 집·여관(`ss4hf*`)·지하(`ss4b*`)가, `ss5` 에는 성·던전(`ss5f*`·`ss5b*`, 대사의 レオン 왕과 魔人の指輪)이 붙습니다. `b0603`~`b0605` 는 스크립트에서 바로 부르는 곳이 없어 같은 단계의 다른 모습으로 보입니다(확인 못 함).

단계별로 맵에 놓인 물건(`param_item_ss*`, 보상으로 볼 수 있는 것):

| 단계 | 물건 |
| --- | --- |
| 1 | うさぎのしっぽ, ちいさなメダル 2 |
| 2 | まもりのたね, ヘアバンド, どくけしそう, ちいさなメダル 2 |
| 3 | いのちのきのみ, ふしぎなきのみ, ちからのたね, まほうのせいすい, キメラのつばさ, 73G, ちいさなメダル 3 |
| 4 | けがわのコート, ほのおのツメ, かしこさのたね, おべんとう, ふしぎなきのみ, うまのふん, 370G, ちいさなメダル 3 |
| 5 | はやぶさのけん, ミラーシールド, きせきのつるぎ, まもりのルビー, ほしふるうでわ, すばやさのたね, ちいさなメダル 5 |

レオン 왕을 구하면 ちいさなメダル 하나를 줍니다(`b0606`). 단계를 올리는 이민자 수는 찾지 못했습니다.

## 판단 기준

- **원작 존중**: FC 판 이야기·밸런스를 바탕으로 두고, DS 추가분은 FC 흐름을 바꾸지 않는 것부터 넣습니다(6장은 5장 엔딩 뒤라 FC 흐름을 건드리지 않음). FC 에 있는 몬스터 능력치·가게 값·경품은 FC 값을 씁니다.
- **롬 확장 전제**: 용량 때문에 빼지는 않습니다. 막는 것은 엔진 기능입니다. 동료 대화·이민 마을처럼 DQ5(SFC)에 없는 장치가 필요한 것은 장치 하나를 만들면 여러 항목이 따라옵니다(동료 대화 장치로 ミネア 점·トルネコ 감정도 처리).
- **SFC 에 없는 하드웨어 기능**(엇갈림 통신, 터치)은 옮기지 않고 게임 안 방식으로 바꿉니다.

## 남은 것

- 동료 대화 조건 가운데 `+00`·`+0C`·`+1C`, 일행 조건, 밤 실측([param-format.md](param-format.md#남은-것)).
- 이민 마을 단계를 올리는 이민자 수, `b0603`~`b0605` 를 쓰는 곳.
- 가게 레코드와 마을의 대응, 아이템 강도·장비 표 위치(새 장비의 수치).
- 6장 이벤트를 스크립트 명령 단위로(지금은 대사 파일을 부르는 맵만).
