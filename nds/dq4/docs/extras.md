# NDS 판에서 늘어난 것과 이식 판단

FC 판에 없고 DS 판에 있는 이야기·즐길 거리·편의 기능을 모으고, 롬 확장을 전제로 DQ5(SFC) 엔진에 옮길지 판단합니다. 근거는 대사 파일·이름 표와 PARAM 표입니다([text-format.md](text-format.md), [glossary.md](glossary.md), [param-format.md](param-format.md)). 게임 화면으로 확인하지 않은 것은 「근거」 열에 대사만 적었습니다.

## 이민 마을

맵 이름 `ss0`~`ss5` 가 단계이고 단계마다 바깥 맵이 따로 있습니다(`ss0out` → `ss5out`). `ss0out` 은 「砂漠のバザーは 終了しました」 팻말만 있는 빈터(`b0600`), `ss1`·`ss2` 는 `b0601`, `ss3` 은 `b0602`, `ss4`·`ss5` 는 `b0606` 을 부릅니다. `ss4` 에는 집·여관(`ss4hf*`)·지하(`ss4b*`)가, `ss5` 에는 성·던전(`ss5f*`·`ss5b*`, 대사의 レオン 왕과 魔人の指輪)이 붙습니다. `b0603`~`b0605` 는 그 번호 범위(MPT0 머리 `+08`~`+0C`)의 값을 롬의 모든 파일(SCRIPT·PARAM·MAP·ARM9·오버레이)에서 4바이트 정렬로 찾아도 우연한 값 몇 개뿐이라, 쓰지 않는 대사로 봅니다. 내용은 `b0606` 과 같은 사람·같은 이야기의 다른 판입니다.

단계별로 맵에 놓인 물건(`param_item_ss*`, 보상으로 볼 수 있는 것):

| 단계 | 물건 |
| --- | --- |
| 1 | うさぎのしっぽ, ちいさなメダル 2 |
| 2 | まもりのたね, ヘアバンド, どくけしそう, ちいさなメダル 2 |
| 3 | いのちのきのみ, ふしぎなきのみ, ちからのたね, まほうのせいすい, キメラのつばさ, 73G, ちいさなメダル 3 |
| 4 | けがわのコート, ほのおのツメ, かしこさのたね, おべんとう, ふしぎなきのみ, うまのふん, 370G, ちいさなメダル 3 |
| 5 | はやぶさのけん, ミラーシールド, きせきのつるぎ, まもりのルビー, ほしふるうでわ, すばやさのたね, ちいさなメダル 5 |

レオン 왕을 구하면 ちいさなメダル 하나를 줍니다(`b0606`).

가게는 ARM9 가게 표 second 31~35(맵 `ss1`~`ss5`)에 단계마다 있습니다. 여관 값은 단계 1 의 0(여관 없음)에서 4·5·10·15G 로 오르고, 단계 4·5 에는 방어구점이 생깁니다(`ndsparam.py shops`).

### 단계 전환

필드 스크립트 `SCRIPT/field.bin` 의 initialize 가 이야기 플래그로 단계 맵을 고르고, 필드 기호(`0x48` 명령의 마지막 인자 `7D`~`7F`)의 행선지를 그 맵으로 씁니다. 같은 자리에서 명령 `0x102` 가 다음 단계 플래그를 켭니다.

| 단계 | 이야기 플래그 | 맵 | 다음 단계로(명령 `0x102` 인자) |
| --- | --- | --- | --- |
| 0 | 481(`0x1E1`) 꺼짐 | `ss0out` | 1·5 → 481 켬 |
| 1 | 481 켜짐 | `ss1out` | 5·9 → 484(`0x1E4`) |
| 2 | 484 | `ss2out` | 9·13 → 490(`0x1EA`) |
| 3 | 490 | `ss3out` | 13·17 → 502(`0x1F6`) |
| 4 | 502 | `ss4out` | 17·25 → 504(`0x1F8`) |
| 5 | 504 | `ss5out` | |

5장 상태에서 이 플래그들을 RAM 에서 켠 뒤 필드로 들어가자, 필드 기호 행선지 문자열(`0x020EAEDA`)이 표대로 `ss0out`~`ss5out` 으로 바뀌었습니다. `0x102` 는 이민 마을 스크립트(`field.bin`·`sshout`·`sshm1f1`·`ss1out`)에서만 쓰이고, 인자 둘이 이어지는 구간(1~5, 5~9 …)이라 「이민자 수가 a 이상 b 미만」으로 보입니다. 그러면 단계는 이민자 1·5·9·13·17명에서 오릅니다. 처리 루틴(ARM9 `0x0202121C` → `0x02024448`, nds-text2 의 `ndsscript.py ops`)은 `0x02037534` 가 돌려주는 `0x020ED358`(u32)를 읽어 「a 이상 b 미만」이면 참을 냅니다. 이 칸이 이민자 수입니다.

실측: 5장 상태에서 단계 k 의 플래그만 켜고 `0x020ED358` 에 수를 쓴 뒤 필드로 들어갔습니다.

| 단계 | 이민자 수 | 다음 단계 플래그 |
| --- | --- | --- |
| 0 | 0 → 1 | 꺼짐 → 481 켜짐 |
| 1 | 4 → 5 | 꺼짐 → 484 켜짐 |
| 2 | 8 → 9 | 꺼짐 → 490 켜짐 |
| 3 | 12 → 13 | 꺼짐 → 502 켜짐 |
| 4 | 16 → 17 | 꺼짐 → 504 켜짐 |

그래서 단계는 이민자 1·5·9·13·17명에서 오릅니다. 같은 번에 맵 이름은 플래그를 켜기 전 값으로 정해지므로, 바뀐 마을은 다음에 필드로 나올 때부터 보입니다. 수가 b 이상이면(예: 단계 0 에서 5명) 그 단계의 조건은 거짓이고, 대신 위 단계의 조건이 맞아 그 플래그가 켜졌습니다.

## 판단 기준

- **원작 존중**: FC 판 이야기·밸런스를 바탕으로 두고, DS 추가분은 FC 흐름을 바꾸지 않는 것부터 넣습니다(6장은 5장 엔딩 뒤라 FC 흐름을 건드리지 않음). FC 에 있는 몬스터 능력치·가게 값·경품은 FC 값을 씁니다.
- **롬 확장 전제**: 용량 때문에 빼지는 않습니다. 막는 것은 엔진 기능입니다. 동료 대화·이민 마을처럼 DQ5(SFC)에 없는 장치가 필요한 것은 장치 하나를 만들면 여러 항목이 따라옵니다(동료 대화 장치로 ミネア 점·トルネコ 감정도 처리).
- **SFC 에 없는 하드웨어 기능**(엇갈림 통신, 터치)은 옮기지 않고 게임 안 방식으로 바꿉니다.
