# NDS DQ4 명칭 대조표

FC 판에서 옮길 이름을 정할 때 보는 표입니다. DS 일본판(`rom/dq4ds.nds`)의 이름 표 8개를 일본어·영어로, 같은 자리를 한글 팬패치(`rom/dq4ds-kr.nds`)로 읽어 나란히 놓았습니다. 「채택」 열은 FC 판 한글 해킹롬에 실제로 넣을 이름이고, 「근거」 열은 그 이름을 고른 까닭입니다. 두 열의 정본은 [adopt.tsv](../tables/adopt.tsv) 이고, 대조표는 그 파일을 옮겨 적기만 합니다. 대조표를 다시 만들어도 채택이 사라지지 않습니다.

- **DS 일본어**: `MESS/ja/b1000000`~`b1007000.mpt` 의 문자열. 줄바꿈 표지 `;` 는 뺐습니다.
- **FC 에 같은 이름**: FC 판 이름 목록(`fc/dq4/tools/dq4data.py names`, dq4 트랙 도구)에 같은 이름이 있으면 「있음」입니다. 히라가나·가타카나 차이는 무시합니다. 「없음」은 DS 에서 새로 생겼거나 표기가 바뀐 이름입니다(예: FC `いかづちのつえ` ↔ DS `いかずちのつえ`). 인물·메뉴·작전·능력치 표는 FC 에 대응 목록이 없어 비웠습니다.
- **DS 영어**: 같은 롬의 `MESS/en`(북미·유럽판 번역).
- **DS 한글 팬패치**: [한글 팬패치 v1.1](../references.md)을 [kr-font.tsv](../tables/kr-font.tsv) 로 읽은 값. 팬패치가 비워 둔 줄은 일본어 그대로 나옵니다.
- 같은 일본어·한글 짝이 여러 번 나오면 첫 번호만 둡니다.
- **채택**·**근거**: [adopt.tsv](../tables/adopt.tsv) 의 (표, 번호) 줄. 그 줄의 일본어가 롬과 다르면 채택을 비우고 근거에 그렇다고 적습니다.

다시 만들기:

```sh
uv run --locked python nds/dq4/tools/ndstext.py glossary work/nds/jp work/nds/kr rom/dq4.nes > nds/dq4/docs/glossary-table.md
```

## 채택 원칙

아래 순서로 적용합니다. 앞 순위에서 정해지면 뒤는 보지 않습니다.

1. **정발 한글판 용어**: 공식 한국어판 드래곤 퀘스트에 같은 일본어 이름의 번역이 있으면 그것을 씁니다. DQ4 는 한국어판이 없으므로 다른 작품에서 찾았습니다. 작품마다 다르면 가장 최근에 나온 작품을 따르고, 나머지 표기는 [kr-official.tsv](../tables/kr-official.tsv) 에 남깁니다. 근거 값은 `정발:<작품>`.
2. **FC 이름**: DS 에서 이름이 바뀐 줄(「FC 에 같은 이름」이 「없음」이고 [param-format.md](param-format.md#fc-와-대조) 에서 같은 가게 칸·같은 값으로 짝지어진 줄)은 FC 이름을 옮깁니다. 근거 값은 `FC:<FC 이름>`.
3. **DS 한글 팬패치**: 그 밖에는 팬패치 표기를 씁니다(`팬패치`). 오역·오타·같은 이름 다른 표기, 정발 용어와 어긋나는 합성어는 고치고 `팬패치 수정:<이유>` 로 적습니다.
4. 원칙으로 정할 수 없던 51줄은 사용자가 정했습니다(아래 「사용자 결정(2026-10-26)」). 근거 값은 `사용자 결정`, 낮은 신뢰 정발 표기를 고른 줄은 `정발(낮은 신뢰):<작품>`, FC 이름을 따른 줄은 `FC:<FC 이름>` 입니다.

정발 출처로는 공식 사이트(스퀘어 에닉스 아시아 한국어 뉴스포털, PlayStation·Steam 한국어 페이지), 스퀘어 에닉스·SIEK 보도자료 전문을 실은 기사, 한국어판 리뷰 기사만 셉니다. 공략 사이트·개인 블로그·사용자 글에서만 본 표기는 [kr-official.tsv](../tables/kr-official.tsv) 비고에 「낮은 신뢰」로 남기고 `정발` 근거로는 쓰지 않았습니다. 그 표기가 팬패치와 뜻이나 소리가 다른 줄은 사용자 결정에 따라 대부분 그 표기(`정발(낮은 신뢰)`)로 바꿨고, 띄어쓰기만 다르면 팬패치를 그대로 두었습니다. 나무위키는 본문을 읽지 못해 출처로 쓰지 않았습니다.

## 눈여겨볼 것

- **인물**: 팬패치는 `トルネコ` 를 「톨네코」, `マーニャ` 를 「마냐」, `ライアン` 을 「라이안」으로 옮겼습니다. 이름 표 맨 앞 `ソロ`(DS 의 기본 남자 주인공 이름)와 `ソフィア`(여자)는 FC 에 없는 DS 설정입니다.
- **같은 인물, 다른 표기**: 팬패치 안에서도 이름 표는 `フレア` 를 「프레아」, 동료 대화는 「플레어」로 적습니다. 대조표는 이름 표 기준이고, 사용자 결정으로 「프레아」를 씁니다.
- **지명**: 같은 일본어 지명이 표에 여러 번 나옵니다(장마다 다른 번호). 팬패치는 `レイクナバ` 를 「레이크바나」로 적었고, 채택은 「레이크나바」로 고쳤습니다.
- **장 제목**: 이름 표에는 서장~5장만 있고 `６章` 은 능력치·직업 표(`b1006000` 808번)에 있습니다.
- **주문·특기**: DS 표는 주문 뒤에 특기·몬스터 행동 이름까지 이어지므로 「없음」이 많습니다. FC 에 없는 주문 이름은 특기·행동 이름입니다.
