# nds 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

NDS DQ4 리메이크와 그 한글 팬패치를 참고 자료로 분석합니다. 시작점은 [handoff.md](handoff.md).

- **채택 이름 정하기**: [glossary.md](docs/glossary.md) 의 「채택」 열. 사용자 확인.
- **그래픽 남은 것**([graphics-format.md](docs/graphics-format.md#남은-것)): DSSA 셀 플래그 `0x4000`·셀 머리 u32·프레임 표 첫 8바이트, 몬스터 동작 칸 7·4 화면 확인과 칸 2·3·12, `LOCN` 의 쓰임(걷기 판정 아님)과 머리 수 넷·격자, gotmap·yamimap·기호 변형·3D 효과를 게임 화면과 견주기.
- **사운드 남은 것**([sound-format.md](docs/sound-format.md#남은-것)): 합성과 실기 소리 대조(desmume 녹음이 뭉개짐), 쓰는 곳 못 찾은 곡(4, 장 끝 6·8·10·13, ME 몇 개)과 승리 팡파르 유무, 5·6장 선두 인물별 필드 곡, 고정 전투 ↔ 보스 이름, 효과음 대부분의 장면, `.mini2sf`.
- **늘어난 내용 나머지**([param-format.md](docs/param-format.md#남은-것)): `0x020B91C8`·직전 대화 값·최근 이벤트 값을 쓰는 쪽, `FMAP` 에 짝이 없는 얻는 물건 종류(`2C` 등)와 `+15` 플래그, 몬스터 내성 값 1·2 의 효과와 `+28`~`+2E`·`+36`~`+3B`, 가게 first 18 의 쓰임.
- **스크립트 남은 것**([script-format.md](docs/script-format.md#남은-것)): 이름 없는 명령 240여 가지(전투 안 시험 안 함), `0x07` 이 켜는 인물 그룹과 `script` 열 칸, 상태 비트 `0x02`, 깃발 종류 1·2 를 나눠 쓰는 기준, `0x98` 인자 중 반응 없던 것.
- **디버그 남은 것**([debug.md](docs/debug.md#남은-것)): 혼란·주문 봉인·환혹의 상태 번호, 상태 `0x0B`·`0x15`·`0x1A`·`0x1E` 를 거는 주문·특기.
- **대사 나머지**([text-format.md](docs/text-format.md#남은-것)): 마을 대화에서 `@c` 소리가 바뀌지 않는 까닭과 창 `+0x9E0` → `0x02084268` 경로, 유럽어 `%a` 꼴, 「떠난 주민 찾기」 화면의 撒·燕.
- **롬 구조 나머지**([rom-map.md](docs/rom-map.md#남은-것)): `PARAM` 나머지 파일 형식.
