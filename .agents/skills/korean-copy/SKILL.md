# 한국어 문구

이 스킬이 COPY-01 의 정본이다. 대상은 `README.md`, `docs/`, `tools/README.md` 다. 에이전트 문서(`AGENTS.md`, `.agents/`)와 코드 주석은 한다체로 짧게 쓴다.

## 규칙

- **어조**: 사용자 문서는 합니다체. 한 문서 안에서 섞지 않는다. 형식 문서의 표·목록 칸은 명사형으로 끝내도 된다.
- **번역투를 피한다**.

  | 피할 것                         | 쓸 것                       |
  | ------------------------------- | --------------------------- |
  | `X 에 대한 분석을 진행했습니다` | `X 를 분석했습니다`         |
  | `~하는 것이 가능합니다`         | `~할 수 있습니다`           |
  | `성공적으로 ~되었습니다`        | `~했습니다`                 |

- **이름은 하는 일 그대로 짓는다**: 절 제목·도구 이름을 비유로 짓지 않는다. 「영역 이동(트리거)」처럼 하는 일을 쓰고, 원문 용어가 있으면 괄호로 붙인다.
- **추측과 사실을 문장에서 구분한다**: 확인한 것은 「~입니다」, 추측은 「~로 보입니다」 와 근거. [VERIFY-01](../analysis/SKILL.md#verify-01--실측으로-확인)
