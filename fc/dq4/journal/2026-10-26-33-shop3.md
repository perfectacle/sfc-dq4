# 2026-10-26-33: 뱅크 코드가 켜는 비트의 앞 조건, 시간 멈춤의 명령 건너뛰기, 그룹 `FE`

`dq4shop.py hidden` 이 거르는 「뒤 비트가 켜져 있으면 앞 비트도」 관계를 대화 스크립트 4쌍에서 뒤 비트 14개로 늘렸습니다. 뱅크 코드의 `BRK n CB m` 마다 그곳에 닿는 모든 길을 롬만으로 따라가, 길에서 지난 플래그 검사를 모았습니다. 새 관계 넷은 게임 안에서 확인했습니다. 시간 멈춤 중 명령을 건너뛰는 `11:$834F` 는 일행 넷으로 실측했고, 조우·가게 그룹 `FE` 는 정적 검색을 넓혀 쓰이지 않는 곳으로 닫았습니다. 결과는 [dq4-shop-format.md](../docs/dq4-shop-format.md#앞뒤-비트-관계) 와 [dq4-encounter-format.md](../docs/dq4-encounter-format.md#시간-멈춤과-2배) 에 있습니다.

## 1. 길마다 플래그 검사를 들고 가기

[dq4shop.py](../tools/dq4shop.py) 에 `guard_walk` 를 넣었습니다. 진입점에서 시작해 갈래는 양쪽을, 같은 뱅크 `JSR` 은 안까지 따라갑니다. 들고 가는 것은 「아는 비트」 입니다. `BRK n EB m` 이나 `LDA $62xx`·`AND #` 뒤의 `BEQ`·`BNE`, `BIT $62xx` 뒤의 `BMI`·`BPL` 을 지나면 그 갈래 쪽 값이 아는 비트가 됩니다. 이미 아는 비트와 어긋나는 갈래는 버립니다. `BRK n CB m` 에 닿으면 그때 켜져 있다고 아는 비트를 적고, 닿는 길 모두의 교집합을 앞 비트로 씁니다.

진입점은 코드 뱅크의 BRK 일반 호출이 부르는 함수, 1C 이벤트 표, 1D 블록 이벤트 표, 대화 호출 문장이 부르는 뱅크 `15` 루틴으로 875곳입니다. 대화 호출 루틴 25곳은 그 주소를 부르는 문장 모두에 공통인 조건 `1B` 를 들고 시작합니다.

처음 돌렸을 때는 켜는 곳 121곳 가운데 85곳에만 닿았습니다. 길이 끊긴 자리를 모아 보니 바로 앞 BRK 가 `BRK 07 6F` 같은 창 열기였습니다. 뱅크 `16` 함수 `07` 은 스택의 복귀 주소를 `INC $0106,X` 로 하나 늘려 창 번호 바이트를 읽습니다. 함수 머리에서 이 꼴을 찾으니 `01`·`07`·`09`·`29` 넷이 나왔고, 이 바이트를 건너뛰게 하자 104곳에 닿았습니다.

```text
$6288&08 ← $6288&02           15:$9D1A
$628E&04 ← $628E&20           15:$9D25
$6294&40 ← $6292&04 $6292&08 $6292&10   1C:$BA0A
$62A1&10 ← $6292&01 $6292&08  1E:$9582
...
```

## 2. 바뀐 줄

새 관계를 넣고 이어 붙여 닫으니 `hidden` 에서 바뀐 줄은 `0D/01` 인물 3(대화 `0AE`) 하나였습니다.

```text
전  인물 3((13,06) 대화 0AE) 숨김: [$6292&10 켜짐] 또는 [$6294&80 켜짐 & $6294&40 켜짐]
뒤  인물 3((13,06) 대화 0AE) 숨김: [$6292&10 켜짐]
```

근거는 1C 이벤트 `24`(クリフト 회복)입니다. `1C:$BA06` 의 `BRK 17 CB 1C` 가 `$6292` bit4 를 켜고 바로 뒤 `$BA0A` 가 `$6294` bit6 을 켭니다. 5장 시작 상태에서 `0D/01` (11,08)로 워프해 위의 クリフト(대화 `0B0`)에게 말을 걸었습니다. `$6292` 를 `00` 으로 두어도 `10` 으로 두어도 끝에는 `$6292` = `1C`, `$6294` = `C0` 이었습니다. 이 상태로 `0D/01` 에 다시 들어가니 숨은 슬롯이 예측과 같았습니다.

```sh
STATE=$PWD/work/state/dq4-ch5-start.mss SET="6291=08;6292=00;6294=80" DIR=0 SEQ="wait:30,a:4,wait:50,..." \
  TAIL=300 fc/dq4/tools/dq4warp.sh work/shop3/m00 0D/01 11 08 0
uv run python fc/dq4/tools/dq4shop.py rom/dq4.nes hidden 0D 01 --compare work/shop3/h1C
```

```text
0D/01 낮 인물 7명, 맞는 길 1개
덤프 (80,80): [0, 2, 3, 4, 6]  예측 숨김: [0, 2, 3, 4, 6] — 같음
```

## 3. 다른 관계 셋

`1E:$9582` 는 필드로 나올 때 `1E:$9540` 이 `$6292` bit3, bit0 을 차례로 보고 부릅니다. 5장 시작 상태에서 필드 0 (A4,32)로 워프하고 A 로 대사를 넘겼습니다.

```text
$6292=09  msg 04AF ホフマン「とつぜんですが みなさん！  끝 $62A1=10
$6292=08  (대사 없음)                                  끝 $62A1=00
$6292=01  (대사 없음)                                  끝 $62A1=00
```

`15:$9D1A`·`$9D25` 는 뱅크 `15` 함수 `10`(`15:$9CEB`) 안에 있습니다. 이 함수는 맵에서 필드로 나갈 때 `1E:$9311` 이 부르고, 장 `$615A` 가 `02` 면 `$9D14`, `04` 면 `$9D1F` 로 갑니다. 같은 워프로 확인했습니다(3장은 `$615A` = `02` 로 바꿈).

```text
5장 $628E=20 → 24   $628E=00 → 00
3장 $6288=02 → 0A   $6288=00 → 00
```

## 4. 시간 멈춤과 명령

디버그 B 상태(걷는 일행 넷)로 필드에 나와 [guestai.lua](../tools/lua/guestai.lua) 로 スライム 과 싸우며 `$72E5` = `80` 과 `$72E6` 을 프레임마다 썼습니다. 명령 고리는 턴마다 주인공에게서만 `11:$834F` 를 지났습니다. 동료는 처음부터 명령을 받지 않습니다.

```text
$72E6=C0  324 11:834F 96=00 → 8360(SEC)
$72E6=C1  324 11:834F 96=00 → 8362(CLC)
          343~349 11:89E6 → 8A28  96=02 03 04 00
          351 11:89E6 96=01 → msg 004C
```

`$834F` 가 막는 것은 부른 사람이 주인공이 아닐 때의 주인공 명령이고, 다른 동료는 행동 차례의 `11:$89E1` 에서 건너뜁니다.

## 5. 그룹 `FE`

`15:$BEF4` 를 부르는 길을 더 찾았습니다. BRK 를 거치지 않고 `$23`·`$24` 를 써서 `$C38B` 로 부르는 꼴은 롬에 없습니다(`JMP $C38B` 는 BRK 처리기 안뿐, `JSR $C38B` 는 없음, `STA $24` 28곳 중 `17` 을 쓰는 곳 없음). 1절의 뱅크 `15` 진입점 122곳에서 `JSR` 4단까지 따라가도 `$BEF4`~`$BF27` 에 닿지 않았습니다. 쓰이지 않음[정적]으로 닫습니다.

## 틀렸던 것들

- `15:$9D1F` 를 처음에 「`$6293` bit5 를 본다」 로 읽고 `$6293` = `20` 으로 워프해 아무것도 켜지지 않았습니다. `BRK 13 EB 20` 의 `13` 은 `$627B` + `13` = `$628E` 입니다.
- `15:$9CEB` 의 `CMP #$02`·`#$04` 를 2장·4장으로 읽었습니다. `$615A` 는 0 부터 세므로 3장·5장입니다.
- [dq4-story-format.md](../docs/dq4-story-format.md#남은-것) 의 「부르는 곳이 없는 대화 호출 루틴」 `15:$9D14`·`$9D1F`·`$A1C0` 은 앞 루틴에서 갈래로 닿습니다. `$9D14`·`$9D1F` 는 `15:$9CEB` 의 `BEQ`, `$A1C0` 은 대화 `03F` 가 부르는 `15:$A118` 안 `$A180` 의 `BEQ` 입니다. 앞의 둘은 3절에서 켜지는 것을 봤습니다.

## 남은 것

- 진입점에서 닿지 않는 켜는 곳 18곳(`1E:$A399` 장 시작, `1A:$9DC9` 엔딩, `1D:$9D88` 등)과 `STA $62xx` 로 켜는 비트의 앞 조건.
- `15:$A1C0`(`$6288` bit4)은 갈래로 닿는다는 것까지입니다(코드 읽기). 3장 무기 납품 `$628F` = `77` 을 실측하지 않았습니다.
