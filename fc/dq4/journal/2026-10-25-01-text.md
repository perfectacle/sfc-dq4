# 2026-10-25-01: 대사 텍스트

FC DQ4 의 대사가 어떻게 압축돼 있는지 풀고, 롬만 읽어 메시지 2633개를 모두 글자로 뽑는 디코더를 만들었습니다. 결과는 [dq4-text-format.md](../docs/dq4-text-format.md) 에 있습니다.

## 1. 대사를 읽는 코드 찾기

[앞 일지](2026-10-24-02-bankcall.md) 에서 한 번도 실행되지 않은 뱅크 `00`~`07` 을 데이터 후보로 남겼습니다. 이름 입력을 마치고 오프닝 내레이션이 찍히는 120프레임 동안 `probe/reads.lua` 를 돌리니, 그 뱅크를 읽는 명령은 셋뿐이었습니다.

```
pc=3DF9B(DF9B) n=35 range=02D53-02D6C first=5
pc=3DFBC(DFBC) n=9  range=02D54-02D6C first=6
pc=3DFC8(DFC8) n=9  range=02D55-02D6D first=7
```

화면 글자는 100자쯤인데 읽은 곳은 27바이트였습니다. `0F:$DF99` 를 읽으니 바이트를 쪼개 6비트 부호를 꺼내고 있었습니다(3바이트에 4개).

## 2. 메시지 번호

시작 포인터 `$49/$4A` 를 쓰는 곳은 세이브스테이트 전에 있어서, 전원부터 `probe/writes.lua` 를 다시 돌렸습니다. 598프레임에 `16:$8687` 이 `16:$88B0,Y` 표에서 포인터를 꺼냈습니다. 그 앞 `16:$8656` 은 메시지 번호 `X:A` 를 32로 나눠 표를 찾고, 나머지만큼 앞 메시지를 건너뜁니다. 실제로 왕의 대사 두 개를 부를 때 `X:A` 가 `0301`, `0302` 였습니다.

## 3. 글자와 화면

부호를 표(`16:$8765`)로 바꾼 바이트를 내레이션 화면의 nametable 과 나란히 놓으니 그대로 같았습니다. 글자 바이트가 곧 타일 번호였고, CHR `$1000` 의 폰트를 그려 글자를 정했습니다. `3D`(탁점)는 꾸미는 글자 **앞**에 오고, 화면에는 윗줄에 찍힙니다.

```
これは　バトランドという　ちいさな　くにの
おうきゅうせんしの　ものがたり。
```

## 4. 필드의 대사 창

왕좌의 방 대사는 nametable 덤프에 없었습니다. 세이브스테이트를 불러 보면 창도 사라져 있었습니다. 대신 디코더가 낸 줄을 RAM 에서 찾으니 `$06C0` 부터 줄 버퍼가 있었고, 쓰는 코드 `16:$830F` 에서 탁점 행·글자 행 22바이트씩 3줄인 것을 확인했습니다. A 를 한 번씩 누르며 10번 덤프해 비교했습니다.

```
work/nt/p4/end.ram: 창 3줄 모두 메시지 0301 에 순서대로 있음
...
work/nt/p10/end.ram: 창 3줄 모두 메시지 0302 에 순서대로 있음
```

처음엔 0301 이 맞지 않았습니다. 화면 끝에는 `。` 가 있는데 메시지는 `F9`(끝)로 바로 끝났습니다. `16:$805A` 가 끝 앞 글자가 `！？。` 가 아니면 `。` 를 끼워 넣고 있었습니다.

## 5. 전부 뽑기

블록 88개를 모두 풀어, 블록의 32번째 메시지 끝이 다음 블록 시작과 같은지 봤습니다. 87곳 중 81곳이 같았고, 나머지는 32개를 다 채우지 않은 블록이었습니다. 마지막 블록은 `0AE2`(엔딩) 뒤부터 글자가 깨졌는데, 그 끝이 `1B:$BB93` 이고 바로 다음 `1B:$BB94` 가 사전 시작이었습니다. 그래서 `0AE2` 를 마지막으로 정했습니다.

```
uv run python fc/dq4/tools/dq4text.py rom/dq4.nes all   # 메시지 2633개
```

## 틀렸던 것들

- 탁점이 글자 뒤에 붙는다고 보고 찍었더니 「ハ゛トラント゛」 처럼 한 글자씩 밀렸습니다.
- 대사 창은 nametable 에 있다고 보고 필드 장면을 비교했지만, 필드 창은 nametable 덤프에 남지 않았습니다.
- 블록 표 88개가 모두 글이라고 보고 끝까지 풀었더니 마지막 블록 뒷부분은 사전을 읽은 쓰레기였습니다.

## 남은 것

- 제어 바이트 `ED`, `EE`, `F1`, `F4`, `FE`, `FF` 의 뜻과 `F5`~`F8`·`EF` 가 넣는 값.
- 맵·인물·이벤트가 어떤 메시지 번호를 부르는지.
- 메뉴·상점 같은 다른 창의 문구.
