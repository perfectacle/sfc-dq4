# 2026-10-25-61: 창과 블록의 남은 것 — いれかえ, 투기장 배당, 낮밤 막기, 결계 막이, 배 자리

창(일지 55)과 블록·맵(일지 49)에 남겨 둔 세부를 실험으로 닫았습니다. 창 쪽은 상점 품목 `0B`, 대열 자리 `20`, 투기장 배당 그룹 1 `06`·`07` 을 실제 장면에서 띄웠고, 5장 전투 いれかえ 에서 `11:$BC2B` 가 도는 조건(잠든 동료)을 찾았습니다. 블록 쪽은 맵 번호 bit6 과 `$41` bit7, `12:$A728`·`15:$B110` 을 부르는 곳, 결계 막이 `$62A4`, `$7500` 스프라이트, 배 자리 `$6195/$6196`, 성 앞 워프 nametable, `42/01` 갈래를 풀었습니다. 결과는 [dq4-text-format.md](../docs/dq4-text-format.md#장면마다-여는-창), [dq4-bank-format.md](../docs/dq4-bank-format.md#83-이-도는-장면), [dq4-field-format.md](../docs/dq4-field-format.md#필드-3-갈래), [dq4-map-format.md](../docs/dq4-map-format.md), [dq4-block-format.md](../docs/dq4-block-format.md) 에 있습니다.

## 1. 상점 품목 `0B` 와 투기장 배당

`0B` 는 창만 억지로 열면 줄 수가 0 이라 빈칸이었습니다. 이번에는 [warp.lua](../tools/lua/warp.lua) 로 `02/00` 무기점 앞에 서서 말을 걸고 「かう」 까지 눌렀습니다.

```sh
DRIVER=$PWD/fc/dq4/tools/lua/warp.lua MAP=02/00 X=0D Y=18 DIR=0 \
  SEQ="wait:30,a:6,wait:30,a:6,wait:200,a:6,wait:150,a:6,wait:150" TAIL=300 MAXF=1400 SHOT_DIR=$PWD/work/shop1 \
  "$MESENCE" --testrunner --nes.ramPowerOnState=AllZeros "$PWD/rom/dq4.nes" "$PWD/fc/dq4/tools/lua/textitem.lua"
```

```text
452 open W=3F
453 top g=0 n=0B F3=00   put 2:14 3:38 4m3D 4:28 5:0D      こんぼう
453 top g=0 n=21 F3=00   put 15:04 16:01                  30
```

화면에는 `こんぼう 30`·`どうのつるぎ 100`·`いばらのむち 200`·`くさりがま 550` 이 나왔습니다. 그룹 1 `06`·`07` 을 쓰는 창 `6E` 는 `18:$A8E6` 이 엽니다. 이 루틴은 투기장 고리(`18[14]`) 안이라, `04/01` (08,0B)에 워프해 코인을 넣고 말을 걸었습니다. 창 `6E` 에 `ピクシーA — ＊ 4.7` 부터 `ピクシーD — ＊ 5.1` 까지 네 줄이 찍혔습니다. `06` 이 이름 + `A`~`D`, `07` 이 배당입니다.

## 2. 5장 전투 いれかえ

`20`(대열 자리 이름)을 쓰는 창 `3C` 는 `11:$8759` 가 엽니다. 마차 동료를 고르는 `3B` 바로 뒤라 5장 전투의 いれかえ 로 보였습니다. 디버그 B 상태로 필드 0 에 워프한 뒤, 걸음마다 전투가 나게 하고 세이브스테이트를 남기는 드라이버 [uibattle.lua](../tools/lua/uibattle.lua) 를 새로 만들었습니다.

```sh
STATE=$PWD/work/state/dq4-debugB-start.mss fc/dq4/tools/dq4warp.sh work/wB field 0 67 67
DRIVER=$PWD/fc/dq4/tools/lua/uibattle.lua STATE=$PWD/work/wB/warp.mss MON="05:1" WAIT=400 MAXF=1500 TRACE=C000 \
  SHOT_DIR=$PWD/work/bt5 "$MESENCE" --testrunner --nes.ramPowerOnState=AllZeros "$PWD/rom/dq4.nes" "$LIBDIR/probe/trace.lua"
```

걷는 일행이 4명이면 いれかえ 가 창 `69`(いれかえをする·せんとうからはずす)를 엽니다. いれかえをする 는 `3A` だれと → `3B` だれを 로 끝나 `3C` 가 나오지 않았습니다. 「せんとうからはずす」 로 クリフト 를 빼고 한 턴을 넘기니 걷는 일행이 3명이 되었고, 그때는 셋째 줄 「せんとうにくわえる」 가 붙은 창 `68` 이 열렸습니다. 거기서 `3B` 로 마차 동료를 고르자 `3C` 「どこに」 가 걷는 일행 셋(`あああ`·`ミネア`·`マーニャ`)을 찍었습니다. 창 고르기는 `11:$818A` 의 `BRK 62 23 40`(걷는 일행 수)이 4 면 `69`, 1 이면 `6A`, 그 밖이면 `68` 입니다.

`11:$BC2B` 는 처음에 지나지 않았습니다. `11:$BB91` 은 전투원 차례마다 그 전투원이 `$7357`·`$7358` 인지 보고, `11:$BC02` 가 들어올 동료의 상태 플래그 `07`·`06`·`10` 을 차례로 봅니다. 그 셋을 모두 지나면 `$BC1C` 에서 끝나고, 걸리면 `$BC21` → `$BC2B` 로 갑니다. 플래그 `10` 은 `$7210 + 10 × 슬롯` 의 바이트 5 bit0 이라, 마차에서 들어올 ブライ(전투원 4)의 `$723D` 에 `01` 을 두고 다시 했습니다.

```text
215 BC02 prg=47C02 A=01 X=00 Y=01      (나갈 クリフト)
215 BC1C prg=47C1C
224 BC02 prg=47C02 A=04 X=01           (들어올 ブライ)
225 BC21 prg=47C21 A=80 X=07 Y=02
225 BC2B prg=47C2B A=08 X=00 Y=02      00FA=07 0000=08
225 BC3B prg=47C3B
```

화면에는 「クリフトは ばしゃに かけこんだ！ / あああは ブライを ばしゃから ひきずりだした！」 가 나왔고, 상태 창의 ブライ 칸은 `ま：ねる` 였습니다. 잠든 동료는 걸어 나오지 못해, `BC2B` 의 고리가 잠들지 않은 첫 사람(여기서는 주인공)을 골라 끌어냅니다. `BC23` 의 `BRK 62 23 03` 은 걸러내기 아래 2비트를 쓰는 곳으로, 실행으로 본 두 번째 예입니다.

## 3. 낮밤 바꾸기를 막는 `12:$A728`

`12:$A728` 을 `JSR` 하는 곳은 `12:$A764`·`$B435` 둘이었습니다. 둘을 품은 루틴 `$A75C`·`$B42A` 는 같은 뱅크의 주소 표에 있었고, 주문 표 `12:$A9F4`(ID 목록 `12:$AA14`)의 순번 5 가 주문 `38` ラナルータ, 아이템 표 `12:$B679`(ID 목록 `12:$B6BB`)의 순번 24 가 아이템 `67` やみのランプ 였습니다. 낮밤을 바꾸는 둘이 같은 검사를 씁니다.

ライアン 의 첫 소지품(`$60C8`)을 `67` 로 두고 여러 곳에서 どうぐ → ライアン → やみのランプ → つかう 를 눌렀습니다.

```text
필드 0           41=00 07BA=00       → B452 → A77A   (밤, 62ED=8C)
필드 0, 62ED=80                       → B457          (이미 밤)
필드 3           65=03               → B457
02/00            41=80 07BA=00       → B452 → A77A
0D/00            41=80 07BA=01       → B457          (그룹 0D)
2C/00            41=80 07BA=04       → B45D          「しかし ここでは なにも おこらなかった！」
35/00            41=80 07BA=05       → B45D
```

## 4. 맵 번호 bit6 과 `15:$B110`

같은 방법으로 キメラのつばさ(`56`)를 썼습니다. 「どこへ」 창이 하나 더 나와 A 를 한 번 더 눌러야 했습니다. 맵 번호 `52`(bit6 켜짐)인 `35/00` 에서는 `08:$B71F` 의 P 가 `46`(V)이었고 「しかし キメラのつばさは てんじょうに ぶつかって おちてきた。」 가 나왔습니다. `20` 인 `2C/00` 에서는 P 가 `06` 이고 バトランド 앞 필드로 날아갔습니다.

`15:$B110` 은 `JSR` 도 주소 표도 없었는데, 바로 앞 `15:$B10E` 가 `STA $DA` 하나라 그 뒤로 이어지는 자리였습니다. `$B10E` 는 대화 `15:$993F` 의 「말 걸기 앞 검사」 입니다. `45/00` (23,1E)에 워프해 위의 인물에게 말을 걸며 `$65` 를 바꿔 보았습니다.

```text
65=00: 993F → B10E → B110 → B117
65=03: 993F → B10E → B110 → B116 (RTS)
```

## 5. 결계 막이와 `$7500`

`1E:$93CF` 는 `$62A4` 의 위 4비트에서 켜진 비트를 셉니다. 그 수 n 만큼 막이 줄을 덜 씁니다. `SET` 으로 값을 바꿔 필드 3 (23,2C)에 워프했습니다.

```text
62A4=00 Y 20 20 20 20 1F 1F 1E 1E
62A4=10 Y 20 20 20 20 1F 1F FF FF
62A4=30 Y 20 20 20 20 FF FF FF FF
62A4=70 Y FF FF 20 20 FF FF FF FF
62A4=F0 Y FF FF FF FF FF FF FF FF
62A4=0F Y 20 20 20 20 1F 1F 1E 1E
```

(23,22)에서 위로 걸으면 `00` 은 (23,21)에서 멈추고 `F0` 은 `45/00` 입구 (23,1F)로 들어갔습니다. [이벤트 표](../docs/dq4-script-format.md#이벤트-표)에서 `$62A4` 위 4비트는 결계를 지키는 넷을 이길 때마다 켜지는 비트입니다. 같은 덤프의 OAM 에서 슬롯 `0A`~`0D` 자리에는 타일 `AE`~`B1`(팔레트 3) 스프라이트가 있었고, `$7500` = `AE 03 AF 03 B0 03 B1 03` 이었습니다. 반짝이는 막이 그림이 곧 `1D:$8D26` 이 번갈아 쓰는 네 타일입니다.

## 6. 배 자리 `$6195/$6196`

`0F:$CCA3` 은 탈것을 타고 걸을 때 `$42`/`$43` 을 `$6195 + X` 에 쓰고, `0F:$CFCA` 는 물 칸으로 걸으려는 자리가 `$6195`/`$6196` 이면 `$0527` = 1 로 둡니다. `1E:$932A` 는 필드로 나올 때 이 자리를 인물 슬롯 6 에 옮깁니다. 처음에 `SET="6195=A631"` 만 주고 필드 0 에 워프하니 끝 덤프에서 `$6195` 가 `00` 이었습니다. `1E:$9768` 의 `BRK 13 EB`(플래그 `$628E` bit0)가 꺼져 있으면 `$9771` 이 지웁니다. `628E=01` 을 함께 주니 슬롯 6 이 (A6,31)이고 주인공 오른쪽 아래에 배가 보였습니다.

## 7. 성 앞 워프 nametable 과 `42/01`

성 앞 `02/00` 의 워프 덤프만 nametable 이 크게 다른 까닭은 덤프 시각이었습니다. 도착 뒤 기다림을 바꿔 [dq4block.py](../tools/dq4block.py) `compare` 를 다시 했습니다.

```text
WAIT=120  7C=08 7B=0F   nametable 914 다름
WAIT=200  7C=0A 7B=03   0 다름
WAIT=400  7C=0A 7B=03   64 다름(상태 창)
```

`08:$B397` 의 `42/01` 갈래는 `08[0A]`(`08:$B22E`) 안의 `JSR` 하나로만 닿습니다. 고정 표 6항목과 연결 표 어디에도 목적지 그룹 `42` 가 없고, 그룹 `42` 의 맵 둘은 필드로 나가는 레코드만 가집니다. `42/01` (05,0F)에서 아래로 나가 보니 `$B22E` 는 지났지만 `$B397` 은 지나지 않았습니다.

그룹 `48` 은 [dq4-story-format.md](../docs/dq4-story-format.md) 에서 이미 실측한 `48/04` 의 레버(「まじんぞうが うごきはじめた！」)로 보아 5장 まじんぞう 의 안입니다. 그룹 안의 맵끼리만 이어져 있습니다.

## 틀렸던 것들

- 「막이 줄에는 반짝이는 블록만 있고 인물 그림은 없다」: 반짝임이 바로 슬롯 `0A`~`0D` 의 스프라이트였습니다.
- 「`$6195` 만 쓰면 배가 나온다」: 배를 가졌다는 플래그 `$628E` bit0 이 없으면 필드로 나올 때 지워집니다.
- 「いれかえ 만 하면 `11:$BC2B` 가 돈다」: 보통 교대는 `$BC1C` 에서 끝나고, 들어올 동료가 잠들어 있을 때만 `$BC2B` 로 갑니다.

## 남은 것

- `10:$BAE1` 의 실제 장면. 부르는 `10:$AEF0`·`$AF2B`·`$B0C3` 은 몬스터 AI 평가 쪽이라, 일행 쪽 전투원이 몬스터 AI 로 움직이는 경우가 있는지 찾아야 함.
- 루틴 항목 `25` 는 쓰는 창 레코드가 없어 화면으로 볼 수 없음. 걸러내기 `04` 를 주는 호출(상수로는 없음).
- ラナルータ 를 주문으로 써서 やみのランプ 와 같은지, 배를 타고 내리는 장면(`$0527`)을 물가에서 보기, `1E:$86BB` 의 `48/09` 갈래.
