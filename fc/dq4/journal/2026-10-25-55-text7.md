# 2026-10-25-55: 전투 대상 창의 적·일행 바꾸기와 동료 걸러내기 값

지난번 남긴 창 세부 중 다섯 가지를 실측으로 풀었습니다. 본문 바이트 `B0` 은 전투 대상 창에서 적과 일행 사이를 오가게 하는 표시였고, 걸러내기 값 `08`·`80`·`40` 은 손님 빼기·마차 안·걷는 일행이었습니다. 쓰는 창이 없던 값 번호 `4A` 는 골드, 목록 `DC` 는 빈 루틴, 곁 창 `0F` 는 마차 동료의 HP·MP 표입니다. 결과는 [dq4-text-format.md](../docs/dq4-text-format.md#본문-바이트) 에 있습니다.

## 1. `B0` 은 적·일행 바꾸기

`B0` 이 켜는 `$F5` bit0 을 `LSR`·`BCS` 로 보는 곳은 `16:$99A4`·`$99F5` 둘이었습니다. 둘 다 `$03CC` 가 1·2 이고 `$03CF` 낮은 니블이 `F` 일 때 지나갑니다. `$03CC` 는 `12:$BCC1` 이 패드 `$14` 의 가장 낮은 켜진 비트 번호로 만들어, 1 이 A, 2 가 B, 5~8 이 위·아래·왼쪽·오른쪽입니다. 실제로 방향을 누르며 기록하니 `$03CC` 는 `05`·`06`·`07`·`08` 이었습니다. 위를 누르면 `$03CF` 는 `10` → `1F` 가 되어, 커서가 첫 줄 위의 화살표 칸으로 올라갑니다.

```text
16:99A4  LDA $F5 / LSR A / BCS $99CF     ; bit0 이면
16:99CF  LDA #$FE / STA $F8              ; 쪽을 넘기지 않고 FE 로 닫음
11:85F8  CMP #$FE / BNE … / LDA $7354 / EOR #$80 / STA $7354 / JMP $85E6
```

`11:$85E6` 은 `$7354` bit7 이 켜져 있으면 `2E`(몬스터 무리), 아니면 `33`(동료)를 엽니다. 1장 첫 전투(`dq4-ch1-battle.mss`)에서 こうげき 를 고르면 `2E` 가 열리고, 거기서 위 → A 를 누르니 `33` 이 `ライアン` 한 줄로 열렸습니다. B 를 눌러도 같았습니다.

```text
67 99CF prg=599CF A=20 … 03CC=01 03CF=1F 00F5=41 7354=80
68 open W=2E
68 open W=33
```

## 2. 걸러내기 값

창 `08`(つよさ 동료 고르기)의 `80` 바이트(PRG `5A787`)를 `81`~`83` 으로 바꿔 디버그 B 모드(8명, 마차 함께)에서 띄웠습니다.

```sh
THEN=textitem.lua PRGPOKE="5A787=82" WIN=08 DRIVER=$LIBDIR/seq.lua STATE=$PWD/work/state/dq4-debugB-start.mss \
  SEQ="wait:30,a:4,wait:60" TAIL=200 EVERY=0 MAXF=320 SHOT_DIR=$PWD/work/f82 "$MESENCE" --testrunner \
  --nes.ramPowerOnState=AllZeros $PWD/rom/dq4.nes $PWD/fc/dq4/tools/lua/textx3.lua
```

| 바꾼 RAM | `80`(`00`) | `81`(`08`) | `82`(`80`) | `83`(`40`) |
| --- | --- | --- | --- | --- |
| 없음 | 8 | 8 | 4(마차 4명) | 4(걷는 4명) |
| `$618E` = `00`(마차 없음) | 4 | 4 | 0 | 4 |
| 마차 자리 `$6176` = `89` | 9 | 8 | | |
| 마차 자리 `$6176` = `88` | 9 | 9 | | |

`08` 은 레코드 번호 9 이상을 뺍니다. 코드도 같았습니다: `10:$8254` 가 `80`, `10:$826D` 가 `40` 을 보고 걷는 자리·마차 자리를 건너뛰며, `10:$82CE` 가 `08` 일 때 `$616A,Y & 1F` ≥ 9 를 건너뜁니다. 동료 둘의 HP 를 0 으로 둬도 네 값 모두 그대로 셌습니다.

## 3. 값 번호 `4A`, 목록 `DC`, 곁 창 `0F`, 항목 `0C`

- 수 항목이 값 번호 표를 읽는 `16:$BAF3` 에서 X 를 `0D` 로 바꿔 つよさ 창 `0B` 를 띄우니 모든 칸이 `90` 이었고, 동료를 바꿔도 같았습니다. SRAM 에서 `5A` 인 곳은 골드 `$6157` 하나였고, 골드를 `12345` 로 두니 `12345` 가 찍혔습니다.
- 목록 `DC` 의 표 값 + 1 은 `16:$A328` 의 `RTS` 하나입니다.
- 디버그 B 필드에서 `10` 을 강제로 여니 곁 창 `0F` 가 x6 y16 w22 h12 에 마차 4명을 그렸습니다. nametable 에 쓴 `┌`·`┐`·`└` 자리로 쟀습니다.
- 맡긴 아이템 `$61DB`~ 를 `02 10 FF` 로 두고 `47` 을 띄우니 항목 `0C` 가 `どうのつるぎ`·`りりょくのつえ` 두 줄을 찍었습니다.

## 틀렸던 것들

- `B0` 의 `$F5` bit0 을 방향 키와 관계있다고 보고 왼쪽·오른쪽부터 눌렀습니다. 비교 값 1·2 는 A·B 였고, 그 상태는 커서를 화살표 칸에 올렸을 때만 생깁니다.
- 디버그 B 에서 `00` 과 `08` 이 같은 수를 내서 생존 조건이라 짐작했습니다. HP 0 으로는 바뀌지 않았고, 손님 레코드를 마차에 넣어야 갈렸습니다.
- 동료 AI 를 보려고 디버그 B 에서 Start 를 누른 채 걸었지만 전투가 나지 않고 건물로 들어갔습니다.
