# 2026-10-25-17: 블록 속성 값 표

SFC DQ5 쪽 블록 속성에 대응시킬 수 있게, 롬의 맵 269개와 필드 3개에서 실제 칸에 쓰인 블록 속성(`$6F40`) 값을 모두 모아 뜻을 붙였습니다. 독늪은 걸어서 데미지를 확인했고, 카운터는 다른 분석의 말 걸기 실측과 자리를 맞춰 정했습니다. 결과는 [dq4-block-format.md](../../dq4-block-format.md#속성-값) 의 「속성 값」 표입니다.

## 1. 값 모으기

`tools/dq4block.py props` 가 맵마다 장소별 고치기(`08:$8A2A`)까지 반영한 속성으로 칸을 세어 값별로 묶습니다. 값은 43가지였고, 그중 막힌 값(bit7)이 22가지였습니다.

```
00 | 바닥 | 272 | 85784 | 00/00:00 00/01:02 00/02:02
01 | 독늪(걸음마다 HP 1) | 12 | 1003 | 0A/00:05 14/02:05 16/00:05
A7 | 카운터(너머로 말 걸기) | 124 | 821 | 00/00:19 00/01:10 00/02:10
```

통행 지도도 막힌 값을 `#` 하나로 뭉치지 않고 맵마다 `a`, `b`… 로 나눠 찍게 바꿨습니다.

## 2. 독늪

필드 블록 07 의 속성이 `01` 입니다. 그룹 `40`(동굴) 입구 (81,40) 둘레가 블록 07 이라, 워프로 필드 0 (83,40) 에 서서 입구 칸을 피해 걸었습니다. 라이안 HP 는 인물 레코드 6번의 `+01`(`$60B6`)입니다([dq4-save-format.md](../../dq4-save-format.md)).

```sh
tools/dq4warp.sh work/sw field 0 83 40
SEQ="left:16,wait:60,up:16,wait:60,left:16,wait:60,left:16,wait:60,up:16,wait:60" WATCH="x=0042;y=0043;h=60B6" ...
```

```
x=83 y=40 h=1B|x=82 y=40 h=1A|x=82 y=3F h=19|x=81 y=3F h=18|x=80 y=3F h=17|x=80 y=3E h=17
```

블록 07 칸에서 한 걸음마다 1 씩 줄고, 바닥(블록 01)으로 나오자 줄지 않았습니다.

## 3. 카운터

[dq4-script-format.md](../../dq4-script-format.md) 는 `12/00` 여관 주인에게 두 칸 아래에서 말을 걸면 「카운터 너머」 로 잡힌다고 적었습니다. 주인은 (11,12), 말 건 자리는 (11,14) 이고, 그 사이 (11,13) 의 블록 0F 속성이 `A7` 이었습니다. `A7` 은 124개 맵에 있습니다.

## 틀렸던 것들

- 앞 일지의 걷기에서 `3C/01` 의 「`0B` 를 밟자 다른 자리로 옮겨짐」 은 맵 오른쪽 끝을 넘어 `3C/00` 으로 나간 것이었습니다. `0B` 는 그 맵의 바깥 블록이었습니다. 맵 번호(`$63`/`$64`)를 같이 찍어 다시 걸어 보고 알았습니다. 형식 문서와 앞 일지를 고쳤습니다.
- `02/01` 의 `02` 칸을 데미지 바닥으로 보고 워프했는데, 이벤트(「どこからともなく こえがきこえる……。」)가 돌아 데미지는 보지 못했습니다.

## 남은 것

- `02` 의 실제 효과.
- `05`·`0B`(`1E:$8676`)·`0A`·`31`·`33` 의 뜻, 막힌 값 `85`~`B2` 의 값별 차이(조사·문 플래그 `$6272` 와의 관계 등).
- 미끄러지는 바닥 `10`~`13` 의 방향.
