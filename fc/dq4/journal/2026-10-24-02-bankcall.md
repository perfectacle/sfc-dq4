# 2026-10-24-02: BRK 뱅크 호출

[앞 일지](2026-10-24-01-fc-env.md) 에서 맵 번호를 쓰는 코드 바로 앞에 `BRK` 와 데이터 두 바이트가 있었습니다. 그 `BRK` 가 다른 뱅크 루틴을 부르는 방식을 풀고, 롬만 읽는 디코더 결과를 실행 기록 1019건과 맞춰 봤습니다. 결과는 [dq4-bank-format.md](../docs/dq4-bank-format.md) 에 있습니다.

## 1. BRK 처리기 읽기

IRQ/BRK 벡터는 `$C408` 입니다. 처리기는 스택의 복귀 주소에서 BRK 다음 두 바이트(`b1`, `b2`)를 읽습니다.

```
0F:C425  b1 26    LDA ($26),Y      ; b2
0F:C428  29 0f    AND #$0F
0F:C42A  c9 0b    CMP #$0B         ; 특수 형식
0F:C42E  c9 03    CMP #$03         ; 특수 형식
...
0F:C439  6a       ROR A            ; b2 bit3 을 붙여
0F:C43D  85 23    STA $23          ; 5비트 뱅크
0F:C440  b1 26    LDA ($26),Y      ; b1
0F:C442  30 0d    BMI $C451        ; bit7: 주소만 꺼내기
0F:C444  85 24    STA $24          ; 함수 번호
```

이어지는 `$C3BA` 는 `$FF91` 로 대상 뱅크를 끼운 뒤 그 뱅크 `$8000 + 함수 번호 × 2` 의 두 바이트를 함수 주소로 읽습니다. 모든 코드 뱅크 앞머리가 함수 표인 셈입니다.

`$FF91` 은 A 를 `$0507` 에 두고 bit4 를 256KB 절반 선택에 씁니다. 그래서 `$0507` 을 보면 지금 끼워진 뱅크와 고정 영역이 `0F` 인지 `1F` 인지를 알 수 있습니다.

## 2. 디코더와 실행 기록 맞추기

[fc/dq4/tools/dq4bank.py](../tools/dq4bank.py) 는 호출 위치와 그때의 `$0507` 만 받아 롬에서 뱅크·함수 번호·함수 주소를 냅니다. 처리기 안 세 곳을 `probe/trace.lua` 로 찍었습니다.

```sh
TRACE=C446,C455,C3CD,C484,C460,C46C LOG=0023,0024,0025,0026,0027,0507 LIMIT=100000
```

`$C446`·`$C455` 에서 `$23`(뱅크)·`$24`(함수 번호)·`$26/$27`(BRK+1), `$C3CD` 에서 `$24/$25`(함수 주소)를 얻습니다.

```
371 호출 중 0 다름, 호출 위치 24 곳     # 부팅
648 호출 중 0 다름, 호출 위치 43 곳     # 왕좌의 방 → 성 밖
```

보행 장면의 호출 대상 42곳은 `probe/cover.lua` 에서 모두 실행됐습니다. 일반 호출은 BRK+3 에서 이어집니다(`1B:$807A` 의 BRK 와 +3 만 실행 기록에 있음).

## 3. 특수 형식

`b2` 의 아래 3비트가 `3` 이면 다른 길로 갑니다. 아래 4비트 `3` 은 상위 4비트로 뱅크 `10`·`12` 의 함수를 고르고 셋째 바이트까지 넘깁니다. 아래 4비트 `B` 는 `$627B` 영역의 비트를 켜고·끄고·검사하는 것으로 읽히고, `FB` 는 뱅크 `19` 함수 `03` 입니다. 두 장면에서는 `x3` 이 12번, `FB` 가 6번 나왔습니다.

`x3` 호출 뒤 실행이 이어진 곳을 cover 로 보니 BRK+3 인 곳과 BRK+4 인 곳이 섞여 있었습니다.

```
8EE6 00 56 33 68 ...   +3 실행
AC0A 00 62 63 40 ...   +4 실행
```

## 4. 실행된 뱅크

두 장면의 cover 를 뱅크별로 세니, 뱅크 `00`~`07` 은 한 번도 실행되지 않았습니다. 대사 텍스트를 찾을 때 먼저 볼 곳입니다.

## 틀렸던 것들

- 특수 형식도 일반 호출처럼 BRK+3 에서 돌아온다고 봤는데, `x3` 은 함수에 따라 +4 에서 이어졌습니다.
- 첫 trace 는 zsh 가 `$L` 을 한 인자로 넘겨 `LOG` 가 빠졌습니다. `${=L}` 로 나눠야 합니다.

## 남은 것

- `x3` 형식의 인자 길이 규칙, 플래그 형식을 실제로 쓰는 곳.
- 뱅크마다 함수 표의 길이와 역할, 뱅크 `00`~`07` 의 내용.
