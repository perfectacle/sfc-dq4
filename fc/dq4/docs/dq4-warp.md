# DQ4(FC) 장면 이동(워프) 도구

세이브스테이트 하나에서 시작해 원하는 맵·필드 자리로 옮기고, 화면·인물·출구가 정상으로 실린 「조작 가능한」 상태를 세이브스테이트로 남기는 도구입니다. 게임 진행이 많이 필요한 장면(다른 장의 마을, 깊은 동굴)을 실험할 때 씁니다. 스크립트는 [fc/dq4/tools/lua/warp.lua](../tools/lua/warp.lua), 감싼 셸은 [fc/dq4/tools/dq4warp.sh](../tools/dq4warp.sh) 이고, 만든 과정은 [2026-10-25-08 일지](../journal/2026-10-25-08-warp.md) 에 있습니다. 주소 표기는 [dq4-ram-format.md](dq4-ram-format.md) 를 따릅니다.

## 쓰는 법

```sh
export MESENCE=/path/to/Mesen
fc/dq4/tools/dq4warp.sh work/w1 0E/00                # 맵 0E/00. 좌표를 빼면 그 맵으로 들어오는 첫 출구의 도착 자리
fc/dq4/tools/dq4warp.sh work/w2 0E/00 15 0E 0        # 좌표 (15,0E), 위를 보고 섬
fc/dq4/tools/dq4warp.sh work/w3 field 0 67 67        # 필드 0 의 (67,67)
SET="6157=E803" SEQ="up:16,a:6,wait:40,a:6,wait:150" fc/dq4/tools/dq4warp.sh work/w4 04/00
```

결과 폴더에 `warp.mss`(도착 직후 세이브스테이트)·`warp.png`·`warp.txt`(출발·도착·끝의 `$63 $64 $65 $42 $43 $44 $45 $28`)가 생기고, `SEQ` 를 재생한 뒤의 `end.png`·`end.mss`·`end.ram`·`end.sram` 등이 생깁니다. `warp.mss` 는 다른 실험의 `STATE` 로 그대로 쓸 수 있습니다.

`warp.lua` 는 툴킷 `seq.lua` 처럼 입력 드라이버이기도 해서, 프로브의 `DRIVER` 로 주면 워프 → `SEQ` 재생 동안 프로브가 돕니다. 이때는 프로브의 `MAXF` 까지 기다렸다가 멈춥니다.

```sh
LIBDIR=$(uv run krpatch fc lua) DRIVER=$PWD/fc/dq4/tools/lua/warp.lua MAP=0E/00 X=15 Y=0E DIR=0 \
  SEQ="a:6,wait:40,a:6,wait:150" TAIL=60 MAXF=600 TRACE=8656 SHOT_DIR=$PWD/work/talk \
  "$MESENCE" --testrunner --nes.ramPowerOnState=AllZeros "$PWD/rom/dq4.nes" "$LIBDIR/probe/trace.lua"
```

| 환경 변수 | 뜻 |
| --- | --- |
| `MAP=GG/KK`, `X`, `Y`, `DIR` | 맵 장소(그룹 `$63`/순번 `$64`), 도착 좌표 `$44`/`$45`, 도착 방향(0 위, 1 오른쪽, 2 아래(기본), 3 왼쪽). 모두 16진 |
| `FIELD=F`, `X`, `Y` | 필드 번호 `$65` 와 필드 좌표 `$42`/`$43` |
| `STATE` | 출발 세이브스테이트. 기본 `work/state/dq4-ch1-throne.mss`. 맵 안에서 `KEY` 쪽으로 한 칸 걸을 수 있어야 함 |
| `KEY` | 출발할 때 걸을 방향(기본 `down`) |
| `SET` | 출발 전에 한 번 쓸 값. `주소=바이트들;…`(CPU 주소, 바이트는 이어 씀). 예: `6157=E803` 골드 1000 |
| `AFTER` | 도착 뒤 한 번 쓸 값(`SET` 과 같은 꼴) |
| `WAIT` | 진입 루틴이 돈 뒤 세이브스테이트를 남기기까지 기다릴 프레임(기본 120) |
| `SEQ`, `TAIL` | 도착 뒤 재생할 입력(`seq.lua` 와 같은 꼴)과 그 뒤 프레임(기본 60) |
| `STATE_OUT` | 도착 세이브스테이트 이름(기본 `warp.mss`) |
| `MAXF` | 프로브의 `DRIVER` 로 쓸 때 프로브의 종료 프레임 |

`SET` 으로 쓸 만한 주소(다른 형식 문서에서 확인한 것): 골드 `$6157`(2바이트), 라이안 경험치 `$60C5`, 이벤트 플래그 `$627B`~ 영역(`$62A1`, `$62AA` 등). 장 번호는 `$615A` 로 보입니다(1장 세이브스테이트에서 `00`; 아래 「남은 것」).

## 원리

두 경로 모두 RAM 의 입력값만 바꾸고, 장소를 바꾸는 일은 게임의 루틴이 합니다.

### 맵: 출구 표에 출구를 넣고 한 걸음

맵 안에서 한 걸음을 걸으면 `1E:$9155` 가 맵 밖으로 나갔는지 보고, 아니면 출구 검사 `1B:$8014`(BRK `1B` 함수 0)가 일행 슬롯 0 의 자리(`$6F60`/`$6F80`)를 출구 표 `$05A0`([dq4-map-format.md](dq4-map-format.md#출구-표-05a0))과 비교합니다. 같은 칸이 있으면 `1B:$8024`~`$805D` 가 목적지를 `$63`·`$64`·`$44`·`$45` 에 쓰고, 화면을 어둡게 한 뒤 BRK `1E` 함수 `1E`(`1E:$8ED6`)로 맵에 들어갑니다. 출구 플래그(+6)의 bit1-0 이 도착 방향입니다.

`warp.lua` 는 주인공 둘레 네 칸을 목적지로 가는 출구로 `$05A0` 앞 네 칸에 쓰고(플래그 `80 | DIR`) `KEY` 로 한 걸음 걷습니다. 그 뒤는 문·계단을 지날 때와 같은 경로입니다.

### 필드: 맵 가장자리로 나가기

`1E:$9155` 는 걸은 뒤 `$44 ≥ $3F`(폭)나 `$45 ≥ $40`(높이)면 맵 밖으로 나간 것으로 보고 `1E:$9290` 으로 필드에 나갑니다. 그 안의 `08:$B06A`(BRK `08` 함수 9)가 지금 그룹의 필드 입구([dq4-field-format.md](dq4-field-format.md#필드--마을-입구))를 찾아 `$65`·`$42`·`$43` 을 씁니다.

`warp.lua` 는 `1E:$9155` 에서 `$3F` 를 잠깐 0 으로 바꿔 아무 걸음이나 「맵 밖」으로 만들고(`1E:$9166` 에서 되돌림), `08:$B09B`(`$43` 을 쓴 직후)에서 `$65`·`$42`·`$43` 을 목적지로 바꿉니다. `$B09B` 뒤의 그룹별 보정(그룹 `0E`·`0B`·`35`·`2B`·`21`)은 출발 맵의 그룹 기준이라, 출발 맵이 그룹 `02`(기본값)면 보정 없이 그 자리에 섭니다.

## 확인

출발은 모두 `dq4-ch1-throne.mss`(1장, `$615A`=`00`)입니다. 인물 표는 `fc/dq4/tools/lua/atpc.lua` 로 로드 직후(`1C:$9890`) 덤프해 비교했습니다.

| 목적지 | 도착 `$63/$64/$44/$45` | `dq4map.py npcs --compare` | `exits --compare`(`$05A0`) | 걷기·말하기 |
| --- | --- | --- | --- | --- |
| 맵 `04/00`(11,09) | `04/00/11/09` | 15명 0 다름 | 같음 | 아래로 한 칸, 「はなす」 → `02F0`(앞에 아무도 없음) |
| 맵 `0B/00`(06,30) | `0B/00/06/30` | 11명 0 다름 | 같음 | 오른쪽으로 한 칸 |
| 맵 `1B/00`(0C,0C) | `1B/00/0C/0C` | 11명 0 다름 | 같음 | 아래로 한 칸 |
| 맵 `2B/00`(0B,09) | `2B/00/0B/09` | 4명 0 다름 | 같음 | 「はなす」 → `02F0` |
| 맵 `0E/00`(0A,2C) | `0E/00/0A/2C` | 15명 0 다름 | 같음 | 위로 한 칸 |
| 맵 `0E/00`(15,0E) 위 | `0E/00/15/0E` | — | — | 위 인물에게 「はなす」 → `07C1`(「おれは　いやだ！ ニーナを…」) |
| 맵 `45/00`(1D,1B) | `45/00/1D/1B` | 1명 0 다름 | 같음 | 아래로 한 칸 |
| 필드 0 (67,67) | `$65/$42/$43` = `00/67/67`, `$28`=`00` | — | — | 위로 두 칸 → 입구 (67,65) 로 `04/00`(17,20) 에 들어감 |
| 필드 0 (A3,2E) | `00/A3/2E` | — | — | 오른쪽 한 칸 → `02/00`(00,1D)(입구 표와 같음) |
| 필드 1 (1E,1E) | `01/1E/1E` | — | — | 위·왼쪽으로 (1D,1D) |

`SET="6157=E803"` 은 도착 뒤에도 `$6157`=`E8 03` 이었습니다(화면의 골드 표시는 보지 않았습니다).

## 한계

- 출발 맵에서 `KEY` 쪽 칸이 막혀 있으면(벽·인물) 걷지 못해 진입 루틴이 돌지 않습니다. 240프레임 안에 돌지 않으면 `warp.txt` 에 「실패」를 쓰고 멈춥니다. `KEY` 를 바꾸거나 다른 `STATE` 를 씁니다.
- 출발이 필드인 세이브스테이트는 지원하지 않습니다(필드 걸음은 `1E:$9155` 를 지나지 않음).
- 장·일행 구성·레벨·소지품은 RAM 을 `SET` 으로 쓰는 것뿐이고, 게임의 장 시작 루틴을 타지 않습니다. 일행 레코드 형식은 아직 모릅니다.
- 이벤트 장면이 있는 맵은 들어가자마자 이벤트가 돌 수 있습니다. 그 맵의 플래그는 `SET` 으로 미리 맞춥니다.
- 도착 방향 `DIR` 은 맵에서만 듣습니다. 필드에서는 `08:$B131` 이 정한 방향(그룹 `02` 출발이면 아래)으로 섭니다.

## 남은 것

- `$615A` 가 장 번호인지: `1E:$A36B` 가 이어하기 메뉴 뒤에 쓰고, `12:$905F` 가 5 이상이면 4로 바꾸는 것(코드 읽기)뿐, 값을 바꿔 장 시작을 확인하지 않았습니다.
- 일행 구성·레벨·소지품 레코드 형식.
- 루이라(ルーラ)·키메라의 날개 경로(이 도구는 쓰지 않음).
