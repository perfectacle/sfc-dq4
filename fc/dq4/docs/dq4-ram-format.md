# DQ4(FC) 필드 RAM 과 뱅크 전환

FC 「드래곤 퀘스트 IV」 일본판 Rev A(`rom/dq4.nes`)를 MesenCE 로 돌려 확인한 RAM 주소와 뱅크 구조입니다. 주소 표기는 [dq4-handoff.md](../handoff.md#조심할-것) 를 따릅니다: CPU 주소는 `$0044`, PRG 위치는 「뱅크 `08`:`$B708`」(16KB 뱅크 번호) 또는 「PRG `23708`」(iNES 헤더 16바이트를 뺀 PRG ROM 오프셋)입니다.

근거가 실측이 아니라 코드 읽기인 줄에는 「코드 읽기」라고 적었습니다. 실험 과정은 [2026-10-24-01 일지](../journal/2026-10-24-01-fc-env.md) 에 있습니다.

## 롬

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 헤더 | iNES, 매퍼 1(MMC1), PRG 512KB(16KB × 32), CHR-RAM, 배터리 백업 | `krpatch fc info` |
| PRG 배치 | `$8000`~`$BFFF` 에 바꿔 끼우는 16KB, `$C000`~`$FFFF` 는 그 256KB 절반의 마지막 뱅크(`0F` 또는 `1F`) | 실행 커버리지: 같은 고정 영역 코드가 PRG `3Cxxx` 와 `7Cxxx` 양쪽에서 실행됨 |
| 벡터 | NMI `$0502`(RAM), RESET `$FFD8`, IRQ/BRK `$C408`. 두 절반 모두 같음 | 롬 바이트 |
| NMI 진입 | 부팅 때 `$0502`~`$0504` 에 `4C 5A C1`(`JMP $C15A`)을 씀 | `probe/writes.lua` |

뱅크 `0F` 와 `1F` 는 같은 주소에 같은 공통 루틴(아래 뱅크 전환, `$C100` 부근, `$C3EA` 부근)을 갖지만 전체가 같지는 않습니다. 16KB 중 6548바이트가 다르고, `$C000`~`$C03C` 의 점프 표와 `$E54A` 부터의 넓은 구간이 다릅니다.

## 뱅크 전환

| 루틴 | 하는 일 | 근거 |
| --- | --- | --- |
| `$FFAC`~`$FFBC` | A 의 아래 4비트를 `STA $FFFF` 다섯 번(LSR 하며)으로 MMC1 PRG 뱅크 레지스터에 씀 | 쓰기 프로브: 매 프레임 이 다섯 PC 가 `$FFFF` 에 씀 |
| `$FFBF`~`$FFD2` | `$0501` 을 `STA $BFFF` 다섯 번으로 CHR 0 레지스터에 씀. SUROM 보드는 이 레지스터의 bit4 로 256KB 절반을 고름 | 쓰기 프로브, 위 「PRG 배치」 관찰 |
| `$C11B`~`$C12B` | `STA $9FFF` 다섯 번: MMC1 제어 레지스터 | 쓰기 프로브 |
| `$6CC2`~`$6CFB`(WRAM) | `$BFFF` 에 쓰는 코드가 WRAM 에서도 실행됨 | 쓰기 프로브(PC 의 PRG 오프셋 없음) |
| `BRK` + 2바이트 | 다른 뱅크의 루틴 부르기. 형식은 [dq4-bank-format.md](dq4-bank-format.md) | 실행 기록 1019건과 디코더 비교 |
| `JSR $C3EA`(A=뱅크) | 다른 뱅크의 바이트 읽기. 예: `08:$B703` 이 `LDA #$17` 뒤에 부르고 결과를 `$0550` 에 씀 | `probe/reads.lua`: `$C3FD` 가 다른 뱅크 데이터를 읽음 |

## 필드 상태

`work/state/dq4-ch1-throne.mss`(1장 시작, 바트랜드 성 왕좌의 방)에서 걸어 확인했습니다. 한 칸 걷는 데 16프레임입니다.

| 주소 | 내용 | 근거 |
| --- | --- | --- |
| `$0044`, `$0045` | 주인공 맵 좌표 X, Y. 걸음을 시작할 때 바뀜 | 아래로 걸으면 Y+1, 왼쪽은 X−1. 맵 전환 때 도착 좌표가 들어감 |
| `$00EC`, `$00ED` | 같은 좌표가 8프레임 늦게(걸음 중간에) 따라옴 | `probe/watch.lua` |
| `$007C`, `$007B` | X−8, Y−7. 화면 왼쪽 위 칸의 좌표로 보임 | 걸을 때 좌표와 같이 움직임. 화면과의 관계는 아직 확인 못 함 |
| `$0028` | 맵 종류 번호(맵 레코드 첫 바이트). 왕좌의 방 `0D`, 성 밖 `0A`. 장소는 `$63`/`$64`([dq4-map-format.md](dq4-map-format.md#장소-번호)) | 왕좌의 방 → 성 밖 → 왕좌의 방으로 걸어 `0D`→`0A`→`0D` |
| `$63`, `$64` | 장소(그룹, 순번). 왕좌의 방 `02/01`, 성 밖 `02/00` | 같은 실험, 맵 해제 비교 |
| `$0550` | `$0028` 과 같은 값 | 같은 실험. `08:$B708`(PRG `23708`)이 씀 |

맵 전환 때 `$0550` 은 `08:$B708`, `$0028` 은 `0F:$E94E`(PRG `3E94E`)가 한 번씩 씁니다(`probe/trace.lua`, A=`0D`). 도착 좌표는 `1B:$8050`~ 이 아래 출구 표에서 `$0064`, `$0044`, `$0045` 로 옮깁니다(쓰기 프로브: `1B:$8058` 이 `$0044`, `1B:$805D` 가 `$0045`).

### 출구 표 `$05A0`

현재 맵의 출구가 7바이트씩 들어 있습니다. 형식은 [dq4-map-format.md 「출구 표」](dq4-map-format.md#출구-표-05a0) 로 옮겼습니다.
