# DQ4(FC) 인물 블록(움직임·자동 이벤트 스크립트)

맵 인물 레코드에 붙은 블록([dq4-map-format.md](dq4-map-format.md#인물))은 인물마다 도는 작은 스크립트입니다. 걷기·방향 돌기·숨기, 메시지 띄우기, 플래그 쓰기, 일행을 움직이는 자동 장면이 모두 이 블록 명령으로 되어 있습니다. 디코더는 [tools/dq4npcblock.py](../tools/dq4npcblock.py), 실측 프로브는 [fc/dq4/tools/lua/npcblock.lua](../tools/lua/npcblock.lua) 이고, 실험 과정은 [2026-10-25-36 일지](../journal/2026-10-25-36-event3.md) 에 있습니다. 플래그·이벤트 쪽 교차 참조는 [dq4-save-format.md](dq4-save-format.md#인물-블록의-이벤트-명령) 에 있습니다.

근거가 실측이 아니라 코드 읽기인 줄에는 「코드 읽기」라고 적었습니다. 주소는 고정 뱅크(`1F`)의 CPU 주소입니다.

```sh
uv run python tools/dq4npcblock.py rom/dq4.nes 02 01        # 맵 02/01 인물마다 블록1·2 를 명령 단위로
uv run python tools/dq4npcblock.py rom/dq4.nes alt          # 이벤트 목록(1C:$9D0E 표)의 인물 블록
uv run python tools/dq4npcblock.py rom/dq4.nes check        # 롬 전체: 못 읽은 명령·넘친 명령·점프 대상
uv run python tools/dq4npcblock.py rom/dq4.nes stats        # 명령마다 쓰인 수
uv run python tools/dq4npcblock.py rom/dq4.nes patterns     # 명령 22 의 일행 움직임 패턴
uv run python tools/dq4npcblock.py rom/dq4.nes trace work/x/npcblock.txt   # 프로브 기록과 대조
```

## 블록과 실행

레코드의 블록1 은 낮(F bit4) 목록, 블록2 는 밤(F bit3) 목록에 들어갈 때 쓰입니다. 블록은 길이 바이트 + 본문이고, 맵을 실을 때 본문 주소가 인물 표 `$7060`(위)/`$7080`(아래)에 들어갑니다. 블록은 인물 목록과 같은 뱅크(맵 목록 `05`, 이벤트 목록 `1C`)에 있고, 실행할 때 그 뱅크(`$67`)가 `$8000` 에 걸려 있습니다.

| 단계 | 루틴 | 하는 일 |
| --- | --- | --- |
| 슬롯 돌기 | `1F:$D572`(평소), `1F:$D5A0`(`$41` bit7 일 때) | 슬롯 6~`1D` 를 차례로. `$41` bit7 일 때는 `$70E0` bit6 인 인물만 |
| 간격 | `1F:$D62E` | `$7040` 을 하나 줄여 아래 4비트가 0 이 되면 위 4비트를 다시 채우고 명령을 하나 실행. `$7040` = 0 이면 실행하지 않음 |
| 명령 실행 | `1F:$D884` | `($7060:$7080)` 의 바이트가 `31` 미만이면 `1F:$DEF5`, bit7 이면 `1F:$DF57` 의 처리기로. `31`~`7F` 는 `00` 으로 실행 |
| 포인터 넘김 | `1F:$DDCD`/`$DDD0`/`$DDD3`/`$DDD6` | 4·3·2·1 바이트 |
| 끝내기 | `1F:$DDE3`(`PLA PLA RTS`) | 이 프레임의 명령 실행을 끝냄. 「쉼」 |
| 이어 가기 | `JMP $D884` | 같은 프레임에 다음 명령을 바로 실행 |

명령은 세 가지로 끝납니다. 포인터를 넘기고 쉬는 것, 포인터를 넘기고 같은 프레임에 다음 명령으로 이어 가는 것, 포인터를 넘기지 않고 쉬는 것(「머묾」: 다음 차례에 같은 명령을 다시 함)입니다. 걷는 명령은 방향을 `$7000` 아래 2비트에 두고 C 를 돌려줘 슬롯 루틴이 한 칸 걷게 합니다.

### 인물 표 열

인물 표는 슬롯 32개, 열마다 `$20` 바이트입니다. 블록 명령이 쓰는 열입니다(실측은 표시한 것만, 나머지는 코드 읽기).

| 열 | 뜻 |
| --- | --- |
| `$6F60`/`$6F80` | X·Y. `81` 이면 맵에서 빠짐(명령 08·0A). 실측: 목표 칸에 닿았을 때의 자리 |
| `$6FA0`/`$6FC0` | 이전 자리로 보임. 명령 0B·25 가 지금 자리를 복사 |
| `$6FE0` | 아래 4비트 = 그림 칸 + 4([dq4-script-format.md](dq4-script-format.md) 의 겉모습) |
| `$7000` | 아래 2비트 = 방향(0 위, 1 오른쪽, 2 아래, 3 왼쪽). 실측 |
| `$7020` | bit7 = 숨음. `FF` 면 빈 슬롯 |
| `$7040` | 명령 간격. 위 4비트 = 간격, 아래 4비트 = 남은 차례(맵을 실을 때 값은 [dq4-script-format.md](dq4-script-format.md#그림과-움직임)). 명령 11·12~20 은 위·아래에 같은 값을 씀 |
| `$7060`/`$7080` | 다음 명령 주소(위/아래) |
| `$70A0`/`$70C0` | 되돌아갈 주소(명령 82·85 가 씀, 80·81 이 씀) |
| `$70E0` | 상태 비트. bit7 은 00·01·0F·10·2A·2F, bit6 은 11·12~20, bit3 은 0E 가 다룸. bit7·bit3 의 뜻은 남은 것 |
| `$7140` | 명령 25 가 새 자리로 `1F:$D3D9` 를 불러 얻은 값 |
| `$7160` | 깜박임 카운터(명령 09·0A·0C) |
| `$7180` | 되풀이 횟수(명령 82) |
| `$71A0`/`$71C0` | 목표 X·Y(명령 24). 둘 다 `FF` 면 일행 선두(슬롯 0) |
| `$71E0` | 명령 2D 의 범위 기준 |

### 이벤트 명령

`88`~`8A` `n` 은 `BRK 04 DF`(`1D[04]`, `1D:$989F`)로 `1D:$B639` + 2n 의 루틴으로 뜁니다. 표는 138개(`00`~`89`)이고 롬의 블록은 그중 136개를 씁니다(`00`·`0D` 는 블록에서 안 씀). 루틴이 C 를 세우고 돌아오면 다음 명령으로 이어 가고, C 가 0 이면 포인터를 그대로 두고 쉽니다(n = `16` 이면 `$70E0` bit7 을 끄고, 나머지는 켬). 조건(일행 자리·플래그)이 맞을 때까지 같은 이벤트를 차례마다 다시 묻는 꼴입니다(코드 읽기). 실측으로 지나간 이벤트는 `2F`·`39`·`3F`·`40`·`42`·`54` 입니다([dq4-save-format.md](dq4-save-format.md#인물-블록의-이벤트-명령)). `dq4event.py events` 가 블록마다의 이벤트 명령과 루틴 주소를 찍습니다.

### 일행 움직임 패턴

`22` `n` 은 `1C:$8014` 의 두 워드(본문 `1C:$804E`, 길이 표 `1C:$802C`)로 패턴 n 을 찾아 `$0532`/`$0533` 에 주소, `$0531` 에 길이, `$0530` 에 `80` | 첫 바이트 아래 4비트를 둡니다(`1F:$DAB9`). 패턴은 34개(`00`~`21`, `19` 는 길이 0)입니다. `$0530` bit7 이 서 있는 동안 `1F:$CA41` 이 `1F:$DB0B` 로 패턴 바이트의 위 4비트를 패드 입력 `$14`(bit4 위, 5 아래, 6 왼쪽, 7 오른쪽)에 넣고, 아래 4비트만큼 되풀이한 뒤 다음 바이트로 갑니다. 일행은 사람이 패드를 누른 것처럼 걷습니다. 엔딩([dq4-save-format.md](dq4-save-format.md#5장-끝과-엔딩))도 같은 장치로 일행을 움직입니다.

실측: 엔딩 첫 장면에서 `1F:$DB0B` 가 16프레임마다 불리고 `$0530` 이 `8F`→`88` 로 하나씩 줄었습니다. 패턴 `00`~`0A` 는 방향 없이 1~`B` 번 쉬는 것입니다. 바이트 하나가 한 걸음인지는 화면으로 맞추지 못했습니다.

```
0B 1C:$8059 위×2 왼쪽×3 멈춤×1 왼쪽×6 위×5 왼쪽×3 위×3 멈춤×1 위×E …
13 1C:$8085 멈춤×E
```

## 예: 바트랜드 왕좌의 방 첫 장면

`02/01` 레코드 20(슬롯 `1A`, 블록 `05:$8680`)은 1장 처음에 왕이 ライアン 에게 말하는 장면입니다.

```
+00 82 0c        횟수 0C, 되돌아갈 자리 저장
+02 01           멈춤 표시 켬 뒤 쉼
+03 81           횟수를 하나 줄여 0 이 아니면 되돌아감
+04 26 01 03     메시지 0301
+07 22 13        일행 움직임 패턴 13: 멈춤×E
+09 24 10 13     목표 (10,13)
+0C 03           목표 자리로 한 걸음
+0D 26 02 03     메시지 0302
+10 27 10 7e 62  $627E(플래그 03) |= 10
+14 2a           서 있기(머묾)
```

성 앞마당 세이브스테이트에서 `$627E` 를 `00` 으로 두고 `02/01` 로 워프해 프로브로 본 순서입니다. `01` 을 12번 실행하고(16프레임 간격), 메시지 뒤 `22`·`24`·`03` 을 지나 (10,0D) 에서 (10,13) 까지 걸어 내려온 뒤 `26`·`27` 을 실행했고, 끝난 SRAM 의 `$627E` 는 `10` 이었습니다. `$627E` bit4 가 켜진 채 들어가면 이 인물은 실린 직후 X·Y 가 `80` 이 되어 장면이 다시 일어나지 않습니다(어디서 빼는지는 남은 것).

## 확인
