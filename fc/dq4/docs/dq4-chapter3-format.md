# DQ4(FC) 3장 「무기상인 톨네코」: 사건 차례, 무기점 일, 톨네코, 조우, 굴과 장 끝

FC 「드래곤 퀘스트 IV」 일본판 Rev A(`rom/dq4.nes`) 3장을 SFC 로 옮길 때 쓰는 값입니다. 장 시작 값은 [dq4-save-format.md](dq4-save-format.md#15장-시작-표), flag 뜻과 장마다 진행 표는 [dq4-story-format.md](dq4-story-format.md#장마다-진행-순서--플래그)·[fc/dq4/tools/dq4flags.py](../tools/dq4flags.py) 의 `STORY[3]`, 조우 표 형식은 [dq4-encounter-format.md](dq4-encounter-format.md) 를 따릅니다.

근거가 실측이 아니라 코드 읽기인 칸에는 「코드 읽기」 라고 적었습니다. 나머지는 MesenCE 헤드리스 실행으로 확인한 값입니다. flag 는 `$627B` 영역의 바이트·비트, 메시지·대화 번호는 16진입니다. 맵은 `그룹/순번 (X,Y)`, 인물은 그 맵의 슬롯(레코드 + 6)입니다.

```sh
uv run python fc/dq4/tools/dq4story.py rom/dq4.nes story 3        # 3장 진행 순서 → flag
uv run python fc/dq4/tools/dq4encounter.py rom/dq4.nes chapter3   # 걸어서 닿는 필드·입구, 구역·던전 몬스터, 떠돌이 상인
```

### 방어구 매입

`05/01` 슬롯 13 (04,15), 대화 `060` → `15:$A54C`. 3장 상태(`$615A` = 2)에서 (04,16) 에 서서 위를 보고 말을 걸어 쟀습니다.

| 갈래 | 메시지와 결과 |
| --- | --- |
| 처음 | `0829` 「팔아 주겠나?」. 「いいえ」 `082A` 끝 |
| 소지품이 비었음 | `082B` 끝(「はい」 바로 뒤, 팔고 나서 비었을 때도) |

카운터 너머(`04/00` (06,1A) 에서 아래를 보고) 네네(대화 `075`)에게 말을 걸면 `036B` → 「예」 면 매상이 있을 때 `036D`(금화에 더함), 이어 `036E` 로 톨네코 소지품에서 고른 물건이 팔 수 있으면 `036F`(값 × 1.5, `LDA #$60` / `JSR $A638`) → 「예」 `0370`(물건을 `$61DB` 로) · 「아니요」 `0372`, 팔 수 없으면 `0373`. 그 뒤 `0371` 「예」 면 다시 `036E`, 「아니요」 면 `0374`. 톨네코 소지품이 비었으면 `036E` 대신 `0334`(「오늘은 아무것도」) 뒤 `0374`, 목록이 120개면 `0377`(끝에 같은 물음) 뒤 `0374` 의 물음 갈래로(`15:$9F4E`, 코드 읽기). 한 바퀴 실측: ひのきのぼう(10)를 내놓자 `036F` 「15ゴールドいじょうで」, `$61DB` = `00`. 옆에서 네네와 자고(씨앗 넷) 팔린 날은 매상 15·16·목록이 빔, 안 팔린 날은 매상 0·목록에 남음. 이어 카운터에서 팔린 날은 `036D` 뒤 금화 50 → 65, 안 팔린 날은 `036D` 없이 `036E`. `0374`·`0377` 물음(`15:$9F4E`): 「아니요」 면 `0375`. 「예」 면 목록이 비었을 때 `0376` 만(`0375` 없음), 아니면 `B7DD #$66` 창 뒤 `0375`. 창은 물건 이름만 한 쪽 8줄로 보이고 값·커서·「E」 가 없습니다. 9개 이상이면 위에 「→」 가 깜빡이고 A 로 다음 쪽(`JSR $C8CC`)입니다(헤드리스: 3개는 한 쪽, 11개는 8 + 3, 0개는 `0376`).

3장 그룹(`3E`·`3F`·`40`·`47`·`48`)에는 맡기는 곳(가게 종류 4)이 없어 `$61DB` 가 곧 네네의 가게 물건입니다.

### 떠돌이 상인

3장 필드(`$615A` = 2, 맵 밖)에서는 무리를 고르기 전에 rand(10) = 0 이면 たびのしょうにん(`AD`) 한 마리로 조우합니다(`18:$9D12`). 전투 곡은 `0C` 입니다([dq4-sound-format.md](dq4-sound-format.md)). 전투 시작 `12:$84B3` 이 첫 무리가 `AD` 이면 `BEQ` 로 `12:$84AA` 의 `BRK 17 5F`(`15:$BEF4`)를 부르고, 싸우지 않고 끝납니다.

| 단계 | 하는 일 |

| `15:$BEF4` | `$63`/`$64` 를 스택에 두고 둘 다 `FE`(가짜 장소) |
| rand < `10`(16/256) | 여관 `15:$BF30`: `0231` 또는 `0232`(「こんな よふけまで」, `15:$9CE5` 의 갈래) → `0233` 「ひとばん [F8]ゴールドですが」(1인 10G) → 「はい」 `0236` → `15:$A72A`(`$64` = `FE` 인 마무리) → `0237`, 골드 − 10. 「いいえ」 `0234`, `15:$A876` 이 C = 0 이면 `0235`(코드 읽기) |

## 남은 것

- 3장을 처음부터 끝까지 한 번에 돌려 사건 차례 확인. 지금은 장면마다 앞 flag 를 써 넣고 확인했습니다.
- 다리: 블록 16 은 필드 0 에 여덟 칸(`dq4field.decode`)이고 3장 다리는 (6F,4F)(서쪽 (6E,4F) 에서 동쪽 섬으로). `$6286` bit4 가 꺼져 있으면 (6E,4F) 에서 막히고 가운데가 끊긴 다리가 보이며, 켜면 (72,4F) 까지 지나가고 이어진 다리가 보임(실측). 블록 정의를 바꾸는 때(`08:$8055` 의 `$0A`/`$0B`)는 재지 않음.
- `12` 함수 `2C`(`12:$B6DD`)의 다른 그룹 갈래(`1C`·`2D`·`46`·`2E`·`30`)와 전투 뱅크에서 부르는 까닭. 북쪽 동굴 구덩이 갈래만 실측.
- 개가 따라올 때 `1E:$94C6` 의 `BRK 0D 87`(A = `24`).
- 본몰 방어구 매입 값 식(코드 읽기: 248/256 은 값 × (54 + ⌊r × 27/256⌋)/64, 8/256 은 값 × (96 + ⌊r × 33/256⌋)/64).
- 무기점: 웃돈 수락 `0332`, はじゃのつるぎ 파는 손님, 일행이 (02,1A) 에 없을 때 손님, 카운터 너머 대화 `053` → `15:$A277`, 네네와 자는 갈래, 같은 날 다시 일하기. 네네 가게 물건이 없을 때의 `0376` 이 뜨는 자리.
- 톨네코 특수 행동의 5장 실측, `$7300` bit6-4 의 뜻, 행동마다 첫 메시지 번호, `7C`·`AB`(`11:$9D3F`)의 효과, `11:$B2AC` 갈래, `01C4` 를 부르는 곳, 줍기 확률을 많은 표본으로.
- 떠돌이 상인 여관에서 잔 뒤 `15:$A72A` 의 마무리(시각·HP).
