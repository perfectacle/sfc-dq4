# DQ4(FC) 필드(세계 지도)

필드 3개의 타일 배치입니다. 디코더는 [fc/dq4/tools/dq4field.py](../tools/dq4field.py), 실험 과정은 [2026-10-25-05 일지](../journal/2026-10-25-05-field.md) 에 있습니다. 필드에 있을 때 맵 종류 `$0028` 은 `00` 입니다([dq4-ram-format.md](dq4-ram-format.md#필드-상태)).

## 필드

RAM `$65` 가 필드 번호입니다. 크기는 `0F:$D2D6`(폭)·`$D2D9`(높이)에 있습니다.

| `$65` | 크기 | 내용 |
| --- | --- | --- |
| 0 | 250×250 | 세계 지도 |
| 1 | 61×61 | 모름 |
| 2 | 42×54 | 모름 |

## 좌표 → 타일

`0F:$D244`(뱅크 0B 를 끼우고 `$D259`)가 X·Y 레지스터의 좌표로 타일 번호(0~31)를 돌려줍니다.

1. X−3 이나 Y−3 이 폭·높이 이상이면 0(`$D2AA`). 아니면 원래 좌표 그대로 찾는다.
2. 줄 레코드: `0B:$8000 + 필드 × 2` 의 포인터 + Y × 4. 4바이트 = 줄 데이터 포인터, X=80 이 시작되는 바이트 위치, 줄 끝(X=100) 바이트 위치(`$D2DC`).
3. 줄 데이터는 바이트마다 RLE 입니다(`$D326`). X 가 40~7F 나 C0~FF 이면 다음 기준점(80, 100)에서 거꾸로 읽어 빨리 찾습니다(`$D37E`).

| 바이트 | 뜻 |
| --- | --- |
| 위 3비트 0~6 | 그 타일이 (아래 5비트 + 1)칸 |
| 위 3비트 7, 아래 5비트 0~7 | 타일 7 이 (아래 5비트 + 1)칸 |
| 위 3비트 7, 아래 5비트 8~31 | 타일 (아래 5비트) 한 칸 |

`$D516` 은 필드 0 의 (C2, 2E) 를 이벤트 플래그 `$62A1` bit7 이 켜져 있을 때 타일 2 로 바꿉니다(코드 읽기).

## 필드 → 마을 입구

필드 좌표는 RAM `$42`·`$43` 입니다. 걸음마다 `08:$AEE8` 이 입구 표를 찾습니다.

| 표 | 위치 | 레코드 |
| --- | --- | --- |
| 입구 74개 | `BRK 82 E7`(뱅크 0E 함수 2 의 주소) → `0E:$BE69`, `FF` 끝 | 그룹, 필드 X, 필드 Y |
| 도착 73개 | `08:$B7F7` 의 포인터 → `08:$B7F9`, `FF` 끝 | 그룹, bit6-5 필드 번호(`$65`)·bit4-0 순번(`$64`), X, Y, 방향 |

필드 좌표가 같은 입구가 있으면 그 그룹을 `$63` 에, 같은 그룹의 첫 도착 레코드로 순번·좌표를 정합니다(`$B037`). 그룹 `45`·`18`·`0E` 는 이벤트 플래그로 순번·좌표가 바뀝니다(`$AF15`~`$AF7F`, 코드 읽기).

## 확인

- `fc/dq4/tools/dq4field.py check`: 필드 0 의 250줄 모두, 앞에서부터 푼 위치가 X=80 기준점·줄 끝 바이트 위치와 표 값이 같음.
- 필드 (A3,2E)에서 오른쪽으로 걸어 (A4,2E)에 닿자 `$63`/`$64`/`$44`/`$45` 가 `02`/`00`/`00`/`1D` 가 됨. 입구 표 `02 A4 2E` 와 도착 레코드 `02 00 00 1D 01` 그대로(`fc/dq4/tools/dq4field.py entrances`).
- `fc/dq4/tools/lua/fieldlookup.lua` 로 필드를 걸을 때 게임이 `$D259` 를 부른 147번의 (X, Y, 결과)를 기록해 `fc/dq4/tools/dq4field.py compare` 로 비교: 0 차이.

## 남은 것
