# dq4 남은 일: SFC 포팅 결과물

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

실제 SFC 기기 검증은 사용자 결정으로 작업 범위에서 제외합니다.

SFC DQ5 엔진에 넣을 포팅용 그래픽. 시작점은 [handoff.md](handoff.md). FC 원작 분석의 남은 일은 [fc/dq4/todo.md](../../fc/dq4/todo.md) 에 있습니다.

- **환경 그래픽**: [DQ5 에 넣은 환경 맵](docs/dq4-environment-format.md#dq5-엔진-삽입)의 출구·인물·이벤트 연결, とびら 명령으로 문 열기 실측, 간판 바탕색, 바꾼 맵에서 전투 뒤 물 애니메이션 실측, 다른 지역·던전·필드 지형으로 확대.
- **게임 안 창 한글**: [조사](docs/dq4-window-text-format.md) 결과 창 글자는 가나 칸 100칸 남짓을 한글 칸으로 돌리는 길이 유력합니다. 창 글자 크기 결정(목록은 8점 높이 글꼴이 칸을 절반만 씀), 이름 자리 표시 코드 가르기, 이름 목록과 메시지가 함께 뜨는 장면 실측, 이름을 붙여 그리기가 남았습니다.
- **메뉴 메시지 후속**: [메뉴 메시지](docs/dq4-menu-format.md#메뉴-메시지)를 옮긴 뒤 원래 보행 메시지 자리 `07:D77C`~`0C:8020` 을 색인 밖에서 읽는 코드가 있는지, 글자 그림 뒤 `08:F277`~`0C:8020` 의 쓰임.
- **메뉴 한글화의 확인**: 창 `62` 가 게임 안에서 쓰이는지, 공용 창 자리 `7E:1AC0`~`1AEF` 를 실행하지 않은 코드가 쓰는지.
- **스프라이트 나머지**: [스프라이트 규격](docs/dq4-sprite-format.md)의 9명 중 라이안 정면만 사용자 확인. 나머지 8명과 측면·후면·보행의 확인, 복장 색 대조(크리프트·주인공 모자, 미네아 띠), `_step` 보행 자세를 손으로 그리기. 마을 인물·몬스터(슬라임 외)는 아직 없음.
- **정면 시안 16×24**: [72번 일지](journal/2026-10-25-72-sprite-drafts.md)의 톨네코·주인공 정면을 MesenCE 필드에서 확인하고 `dq4sprites.py` 와 합치기. 손으로 그리는 방식의 품질 한계 때문에 DQ5 정식 인물 조립·AI 도트 생성·사람이 그리기 중 제작 방식 정하기.
- **포팅용 그래픽 나머지**: 타이틀·일러스트 보존([그래픽 핸드오프](handoff.md)). DQ5 형식을 이용한 [첫 롬 삽입](docs/dq4-rom-assets-format.md) 이후 인물 고유색을 보존하는 팔레트 배정과 모든 방향·보행의 연결, 채택 미확인인 샘플 맵의 재검토·원작 배치·통행·출구·이벤트 연결, 일러스트의 게임 내 사용 여부 결정.
- **사운드 포팅**: [사운드 포팅](docs/dq4-sound-port-format.md)은 성 곡 하나를 사용자 청취까지 마쳤고, 마을·필드 곡은 맵에서 재생까지 확인했습니다(청취 대기). 전투 곡과 팡파르·효과음, 8KB 넘는 곡 줄이기, 맵 전환 페이드의 청취·같은 곡·전투 복귀·연속 이동, 늘 두는 곡 교체 때 샘플 전송, 최신 이름 입력 빌드 위에서의 회귀가 남았습니다.
- **타이틀 서곡의 후속 확인**: [타이틀 서곡](docs/dq4-overture-format.md)은 2026-10-26 사용자 청취로 채택했습니다. DQ5 의 「새 게임 → 프롤로그 → 로고(시퀀스 `15`, `0F:D93A`)」는 DQ4 흐름(타이틀 → 모험의 서 → 게임)으로 바꿀 때 장면째 정리합니다([게임 시작 뒤의 서곡](docs/dq4-overture-format.md#게임-시작-뒤의-서곡)).
- **채택된 타이틀의 후속 검증**: [용·구름 애니메이션](docs/dq4-title-animation.md)은 2026-10-26 부제 얼룩·획 간격과 구름 변형까지 사용자 확인을 받았습니다([39번 일지](journal/2026-10-26-39-title-cloud-variation.md)). 게임 후반 전체의 동작 검증은 남아 있습니다.
