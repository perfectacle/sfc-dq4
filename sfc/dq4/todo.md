# dq4 남은 일: SFC 포팅 결과물

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

실제 SFC 기기 검증은 사용자 결정으로 작업 범위에서 제외합니다.

SFC DQ5 엔진에 넣을 포팅용 그래픽. 시작점은 [handoff.md](handoff.md). FC 원작 분석의 남은 일은 [fc/dq4/todo.md](../../fc/dq4/todo.md) 에 있습니다.

- **환경 그래픽**: [DQ5 에 넣은 환경 맵](docs/dq4-environment-format.md#dq5-엔진-삽입)의 출구·인물·이벤트 연결, 필드 지형을 DQ5 필드 엔진에 넣기(그림과 FC 필드 비교 맵은 있음), 던전·탑 시트의 벼랑 모서리·비탈 블록 따로 그리기(지금은 재질 벽), 나머지 맵 삽입(뱅크 01 문 물체 자리가 다 찼고, 맵 레코드는 뱅크 3F 에 약 17KB 남음), 열쇠 아이템을 DQ4 열쇠에 맞추기(잠금 0·1·2 는 とびら 로 실측함).
- **게임 안 창 한글**: [조사](docs/dq4-window-text-format.md) 결과 창 글자는 가나 칸 100칸 남짓과, [BG3 타일맵을 옮겨](docs/dq4-window-text-format.md#bg3-타일맵-옮기기) 비운 `180`~`1FF` 128칸을 한글 칸으로 씁니다. 필드·전투 상태 창의 주인공 이름은 [상태 창 이름](docs/dq4-window-text-format.md#상태-창-이름)으로 찍었습니다. つよさ·「누구」 고르기 창의 이름(`04:B79B`)도 같은 렌더러로 찍었습니다. 전투 메시지 이름과 쓰러짐 등의 이름 색도 찍었습니다. 도구 목록은 [창 글자](docs/dq4-window-text-format.md#창-글자) 엔진(이름 표 → Galmuri9 그림, 자리 묶음 슬롯, NMI 전용 대기열)으로 한글이 됐고, 주문 목록(필드·전투)과 명령 창·つよさ·さくせん·「どうする」·전투 명령 창·창 제목의 고정 문구도 켰고, 전투 몬스터 목록·전투 도구 창·가게 창도 켰고, 강함 보기 라벨·성별, 교회·맡기는 곳·예/아니요 창도 켰고, 나머지 고정 문구와 메시지 동안 명령 창 밖의 창 글자가 비는 것을 풀 가나 칸 회수가 남았습니다. 석 자 출력 `D1` 의 나머지 창(강함 보기 성별 밖에는 흔한 장면에서 불리지 않음), 주문 연출이 전투 이름 칸 `1D0`~ 을 덮는지, ベネット 지도 장면 뒤 이름 다시 그리기, 나머지 한글 타일 그려 넣기, BG3SC 를 직접 바꾸는 특수 장면과 마을 6곳 이벤트 전투의 실측, 창 글자 크기 결정(목록은 8점 높이 글꼴이 칸을 절반만 씀), 이름 자리 표시 코드 가르기, 이름 목록과 메시지가 함께 뜨는 장면 실측, 이름을 붙여 그리기가 남았습니다.
- **메뉴 메시지 후속**: [메뉴 메시지](docs/dq4-menu-format.md#메뉴-메시지)를 옮긴 뒤 원래 보행 메시지 자리 `07:D77C`~`0C:8020` 을 색인 밖에서 읽는 코드가 있는지, 글자 그림 뒤 `08:F277`~`0C:8020` 의 쓰임.
- **메뉴 한글화의 확인**: 창 `62` 가 게임 안에서 쓰이는지, 공용 창 자리 `7E:1AC0`~`1AEF` 를 실행하지 않은 코드가 쓰는지.
- **스프라이트 나머지**: [스프라이트 규격](docs/dq4-sprite-format.md)의 9명 중 라이안 정면만 사용자 확인. 나머지 8명과 측면·후면·보행의 확인, 복장 색 대조(크리프트·주인공 모자, 미네아 띠), `_step` 보행 자세를 손으로 그리기. 마을 인물·몬스터(슬라임 외)는 아직 없음.
- **정면 시안 16×24**: [72번 일지](journal/2026-10-25-72-sprite-drafts.md)의 톨네코·주인공 정면을 MesenCE 필드에서 확인하고 `dq4sprites.py` 와 합치기. 손으로 그리는 방식의 품질 한계 때문에 DQ5 정식 인물 조립·AI 도트 생성·사람이 그리기 중 제작 방식 정하기.
- **포팅용 그래픽 나머지**: 타이틀·일러스트 보존([그래픽 핸드오프](handoff.md)). DQ5 형식을 이용한 [첫 롬 삽입](docs/dq4-rom-assets-format.md) 이후 인물 고유색을 보존하는 팔레트 배정과 모든 방향·보행의 연결, 채택 미확인인 샘플 맵의 재검토·원작 배치·통행·출구·이벤트 연결, 일러스트의 게임 내 사용 여부 결정.
- **사운드 포팅**: [사운드 포팅](docs/dq4-sound-port-format.md)은 성 곡과 마을·필드 곡을 사용자 청취까지 마쳤습니다(마을·필드 2026-10-27 「다 좋다」). 전투 곡 `1E` → `17` 은 곡 뒤 샘플 전송으로 필드 전투 재생·전투 뒤 필드 복귀까지 확인했고 청취(`work/sound/listen/v7-battle.wav`)가 남았습니다. 시퀀스를 되풀이·부르기로 묶어 50곡 합 272,041 → 246,762바이트, 전투 곡 시작을 158 → 145프레임으로 줄였지만 원래(7)와는 전송 길의 한계로 멉니다(전투 시퀀스를 늘 두거나 곡 앞 샘플을 줄이는 편곡이 필요). 조사 대응표대로 [곡 자리 45곳](docs/dq4-sound-port-format.md#곡-자리-45곳-한꺼번에-넣기)에 NDS 곡을 한 롬으로 넣었습니다(샘플 나눠 쓰기로 149개, 소리 뱅크 `6A`~`6F`·`72`~`7D`, 곡 묶음 표 523바이트). 남은 것: 전투 `17`·레벨 업 `21` 을 다시 늘 두기([조사](docs/dq4-sound-port-format.md#전투레벨-업을-다시-늘-두기조사): 늦게 시작해도 괜찮지 않은 곡만 곡 자리마다 근거·실측으로 정해 늘 두고, 모자라면 더 묶은 뒤 덜 들리는 부분을 하나씩 빼며 단계마다 `work/sound/listen/v10-<자리>-step<N>-<뺀 것>.wav` 로 청취), 새 42곡 청취(`work/sound/listen/v9-*.wav`), 미리듣기 검사 실패 30곡(목소리마다 첫 KON 이 0~3프레임 나뉘어 나옴, 몇 초짜리 곡의 속도 비, `09` 에서 한 번 빠진 KON), 짝이 추정인 `07`(카지노)·`21`(레벨 업, 늘 두는 목록에서 빠짐) 실측, 곡 중 늘 두지 않는 효과음 `42`(샘플 10.9KB)가 28곡에서 울리지 않음(보고서 `effects_without_room`, 포팅 스크립트가 부르면 예산을 빼야 함), 곡이 목소리 7개를 다 쓸 때 효과음이 목소리 6 을 씀, 밤 곡 `30`·`31` 을 고르는 훅과 새 번호 `47`~ 확장(ピサロ·BARON 곡 NDS `1A`·`1B`·`33`·`32`), 필드 곡을 장·선두로 고르는 코드, 4장 전투 `1B`·전투 중 교체 `1C`. 새 압축으로 쉼 앞 KOF 가 줄어든 마을·필드와 `work/sound/listen/v8-battle-compact.wav` 의 청취, 효과음, 전투 중 효과음과 곡 뒤 샘플 전송의 겹침, 맵 전환 페이드의 청취·같은 곡·전투 복귀·연속 이동, 최신 이름 입력 빌드 위에서의 회귀도 남았습니다.
- **타이틀 서곡의 후속 확인**: [타이틀 서곡](docs/dq4-overture-format.md)은 2026-10-26 사용자 청취로 채택했습니다. DQ5 의 「새 게임 → 프롤로그 → 로고(시퀀스 `15`, `0F:D93A`)」는 DQ4 흐름(타이틀 → 모험의 서 → 게임)으로 바꿀 때 장면째 정리합니다([게임 시작 뒤의 서곡](docs/dq4-overture-format.md#게임-시작-뒤의-서곡)).
- **채택된 타이틀의 후속 검증**: [용·구름 애니메이션](docs/dq4-title-animation.md)은 2026-10-26 부제 얼룩·획 간격과 구름 변형까지 사용자 확인을 받았습니다([39번 일지](journal/2026-10-26-39-title-cloud-variation.md)). 게임 후반 전체의 동작 검증은 남아 있습니다.
