# 2026-10-29-07: 공용 창 62 는 게임 안에서 열리나

타이틀 메뉴와 게임이 함께 쓰는 예/아니요 창 `32`·`62` 가운데, `62`(いいえ / はい)가 게임 안에서 열리는지와 공용 자리 `7E:1AC0`~`1AEF` 를 다른 코드가 쓰는지 쟀습니다. 결과는 [공용 창](../docs/dq4-menu-format.md#공용-창-3262)에 있습니다.

## 1. 동적으로

선실 파파스의 대화 번호(`7E:36EB`)를 `00`~`3F` 로 바꿔 가며 A 와 아래를 섞어 열 번 고르고, 무작위 입력 여섯 벌(선실 넷, 09/00 전투 둘)을 돌렸습니다. 창을 여는 `04:9C52` 의 A(레코드 주소)와 `WRAMWATCH=1AC0-1AEF` 를 기록했습니다.

```
04:9C52 A=1AD1 (창 62)   0 실행
04:9C52 A=1AC0 (창 32)   20 실행(대화 01·03·05·06·07·08·0A·0B … 와 무작위 둘)
1AC0~1AEF 를 쓴 PC      60:8253 하나(맵을 불러올 때 원래 레코드를 복사하는 우리 MVN)
```

## 2. 정적으로

창 번호는 `04:9C3F` 가 `$0A00` 에서 읽고, 레코드 첫 바이트 bit7 이면 `+2` 의 창으로 넘어갑니다. 창 표의 레코드를 훑으니 `84`·`85` 가 `32` 로 넘어가고 `62` 로 넘어가는 레코드는 없었습니다. 롬에서 `LDA #$62` 뒤에 `$0A00` 에 쓰는 코드도 없었습니다.

## 남은 것

- 이벤트 장면·후반 장면(저장·전멸 등)에서 `62` 가 열리는지
