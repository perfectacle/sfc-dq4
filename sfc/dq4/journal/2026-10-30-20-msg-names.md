# 2026-10-30-20: 메시지의 물건·주문 이름을 한글로

조사 코드를 넣은 뒤에도 메시지의 물건·주문 이름(`{100A}`·`{100B}`)은 가나로 찍혔고, 그 뒤 조사는 늘 받침 없는 쪽이었습니다. 창 글자 작업이 이미 이름을 adopt 표와 이어 두었으므로, 그 짝을 메시지 길에도 썼습니다. 명세는 [조사 코드의 이름](../docs/dq4-josa-format.md#이름)에 있습니다.

## 1. 이름이 찍히는 길

물건 이름 처리기(`24:84DA`)는 `JSR $89A8` 뒤 공통 `24:84C3` 으로 갑니다. 처리는 다음 차례입니다.

1. `89A8` 이 종류 5 를 `$43` 에 두고, `24:889F` 로 번호를 `$F5` 에서 꺼내 밉니다.
2. `BRK 88` 로 이름 바이트를 `$01~` 에 모읍니다.
3. `24:A7B6` 이 바이트를 `24:B270` 표로 메시지 코드로 바꿔 대기열에 쌓습니다.

이름 바이트는 1바이트라 한글 글자 코드(16비트)를 담을 수 없습니다. 그래서 종류를 고르는 공통 자리 `24:89BB` 에 훅을 걸어, 한글 이름이 있으면 바이트 길을 건너뛰고 대기열에 글자 코드를 바로 씁니다.

## 2. 처음 판에서 고친 것

- **복사 고리 거리**: `BNE` 거리를 `F2` 로 적어 `LDA` 한가운데로 갔습니다. 손으로 다시 세어 `F0` 으로 고치고 시험을 더했습니다.
- **X 폭**: 원래 길로 돌아갈 때 훅이 `REP #$30` 으로 X 폭을 바꾼 채였습니다. 훅 첫머리에 `PHP` 를 두고, 돌아가기 전에 `PLP` 합니다.
- **몬스터 제외**: 몬스터 이름 코드 `{100F}` 는 이름 뒤에 Ａ·Ｂ 를 붙입니다. 훅이 그 뒤를 건너뛰므로 몬스터는 넣지 않았습니다.

## 3. 확인

시험 서술(커밋하지 않음)에 `{100A}{을} 샀다 / {100B}{은} 주문` 을 넣었습니다. 서술이 뜨기 전 `$F5`·`$F6` 에 번호를 써 넣는 Lua 로 띄웠습니다. 「구리 검을 샀다 / 베기라곤은 주문」이 나왔습니다. 주문 번호는 써 넣기가 메시지가 뜬 뒤에도 이어져 섞였습니다. 한글 이름 뒤 조사는 받침대로 골라졌습니다.

한글 물건 이름이 9글자까지라 시스템 메시지의 물건 칸을 9칸으로 다시 세어, 넘친 네 줄을 둘로 나눴습니다.

## 남은 것

- 실제 장면(상자·도구 사용)에서 물건 이름 메시지 띄우기.
- 몬스터 이름.
