# 2026-10-29-14: 타이틀 구름 모서리·로고 둘레·부제 정리

사용자가 MesenCE 로 타이틀을 보다가 어색한 곳을 짚어 왔습니다. 성 왼쪽 아래 구름이 네모나게 잘린 자국, 로고 둘레의 잡티와 띠, 그리고 부제 「인도받은 자들」의 뭉개진 글자와 좌우가 다른 문양입니다. 결과 규격은 [타이틀 애니메이션](../docs/dq4-title-animation.md)에 반영했고, 2026-10-29 사용자가 실제 화면을 보고 채택했습니다.

## 1. 성 왼쪽 아래의 네모난 자국

성 아래 바위를 지우는 영역이 직사각형 x=180~207, y=185~223 이었습니다. 그래서 남은 구름 받침이 x=208 에서 세로로, y=185 에서 가로로 곧게 잘렸습니다. 직사각형을 다각형 `CORNER_CUT` 으로 바꿔 (195,176)에서 (224,201)까지 비스듬히 비우고, 원 세 개 `CORNER_LOBES` 로 받침 끝을 둥근 구름 덩이로 남겼습니다. 되살아난 27픽셀에 바위의 짙은 색이 없는 것을 색 번호로 확인했습니다.

## 2. 로고 둘레의 하늘 픽셀

글자 마스크는 원본 그림에서 로고 둘레를 넉넉하게 땄습니다. 그래서 검은 외곽선 바깥의 원본 하늘 픽셀이 고정된 채 남았고, 하늘이 흐르면 「드」 왼쪽에서는 잡티로, 칼 결정 오른쪽에서는 노랑·분홍 띠로 보였습니다.

- `OUTLINE_TRIMS`: 두 상자 안에서 행마다 가장 바깥의 어두운 외곽선(밝기 60 미만) 너머를 뺍니다. 처음에는 결정 몸통이 세 행에서 통째로 지워졌습니다. 그 행의 외곽선이 어두운 색이 아니었기 때문이라, 위아래 행의 경계를 함께 보게 고쳤습니다.
- `SKY_BOXES`: 「곤」과 「퀘」 사이 틈과 「스」 꼭대기에서 보라·분홍 계열만 뺍니다.
- y=170 위에서 다른 글자 픽셀과 이어지지 않은 1~3픽셀 점도 뺍니다.

로고 전체에 위·아래·좌·우 정리를 일괄로 거는 방법과 하늘에 흔한 색을 따라 번지는 방법도 시험했습니다. 둘 다 글자 안쪽까지 깎여서 버렸습니다.

## 3. 부제를 다시 찍기

원래 부제는 글꼴이 아니라 이미지 생성 그림 속 글자를 256×224 로 줄인 것입니다. 채움에 4~5색, 외곽선에 4색이 섞여 자글자글했습니다. 좌우 문양도 길이와 보석 위치가 달랐습니다. 시안을 여러 차례 합성해 사용자에게 보였습니다.

| 시안 | 결과 |
| --- | --- |
| Galmuri11 Bold + 그라데이션 + 그림자 | 너무 크고 이질적이라 탈락 |
| 원래 글자 모양에 색만 3색으로 정리 | 「들」처럼 2px 획이 틈 없이 쌓여 읽기 어려움 |
| 위 + 음절 사이 2px 벌리기 | 간격이 어색해 탈락 |
| Galmuri9, 흰 채움·남색 외곽선·맨 아래 1줄 연청 | 깔끔하나 위 로고에 비해 가늘다는 의견 |
| 위 + 획을 오른쪽으로 1px 넓히고 1줄 내림 | 채택 |

채택본은 `dq4titlesubtitle.py` 가 만듭니다. Galmuri9 의 각 획을 오른쪽으로 1px 넓히되, 1px 틈을 닫게 되는 칸은 넓히지 않습니다. 글자를 그냥 덧칠하면 「자들」의 틈이 메워져 뭉개졌기 때문입니다. 문양은 왼쪽만 그리고 글자 가운데를 축으로 뒤집어 좌우를 픽셀 단위로 맞췄습니다.

결과 그림 `title-subtitle.png` 는 커밋해 두므로, 타이틀 빌드에는 글꼴이 필요 없습니다. 오른쪽 문양 끝이 성 모서리 정리 영역에 깎인 일이 있어, 모서리 정리는 글자 픽셀을 지우지 않게 했습니다.

## 남은 것

- 메뉴 빌더 `dq4menupatch.py` 는 서곡 롬 SHA-1 `ed46db6d…` 만 받습니다. 그런데 현재 채택 타이틀로 만든 서곡은 이번 변경 전에도 그 해시가 아니었습니다(`ccfebebc…`). 그래서 확인용 통합 롬은 이 검사만 로컬에서 바꿔 만들었습니다. 서곡·메뉴 기준 해시를 다시 정하는 일이 남았습니다.
- 실제 SFC 기기에서는 확인하지 않았습니다.
