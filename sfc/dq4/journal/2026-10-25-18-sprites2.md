# 2026-10-25-18: DQ5 실측 규격으로 다시 그린 인물 스프라이트

반려됐던 라이안 스프라이트를 버리고, SFC DQ5 필드 인물을 픽셀 단위로 실측한 뒤 그 격자 규칙 안에서 DQ4 인물 9명을 처음부터 그렸습니다. 규격과 도구는 [DQ4 포팅용 인물 스프라이트 규격](../docs/dq4-sprite-format.md)에 정리했습니다. 라이안 정면은 사용자가 「훨씬 낫다」 고 확인했고, 나머지는 같은 규칙으로 그린 1차 시안입니다.

## 1. 반려 시안의 진짜 문제 찾기

[그래픽 핸드오프](../handoff.md)는 눈·광택을 문제로 적었지만, 원작 인물을 실제로 재 보지는 않았습니다. 먼저 DQ5 주인공의 도트를 꺼내 봤습니다. 이전 실험이 남긴 VRAM·OAM·CGRAM 덤프에서 OAM 슬롯 0~7 의 8×8 OBJ 를 16×24 상자로 되돌렸는데, 처음엔 얼굴이 없는 그림이 나왔습니다. 슬롯 2·3 이 같은 자리에 겹쳐 있고 OAM 은 낮은 슬롯이 위에 오는데, 슬롯 순서대로 덮어써서 몸(슬롯 3)이 얼굴(슬롯 2)을 가린 것입니다. 역순으로 겹치자 얼굴이 나왔습니다.

```
.....111111.....   폭 14, 높이 17
....1BBBBAA1....   터번 7줄, 얼굴 4줄, 몸 6줄
...1BBBBBBAA1...
...1ABBBBAAA1...
...1BBAAABBA1...
...1ABBBBBAA1...
...1AAAAAAAA1...
.11114133131111.   눈 = 1 픽셀 폭, 2줄, 6열·9열
..113414413311..
.11113444331111.
..11B113211B11..
```

반려 시안은 16×24 를 꽉 채워 원작보다 7줄 컸고, 15색에 윤곽이 여러 색이었습니다. 원작은 8색이고 윤곽·머리카락·눈이 한 색입니다. 눈 모양 이전에 **크기와 색 수**가 달랐던 것입니다.

## 2. 보행 프레임 규칙 재기

`sfc/dq4/tools/lua/dq4objdump.lua` 로 네 방향으로 걷다 멈춘 순간을 덤프하고, 걷는 동안 4프레임마다 덤프한 것을 중복 제거해 자세 수를 셌습니다. 방향마다 두 장뿐이고 머리는 고정, 몸(16~21행)의 망토 주름과 손만 바뀝니다. 정지 자세는 둘 중 하나입니다. 반려 시안의 「정지·왼발·오른발」 세 자세는 원작에 없는 구조였습니다.

## 3. 라이안 정면을 격자에서 다시 그리기

생성 이미지를 축소하지 않고 `sfc/dq4/tools/dq4sprites.py` 의 문자 행렬에 직접 그렸습니다. DQ5 규칙(머리 폭 10, 몸 폭 12~14, 윤곽 1색, 눈 1×2 를 6·9열에, 바닥 윤곽 없음, 2프레임)을 지키고 그 안에 DS 그림의 복장(분홍 투구와 붉은 깃, 콧수염, 은 어깨, 금 벨트, 붉은 망토, 회색 장화)만 넣었습니다. 높이는 투구 깃 때문에 19줄입니다. 콧수염은 눈 아래 한 줄을 띄운 뒤 6픽셀 폭으로 두고 양끝을 한 줄 내려 눈과 분리했습니다.

`sfc/dq4/tools/dq4spritelab.py compare` 로 DQ5 주인공 네 방향과 같은 배경(주인공 OBJ 를 숨기고 찍은 필드 화면)·같은 배율(8배)에 나란히 놓고 봤습니다. 그다음 `sfc/dq4/tools/lua/dq4sprite.lua` 로 실제 DQ5 필드에서 VRAM·OAM·팔레트를 바꿔 띄워 네 방향 180프레임 자동 보행을 확인했습니다.

![DQ5 주인공과 라이안을 같은 배경에, 아래는 자동 보행 화면](../images/dq4-sprites-field.webp)

```
frame=30 x=86 y=56 direction=10
frame=60 x=89 y=56 direction=10
frame=90 x=90 y=59 direction=40
frame=120 x=87 y=60 direction=20
frame=150 x=87 y=56 direction=80
```

## 4. 같은 규칙으로 9명 그리기

사용자가 정면 방향을 확인한 뒤 같은 규칙으로 호이미 슬라임, 아리나·크리프트·브라이, 토르네코, 마냐·미네아, 주인공을 그렸습니다. 방향마다 정지 자세만 손으로 그리고, 보행 자세는 `_step` 이 머리를 고정한 채 몸 명암을 좌우로 뒤집고 발 줄을 옮겨 만듭니다(라이안과 슬라임은 손으로 그림). `sfc/dq4/tools/dq4graphics.py` 는 이제 9개 시트를 모두 4bpp CHR·팔레트로 내보내고 `--check` 를 통과합니다.

![DQ4 인물 9명](../images/dq4-sprites-gallery.webp)

## 틀렸던 것들

- OAM 을 슬롯 순서대로 겹치면 뒤 슬롯이 앞 슬롯을 덮습니다. 실제 우선순위는 반대입니다.
- 주인공 OBJ 를 숨긴 배경 화면을 찍을 때 `startFrame` 에서 OAM 을 바꾸고 같은 프레임 번호의 `endFrame` 에서 찍으면 한 프레임 늦어 주인공이 남습니다. 두 프레임 전부터 숨기고 찍었습니다.
- 주인공 모자 챙을 머리카락보다 넓게 그리면 버섯처럼 보였습니다. 챙을 모자 폭에 맞추고 머리카락이 챙 밖으로 나오게 했습니다.

## 남은 것

- 라이안 외 8명과 측면·후면·보행의 채택 확인, 복장 색 확인(DS 그림 대조).
- `_step` 보행 자세를 라이안처럼 손으로 그리기.
- DQ5 인물 그래픽의 롬 위치·압축·VRAM 배치(dq5 트랙)를 풀어야 IPS 로 옮길 수 있습니다.
