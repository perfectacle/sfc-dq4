# 2026-10-31-30: 상자·열쇠 문·여관·교회·가게 갈래 메시지를 게임에서 띄웠다

[2026-10-31-24](2026-10-31-24-shop-inn-church-text.md)에서 한글로 덮은 시스템 메시지 가운데 게임에서 보지 못한 장면(보물상자, 열쇠 문, 교회 저주 풀기와 밤 인사, 여관 돈 모자람과 안주인, 가게의 마차·관 갈래, 일행이 둘일 때의 「누가」 창)을 1장 롬에서 띄웠습니다. 일본어로 남은 것은 없었고, 방어구점이 물건 이름을 되묻는 말이 짧은 이름에도 줄을 바꾸던 것과 도구점·방어구점이 함께 쓰는 문장의 말투를 고쳤습니다. 쓰는 곳을 몰랐던 `1CC` 도 찾아 덮었습니다. 결과는 [조사 코드 형식 문서](../docs/dq4-josa-format.md#검증)에 있습니다.

## 1. 장면 만들기

1장 이어 걷기 세이브스테이트(바트랜드 성 앞 `36/00`)에서 `dq5warp.lua` 를 「어디서나」 방식으로 돌려 시설 앞으로 옮기고, 같은 실행 안에서 `TEST` 입력으로 말을 걸었습니다. `dq5warp.lua` 를 감싼 작은 Lua 가 `24:8BAF` 의 A(메시지 번호)를 적고 첫 메시지부터 20프레임마다 화면을 찍었습니다. 서는 칸은 `dq4npccheck.talk_side` 로 구했고, 「어디서나」 는 목적지보다 한 칸 아래에 내리므로 `TO` 의 y 를 하나 줄였습니다.

상태는 `dq5warp.lua` 의 `SET`·`POKE`·`PARTY`·`WAGON` 으로 만들었습니다.

```
금화 0           SET 2019=00
밤               POKE 7E075E=F0;7E075F=00
주인공 저주      POKE 7E2041=88   (일행 레코드 +1 의 & 0C)
일행 둘          PARTY=05         (호이민)
호이민 죽음      SET 206B=00      (+1 bit7 꺼짐)
마차 안 동료     PARTY=05,05,05 WAGON=1   (넷째가 마차 안)
소지품 가득      SET 2056~2061    (+16~+21 열두 칸)
```

## 2. 여관·교회

이무르(`37/00`) 여관에서 금화 0 이면 `070 072 074 073`, 밤이면 `071` 로 시작했습니다. 교회는 밤에 `080` 두 쪽 뒤 고르기 창이 떴습니다. 「저주 풀기」 는 저주가 없으면 `0A4 0A6 0AC`, 저주가 있으면 `0A4 0B0 0A8 0AC`, 금화 0 이면 `0B0` 뒤 `0B2` 였습니다.

여관 안주인과 교회 수녀의 문장은 1장에서 나오지 않습니다. 처리기를 고르는 대화 번호 표 `06:DBDB` 에서 여관은 `06`, 교회는 `05` 이고, 안주인은 `10`, 수녀는 `0F` 입니다. 1장 그룹의 인물은 `npc-report.json` 에서 대화 번호가 `01`~`03`·`05`·`06` 과 `11` 이상뿐이었습니다. 그래서 시험 롬에서 표의 여관 칸을 `E375`(`10`), 교회 칸을 `E036`(`0F`)으로 바꿔 띄웠습니다.

```
안주인  077 079 07C 07D / 돈 모자람 077 079 07B 07A / 밤 078
수녀    07F 083 08A 085 087 089 / 밤 081 / 저주 07F 0A5 0B1 0A9 0AD / 돈 모자람 0B3 / 저주 없음 0A7
```

## 3. 1CC

`1CC`「その方向には　ダレモイナイ。」 는 대화 번호 `000` 의 처리기 `06:DBFD` 가 띄웁니다([DQ5 대화 형식](../../dq5/docs/dq5-text-format.md#특수-기능-06dbd2)). 1장 인물에는 `000` 이 없어 나오지 않지만, 뒤 장에서 인물을 옮길 때 쓰일 수 있어 「그 방향에는 아무도 없다.」 로 덮었습니다. 원문에 `{1006}` 이 없어 대사(`SPEECH`)에 넣었고, 표의 여관 칸을 `DBFD` 로 바꾼 롬에서 ＊「 가 붙어 나왔습니다.

## 4. 가게 갈래

이무르 방어구점에서 일행 둘로 「사기」 를 고르면 `011` 뒤 「누가」 창(ああああ·호이민)이 떴고, 「팔기」 는 `045` 뒤 같은 창이었습니다. 빈손인 호이민을 고르자 `049` 였습니다. 죽은 호이민에게 사 주면 `02D`(관), 마차 안의 넷째에게 사 주면 `029`(마차)였습니다.

소지품이 가득한 주인공에게 사 주면 혼자일 때 `019 01D`, 둘일 때 `019 014` 뒤 다시 「누가」 창이었습니다. 도구점도 `018 014` 로, 두 가게가 `014` 를 함께 썼습니다. `015` 가 장비해 줌 서술이라 방어구점 몫이 비어 있는 것입니다. `014` 는 도구점 말투(「가지시겠어요?」)였으므로 두 가게에 맞게 「다른 분이 가지시겠습니까?」 로 바꿨습니다.

방어구점의 `009`「{I} 말씀이시군요.」 는 `{I}` 를 9칸으로 세면 14칸을 넘어 줄이 바뀌었고, 「체인 메일」 같은 짧은 이름도 혼자 한 줄에 찍혔습니다. `{I}` 뒤에는 4칸만 남으므로 `009`·`051` 을 「{I}입니까?」 로 줄였습니다. 「입니다」 는 받침과 상관없이 붙어 조사 코드가 필요 없습니다. 게임에서 「체인 메일입니까? 감사합니다.」 는 첫 문장이 한 줄에 들어갔고, 팔기에서도 「천 옷입니까?」 였습니다.

## 5. 보물상자·열쇠 문

바트랜드 성(`36/01`)의 상자 앞에 서서(`dq4chestcheck.stand`, 위를 봄 `31E0` = `88`) 「조사」 를 골랐습니다. 이 맵으로 「어디서나」 이동하면 1장 연출 깃발 `7E:2199` & `01` 이 꺼진 세이브스테이트라 연설 `1D1` 이 다시 나와서, 깃발을 켜고 들어갔습니다.

```
물건      131 12E 132
금화      131 14C                       (160골드)
가득·혼자 131 12E 14A 13D 13F 140       (곤봉을 버리고 받음)
가득·둘   131 12E 13C 13D 13E 13F 140   (둘 다 가득). 호이민 칸이 비면 132 로 호이민이 받음
```

1장 상자에는 몬스터가 없어, 내용물을 읽는 `12:F43B` 에 들어올 때 `7E:1E73` 을 `FFFE`·`FFFD` 로 바꿨습니다. `13A`(미믹)·`139`(식인 상자) 뒤 전투가 걸렸고, 레벨 1 주인공이 져서 바트랜드 성 앞 교회로 돌아오자 `0B7` 이 나왔습니다.

열쇠 문은 1장에 FC 도둑의 열쇠 문(`95`, DQ5 잠금 1) 하나가 `36/01` (6,23)에 있었습니다. 아래 칸에서 「문」 을 고르자 `187`「열쇠를 가지고 있지 않다.」 였습니다.

## 틀렸던 것들

- 가게에서 「누가」 창을 고르려고 `011` 뒤에 A 를 한 번 눌렀더니 주인공이 골라졌습니다. `011` 은 ▼ 를 기다리는 메시지라, 글이 다 찍히기 전의 A 는 글을 끝까지 찍기만 하고 다음 A 가 창을 엽니다. 300프레임 기다린 뒤 A 로 창을 열고 아래를 눌러야 호이민이 골라졌습니다.
- 교회 고르기 창은 둘째 쪽에서 A 를 누르면 바로 열립니다. A 를 하나 더 넣었더니 「기도하기」 가 골라졌습니다.

## 남은 것

- `188`(열쇠가 맞지 않음)은 1장에 마법의 열쇠 문(FC `96`)이 없어 띄우지 않았습니다. `189`·`18A` 는 FC 문을 옮긴 잠금에서 나오지 않습니다.
- 도구점이 귀한 물건을 받지 않는 `054`~`057` 은 1장에 팔 수 없는 물건이 없어 띄우지 않았습니다.
- 「누가」 창을 띄운 동안 메시지 창 셋째 줄에 물건 창의 이름과 깨진 글자 조각이 비칩니다(창 글자 쪽 남은 것).
- 맡기는 곳 대사(`0B9`~`0E7`)는 아직 일본어입니다.
