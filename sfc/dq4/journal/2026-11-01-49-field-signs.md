# 2026-11-01-49: 필드 팻말 읽기

1장 바트랜드 성 바로 아래 팻말에 「はなす」 를 고르면 「그 방향에는 아무도 없다.」 가 떴습니다. FC 는 「あやしいものを　みつけたら　おしろまで！　バトランドおう。」 를 띄웁니다. DQ5 엔진이 팻말을 읽는 길을 실측하고, 그 길의 표를 FC 필드 팻말로 바꿔 다섯 팻말 모두 FC 와 같은 방향 조건으로 읽히게 했습니다. 결과는 [dq4-field-format.md 「팻말」](../docs/dq4-field-format.md#팻말)에 있습니다.

## 1. FC 규칙

FC 쪽은 이미 풀어 두었습니다([FC 블록 형식](../../../fc/dq4/docs/dq4-block-format.md#앞-칸을-보는-명령)). 「はなす」·「しらべる」 모두 앞 칸 속성이 `A8` 이면, 아래를 보고 있을 때 「たてふだを　みた。」(031B, 뒷면이라 못 읽음), 아니면 03B8 「たてふだを　よんだ。」 뒤 팻말 표 `1E:$BBB6` 에서 좌표로 찾은 메시지입니다. 필드 쪽 표는 5개입니다(`fc/dq4/tools/dq4block.py tables`).

```
{table: 01, x: A6, y: 2F, msg: [3D9]}   あやしいものを　みつけたら / おしろまで！　バトランドおう。
{table: 01, x: 6C, y: 62, msg: [3DA]}   はしは　みんなのもの。 / こわさないように　しましょう。
{table: 01, x: 35, y: 3B, msg: [3DB]}   ここより　ひがし　テンぺのむら。
{table: 01, x: 9E, y: 16, msg: [3DC]}   もりの　なかでは / あそばないように。
{table: 01, x: 38, y: CB, msg: [3FE]}   ここより　きた　コーミズむら。
```

맵 쪽 9개는 FC 그룹 `04`·`0A`·`0B`·`0C`·`13`·`16`·`17` 에 있어 1장 그룹(`02`·`12`·`1C`·`30`·`41`·`3A`)에는 없습니다.

## 2. 원래 DQ5 는 어떻게 읽나

[DQ5 필드 팻말 표](../../dq5/journal/2026-10-25-200-signs.md)(`1E:F4BF`)는 「しらべる」 로만 재 두었습니다. 사용자는 「はなす」 로 했으므로 원래 DQ5 롬에서 둘 다 재었습니다. 배 선실 세이브스테이트에서 `dq5warp.lua FIELD=182,198` 로 팻말 (183,197) 아래에 내리고, `dq5chestcheck.lua` 로 위를 누른 뒤 명령을 골라 `24:8BAF` 의 메시지 번호와 조사 종류(`12:E4A3`)를 적었습니다.

```
はなす    kind 05, message 0169      12:E5AE face=80 B6=182 B8=198, 12:FC9E X=183 Y=197
しらべる  kind 05, message 0169      (12:E5A2 를 거쳐 같은 12:E5AE)
(182,195) 에서 아래:  kind 06, message 0137 → 0138
```

DQ5 도 「はなす」 로 팻말을 읽습니다. 앞에 인물이 없으면 「しらべる」 와 같은 `12:E5AE` 를 부릅니다. 아래를 보면 표를 보지 않고 137「…は　立て札を　見た。」·138「しかし　こっちは　うら側。」 이라, FC 031B 와 같은 규칙입니다. 이 둘은 이미 한글이었습니다(`dq4sysmsg`).

169 는 「…は　立て札を　読もうとした…{100D}が　まだ字が　読めなかった！」 입니다. 종류 5 처리기 `12:F2D8` 를 읽으면 `BRK 0B 40 00`(`7E:2190` bit6, 어른)이 꺼져 있으면 169 에서 끝나고, 켜져 있으면 136「…は　立て札を　読んだ。」 뒤 `JSL $248157` 로 `$1E73` 의 메시지를 띄웁니다.

```
12:F2E7  BRK 0B 40 00 / BNE F30B        어른이면
12:F2ED  … BRK 98 69                    169(못 읽음)
12:F30B  BRK 98 36 / LDA $1E73 / … / JSL 24:8157    136 뒤 팻말 글
```

## 3. 1장 롬에서는 왜 「아무도 없다」 였나

포팅한 필드의 팻말 블록(FC `15`)은 DQ5 블록 21 의 타일 속성 `96 96 97 98` 을 빌리므로 `12:E5AE` 는 팻말 타일을 찾습니다. 그러나 표 `1E:F4BF` 는 DQ5 좌표 그대로라 `12:FC9E` 가 항목을 찾지 못했고, 「はなす」 는 129, 「しらべる」 는 12B 뒤 12C 로 끝났습니다. 고치기 전 main 의 1장 롬으로 아래 검사를 돌리자 아래·왼쪽·오른쪽 28장면이 모두 이렇게 실패했고, 위에서 본 10장면(뒷면)만 통과했습니다.

## 4. 바꾼 것

`sfc/dq4/tools/dq4signs.py` 가 1장 빌드 끝(`dq4chapter1.build`)에서 두 곳을 바꿉니다.

- 표 `1E:F4BF` 의 다섯 항목을 FC 필드 팻말로. 속성 `98` 은 팻말 블록의 오른쪽 아래 칸이라 FC 블록 (x, y) 는 DQ5 칸 (2x+1, 2y+1) 입니다. 바트랜드 팻말 (A6,2F) 는 (333,95) 입니다.
- `12:F2EB` 의 `BNE` 를 `BRA` 로. 늘 136 「팻말을 읽었다」 뒤 팻말 글로 갑니다.

팻말 글은 DQ5 팻말 글이 쓰던 `17F`·`180`·`181`·`182`·`185` 에 넣었습니다(책장 `183`·`184` 는 남김). 지명은 NDS 한글패치 명칭(바트랜드·텐페·코미즈)을 따랐습니다. NDS 리메이크 대사에는 이 팻말 글이 없어 직접 옮겼습니다.

| FC 메시지 | 한글 |
| --- | --- |
| `3D9` | 수상한 것을 발견하면 / 성으로! 바트랜드 왕. |
| `3DA` | 다리는 모두의 것. / 부수지 않도록 합시다. |
| `3DB` | 여기서 동쪽 / 텐페 마을. |
| `3DC` | 숲 속에서는 / 놀지 않도록. |
| `3FE` | 여기서 북쪽 / 코미즈 마을. |

## 5. 검사

`sfc/dq4/tools/dq4signcheck.py` 는 팻말마다 걸을 수 있는 이웃 FC 블록(아래·왼쪽·오른쪽·위)에 내려 패드로 팻말 쪽을 보고(필드는 8프레임마다 패드를 읽어 10프레임 누름) 「はなす」·「しらべる」 를 고릅니다. 1장 롬(`dq4build.py`)에서 38장면이 모두 통과했습니다(2분 25초).

```
{"status": "passed", "entries": 38, "failed": {}}
3D9-below-talk  shown 136, 17F       3D9-above-talk  shown 137, 138
```

화면으로도 보았습니다. 바트랜드 팻말 아래에서 「はなす」 하면 「(이름)는 팻말을 읽었다.」 다음 쪽에 「수상한 것을 발견하면 / 성으로! 바트랜드 왕.」, 위에서는 「그러나 이쪽은 뒷면이다. / 쓰인 글자를 읽을 수 없다.」 였습니다.

1장에서 닿는 팻말은 바트랜드 성 아래(`3D9`)와 이무르 둘레 숲(`3DC`, 41 동굴을 지나)입니다. 성 앞에서 걸을 수 있는 FC 블록을 채우고 41 동굴의 두 입구를 이어 셌습니다(822블록). 나머지 셋도 같은 표라 함께 옮겼습니다.
