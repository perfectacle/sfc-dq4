# 2026-10-27-08: DQ5 에 넣은 환경 맵의 물을 움직이기

[DQ5 에 넣은 환경 맵](2026-10-27-05-environment-rom.md)의 물이 첫 그림에 멈춰 있었습니다. 새로 그린 물 그림 세 장을 24프레임마다 바꿔 끼우게 했습니다. 결과는 [환경 그래픽 문서](../docs/dq4-environment-format.md#물-애니메이션)에 있습니다.

## 1. DQ5 의 움직이는 타일은 쓸 수 없었다

DQ5 는 맵 목록 `03:D82E` 에 있는 맵에 들어갈 때 종류별 블록(`03:D786`, 원래 블록 번호)을 먼저 올리고, 매 프레임 `03:D4B5` 가 그 슬롯을 바꿉니다. 바꾼 맵은 블록 표가 새 블록 42개라 원래 번호가 엉뚱한 블록을 가리킵니다. 목록은 103개 뒤에 바로 주기 표 `03:D964` 가 붙어 있어 항목을 더할 자리도 없습니다.

## 2. 매 프레임 루틴을 바꾼다

맵을 다 푼 뒤 `15:F7D0` 이 맵별 루틴 표 `15:F907` 에서 매 프레임 루틴을 골라 `7E:1AA5`~`1AA9` 에 `JSL 루틴 / RTS` 로 써 둡니다. 롬에서 `22 D0 F7 15` 를 찾으니 부르는 곳은 `01:8F84`·`01:98FC`·`01:9FD6` 셋이었습니다. 셋 다 래퍼로 바꿔 원래 루틴을 부른 뒤, 바꾼 맵이면 `1AA6`~`1AA8` 을 새 루틴 `3D:F060` 으로 고칩니다.

새 루틴은 VRAM 을 직접 쓰지 않습니다. `03:D4B5` 를 풀어 보니 NMI 가 처리하는 DMA 목록에 항목을 넣고 개수를 `$BA` 에 둡니다.

```text
03:D505  LDA $1ED2,Y / STA $1C1C,X     VRAM 워드 주소
03:D50B  LDA $D982,Y / ASL×5 / STA $1C26,X   바이트 수
03:D570  ADC $D9A0,Y / STA $1C0D,X / LDA #$03 / STA $1C0F,X   출발 롱 주소
03:D525  LDA $1EC0 / STA $BA            항목 수
00:8F53  LDA $1C1C,X / STA $2116 ... STA $420B / DEC $BA / BNE   (NMI)
```

새 루틴은 24프레임마다 물 블록 CHR 4개를 항목 넷으로 올립니다. 받는 슬롯은 CHR 로더가 남긴 `7E:6000 + id×2` 의 타일 워드에서 읽고, VRAM 워드는 `2000 + 슬롯×16` 입니다(01/01 의 `7E:2D00` → `2BE0` 과 같은 계산).

처음 만든 루틴은 건너뛰는 분기가 127바이트를 넘어 `BCC` 가 거꾸로 갔습니다. `BCS +3 / JMP` 로 바꿨습니다.

## 3. 검사

검사 도구가 도착 후 10·34·58프레임에 덤프해 물 CHR 4개가 어느 그림인지 봅니다. 다시 그린 맵은 그 순간의 물 그림으로 그린 비교 맵과 견줍니다.

```text
burland 03/00  water frames 1 → 2 → 0   398848 px differences 0
imuru   19/02  water frames 2 → 0 → 1   186368 px differences 0
```

## 4. A 를 덮은 래퍼와 타이밍

부팅 시험에서 처음에는 장면 넷 가운데 셋이 해시가 달랐습니다. 래퍼가 `$BC`·`$BD` 를 비교하느라 `15:F7D0` 이 돌려준 A 를 덮고 있었습니다. 맵 훅·팔레트 훅까지 모두 `PHP`·`PHA` … `PLA`·`PLP` 로 감싸 원래 A·P 를 지켰습니다.

그래도 필드를 지나는 장면은 해시가 달랐습니다. 아무 일 없이 `JSL $15F7D0 / RTL` 만 하는 래퍼를 세 곳에 넣어 봤더니, 걷기·대화 장면 해시가 다르고 전투·메뉴는 같았습니다. 이것도 몇 사이클의 차이에서 온다고 보고, 장면은 끝 상태로 판정합니다. 네 장면 모두 끝 상태가 원래 롬과 같았습니다.

## 틀렸던 것들

- 비교만 하는 래퍼는 아무것도 바꾸지 않는다고 봤습니다. 감싼 루틴이 돌려준 A 를 덮습니다.

## 남은 것

- 전투에서 돌아왔을 때 물이 계속 움직이는지는 `01:98FC`·`01:9FD6` 을 감쌌다는 코드 읽기뿐이고, 실제로 바꾼 맵에서 전투를 치러 보지는 않았습니다.
