# 2026-10-28-09: 강함 보기의 성별 값

강함 보기의 「성별 :おとこ」 를 「성별 :남자」 로 바꿨습니다. 결과는 [강함 보기 라벨](../docs/dq4-window-text-format.md#강함-보기-라벨)에 있습니다.

## 1. 찍는 곳

성별·레벨 창 `06` 의 값 자리는 `D1` 코드입니다. 형식 문서에는 `D1`(`04:B7C3`)이 흔한 장면에서 불리지 않는다고 적혀 있었습니다. 그런데 선실 상태의 원래 롬으로 강함 보기를 열고 `04:B700`~`B8FF` 커버리지를 모으자 `04:B7C3`~`B7DF` 가 돌았습니다. `tools/listing.py` 로 본 흐름입니다.

```
04:B7C3  PLX / JSR $C064 / STA $42 / BRK 88 2C   ; 성별 값
04:B7CC  LDA $46 / STA $42 / LDA #$02 / STA $43 / BRK 88 2B   ; 이름 표 2 의 문자열 → $00~
04:B7D7  PHX / LDX #$0000 / LDA #$03 / STA $00 / BRL $B7A3     ; 석 자 찍기
```

이름 표 2 는 「おとこ / おんな / ？？？」 뒤에 「スライム」 부터 몬스터 종족이 이어집니다. DQ5 에서 몬스터 동료의 성별 자리에 종족을 찍는 표로 보입니다.

## 2. 이름 표 길로 넘기기

`04:B7D7` 의 11바이트를 `LDA #3 / STA $00 / BRL $B808` 로 바꿨습니다. `04:B808` 은 이미 `WnText` 훅이라 `$43`·`$42` 로 한글 표를 찾고, 없으면 원래 고리로 석 자를 찍습니다. 두 고리 모두 `PLX / BRL $BFF2` 로 끝나 스택이 같습니다. 뱅크 04 에서 `04:B7D8`~`B7E1` 로 들어오는 분기는 없었습니다. 한글 표에는 종류 2 로 「남자 / 여자」(석 열)만 넣었습니다(DQ4 동료는 사람뿐).

이 asar 는 `BRL $B808` 을 상대 거리로 바꾸지 않고 `82 08 B8` 로 조립해, `db $82 : dw $B808-$B7DE` 로 적었습니다.

| 장면 | 결과 |
| --- | --- |
| 선실(혼자)·09/00 일행 셋의 강함 보기 | 「성별 :남자」 |
| 2쪽 오른쪽 제목 | 「명령」. 원래 롬도 「コマンド」 |
| 무작위 입력 6벌 · 이름 검사 셋 · 단위 시험 | 모두 정상 |

## 틀렸던 것들

- 2쪽 오른쪽 창 제목이 옛 슬롯 글자로 남는다고 봤지만, 원래 롬의 제목이 「コマンド」 라 「명령」 이 맞았습니다. 앞서 「강함」 으로 보였던 것은 그 전 빌드의 일입니다.
- `D1` 이 흔한 장면에서 불리지 않는다는 앞의 기록은 강함 보기에는 맞지 않았습니다.

## 남은 것
