# 2026-11-04-03: 회심 판정 앞의 조건 셋

[2026-11-03-06](2026-11-03-06-sfx-critical.md) 의 「남은 것」 에 적은 회심 판정 앞 조건(`$100E` bit7, 필드 `41` 상태, `26:8D0A` 의 가진 물건)을 원본 DQ5 와 1장 롬에서 따라가고, 1장 롬의 들판 전투에서 하나씩 켜 보았다. `$100E` bit7 은 회심을 막고, 나머지 둘은 난수를 보지 않고 회심을 낸다. DQ5 형식 문서는 셋 모두 「회심이 없다」 고 적었는데, 뒤의 둘은 반대였다. 효과음 장면 검사 `battle-critical` 은 이제 공격 소리가 대기열에 든 프레임에 셋이 모두 꺼져 있는지 보고, 켜져 있으면 그 까닭을 대며 실패한다. 결과는 [사운드 포팅 「회심을 직접 일으키기」](../docs/dq4-sound-port-format.md#회심을-직접-일으키기2026-11-03)에 옮겼다.

## 1. 판정 코드

원본 DQ5 와 1장 롬(SHA-1 `cbd7add2`)의 `20:C697`~`C6C4` 는 46바이트가 같다.

```
20:C697  BIT $100E / BMI C6BC         $100E bit7 → 회심 아님
20:C69C  LDA #$1A / XBA
20:C69F  LDA $10F5 / BMI C6BC         공격하는 쪽이 몬스터 → 회심 아님
20:C6A4  BRK 8D 80 41 / LDA $49 / BNE C6BE   필드 41, 하위 1A ≠ 0 → 회심
20:C6AC  JSL $268D0A / BCS C6BE       가진 물건 → 회심
20:C6B2  LDA #$20 / JSL $00953A / CMP #$00 / BEQ C6BE   난수 0~31 이 0 → 회심
20:C6BC  CLC / RTS                    회심 아님
20:C6BE  LDA #$80 / STA $0DA8 / SEC / RTS   회심
```

`C6BE` 는 효과음 장면이 회심 효과음(`37-0B`)을 받는 갈래와 같다. 그래서 필드 `41` 이 0 이 아니거나 `26:8D0A` 가 carry 를 켜면 회심이다. DQ5 형식 문서(`sfc/dq5/docs/dq5-data-format.md` 회심 절)의 「회심이 없습니다」 는 분기 방향을 거꾸로 읽은 것으로 보이고, 아래 실측도 회심이었다.

- `$100E` bit7 을 켜는 코드는 롬 전체에서 `20:825B`(`STA $100E`, 값 `80`) 하나다. 이 루틴(`20:8256`)은 `20:8226` 을 거쳐 시설 처리기 `06:F2E7` 에서만 불린다. 시설 표 `06:DBDB` 의 `0E`(`06:F226`) 다음 자리이고, `0E` 는 격투장이다([DQ5 격투장](../../dq5/docs/dq5-data-format.md#격투장-23da97)). 격투장 관전 전투(몬스터끼리)의 표시다. 같은 bit7 이면 전투 연출 대신 효과음만 내는 것과도 맞는다. 찾은 꼴은 `$100E` 를 절대 주소로 쓰는 명령 열둘이다: `STA`·`TSB`·`STX`·`STY`·`STZ`·`TRB`(`8D`·`0C`·`8E`·`8C`·`9C`·`1C` + `0E 10`), `STA abs,X`·`abs,Y`(`9D`·`99`), `STA long`·`long,X`(`8F`·`9F` + `0E 10 7E`/`00`). 롬 전체(두 롬 모두 4MB)를 바이트로 훑었다. 원본 DQ5 에서 맞은 곳은 `STA` `20:825B`, `TSB` `1E:FEF8`·`1F:D0C4`·`20:82EB`·`24:F8CB`, `STZ` `20:8345`, `TRB` `0E:9D54` 이다. `TSB` 가운데 `20:82EB` 는 값이 `40`(bit6)이고, 나머지 셋은 앞뒤를 명령으로 읽으면 이어지지 않아 자료로 보았다(실행으로 확인하지 않음). 그래서 bit7 을 켜는 것은 `20:825B` 하나로 보았다. 다이렉트 페이지·간접·DMA 로 쓰는 길은 이 검색에 걸리지 않는다. 1장 롬에서 더 맞은 곳은 둘이다. `6F:E498`(`TSB`)은 롬 장부로 사운드 단계가 쓴 80바이트(`6F:E483`~`E4D2`) 안이고, 사운드 단계는 뱅크 `6F` 에 곡이 함께 쓰는 샘플을 둔다(`dq4-ch1-sound.json`). `3D:CE7A`(`STA $100E,X`)는 1장 단계가 쓴 자리(`3D:CE01`~`CF03`) 안이고, 1장 롬은 뱅크 `3D` 에 맵 블록 자료를 둔다([환경 형식](../docs/dq4-environment-format.md)). 둘이 실행되는지는 보지 않았다(남은 것).
- 필드 `41` 의 하위 `1A` 는 주인공 전투 칸(`7E:0760`)의 `+7` bit6 이다(3절, 실측). 몬스터 쪽은 상태를 필드 `79` 로 읽고, 상태 `42` 를 `$43` = `42` / `BRK 88 7A` 로 켠다는 것이 DQ5 실측이다(`dq5-data-format.md` つうこん). 같은 짝을 일행 쪽에 대면 읽기 필드 `41` 에 켜기 필드 `42` 다. 그래서 `$43` = `1A` / `BRK 89 80 42` 를 「상태 `1A` 를 켬」 으로 읽었다. 이 꼴은 `20:E7B6` 하나이고, 일행이 외운 パルプンテ 의 효과 표 `20:E2B9` 의 `10` 번(「からだに　ちからが　みなぎってきた」)이다. `20:FB7A`(`$43` = `1A` / `BRK 89 80 43`)는 같은 짝으로 끄는 쪽으로 읽었다. 둘 다 정적 읽기이고, 그 길로 `0767` bit6 이 켜지거나 꺼지는 것은 재지 않았다(남은 것).
- `26:8D0A` 는 `7E:2056`~`205C`(주인공 가진 물건 첫 일곱 칸)를 `26:8D33` = `00 0A 91 02 3C 64 FF` 와 한 칸씩 견주어 일곱이 모두 같으면 carry 를 켠다. 하나라도 다르면 끈다. 두 롬 모두 표가 같다.

## 2. 재는 법

`sfc/dq4/tools/dq4critcheck.py` 는 `dq4battlecheck` 의 들판 장면(서장 끝 상태에서 자리를 잡고 조우 루틴을 정한 무리로 덮음, 몬스터 HP 1)을 쓴다. 사례마다 검사 롬 사본의 판정 난수만 「늘 회심」(`20:C6B3` = `01`) 또는 「회심 없음」(`20:C6B9` = `FF`, 0~31 은 `FF` 와 같지 않음)으로 바꾸고 조건 하나를 켠다. `lua/dq4critprobe.lua` 가 `20:C697`·`C6A8`·`C6B0`·`C6BC`·`C6BE` 실행 때 값과 갈래를 적는다. 첫 판정이 주인공(`$10F5` = `00`)의 공격이어야 하고, 그 갈래를 기대와 견준다. 자리를 한 번 잡고 같은 전투를 두 번 돌려 판정 기록(`crit.txt`) 전체가 같아야 통과다. 난수·낮밤·조우는 `dq4ch1walkcheck` 고정값이다.

| 사례 | 난수 | 켠 조건 | 첫 판정 | 기대 |
| --- | --- | --- | --- | --- |
| `always` | 늘 회심 | 없음 | 회심 | 회심 |
| `never` | 회심 없음 | 없음 | 회심 아님 | 회심 아님 |
| `flag100e` | 늘 회심 | `7E:100E` = `80`(프레임마다) | 회심 아님(`C697` 에서 바로 빠짐) | 회심 아님 |
| `state1a` | 회심 없음 | `7E:0767` = `40`(프레임마다) | 회심(필드 41 = `01`) | 회심 |
| `items` | 회심 없음 | `7E:2056`~ = `00 0A 91 02 3C 64 FF`(한 번) | 회심(carry 1) | 회심 |

다섯 사례 모두 첫 판정이 주인공의 공격이었고 기대와 같았다. 한 실행 안의 두 전투 기록이 같았고, 서장부터 같은 명령으로 따로 두 번 돌린 기록도 다섯 사례 모두 바이트까지 같았다.

## 3. 필드 41 이 읽는 칸

`20:C6A4` 의 `BRK 8D` 동안 읽힌 WRAM `0760`~`07FF` 은 주인공이 칠 때 `0765`·`0767` 둘이었다. 「회심 없음」 난수에서 `0765`~`0768` 의 비트를 하나씩(32번) 켜 보았다(`dq4critcheck.py --sweep`). 필드 41 이 `01` 이 되고 회심이 난 것은 `0767` bit6 하나였고, 다른 비트는 필드 41 이 `00` 이었다. 32번 가운데 23번은 주인공이 먼저 쳤다. 여덟 번(`0765` bit1·5·6·7, `0766` bit2, `0767` bit2·3, `0768` bit7)은 주인공이 잠 등으로 못 움직여 동료(칸 1)가 먼저 쳤고, 그때 읽은 칸은 `0771`·`0773` 이었다. `0766` bit4 에서는 판정을 한 번도 지나지 않았다.

## 4. 1장에서 우연히 켜지나

- `$100E` bit7: 격투장 관전 전투에서만 켜진다. 1장 롬에는 격투장 시합이 없다. 1장 롬에서 더 맞은 두 자리(`6F:E498`·`3D:CE7A`)는 1절에서 본 대로 자료를 둔 자리 안이다.
- 필드 41 상태 `1A`: 일행이 외운 パルプンテ 의 효과 `10` 만 켠다. 1장 일행이 パルプンテ 를 쓸 수 있는지는 확인하지 않았다(남은 것).
- 가진 물건: 주인공 첫 일곱 칸이 위 일곱과 차례까지 모두 같아야 한다. 저장 기록이나 일행 구성을 바꾼 장면에서 우연히 맞을 수는 있다.

셋 다 지금 `battle-critical` 장면에서는 꺼져 있다. 그래도 저장 기록·순간이동 자리·롬이 바뀌면 달라질 수 있으므로 검사가 직접 본다.

## 5. battle-critical 이 셋을 본다

`dq4sfxscene` 은 `battle-critical` 일 때 프레임마다 `$100E`, 일행 전투 칸 여덟의 `+7`(`7E:0767`·`0773`…`07BB`), `7E:2056`~`205C` 를 적는다. 필드 41 은 치는 쪽의 칸을 읽으므로, 누가 치든 걸리게 여덟 칸을 모두 본다. 첫 원하는 항목(공격 소리 `37-01`)이 대기열에 든 프레임의 값을 `critical_blockers` 로 본다.

- 회심 효과음이 울리지 않았으면 「회심 미발생」 뒤에 켜진 조건의 까닭을 붙인다.
- 회심이 울렸어도 필드 41 이나 가진 물건이 켜져 있으면 「고정한 난수 판정이 아닌 길로 났을 수 있음」 으로 실패한다.
- 기록이 비어 있으면 「회심 앞 조건을 기록하지 못함」 으로 따로 실패한다. DSP 를 읽지 않는 대조 실행(`CONTROL`)은 대기열 기록만 남기고 판정 전에 끝나므로 이 기록을 쓰지 않는다.

`dq4sfxscene.py --critical-negative` 는 snes9x 로 `battle-critical` 에 조건 하나씩(`7E:100E` = `80`, `7E:0767` = `40`, `7E:0773` = `40`)을 더 묶어, 셋 모두 실패하고 메시지에 그 까닭이 있는지 본다. `7E:100E` = `80` 은 아래처럼 실패했다.

```
회심 미발생(회심 판정을 고정했는데도 회심 효과음이 울리지 않음): $100E = 80: bit7(격투장 관전 전투)이 켜져 회심 판정 전에 회심 아님으로 빠짐
```

`7E:0767` = `40` 은 「회심이 고정한 난수 판정이 아닌 길로 났을 수 있음: 일행 전투 칸 0 +7 = 40: …」, `7E:0773` = `40` 은 「… 일행 전투 칸 1 +7 = 40: …」 으로 실패했다. 손대지 않은 장면은 bsnes·snes9x 모두 통과했고 셋 모두 꺼져 있었다.

가드는 `dq4-crit-conditions`(위 다섯 사례를 사례마다 두 번, 그리고 `--critical-negative`)를 새로 두고, `dq4-sfx-scene` 의 설명에 조건 확인을 더했다. 두 가드의 `paths` 는 진입 스크립트가 바로 import 하는 모듈·빌드 단계까지 채웠고, `test_dq4readset` 의 import 확인에 둘을 넣었다.

## 남은 것

- 1장 일행(라이안·호이민)이 전투에서 パルプンテ 를 쓸 수 있는지. 쓰면 효과 `10` 이 필드 41 상태 `1A` 를 켤 수 있다.
- 상태 `1A` 를 끄는 `20:FB7A` 가 언제 불리는지(전투 시작·끝 등). 실측은 프레임마다 값을 묶어 이 시점을 보지 않았다.
- `$100E` 를 다이렉트 페이지·간접·DMA 로 쓰는 길, 1장 롬의 `6F:E498`·`3D:CE7A` 가 실행되는지.
- `20:E7B6`·`20:FB7A` 로 `0767` bit6 이 실제로 켜지고 꺼지는지(1절은 몬스터 쪽 짝에 빗댄 정적 읽기).
- `26:8D33` 의 일곱 물건이 1장 롬의 물건 번호로 무엇인지와, 이 비교를 둔 까닭.
- DQ5 형식 문서 회심 절의 「회심이 없습니다」 는 dq5 트랙이 고칠 몫이다.
