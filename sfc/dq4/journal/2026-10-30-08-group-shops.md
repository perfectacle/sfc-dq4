# 2026-10-30-08: バトランド 성·イムル 의 가게·여관·교회

새 그룹 `36`·`37` 의 FC 가게·여관·교회·맡기는 곳을 DQ5 시설로 이었습니다. 결과는 [환경 그래픽 문서의 가게](../docs/dq4-environment-format.md#가게)에 있습니다. 상자는 이번에 넣지 못했습니다.

## 1. 상자는 왜 남았나

DQ5 일반 상자는 맵 셀의 상자 표시를 센 순서와 맵 연결 표(`1E:EF90`)로 번호를 정합니다. 엔진은 맵 연결 표를 `[그룹][맵]` 낱말로 `$BC` 와 견주므로(`25:FAC3` `LDY $EF90,X` / `CPY $BC`) 새 그룹도 받을 수 있습니다. 그런데 표를 쓰는 dq5 트랙 도구 셋은 원래 롬에 있는 맵만 받습니다. 그 도구를 고치는 것은 dq5 트랙 몫이라, 먼저 가게를 했습니다.

## 2. 가게 인물

인물 이식은 FC 대화를 1장 시작 상태로 돌려 서비스가 나오면 가게로 보았습니다. 그런데 바트랜드 방어구점(1F,16)과 イムル 여관(11,12)은 카운터 너머로 말을 걸 때만 가게를 여는 대화 스크립트(`00D`·`011`, 조건 `counter`)라 대사로 잘못 옮겨져 있었습니다. FC 분석 도구 `dq4shop.merchants` 는 이런 경로까지 「인물 → 가게」 로 풀어 주므로 그것을 씁니다. FC 서비스 번호 1~6 은 DQ5 대화 번호 `01`~`06` 과 뜻이 같습니다. 가게 인물이 쓰던 메시지 7개(자리표시 대사와 카운터 스크립트의 대사)가 빠져, 덮는 DQ5 메시지가 77개에서 70개가 되었습니다.

바트랜드 방어구점 주인은 FC 걸음 간격이 1 이라 돌아다니기 견본으로 옮겨졌습니다. DQ5 의 돌아다니기는 3×3 안을 걸으므로 카운터를 벗어날 수 있어, 시설 인물은 모두 서 있게 했습니다.

## 3. 상점 목록

무기·도구·방어구점은 맵 그룹 `$BC` 를 키로 목록을 찾습니다(`06:DC37`). dq5 트랙의 `dq5progresswrite.py` 가 종류 끝에 새 키 목록을 더하므로, 키 `36`·`37` 로 여섯 목록을 더했습니다. FC 품목은 이름으로 DQ5 물건을 찾았습니다. いばらのむち 는 DQ5 에서 いばらのムチ 라 가타카나로 접어 견주었고, てつのやり 는 DQ5 에 없어 뺐습니다.

## 4. 여관 값

여관 1인 값 표 `04:FD6D` 는 `[그룹][값]` 21항목이고 끝 표시가 없습니다. 새 그룹 값을 더할 자리가 없어, 표를 `3C:F000` 에 옮겨 쓰고 두 항목을 더했습니다. 표를 가리키는 것은 `06:F563` 의 두 즉값뿐입니다.

```text
06:F567  LDA #$04 / PHA / PLB      ; DB = 표 뱅크
06:F56D  LDA #$FD6D / STA $00      ; 표 주소, 뒤에서 LDA ($00),Y 로 훑음
```

## 5. 확인

`dq4npccheck.py` 62장면이 통과했습니다. 가게 장면은 dq5 상점 검사 프로브(`dq5progresscheck.lua`, `MODE=shop`)를 워프 드라이버와 함께 돌려, 「かう」 뒤 목록 창이 늘어놓는 품목을 봅니다.

```text
shop-3600-6  [[2, 60], [6, 270], [28, 350], [7, 900]]   こんぼう·どうのつるぎ·いばらのムチ·くさりがま
talk-3600-2  ['070', '072']  7E:0F28 = 4
talk-3700-0  ['070', '072', '075']  7E:0F28 = 6
```

여관·교회의 첫 메시지는 처음에 낮 값(`070`·`07E`)만 기대해 밤 장면이 실패했습니다. 밤에는 여관 `071`, 교회 `080` 으로 시작했습니다. 여관 값은 첫 메시지를 띄울 때는 0 이었고 둘째 메시지 `072` 에서 정해졌습니다. 첫 메시지를 찍는 동안 누른 A 는 글자를 마저 찍을 뿐이라, 기다린 뒤 A 를 두 번 누릅니다.

## 틀렸던 것들

- 가게 여부를 1장 시작 대화 예측만으로 정했습니다. 카운터 조건 스크립트로 여는 가게 둘을 놓쳤습니다.
- 여관·교회 첫 메시지가 낮·밤 같다고 보았습니다.

## 남은 것

- 상자·タンス·ツボ: dq5 상자 도구가 새 맵을 받아야 합니다.
- DQ5 에 없는 FC 물건(てつのやり), 이야기 플래그로 바뀌는 가게 인물 목록.
