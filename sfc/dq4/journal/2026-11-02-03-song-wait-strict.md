# 2026-11-02-03: 곡 끝을 기다리는 자리를 모두 끝나는 곡으로, 반복 곡 가드

[2026-11-02-02](2026-11-02-02-church-song.md) 의 점검은 되풀이하는 곡이 든 17자리를 「닿는지 미확인」 으로, 곡 번호가 즉값이 아닌 세 자리를 보지 않고 통과시켰습니다. 17자리는 끝나는 징글로 돌리고, 세 자리는 `24:FF0F` 에 반복 곡 가드를 넣어 어떤 곡이 와도 멈추지 않게 했습니다. 판정은 빌드 보고 대신 롬의 시퀀스로 합니다. 결과는 [사운드 포팅 「곡 끝을 기다리는 자리」](../docs/dq4-sound-port-format.md#곡-끝을-기다리는-자리2026-11-02)에 있습니다.

## 1. 17자리

`1C`·`22`·`23` 은 원본 DQ5 에서 동료가 됨·물건을 받음·저주받은 장비 징글입니다. 포팅은 `22` 를 맵 곡(コロシアムスタンド), `23` 을 타이틀 메뉴 곡(インテルメッツォ)으로 쓰고 있어 곡 자리째 바꾸면 다른 곳이 바뀝니다. 곡 묶음 표에 새 곡을 둘 자리도 없습니다. 그래서 기다리는 자리의 `LDA #곡` 즉값만 같은 뜻의 NDS 징글 자리로 돌렸습니다(`--song-call`): `1C` → `26` 仲間が加わった, `22` → `2F` アイテム発見(입구 `25:FCF6` 의 즉값도), `23` → `2E` 呪い.

## 2. 곡 번호가 즉값이 아닌 세 자리

`02:D286` 은 `JSL 00:E9CE` 가 레지스터를 지키고 `BRK 08` 뒤라, A 는 그 앞 고리의 `02:D295` 결과입니다. `03:8EA8` 은 팔레트 페이드 `03:A518` 뒤입니다. `12:F354` 는 `LDA $1E73 / CMP #$054C` 가 같은 갈래라 낮은 바이트가 `4C` 로 보이는데, 포팅에서 `4C` 는 나눈 맵 곡의 본체입니다. 셋 다 코드 읽기로 곡을 정하지 못했고 장면도 찾지 못했습니다.

그래서 `24:FF0F` 를 `JML 71:9000` 으로 바꿔, 곡 번호마다 되풀이 여부 표(`71:9080`)를 보고 되풀이하는 곡이면 기다리지 않고 돌아오게 했습니다. 표는 빌드 끝에 롬 시퀀스를 따라가 셉니다. 교회 세 자리를 되풀이하는 마을 곡 `06` 으로 바꾼 롬에서 두 코어 모두 대화가 1,262~1,383프레임에 끝났고, 고친 롬은 징글을 기다려 1,742~1,863프레임에 끝났습니다.

## 3. 점검을 엄하게

- 되풀이 판정은 롬의 시퀀스(뱅크 70 재배치 표, 없으면 원래 묶음)를 트랙마다 따라갑니다. 나눈 곡 앞부분은 본체를 기다리며 되돌아 되풀이로 칩니다.
- 입구를 부르는 `JSL`·`JML`(어디서나)·`JSR`·`JMP`(같은 뱅크)를 모두 모아 하나도 빠짐없이 분류합니다. `25:FD00` 앞 입구는 롬 바이트에서 곡 번호를 읽습니다. 처음에는 `BRA` 로 가는 꼴만 찾아 `FD00` 으로 흘러드는 `25:FCFC`(곡 `24`)를 놓쳤습니다.
- 원본 DQ5 를 같은 방법으로 훑은 83자리를 `DQ5_SITES` 로 적어 두고, 롬 훑기와 같은지 봅니다. 단위 테스트는 이 표에 `--song-call` 을 적용한 곡이 대응표에서 NDS 징글인지를 롬 없이 봅니다.
- 장부에 소리 단계가 없으면 실패합니다. 1장·2장 빌드에서 둘 다 90자리(끝나는 곡 87, 가드 3)로 통과했습니다.

## 4. 채택한 파형

`dq4sfxscene.ADOPTED_WAVES` 에 번호마다 들어 본 BRR 의 SHA-1 앞 16자리를 적었습니다. 롬의 파형이 다르면 실패합니다. `22` 는 청음 페이지의 공격 시작·빗나감·상자·물건 찾기가 파형 `22` 로 울렸고 사용자가 모두 좋다고 한 것이 근거입니다.

## 틀렸던 것들

- 앞 일지는 17자리를 「1장에서 닿지 않을 것」 으로 두었습니다. 닿는지 실측하지 않은 채 통과시킨 것이라 고쳤습니다.

## 남은 것

- 돌린 자리(동료가 됨·물건을 받음·저주 장비)의 청취. 장면이 DQ5 대화 네이티브라 1장에서 띄우지 못했습니다.
- 곡 번호가 즉값이 아닌 세 자리의 실제 곡과 장면(가드로 멈추지는 않음).
- flag 로 빠져나오는 되돌이를 되풀이로 치는 판정(지금 기다리는 효과음에는 없음).
