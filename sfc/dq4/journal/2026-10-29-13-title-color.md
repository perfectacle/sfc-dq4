# 2026-10-29-13: 창 제목 바탕이 어두운 것

사용자가 MesenCE 로 패치 롬을 돌리다, 「상태 → 공격력」 창의 머리 「레벨 공격 수비」 의 글자 뒤만 어둡다고 알려 왔습니다. 결과는 [창 제목 색](../docs/dq4-window-text-format.md#창-제목-색)에 있습니다.

## 1. 재현과 덤프

선실 일행 세이브스테이트에서 A → 아래 → A(상태) → 아래 → A(공격력)로 같은 화면을 헤드리스로 띄우고, 230프레임에 창 타일맵 버퍼 `7E:5000` 을 덤프했습니다. 제목 글자 줄(9번째 줄)을 패치 롬과 창 패치 전 롬으로 견줬습니다.

```
패치  2C3A 2C3B 2C3C 2001 2001 2C40 2C41 2C42
원래  206B 205E 206A 2001 2001 2019 2012 2018
```

팔레트 3 은 뒤로 물러난 명령 창(`2C8D`)이 쓰는 어두운 색입니다.

## 2. 원인과 고치기

원래 제목 고리 `04:AC25` 는 `($DC),Y` 에 낮은 바이트만 써 버퍼의 색(`20`)을 살립니다. 우리 고정 문구 그리기는 본문 길(`04:B235`)처럼 `$EC` bit6 이면 `$ED` 를 색으로 쓰는데, 제목을 그릴 때 그 값은 앞서 그린 본문 창의 것이었습니다. 제목 두 길(`WnTitle`·`WnTitleName`)에서 그리는 동안 `$EC` 를 `7E:3DCC` 에 맡기고 bit6 을 꺼, 버퍼 색을 쓰게 했습니다. 고친 뒤 같은 칸이 `203A` 가 됐고, 도구·주문·어떻게 할까 제목도 바탕이 창과 같아졌습니다.
