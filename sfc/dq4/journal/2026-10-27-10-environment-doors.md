# 2026-10-27-10: 환경 맵의 문을 DQ5 문 물체로

[DQ5 에 넣은 환경 맵](2026-10-27-05-environment-rom.md)의 문과 성문은 맵 레코드에 그린 그림이라 열리지 않고 지나갈 수도 없었습니다. FC 문 블록을 DQ5 맵 위 물체로 바꿔 DQ5 문처럼 그려지고 열리게 했습니다. 결과는 [환경 그래픽 문서](../docs/dq4-environment-format.md#문과-성문)에 있습니다.

## 1. FC 의 문

두 맵의 블록 속성을 세었습니다. `94`(열쇠 없이 여는 문)는 바트랜드 `(35,21)` 하나, 이무르 `(21,19)`·`(19,21)`·`(3,23)` 셋입니다. 같은 "문" 으로 나오는 `A0` 는 바트랜드 성문 2×2 블록(`10`·`11`·`14`·`15`)이었습니다.

## 2. DQ5 물체 표를 바꾼 맵에만 돌리기

DQ5 의 닫힌 문은 맵 레코드가 아니라 `01:D2FC` 물체 표에 있습니다. 표는 그룹·맵 순서로 이어져 있어 항목을 끼울 수 없습니다. 롬에서 `FC D2` 를 찾으니 읽는 곳은 모두 `01:F3F9`~`F447` 한 루틴이었고, 이 루틴을 부르는 곳은 그리기 `01:F3E8`, とびら `01:DE62`, `01:D920`, `01:F122` 넷이었습니다.

```text
01:F407  LDY #$D2FC / STY $09        표 시작
01:F413  LDA $D2FC,Y ... (그룹·맵 수만큼 건너뜀)
01:F42D  LDX #$0009 / REP #$20 / TYA / JSL $00959A   Y = 이 맵의 항목 자리
```

`01:F42D` 를 `JSR` 로 바꾸고, 바꾼 맵이면 Y 를 뱅크 01 끝(`01:FED0`~ 빈 자리)에 둔 새 항목으로 바꿉니다. 바트랜드는 성문 `48`(4×4셀)과 문 `3B`(2×3셀), 이무르는 문 `3B` 셋입니다. 맵 레코드에서는 문 자리를 바닥으로 그리고 걸을 수 있게 두어, 물체가 열리면 지나갈 수 있습니다.

## 3. 공통 문 타일이 쓰는 색

처음 그리니 문이 분홍색이었습니다. 공통 문 타일은 팔레트 6번 줄(성문은 5번 줄)의 정해진 번호를 씁니다. VRAM 의 문 타일 색 번호를 세고 DQ5 맵 여덟 곳의 팔레트를 보았습니다.

```text
3B 문   색 번호 1 2 3 6 7 9
48 성문 색 번호 1 2 3 6 7
6번 줄 1·2·3·6·7·9 = 000000 292121 52524a 634a00 c69429 ffde00   (00/00, 01/00, 19/02 ... 모두 같음)
5번 줄 1·2·3·6·7   = 000000 292121 52524a 4a4200 846b00
```

새 팔레트도 이 자리에 같은 색을 두고, 그림 코드가 쓰던 색 번호는 `_REMAP` 으로 남은 칸에 옮겼습니다. 6번 줄은 쓰는 색이 11가지라 어두운 나무 `523600`·밝은 나무 `d2ad4a` 를 DQ5 의 `634a00`·`c69429` 로 합쳤습니다.

## 4. 붉은 바닥 위의 회색 네모

문을 연 모양을 다시 그려 보니 의자·둥근 탁자 바탕이 회색 네모였습니다. 투명한 바탕을 바닥으로 채울 때, 물체 팔레트(나무 4번 줄) 안에서 가장 가까운 색을 고르기 때문입니다. 바닥이 회색 판석일 때는 드러나지 않았습니다. 맵에 쓰는 물체마다 채운 바탕과 실제 바닥의 색 차이를 재었습니다.

```text
chair / round_table / gold_door16 (4번 줄) on red_paving  최대 207
statue / well / washbasin (3번 줄)                         최대 197
chimney (2번 줄) on carpet                                 최대 132
sign_* (4번 줄) on stone_wall                              최대 109
```

2·3·4번 줄의 빈칸에 카펫·포장 색 `57072e`·`b3177f`·`de4fa9` 를 넣자 간판을 뺀 모든 물체의 차이가 0 이 되었습니다.

## 5. 검사

```text
burland  objects 2/2  pixel differences 0 (object cells 22 skipped)  walk-layer 0
imuru    objects 3/3  pixel differences 0 (object cells 18 skipped)  walk-layer 0
gate open: 7E:21C2=FF, start (36,27) up 150 frames -> row 18 (closed: stops at row 22)
```

열림 플래그 `7E:21C2`~`21C5` 는 그룹이 바뀌면 지워집니다. 그래서 같은 그룹의 `03/01` 에 다녀오며 플래그를 켜고 `03/00` 으로 돌아와 확인했습니다. 부팅 시험은 배 선실에 닿았고 네 장면 끝 상태가 원래 롬과 같았습니다.

## 틀렸던 것들

- 새 팔레트는 DQ5 의 다른 그림과 상관없다고 봤습니다. 공통 문 타일이 5·6번 줄의 정해진 칸을 씁니다.

## 남은 것

- 명령 창의 とびら 로 여는 것은 재현하지 못했습니다. A 뒤 명령 창 커서가 생기는 시점이 실행마다 달라(한 번은 A 뒤 350프레임) 아래 입력이 먹지 않았습니다. とびら 쪽도 같은 `01:F3F9` 를 지난다는 코드 읽기와 플래그를 켠 상태의 확인만 있습니다.
- 벽 위 간판 바탕색.
