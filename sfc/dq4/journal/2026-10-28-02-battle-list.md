# 2026-10-28-02: 전투 몬스터 목록과 전투 도구 창

전투 몬스터 목록과 전투 도구 창의 이름을 한글로 바꿨습니다. 결과는 [전투 몬스터 목록과 전투 도구 창](../docs/dq4-window-text-format.md#전투-몬스터-목록과-전투-도구-창)에 있습니다.

## 1. `C8` 은 이름이 아니었다

설계 때는 몬스터 목록 창 `1B` 를 띄울 때 실행된 자리 표시 `C8`(`04:B67B`)·`E6`(`04:BBB2`)을 둘 다 이름으로 봤습니다. `C8` 을 읽어 보니 `$10EF` 무리 번호로 `$1005` 마릿수를 꺼내 `04:C0AB` 로 숫자를 찍는 자리, 곧 「1ひき」 의 숫자였습니다. 이름은 `E6` 입니다.

## 2. 아홉 글자 고정

전투 중 `04:B808` 에 실행 감시를 걸었지만 한 번도 불리지 않았습니다. `E6` 을 커버리지로 보니 `BRK 88 2B` 로 몬스터 이름(`$43` = 4)을 받은 뒤 `04:BC08` 에서 `LDA #9 / STA $00 / BRL $B7A3` 으로 탁점이 아닌 글자 아홉을 찍었습니다. 주문 목록의 다섯 글자 고정과 같은 꼴이라, `!wt_mode` 를 「고정 글자 수」 로 바꿔 5 와 9 를 함께 받게 했습니다. DQ5 몬스터 이름 240개 가운데 `adopt.tsv` 와 맞은 것은 29개이고, 시험 전투의 「つちわらし」 가 그중 하나(「황토 아이」)였습니다.

## 3. 전투 도구 창이 따라왔다

예전 실측에서 전투 도구 창은 `04:B808` 을 거치지 않아 가나였습니다. 이번 롬에서는 한글이었습니다. 실행 감시로 보니 `C9`(`04:B6A0`)가 `BRL $BC08` 로 같은 자리에 와서, 도구 이름(`$43` = 5)을 아홉 글자로 찍고 있었습니다. 도구 이름은 열 열까지 허용했기 때문에, 열 열짜리 9개(「독나방의 나이프」 등)는 이 길에서만 가나로 넘깁니다. 주인공 도구 칸(`7E:2058`)에 「どくがのナイフ」 를 넣어 전투에서는 가나, 필드 목록에서는 한글임을 확인했습니다.

| 시험 | 결과 |
| --- | --- |
| 09/00 전투 몬스터 목록 | 「황토 아이 — 1ひき」, 「ナイトウィスプ」 는 가나 |
| 전투 도구 창 | 「천 옷 / 노송나무 막대」 |
| 전투 포함 무작위 입력 4벌, 선실 8벌 × 8000프레임 | 모두 정상 |

## 틀렸던 것들

- `C8`·`E6` 둘 다 이름이라고 봤지만 `C8` 은 마릿수였습니다.

## 남은 것

- DQ5 고유 몬스터 이름(211개)은 가나. DQ4 데이터를 옮기면 이름으로 다시 이어짐
- 전투 메시지 속 몬스터·도구 이름(「スライムが あらわれた」)은 아직 가나
- 전투 도구 창 제목 「のどうぐ」 는 한글 「의 도구」 가 원래 칸에 안 들어가 가나
