# 2026-10-27-28: 도구 목록을 한글로, 게임 전송 목록을 비켜 가기

창 글자 전체를 한글로 바꾸는 첫 단계로 도구 목록을 Galmuri9 로 찍었습니다. 그림을 VRAM 에 올리는 방법을 세 번 바꾼 끝에, 게임의 NMI 전송 목록을 쓰지 않고 우리 대기열을 NMI 에서 따로 보내게 했습니다. 결과는 [창 글자](../docs/dq4-window-text-format.md#창-글자)에 있습니다.

## 1. 설계와 시안

남은 창 글자의 칸 예산을 쟀습니다. 바깥 필드는 BG1·BG2 글자 0~255번 중 250칸이 차 있어 BG3 칸 `200`~ 을 빌릴 수 없었고, 걷는 메시지 캔버스는 `96` 부터 위로 채웠습니다(두 줄 메시지가 `111` 까지). 도구 창 8줄을 Galmuri9·Galmuri7 로 그린 시안을 보고 사용자가 Galmuri9 를 골랐습니다. 한글 표는 롬의 일본어 이름을 `adopt.tsv` 와 이어 만들기로 했습니다(도구 256개 중 95개).

## 2. 문자열이 지나는 길

자리 표시 코드를 실행 감시로 갈라, 도구 목록은 `D3`(`04:B82F`) → `BRK 88 2B`(`$42` 번호, `$43` 표) → `04:B808` 이 글자마다 `04:B235` 로 찍는다는 것을 확인했습니다. `04:B808` 을 훅해 그림을 그리자 첫 그리기에서 「천 옷」·「노송나무 막대」가 나왔습니다.

## 3. 활성화에서 멈춤

A 로 목록을 활성화하면 커서가 생기지 않고 메뉴가 닫힌 것처럼 됐습니다. 원래 롬과 창 해석(`04:B33A`) 호출을 줄마다 견주어 차이를 하나씩 없앴습니다.

- Y 를 한글 열 수만큼 나아가게 했던 것 → 원래처럼 가나 글자 수만큼. 다시 견주니 「ひのきのぼう」 에서 원래 12, 우리 14 였습니다. 탁점 바이트 `84`·`83` 은 칸을 나아가지 않습니다.
- A 에 마지막 글자 바이트를 남기기(`04:BFF2` 는 `PLB / PLP / RTS`).

그래도 같았습니다. 전송만 빼면(`JSR WtUpload` 를 `NOP`) 원래 흐름이었고, 항목을 1워드로 줄여도 흐름이 달라졌습니다.

## 4. NMI 전송 목록의 정체

`$1946` 쓰기를 감시하자, NMI 가 `$1946` 이 가리키는 작업을 돌리는데 평소에는 `00:8DE9`, 게임이 목록을 보낼 때만 `00:8CEF` 로 바뀌었다 돌아왔습니다. `00:8CEF` 는 `$19` bit2 가 켜져 있을 때만 목록을 보냅니다. 게임은 프레임 끝에 `00:958A`(`$19` bit2 → 다른 작업으로 넘어가 NMI 대기)로 한 번 보냅니다. 창을 그리는 도중에 우리가 목록을 쓰면, 게임이 아직 만들고 있는 목록이 먼저 나가거나 동기화가 어긋납니다.

```text
f42 001946=E9 pc 00:882C
f43 001946=EF pc 00:885A
```

그래서 NMI 의 `00:8926`(`JSR $894F`)을 머리 앞 빈 자리 `00:FFA1` 의 받침(`JSL WqNmi` / `JMP $894F`)으로 돌려, 우리 대기열(`7E:3EA0`~`3FFF`)만 따로 DMA 하게 했습니다. 흐름이 원래대로 돌아왔습니다.

## 5. 빈 버퍼를 믿은 칸 할당

메시지가 뜬 뒤 목록 이름이 빈칸이 됐습니다. 칸은 타일맵 버퍼 `7E:5000` 을 훑어 안 쓰는 칸을 빌리고 있었는데, 다른 창을 여는 동안 게임이 그 자리를 0 으로 비웁니다(화면은 그대로). 버퍼 자리(`$E0 + Y`)마다 20칸 슬롯을 묶는 방식으로 바꾸자, 메시지가 떠도 이름이 남았습니다.

## 틀렸던 것들

- 게임 목록을 쓰는 것이 문제라고 보기 전에, NMI 대기(`00:958A`) 중 다른 작업이 도는 것, 목록 항목 크기, 창 작업의 작은 스택을 차례로 의심했습니다. 각각 고쳐도 같았습니다.
- 처음 본 멈춤은 그리기가 느려(이름마다 버퍼 1024워드를 훑고 NMI 를 기다림) 시험 입력의 A 를 놓친 것이었습니다. 버튼을 길게 눌러 시험하도록 바꿨습니다.

## 남은 것

- 주문 `D6`, 전투 몬스터 목록 `C8`·`E6`, 전투 도구 창(`04:B808` 을 거치지 않음), 가게 목록, 고정 문구
- 메시지 본문 속 도구 이름(「ひのきのぼうを 道具として」)
- 대기열이 차서 기다리는 동안 짧게 누른 버튼을 놓칠 수 있음
