# 2026-10-28-07: 교회와 맡기는 곳 창

교회 창과 맡기는 곳 창의 고정 문구를 한글로 바꿨습니다. 결과는 [교회와 맡기는 곳](../docs/dq4-window-text-format.md#교회와-맡기는-곳)에 있습니다.

## 1. 장면 만들기

가게 시험처럼 배 선실에서 파파스의 대화 번호(`7E:36EB`·`370B`)를 바꿔 말을 걸었습니다. 번호 몇 개를 훑어 찍었습니다.

| 번호 | 장면 |
| --- | --- |
| `02`·`03` | 가게(「お買い上げですね」) |
| `04` | 맡기는 곳(「ここは お金と 持ち物の 預かり所です」, 창 `51`) |
| `05`·`0F` | 교회(창 `3C`) |
| `07` | 동료 맡기기(혼자라 거절) |
| `0E` | 몬스터 경주 표 |

맡기는 곳에서 あずける 를 고르면 `51` 이 닫히고 `52`(もちもの / おかね)가, ひきだす 를 고르면 `54`(どうぐ / ぼうぐ / ぶき / おかね)가 뜹니다. 셋이 함께 뜨지 않으므로 가게 창처럼 창마다 전용 칸 `1D0` 부터 겹쳐 씁니다.

## 2. 48칸에 맞추기

전용 칸은 창마다 48칸, 한 열이 위·아래 두 칸이라 24열입니다. Galmuri9 로 그린 열 수를 셌습니다.

| 문구 | 열 |
| --- | --- |
| 기도하기 · 되살리기 · 독을 치료 · 계시 듣기 · 저주 풀기 | 6 |
| 계시를 듣기 · 저주를 풀기 | 7 |
| 계시 · 소생 · 해독 · 그만 | 3 |

`adopt.tsv` 이름 그대로면 36열이라, 「기도하기 / 계시 / 소생 / 해독 / 저주 풀기 / 그만」 으로 24열에 맞췄습니다. 교회 창(x 20, 너비 10)에는 여섯 열 문구와 커서가 들어갑니다.

## 3. 확인

| 장면 | 결과 |
| --- | --- |
| 교회 | 메시지 「わが教会に どんな ご用かな?」 와 함께 여섯 항목 한글 |
| 맡기는 곳 | 「맡기기 / 꺼내기 / 그만」, 「소지품 / 돈」, 「도구 / 방어구 / 무기 / 돈」 |
| 무기점 | 「사기 / 팔기 / 그만」 그대로(문구 번호가 밀려도) |
| 무작위 입력 6벌 · 이름 검사 셋 · 단위 시험 | 모두 정상 |

## 남은 것

- 예/아니요 창 `32` 는 게임 안에서 낮은 WRAM 사본을 써서 아직 가나
- 교회 문구를 줄인 이름(「계시」·「소생」·「해독」)이 DS 판과 다름. 전용 칸을 늘리면 되돌릴 수 있음
