# 2026-10-28-10: 장비 창과 남은 가나

가나 칸을 한글 칸으로 돌려 쓰기 전에, 필드 창이 아직 가나 칸을 가리키는지 재고 남은 창을 한글로 바꿨습니다. 결과는 [장비 창과 남은 가나](../docs/dq4-window-text-format.md#장비-창과-남은-가나)에 있습니다.

## 1. 가나 칸을 가리키는 창 세기

선실 무작위 입력 세 벌을 200프레임마다 VRAM 덤프와 함께 돌려, BG3 타일맵(워드 `3C00`)이 가리키는 칸 중 가나 `010`~`078` 을 셌습니다. `010` 은 세이브스테이트 주인공 이름 「ああああ」 의 あ 라 빼고 보니, 열한 장면이 남았습니다.

| 창 | 가나 |
| --- | --- |
| 강함 보기 | 「パパスのむすこ」 |
| 장비 비교 창 | 제목의 물건 이름(「ひのきのぼう」), 「しゅびりょく」·「こうげきりょく」 |
| 장비 목록 | 끝 항목 「そうびしない」 |
| 혼자일 때 さくせん | 「ならびかえをする」 |

## 2. 어디서 찍나

혼자일 때 さくせん 은 창 `5A` 로, 일행이 있을 때의 `09` 에서 둘째 줄을 뺀 레코드였습니다. 나머지는 창 레코드에 없어, 원래 롬으로 장비 화면을 열고 `04:A000`~`C7FF` 커버리지를 모아 리스팅했습니다. 창 부호로 롬을 찾자 문자열 목록 두 곳이 나왔습니다.

```
04:C2BF  79 79 79 01 01 ff | 19 12 84 18 16 37 41 17 ff | 1b 40 84 2a 37 41 17 ff | ...
         ？？？               こうげきりょく               しゅびりょく
04:C13E  fe ぼうぎょ ff fe にげる ff fe そうびしない ff おわり ff
```

- `04:BDA2` 가 `JSR $C25D`(라벨을 `$01~` 에 베낌) 뒤 `BRL $BC08` 로 찍습니다. `04:BC08` 은 이미 `WnMonster` 훅입니다.
- `04:BA60` 은 `04:C14D`(「そうびしない」)를 `$01~` 에 베끼고 `$00` = 7 로 `BRL $B808`(`WnText`)입니다.
- 제목의 물건 이름은 `04:AA68` 이 `$42`·`$43` = 5 로 이름을 받아 `04:AA79` 부터 제목 줄 고리 `04:ABD6` 으로 찍습니다.

## 3. 버퍼의 9E

두 문자열 길 모두 `$01~` 를 우리 훅에 넘기므로, 문자열을 `9E k` + 빈칸으로 바꾸고 훅 입구에서 `$01` 이 `9E` 면 `$42`·`$43` 을 고정 문구 k 로 바꿨습니다. 표 오프셋(`04:C25D` 가 `LDY` 로 고르는 자리)은 그대로입니다. 훅에 들어올 때 `$42`·`$43` 에는 앞서 받은 이름(물건 번호)이 남아 있어, 그대로 두면 엉뚱한 물건 이름을 그릴 수 있었습니다.

제목은 `04:AA79` 의 11바이트를 `JML WnTitleName` 으로 바꿨습니다. 고정 문구를 제목 줄에 그리는 `WtFixedDraw` 를 이름 표 자리(종류 × 200 + 번호 × 2)를 받는 `WtNameDraw` 로 넓혀 썼습니다. 처음 짠 것은 표 자리를 `$00` 에 잠시 두었는데, `$00` 은 원래 고리의 글자 수라 한글 표에 없는 이름일 때 원래 길이 깨질 수 있어 스택으로 바꿨습니다.

| 장면 | 결과 |
| --- | --- |
| 장비 → 무기 | 제목 「노송나무 막대」, 「공격력 E 13」, 「장비 해제」 |
| 장비 → 갑옷 | 제목 「천 옷」, 「수비력 7▶3」 |
| 혼자일 때 さくせん | 「작전 / 대열 바꾸기」 |
| 선실 무작위 입력 6벌의 VRAM 덤프 234장 | 가나 칸을 가리키는 것은 강함 보기의 「パパスのむすこ」 하나 |
| 무작위 입력 6벌(전투 둘 포함) · 이름 검사 셋 · 단위 시험 | 모두 정상 |
