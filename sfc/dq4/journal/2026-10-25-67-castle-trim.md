# 2026-10-25-67: 성 왼쪽 아래 조각 제거

성 왼쪽 아래의 독립된 조각처럼 보이는 부분을 제거합니다. [타이틀 애니메이션](../docs/dq4-title-animation.md)의 전경 표시 마스크에서 해당 부분을 빼고 움직이는 하늘과 앞 구름이 보이게 합니다.

## 1. 우선순위 수정 이후의 판단

공유 타일의 겹침 오류를 바로잡은 뒤에도 사용자는 아래 조각이 같아 보인다며 제거를 요청했습니다. 가림 관계를 유지하려는 보완 대신 해당 조각 자체를 표시하지 않도록 바꿉니다.

## 2. 제거 범위

성 왼쪽 아래의 작은 구름·구조물 조각만 마스크에서 제외합니다. 원본 그림은 보존하고, 부제 글자와 마름모, 성 본체와 오른쪽 구름 받침은 유지합니다.

## 3. 제거 확인

제거한 313픽셀의 범위는 x=180~207, y=185~199입니다. 해당 영역에 남은 전경 픽셀은 0이며 글자 마스크와 오른쪽 성은 그대로입니다. BG1은 280타일이고 용·구름·스크롤·전송 데이터는 바뀌지 않습니다. Asar 포함 검사 13개가 통과했습니다. 실제 화면 16장과 VRAM이 독립 합성과 일치했고, 메뉴 화면 차이는 0픽셀, CGRAM은 512바이트 일치했습니다. 이전 화면과 같은 구름 위치로 비교해 제거 영역만 달라지는 것도 확인했습니다.

## 남은 것
