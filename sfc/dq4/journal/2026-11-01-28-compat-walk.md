# 2026-11-01-28: snes9x·bsnes 로 1장 끝까지 걷기와 회귀 가드

[11번 일지](2026-11-01-11-spar-brk-db.md)에서 snes9x 의 서장 멈춤을 고친 뒤, 1장 끝까지 다른 에뮬레이터로 걸었습니다. 같은 실수가 다시 들어오지 못하게 가드 셋을 넣었습니다. 형식은 [호환성 검사](../docs/dq4-compat-format.md)에 있습니다.

## 1. libretro 로 1장 걷기

MesenCE 1장 걷기 검사(`dq4ch1walkcheck`)는 구간마다 세이브스테이트를 남기고, 맵 사이를 「어디서나」 워프(롬에 트리거를 깖)로 옮깁니다. 세이브스테이트는 에뮬레이터끼리 오가지 못하므로, 코어 하나에서 처음부터 끝까지 이어 걷는 `dq4compatcheck.py walk` 를 만들었습니다. 같은 구간 표(`SEGMENTS`)를 읽고, 워프의 롬 쓰기는 cheat(PAR 코드)로 합니다.

snes9x 1.63 은 처음부터 27구간을 모두 지났습니다. 끝 리셋 뒤에는 타이틀 → 모험의 서 메뉴까지 갔습니다.

## 2. bsnes 의 가짜 실패 셋

bsnes 115 는 세 번 실패했고, 셋 다 시험 도구 탓이었습니다.

- **우물 워프**: 트리거 목록 포인터(`7E:183A`~`183D`)를 bsnes 는 WRAM API 가 없어 cheat 로 3프레임만 썼더니 덮여 버렸습니다. 40프레임으로 늘리자 지났습니다.
- **왕에게 보고한 뒤 필드로**: 보고와 레벨업까지 하고 성 앞(`36/00`) 대신 필드로 나갔습니다. 같은 칸(32,72)에서 snes9x 는 `36/00` 으로 갔고, WRAM 을 읽지 않고 같은 버튼만 다시 재생해도 bsnes 는 필드로 갔습니다. `king` 직전 상태의 `$183A`~`183D` 가 snes9x 는 `08 B3 3C 01`, bsnes 는 `08 B3 3C 00` 이었습니다. bsnes 는 cheat 를 풀 때 켜기 전 값을 되돌려, 앞 워프 때 맵 로더가 쓴 트리거 개수를 0 으로 덮은 것입니다. 한 번 쓰는 값은 상태를 고쳐 다시 불러오게 바꾸자 지났습니다.
- **끝 리셋**: 리셋 뒤 화면이 어둡다고 실패했습니다. 장면을 보니 타이틀이 떴다가 어두운 메뉴로 넘어간 것이었습니다. 판정을 「타이틀이 한 번이라도 뜸」으로 고쳤습니다.

main 의 걷기 검사가 그 사이 구간마다 난수·시각을 정한 값으로 두게 바뀌어, libretro 걷기도 같이 둡니다. snes9x 로 두 번 돌리자 프레임 수(56,140)와 소리가 같았습니다.

## 3. 높은 뱅크의 BRK

MesenCE 1장 걷기 동안 BRK 핸들러 입구(`00:8F80`)에서 부른 뱅크와 명령을 적었습니다. 뱅크 `40` 이상에서 불린 명령은 `09`·`88`·`89`·`8B`·`8D` 다섯이었습니다. 같은 걷기에 뱅크 `40`~`7D` 아래 절반 접근 기록을 붙이자, DQ5 원래 코드(뱅크 `25`)의 SRAM 접근 말고는 없었습니다.

그래서 이 다섯을 허용 목록으로 하고, 사건 코드를 진입점부터 흐름을 따라 역어셈블해 목록 밖 BRK 를 찾는 `dq4brkscan.py` 를 CI 테스트로 넣었습니다. 정적 검사가 찾은 BRK 는 걷기에서 실행된 것을 모두 포함했고, 걷기가 지나지 않는 11곳(`09`·`8D`)도 더 봅니다. 처음 넣은 허용 목록에는 짐작한 명령(`0E`·`0F`·`11`·`19`)이 있었는데, 실측 근거가 없어 뺐습니다.

뱅크 `00`~`3F` 의 다른 열린 버스 구역까지 기록을 넓혀 걸어 보니, 기록은 같았지만 콜백이 많아 MesenCE 걷기 검사가 첫 구간에서 시간 제한에 걸렸습니다. 프로브는 뱅크 `40`~`7D` 만 봅니다.

## 4. 가드가 잡는지

칼 효과음을 #904 이전의 `BRK 16` 으로 되돌린 롬을 만들어 돌렸습니다. 열린 버스 프로브는 `BRK 16` 과 `24:FE52`·`24:FE55` 의 `5E:` 읽기를 적고 실패했고, snes9x 걷기는 서장 `3C/01` 에서 멈춰 실패했습니다. 정적 검사의 단위 테스트도 같은 되돌림을 잡습니다.

두 실행 검사는 `sfc/dq4/guards.toml` 에 등록해, 높은 뱅크 코드를 만드는 도구를 바꾼 PR 이 결과를 본문에 적게 했습니다([GUARD-02](../../../.agents/skills/guards/SKILL.md#guard-02--걸린-실행-검사는-돌리고-결과를-적는다)).
