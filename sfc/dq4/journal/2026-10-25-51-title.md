# 2026-10-25-51: 한글 타이틀과 DQ5 오프닝 연결

사용자가 고른 한글 타이틀 v2를 실제 크기 원본으로 고정하고 DQ5 시작 구간에 연결했습니다. 표시 규격과 재현 명령은 [타이틀 문서](../docs/dq4-title-format.md)에 있습니다. 그래픽을 Lua로 덮어쓰는 실험이 아니라 롬 코드가 타일·팔레트를 읽고 입력 후 원래 메뉴로 돌아갑니다.

## 1. 실제 크기로 고른 타이틀

용과 구름, 붉은 한글 로고, 금색 IV가 있는 기존 구도를 유지하며 부제의 명암을 다듬었습니다. 부제를 더 크게 만든 비교안도 만들었지만 사용자는 작은 부제의 v2를 골랐습니다. 선택된 256×224 색 번호 PNG를 기준으로 삼아 이후 다시 줄이거나 색을 고르지 않습니다.

117색·890타일을 4bpp CHR, 8개 BG 팔레트, 32×32 타일맵으로 내보냅니다. 먼저 독립 SFC 미리보기 롬을 만들어 MesenCE에서 선택 이미지와 57,344픽셀이 모두 같은 것을 확인하고 사용자에게 띄웠습니다.

## 2. NDS판을 실제로 실행

일본판과 한글패치판을 DeSmuME libretro에서 3,600프레임 실행하고 A·Start·터치 입력을 따로 관찰했습니다. 구름과 천공성, 제작진 표기, 용의 등장, 흰 로고에서 본래 색으로 바뀌는 연출, A 입력 뒤 암전과 메뉴 전환을 확인했습니다. 한글패치판은 영어 본제를 유지하고 작은 부제가 한글인 점도 확인했습니다.

NDS의 두 화면과 3D 용을 그대로 복제하지 않고, 한 화면의 승인된 그림과 SFC의 창·밝기·팔레트 기능으로 도입과 로고 광택을 구성했습니다. NDS 영상·소리는 참고용 로컬 파일에만 보존합니다.

## 3. 기존 초기화와 메뉴 경로 보존

원래 타이틀 진입 `03:FDE8`과 초기화 뒤 `03:FDFB`, 종료 처리 `03:FE5C`를 실행 추적으로 확인했습니다. 새 루틴을 확장 롬에 두고 기존 타이틀 초기화와 메뉴 처리를 이어 씁니다. 타일은 VRAM 위쪽에 올려 메뉴 글꼴 영역을 보존하고, 팔레트와 PPU 설정을 복원합니다.

도입은 어두운 상태에서 화면이 열리며 밝아지고, 로고 안에만 쓰이는 따뜻한 색 7개로 짧은 광택을 냅니다. 효과가 끝나면 원래 팔레트로 돌아옵니다. A·Start 입력 뒤 암전하며, 눌린 버튼을 해제한 뒤 메뉴로 복귀합니다.

## 4. 음악 시작 시점을 옮기기

원래 DQ5 크레딧은 무음이며 메뉴 직전 곡 인자 `$10`(사운드 명령 `$01`)이 실행되는 것을 확인했습니다. 이 명령을 새 타이틀 진입으로 옮기고 원래 위치의 중복 실행을 막았습니다. 타이틀 대기 중 SPC 출력이 발생하고 메뉴에서도 같은 음악이 이어집니다.

## 5. 실행 검증

MesenCE에서 A·Start·버튼 유지·소프트 리셋을 검사했습니다. 타이틀은 기준 그림의 57,344픽셀과 일치하고, 복귀한 메뉴는 원본 화면과 CGRAM 512바이트가 같았습니다. 기존 저장 파일을 사용하지 않는 별도 롬 이름으로 새 게임의 이름 입력 화면까지 진입했습니다. 실제 기기와 기존 저장 파일 불러오기, 전체 게임 진행은 검증하지 않았습니다. 자동 검사 26개와 Python·Lua 문법, 문서 검사를 통과했습니다.

## 틀렸던 것들

- 고해상도 부제만 선명해졌다고 실제 크기에서도 충분히 읽히는 것은 아니었습니다. 사용자가 고른 실제 크기 이미지를 별도 원본으로 고정했습니다.
- 기존 팔레트 변환은 색이 적은 영역에서 팔레트 길이가 짧아질 수 있었습니다. 16색 경계를 채우고 기존 기본 결과가 바뀌지 않는 회귀 검사를 더했습니다.
- PPU의 세로 스크롤만 `FFFF`로 써도 NMI가 원래 WRAM 값을 다시 쓰므로 통합 화면이 한 줄 위로 밀렸습니다. NMI가 읽는 `0033`을 타이틀 동안 바꾸고 복귀 전에 복원했습니다.
- 기존 오디오 초기화가 실행됐다는 사실만으로 타이틀에 음악이 나온다고 판단할 수 없었습니다. 실제 SPC 출력과 음악 명령 실행 시점을 따로 관찰했습니다.

## 남은 것

- NDS의 독립된 용·구름 움직임을 재현하려면 한 장에 합쳐진 그림을 위한 별도 배경과 마스크가 필요합니다. 이번 결과는 승인 그림을 유지하는 SFC식 도입 연출입니다.
- 메뉴 뒤 DQ5 게임 내용의 DQ4 이식은 별도 범위입니다.
