# 2026-10-29-12: 창 문구 다듬기

사용자가 창 문구가 어색하다고 해, 제가 옮긴 고정 문구를 NDS 한글 팬패치의 메뉴 문구와 맞대 보고 사용자 결정으로 고쳤습니다. 결과는 [문구 다듬기](../docs/dq4-window-text-format.md#문구-다듬기)에 있습니다.

## 1. 한글판과 맞대기

`nds/dq4/tools/ndstext.py dump` 로 일본어판·한글판의 메뉴(`b1004000`)·작전(`b1005000`)·능력치(`b1006000`) 표를 나란히 뽑고, `sjis` 로 `arm9` 의 문자열도 뽑았습니다. 대사 파일 전체도 줄 단위로 일본어·한글을 짝지어, `dq4windowtext.FIXED`·`TITLES`·`EXTRA_NAMES` 의 키(빈칸·`@` 표지를 뺀 것)로 찾았습니다.

```
つよさ          강함        강한 정도×1
おつげをきく    계시        계시를 듣기×1
いきかえらせる  소생        되살리기×1
　　もっている  가짐        가지고 있음×1
やめる          그만        그만두기×2
```

115개 가운데 59개가 한글판에 있었습니다. 한글판이 더 나쁜 곳도 있었습니다(「おいのりをする」 = 「명복을 빌기」, 「いいえ」 = 「아니오」).

## 2. 고치기

사용자 결정으로 바꾼 문구는 형식 문서 표와 같습니다. 「강함」 은 한글판 「강한 정도」 도 어색해 일반 게임에서 쓰는 「상태」 로 했고, 「그만」 은 「나가기」, 가게 동료 창의 「가짐」 은 바로 위 「장비 중」 과 꼴을 맞춰 「소지 중」 으로 했습니다. 빌드가 창 폭을 넘으면 오류를 내므로, 넘친 둘(「어떻게 할까」 7열, 「주문을 쓸 수 없다」 11열)은 창을 넓혔습니다. 한 줄 창(`LINE_WINDOWS`)은 넓히는 길이 없어 창 번호 → 넓힐 칸 수 사전으로 바꿨습니다.

## 3. 확인

| 장면 | 결과 |
| --- | --- |
| 명령 창·つよさ 창·どうぐ → 어떻게 할까 | 새 문구가 창 안 |
| 무기점·교회 | 새 문구가 창 안 |
| 깨짐 검사 | #600 과 같이 시험용 가게 `08` 하나 |

## 남은 것

- 시험용 가게 `08` 의 팔기 장비 비교 창 제목이 「공격력」 다음부터 엉뚱한 고정 문구(이번 변경 전부터)
- 가게 동료 창의 「소지 중」 과 한 줄 창 `2D`·`82` 는 빌드의 칸 검사로만 확인(장면을 아직 띄우지 않음)
