# 2026-10-30-55: 우물 아래로 떨어지기, 아이 목소리, 호이민 합류

1장 진행 사건의 두 번째 묶음입니다. 결과는 [1장 첫머리 문서의 우물 아래와 호이민](../docs/dq4-chapter1-format.md#우물-아래와-호이민), [환경 문서의 떨어지는 칸](../docs/dq4-environment-format.md#떨어지는-칸)에 있습니다.

## 1. 떨어지는 칸

FC 는 古井戸 바닥 1C/00 (0D,06)의 구멍으로 떨어져 우물 아래 3A/00 으로 갑니다. 우물 아래의 큰 구멍(584칸)은 3A/02 로 떨어집니다. 그룹 연결은 이 칸을 검은 칸으로 그리기만 했고, 밟아도 아무 일이 없었습니다.

DQ5 의 영역 이동 레코드로 넣었습니다. 사각형이 넓으면 도착 X 가 들어선 자리에 비례하는데, 식(`2A:F650`)을 읽으니 (`span_raw` − 1)을 곱합니다. 그래서 `span_raw` 를 1 로 두면 구멍 어디서 떨어져도 같은 칸에 섭니다. FC 한 줄의 이어진 칸을 묶어 `3B/00` 은 82개 레코드가 되었습니다. 다른 그룹으로 가는 우물 바닥의 구멍도 목적지 그룹만 적으면 됐습니다.

2장 `3D` 에도 맵으로 떨어지는 구멍이 있었지만, 그 장의 이벤트와 얽혀 있을 수 있어 1장 그룹만 넣었습니다.

## 2. 아이 목소리

FC 는 우물 아래 두 칸에서 「こっちへ おいでよ…」·「そっちじゃ ないよ」 를 띄웁니다(1D 블록 이벤트). DQ5 인물 스크립트의 명령 `05` 는 루틴이 A = 0 을 돌려줄 때까지 매 프레임 부릅니다. 서장에서는 이것으로 인물과의 거리를 쟀습니다. 이번에는 주인공 X·Y(`7E:3020`·`3080`)가 정한 칸인지 보는 루틴을 짰습니다. 보이지 않게 숨기고 자리를 치운 인물에게 이 루틴을 기다리게 하자, 그 칸에 서는 순간 목소리가 떴습니다.

## 3. 호이민

DQ5 의 ホイミスライム 는 종류 `05` 이고, 첫 이름이 「ホイミン」 입니다. 동료 기록의 꼴은 이미 재 두었습니다. 동료가 된 スライム 기록을 틀로 종류·레벨·능력치·HP·MP 만 바꾸면 전투에서도 동료로 움직입니다(`dq5warp.lua` 의 `PARTY`). 같은 일을 하는 루틴 `join` 을 짰습니다. 동료 표(`23:AED1`)의 값으로 채운 기록을 일행 끝에 복사하고, 일행 수·걷는 수·순서를 고칩니다.

「예」 갈래에서 이 루틴을 부르려 했지만, 대화 스크립트의 네이티브 호출은 뱅크 06 안의 루틴만 부릅니다. 그래서 대화는 합류 깃발만 켭니다. 기록은 호이민 인물 스크립트가 그 깃발을 기다렸다가(`09`) `37`(어느 뱅크든 JSL)로 씁니다. 다시 들어와도 스크립트가 처음부터 돌므로, 깃발이 켜진 뒤에는 호이민이 없는 대체 목록을 씁니다.

## 4. 확인

1장 시작 세이브스테이트에서 워프해 걸었습니다.

| 장면 | 결과 |
| --- | --- |
| `38/00` 구멍 아래 칸에서 위로 | `3B/00` (46,6) 바닥에 섬 |
| `3B/00` 큰 구멍 (0A,05) 위에서 아래로 | `3B/02` (10,16) |
| 목소리 두 칸 | 「이쪽으로 와……」·「그쪽이 아니야.」 |
| 호이민에게 말을 걸어 예 | 합류 깃발, 일행 수 1 → 2, 둘째 기록 `85 80 …`(Lv4, HP 59, MP 22), 일행 창에 ホイミン, 호이민 인물 사라짐 |
| 합류 깃발을 켜고 다시 들어감 | 호이민 없음, 일행 수 그대로 |

서장부터 1장까지의 `dq4prologuecheck.py` 도 통과했습니다.

## 남은 것

- 합류한 맵에서는 호이민이 뒤따라 걷지 않았습니다. 맵을 다시 불러오면 그려지는지는 재지 않았습니다.
- 호이민의 「아니요」 갈래, 합류 팡파르(FC 는 메시지 안의 효과음 `1A`), 이름 「ホイミン」 의 한글.
- 목소리의 방향 조건과 そらとぶくつ 를 가졌을 때 뜨지 않는 것. 떨어질 때 화면을 흔드는 연출.
