# 2026-11-01-41: 필드에서 반투명하던 주인공

1장 필드(이무르 근처)에서 걷는 주인공이 풀밭과 반씩 섞여 초록빛으로 비쳐 보였습니다. 마을·성 안에서는 멀쩡했고, 전투 전후 모두 같았습니다. 원인은 DQ5 가 필드 맵을 불러올 때 켜는 OBJ 반 더하기였고, 그 값을 끄도록 고쳤습니다. 결과는 [스프라이트 형식의 「필드의 OBJ 색 연산」](../docs/dq4-sprite-format.md#필드의-obj-색-연산)에 넣었습니다.

## 1. 장면과 PPU 상태

1장 성 앞 세이브스테이트(`dq4ch1walkcheck.py --until throne_out`)에서 FC 필드 0 의 이무르 근처 칸으로 워프해(`dq5warp.lua` `FIELD`) 340프레임째에 MesenCE 의 PPU 상태와 OAM 을 찍었습니다.

```text
ppu.colorMathEnabled=16        ← bit4 = OBJ
ppu.colorMathAddSubscreen=true
ppu.colorMathHalveResult=true
ppu.subScreenLayers=3          ← BG1·BG2
OAM 0~5  x 120·128  y 103·111·119  팔레트 6  우선순위 3
```

SNES 색 연산은 OBJ 가운데 팔레트 4~7 에만 걸립니다. 장 주인공은 [인물 그림 단계](../docs/dq4-sprite-format.md#팔레트)가 전용 줄 6 에 둡니다(서장 주인공 7, 호이민 5). 그래서 필드에서는 주인공 점마다 서브 화면의 BG1·BG2 색과 더해 반으로 나눈 색이 찍혔습니다.

## 2. 누가 켜나

레지스터 그림자 `$0737`·`$0738`(NMI 의 `00:8AD0`·`8AD6` 이 `$2130`·`$2131` 로 옮김)은 끝 프레임에 `30`·`00` 이었고, HDMA 채널도 모두 꺼져 있었습니다. 레지스터 거울 뱅크(`00`~`3F`·`80`~`BF`)마다 `$212C`~`$2131` 쓰기 감시를 걸자 필드에 들어가는 프레임에 이것만 남았습니다.

```text
173 212D pc=2B:82F2 v=03
173 2130 pc=2B:82F7 v=02
173 2131 pc=2B:82FC v=50
```

`2B:82DE` 는 `$BE` bit7 이 꺼진 맵(필드)에서만 아래로 내려가 서브 화면 BG1·BG2, `$2130` = `02`, `$2131` = `50` 을 씁니다. 원래 DQ5 롬도 같은 코드입니다. DQ5 형식 문서에 따르면 필드에서 OBJ 팔레트 5 를 쓰는 것은 탈것 그림자이고, 원래 주인공은 0~3 이라 이 설정에 걸리지 않았습니다.

## 3. 고침

`2B:82F7` 의 `LDA #$50` 을 `LDA #$00` 으로 바꿨습니다. 인물 그림 단계가 주인공을 팔레트 4~7 에 두므로 같은 단계의 `dq4people.hook_patch` 에 넣었습니다(원래 바이트 `A9 50` 이 아니면 빌드가 멈춤). 바이트 하나만 바꾼 롬으로 같은 장면을 다시 찍자 색 연산 층 비트가 `00` 이었고, 주인공이 원래 색으로 그려졌습니다. 같은 입력으로 걷다 전투를 치르고 돌아온 3,300프레임째 화면도 불투명했습니다(돌아올 때 같은 맵 불러오기를 다시 지납니다).

## 4. 가드

- 단위 검사 `test_dq4people.py` 가 `hook_patch` 의 `2B:82F7` 쓰기(`A9 50` → `A9 00`)를 봅니다. 고치기 전 코드로는 실패합니다.
- 실행 검사 `dq4fieldmathcheck.py`(`guards.toml` 의 `dq4-field-obj-math`)는 서장 성 마을 출발 상태에서 같은 필드 칸으로 워프해 120프레임 서 있은 끝 프레임을 봅니다. 필드이고, 화면 가운데 OBJ 가 팔레트 4~7 이고, OBJ 색 연산 비트가 꺼져야 통과입니다. 고치기 전 롬은 「층 비트 10」 으로 실패했고, 고친 1장 롬은 가운데 OBJ 6장 팔레트 6·층 비트 `00` 으로 통과했습니다.

## 틀렸던 것들

- 레지스터 그림자 `$0738` 만 보고 필드의 `$2131` 이 0 이라고 볼 뻔했습니다. 필드 맵 불러오기는 그림자를 거치지 않고 `$2131` 에 바로 씁니다. 처음 건 쓰기 감시도 뱅크 `00` 의 `$2130` 만 잡아, 데이터 뱅크 `2B` 로 쓰는 `2B:2131` 을 놓쳤습니다.

## 남은 것

- 필드 OBJ 색 연산을 끄면 DQ5 탈것 그림자(팔레트 5)도 반투명하지 않게 될 것으로 보입니다(코드 읽기). 탈것 그림자가 나오는 장면은 재지 않았습니다.
