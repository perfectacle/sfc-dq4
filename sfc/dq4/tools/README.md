# dq4 도구: SFC 포팅 결과물

저장소 최상위에서 `uv run --locked python sfc/dq4/tools/<스크립트>` 로 실행합니다. 모듈끼리는 같은 폴더에서 import 합니다. SFC 프로브(`lua/`)는 `"$PWD/sfc/dq4/tools/lua/<스크립트>"` 로 주고, 툴킷 `boot.lua` 드라이버는 [공통 도구](../../../tools/README.md) 의 `LIBDIR`·`seqlib.sh` 설정을 따릅니다. FC 원작 분석 도구는 [fc/dq4/tools/README.md](../../../fc/dq4/tools/README.md) 에 있습니다.

사용자가 채택한 타이틀은 `dq4titlelayers.py`와 `dq4titlelayerpatch.py`로 만듭니다. [채택본 재현 절차](../docs/dq4-title-animation.md)를 먼저 읽고, 정지 미리보기·전체 화면 교체 실험과 구분합니다.

## 환경 그래픽

`uv run --locked python sfc/dq4/tools/dq4environment.py --out work/environment --rom rom/dq4.nes --references "$DQ4_ASSETS"`로 FC 원작의 색 역할과 DQ5 색·도트 구조로 새로 그린 환경 에셋, FC 배치 비교 맵, SFC 타일 데이터와 갤러리를 만듭니다. `DQ4_ASSETS`는 비공개 `sfc-dq4-assets` 체크아웃입니다. 캐릭터·몬스터는 포함하지 않습니다.

`dq4environmentprobe.py`는 독립 SFC 미리보기의 MesenCE 화면·VRAM·팔레트를 검사합니다. `dq4environmentrom.py --out 폴더`는 FC 실내 맵을 DQ5 실내 맵 자리(빌린 자리)나 새 그룹에 넣는 `dq5patch/1` 목록을 만들고, `dq4environmentromcheck.py --rom 롬 --out 새폴더`는 MesenCE로 워프해 게임 메모리로 다시 그린 맵·통행 속성·다른 맵 복원을 검사합니다(`lua/dq4environmentdump.lua`, `MESENCE`·`LIBDIR` 필요). 출력 규격과 실행 인수는 [환경 그래픽 문서](../docs/dq4-environment-format.md)에 있습니다. `dq4groupbuild.py --out 폴더`는 FC 그룹을 새 DQ5 그룹으로 넣고 FC 계단·출구 표·필드 입구로 이은 롬을 만들고, `dq4groupcheck.py --rom 롬 --out 새폴더`는 계단·영역 이동·필드 출입을 MesenCE 로 밟습니다(1장 롬은 `--set '2199|01'` 로 왕좌의 방 연출을 건너뜀, [그룹 연결](../docs/dq4-environment-format.md#그룹-연결)). `dq4entrancehook.py` 는 필드 입구마다 도착을, 맵마다 필드로 나오는 자리를 고르는 훅을 만듭니다(빌드가 부름, [입구별 도착](../docs/dq4-environment-format.md#입구별-도착)). `dq4npcport.py --out 폴더`는 새 그룹 맵의 FC 인물을 DQ5 인물 목록과 일본어 원문 메시지로 바꾸고(빌드가 부름), `dq4npccheck.py --build 빌드폴더 --out 새폴더`는 인물 표, 서 있는 인물의 대화, 가게 품목·값·여관 값을 MesenCE 로 봅니다([인물](../docs/dq4-environment-format.md#인물)). `dq4shopport.py --out 폴더`는 FC 가게 인물·품목·여관 값을 DQ5 시설 번호·상점 목록·옮긴 여관 값 표로 바꿉니다(빌드가 부름, [가게](../docs/dq4-environment-format.md#가게)). `dq4shopkey.py` 는 가게 목록·여관 값을 DQ5 그룹 대신 FC 그룹마다 따로 받은 키로 찾게 하는 훅을 만듭니다(`dq4shopport.py` 가 부름, [가게·여관 키](../docs/dq4-environment-format.md#가게여관-키)). `dq4itemport.py` 는 옮긴 가게가 파는 물건의 DQ5 값을 FC 값으로 바꾸고, DQ5 에 없는 FC 물건(てつのやり)에 DQ5 물건 자리를 빌려 이름·공격력·값을 씁니다(`dq4shopport.py` 가 부름, [물건 값과 빌린 자리](../docs/dq4-environment-format.md#물건-값과-빌린-자리)). `dq4chestport.py --out 폴더`는 새 그룹의 FC 상자·タンス·つぼ를 `dq5chestplace/1` 입력으로 바꾸고(빌드가 부름), `dq4chestcheck.py --build 빌드폴더 --out 새폴더`는 그것들을 MesenCE 에서 열어 봅니다([상자](../docs/dq4-environment-format.md#상자)). `dq4fieldport.py map|patch -o 파일`은 FC 필드 0 을 DQ5 세계 0 의 블록 지도와 그림·블록·지도 패치(`dq5fieldgfxwrite.py`·`dq5fieldtables.py`·`dq5fieldwrite.py`)로 만들고(빌드가 부름), `dq4fieldgfx.py preview -o 그림`은 그 필드 그림(DQ4 에셋을 DQ5 필드 팔레트로 옮긴 새 타일·블록)을 게임을 돌리지 않고 그립니다(`rom/dq5.sfc`·`rom/dq4.nes` 를 읽음). `dq4fieldcheck.py --rom 롬 --out 새폴더`는 필드의 WRAM 지도, 지형 걷기, VRAM·CGRAM 의 그림을 MesenCE 로 봅니다([DQ4 필드](../docs/dq4-field-format.md)). `dq4fieldtravel.py -o 폴더`는 옮긴 마을의 ルーラ 목록 칸·내리는 칸·배 칸을 보이고(빌드가 목록·배 자리·이름 패치를 냄), `dq4fieldtravelcheck.py --rom 롬 --out 새폴더`는 ルーラ·キメラのつばさ 로 내리는 칸, 다녀온 플래그, 옮겨진 배와 배 타기를 MesenCE 로 봅니다([ルーラ](../docs/dq4-field-format.md#ルーラキメラのつばさ)·[배](../docs/dq4-field-format.md#배)). `dq4fieldencounter.py -o 폴더`는 FC 필드 조우 구역을 DQ5 구역 레코드·격자로 옮긴 입력과 구역 대응을 내고(빌드가 레코드·격자·지형 조우율 패치를 냄), `dq4fieldencountercheck.py --rom 롬 --out 새폴더`는 FC 구역에서 걸어 구역 번호·무리·걸음 확률을 MesenCE 로 봅니다([조우](../docs/dq4-field-format.md#조우)). `dq4wellswitch.py` 는 우물 아래(FC 그룹 `3A`)의 조우 켬/끔 칸과, 꺼져 있을 때 조우하지 않게 하는 실내 걸음 훅을 만듭니다(빌드가 부름). `dq4dungeonrate.py` 는 던전 구역의 걸음 확률을 FC 처럼 셀 둘마다, 구역이 바뀐 걸음은 `0x55` 로 덮는 훅을 만듭니다(빌드가 부름). `dq4balance.py` 는 조우 배율(FC 의 3/4)과, 전투 경험치·금화 합을 4/3 배로 고치는 승리 처리 훅을 둡니다(빌드가 부름, [사용자 결정에 의한 원작과의 차이](../docs/dq4-chapter1-format.md#사용자-결정에-의한-원작과의-차이)). `dq4door.py` 는 2×3 문을 반 블록 걸친 자리·옆에서도 찾게 하고, 걸어서 문에 막히면 문을 여는 훅을 만듭니다(빌드가 환경 롬에 얹음, [앞 문 찾기](../docs/dq4-environment-format.md#앞-문-찾기)·[걸어서 여는 문](../docs/dq4-chapter1-format.md#걸어서-여는-문)). `dq4outside.py` 는 1장·서장 맵의 맵 밖 칸을 FC 바깥 블록으로 그리게 하는 루틴과 맵 표를 만듭니다(빌드가 환경 롬에 얹음, [맵 밖 칸](../docs/dq4-environment-format.md#맵-밖-칸)). `dq4doorcheck.py --rom 롬 --state 1장세이브스테이트 --out 새폴더`는 서장·1장 맵의 문마다 이웃 블록에서 걸어 들어가 문 열림 flag 를 MesenCE 로 봅니다(`lua/dq4doorwalk.lua`). `dq4dungeonencountercheck.py --rom 롬 --out 새폴더`는 1장 던전 맵에 들어가 걸으며 구역 번호·무리·`$194A`·곡·우물 깃발·FC 걸음 확률을 MesenCE 로 봅니다([던전 조우와 곡](../docs/dq4-chapter1-format.md#던전-조우와-곡)). `dq4wellresetcheck.py --rom 롬 --out 새폴더`는 우물 깃발을 켠 채 전멸하거나 기록을 불러온 뒤 깃발이 꺼지는지 봅니다(같은 절).
