# DQ4 서장

NDS 리메이크는 1장 앞에 서장을 더했습니다. 주인공이 산골 마을 지하에서 검술 수련을 하고, 마을을 돌다가 저녁을 먹는 짧은 이야기입니다([NDS 늘어난 내용](../../../nds/dq4/docs/extras.md)). 이 문서는 서장을 DQ5 엔진에 넣는 명세입니다. 도구는 `sfc/dq4/tools/dq4prologue.py` 이고, `dq4chapter1.py build --prologue` 를 줄 때만 넣습니다. 서장 끝(개구리·신시아·저녁)과 1장으로 넘기기가 아직 없어서, 옵션 없이 빌드하면 지금처럼 1장으로 시작합니다.

무대는 [그룹 연결](dq4-environment-format.md#그룹-연결)이 새 그룹 `3C` 에 넣은 FC 산골 마을입니다. `3C/00` 이 습격 전 마을 FC `14/00`, `3C/01` 이 지하 FC `14/01` 입니다.

| 넣는 것 | 자리 |
| --- | --- |
| 새 게임 첫 맵 | `25:8621` 표 항목 0 → `3C/01` 셀 (6,30)(FC (3,0F), 검사 바로 아래) |
| 장 제목 상자 | 「서장」. 1장 상자와 같은 루틴·캔버스([장 제목 상자의 장면](dq4-chapter1-format.md#검은-화면과-장-제목-상자)) |
| 연출 | 상자 → 지하가 밝아짐 → 칼 소리 셋 → 조작이 풀리고 주인공이 검사에게 말을 걺 → 물음·예·아니요·대답 → 맺음말 → 검사가 걸어 나가 사라짐 |
| 검사의 물음 | 덧붙인 대화 스크립트 `900`(`dq5talkwrite.py`, 묶음 `3A:F000`, 훅 `06:FE10`) |
| 네이티브 코드 | `5E:C000`(20프레임 기다리기) |
| 수련 끝 깃발 | `7E:219E` & `80` |
| 인물 | 지하 검사 1명, 마을 9명 |
| 한글 대사 | NDS `MESS/ja/b0200000.mpt` 81줄 가운데 수련·마을 사람 대사 |

## 대사

NDS 서장 대사는 일본어 원문을 직접 옮겼습니다. NDS 한글 팬패치의 번역은 참고만 했습니다. 고유명사는 `nds/dq4/tables/adopt.tsv`(베기라마)를 따르고, 표에 없는 シンシア 는 「신시아」로 적습니다. 대사 줄 너비와 쪽 수는 [1장 메시지](dq4-chapter1-format.md#메시지)의 규칙과 같습니다(한 줄 14칸, 이름 4칸, 한 쪽 4줄).

- 대화 번호는 1장이 쓴 번호(`300`~`30E`) 바로 다음 `30F` 부터 매깁니다. 대화 번호 T 는 메시지 T + `3C6` 을 띄웁니다. 메시지는 빌드에서 서장을 켜지 않아도 늘 넣습니다. 메시지 단계(`dq4chapter1.py messages`)에는 옵션이 없기 때문입니다.
- 문지기의 물음은 DQ5 묻기 대화 `24F` 입니다(메시지 `615` 뒤 예·아니요, 예면 `616`, 아니요면 `617`, [텍스트 형식의 묻기](../../dq5/docs/dq5-text-format.md#묻기-06b34f)).
- 원문 「ぷはーーっ！！」「ぐがー　ぐがー」의 장음은 메시지 글자에 없어 「푸하아아!!」「쿨쿨…… 쿨쿨……」로 옮겼습니다.
- 이름 뒤 조사는 피했습니다(「@ 아닌가」, 「너를」). `dq4chapter1` 의 대사 함수가 아직 조사 코드를 넣지 않기 때문입니다.

## 수련

검사는 1B/00 의 한 벌 엔트리 `05:B2EE` 2번(스크립트 `05:B329`)을 복사합니다. 1장 연출이 쓰는 배 인물(`05:A84F`·`05:A87B`·`05:A899`)과 FC 걷는 인물의 견본(`05:8888`)은 피했습니다.

| 차례 | 명령 |
| --- | --- |
| 조작 막기 | `3F` |
| 상자 「서장」 | `37` 상자 루틴(장면 `box0`) |
| 지하 밝히기 | `37` 맵 밝히기 루틴(맵 곡을 기다렸다 밝힘) |
| 수련 | `02 03` [`37` 20프레임 기다리기, `20 37 00` 효과음 `37`] `01`, `37` 기다리기 |
| 물음 | `40` 조작 풀기, `09 8E 80`(수련 끝 깃발이 켜질 때까지 대기), `3F` |
| 맺음말 | `21` 메시지 |
| 나가기 | `13`·`14` 로 (4,0E) → (4,07) → (3,07), `28` 숨기기, `40`, `16` |

물음은 주인공이 검사에게 말을 걸면 대화 스크립트 `900` 이 띄웁니다. 메시지(물음) → 조건 `05`(예·아니요 창 `06:B383` 에서 예) → 예·아니요 대답 → `flag-on 0E 80` 입니다. 깃발이 켜지면 인물 스크립트가 `09` 대기를 지나 맺음말을 띄웁니다. NDS 에서는 수련이 끝나면 검사가 저절로 묻지만, 여기서는 말을 걸어야 묻습니다. 다음 두 길은 실측에서 막혔습니다.

| 시도 | 결과 |
| --- | --- |
| 인물 스크립트 `30`(창 열고 메시지) 뒤 네이티브 루틴에서 `BRK 95 32` | 물음은 뜨지만 `BRK 95 32` 에서 돌아오지 않음. CPU 는 `04:DAD2`~`DAEB`(창 목록 `$0A01`·`$0A05,X` 를 도는 고리)에 머묾 |
| 대화 묻기(`06:B34F`)와 같은 순서(스크립트 `33` 으로 창을 열고, 루틴에서 `JSL 24:8157` 로 물음, `BRK 95 32`) | 같음 |
| 인물 스크립트 `08`(사각형 안이면 이벤트 시작)로 말 걸기 | 말 걸기가 아님. 물음 없이 다음 명령으로 넘어감 |

수련 끝 깃발이 켜지면 `3C/01` 은 빈 대체 목록(`new:cellar_after`)을 씁니다. 다시 들어와도 검사가 없습니다. 장 제목 상자의 맵 훅도 이 깃발을 보므로 맵이 검게 불려 오지 않습니다.

`7E:219E` bit7 은 원래 롬에서 비트로 켜고 보는 곳이 없지만([플래그](../../dq5/docs/dq5-flags.md)), 시험에 쓰는 배 선실 세이브스테이트(DQ5 중반)에서는 켜져 있었습니다(`219E` = `A4`). 바이트를 통째로 쓰는 곳이 있다는 뜻입니다. 새 게임에서는 꺼져 있어 상자가 떴습니다.

## 마을

인물은 [1장 인물](dq4-chapter1-format.md#인물)처럼 `05:8E43` 0번(스크립트 없음)을 복사하고, 자는 남자만 누운 선원 `05:A848` 1번(스크립트 `05:A86E` 을 `16` 하나로)을 복사합니다. 그림은 역할이 같은 DQ5 마을 사람입니다.

| 인물 | FC 자리 | 그림 | 대화 |
| --- | --- | --- | --- |
| 문지기 | (0D,17) | `06` | `24F`(묻기) |
| 농부 | (0B,10) | `29` | `313` |
| 남자 | (0F,09) | `03` | `314` |
| 검사(연못가) | (0D,04) | `08` | `315` |
| 노마법사 | (13,0D) | `1F` | `316` |
| 상인(옛 여관) | (14,14) | `40` | `318` |
| 어머니 | (02,10) | `17` | `319` |
| 아버지 | (05,12) | `09` | `31A` |
| 자는 남자 | (13,15) | `29`(누운 꼴) | `317` |

- FC 통행 지도(`fc/dq4/tools/dq4block.py rom/dq4.nes 14 0`)의 열·행 번호는 16진수입니다. 처음에 문지기 칸을 10진수로 읽어 `(0x13, 0x17)` 에 두었더니 벽 칸이었습니다.
- 마을 입구는 열 `0D`·`0E`, 행 `18`·`19` 의 틈입니다. 행 `17` 에서 그 틈으로 가는 칸은 (0D,17) 하나라, 문지기가 서 있기만 해도 마을 밖으로 나가지 못합니다.

## 검증

모두 MesenCE 헤드리스입니다.

| 장면 | 결과 |
| --- | --- |
| 전원부터 A 를 40프레임마다 눌러 새 게임 | 약 500프레임에 검은 화면 「서장」 상자, 지하가 밝아지고 검사와 주인공이 마주 봄. 수련 뒤 말을 걸자 물음과 예·아니요 창(890프레임) |
| 예 | 「그래. 오늘은 이쯤 해 두자……」 → 맺음말 2쪽 → 검사가 위 방으로 걸어가 사라지고 조작이 풀림 |
| 아니요(900프레임에 아래, 915 에 A) | 「오오! 제법 버티는구나.」 「하지만 오늘은 이쯤 해 두자.」 → 맺음말 → 같음 |
| 마을 9명. 이웃 칸으로 워프해 말 걸기(`dq4npccheck.run`·`TALKS`) | 9명 모두 첫 메시지가 그 인물 대사(`615`, `6D9`~`6E0`). 한글로 찍힘 |
| 문지기 위 칸 (0D,16)에서 아래로 96프레임 | (0D,16) 그대로 |
| `3C/01` 에 `219E` \| `80` 으로 워프 | 검사 없음 |
| 서장 없이 빌드한 1장 롬 | 장 제목 상자 코드는 장면 하나일 때 바꾸기 전과 같은 바이트 |

## 남은 것

- 개구리(신시아의 モシャス)·신시아·장로 집 저녁·끝 서술 「이야기는 이렇게 시작된다……」와 1장 첫머리로 넘기기. DQ5 에 개구리 인물 그림이 없습니다.
- 검사가 말을 걸지 않아도 저절로 묻게 하기. 인물 스크립트 문맥에서 예·아니요 창이 돌아오지 않는 까닭(`04:DAD2` 고리)을 재야 합니다.
- 서장 곡. 지금은 맵 속성을 복사한 `19/02` 의 곡입니다.
- 수련 끝 깃발을 끈 채 `3C/01` 로 워프하면 상자 연출 없이 밝은 맵에 검사가 섬. 새 게임 길에서는 생기지 않습니다.
- 마을 사람의 밤 목록. 서장은 해 질 녘이라 낮 목록만 둡니다.
