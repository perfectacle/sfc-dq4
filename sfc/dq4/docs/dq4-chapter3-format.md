# DQ4 3장 넘김과 첫머리

[2장 끝](dq4-chapter2-format.md#빈-산트하임과-2장-끝)의 서술 뒤에 3장 「무기상인 톨네코」로 넘어가, 레이크나바 톨네코의 집(그룹 `3E`, FC `16/01`)에서 3장을 시작하는 명세입니다. 도구는 `sfc/dq4/tools/dq4ch3event.py` 이고 `dq4chapter1.py build` 가 얹습니다. 3장 코드와 인물은 모든 빌드에 들어 있고, 2장 끝 인물이 3장으로 넘기는 것은 `--chapter3` 빌드(`dq4build.py --chapter3`, `--chapter2` 를 함께 켬)뿐입니다. 그 밖의 빌드는 2장 끝에서 「제3장 무기상인 톨네코 / ― 다음에 계속 ―」 상자 뒤 타이틀로 돌아갑니다.

| 넣는 것 | 자리 |
| --- | --- |
| 톨네코 기록·이름, 넘김 이벤트, transfer, 방향 키 네이티브 | `5C:C000`~`CFFF`(`dq4ch2slots.CHAPTER3_CODE`) |
| flag | `7E:2208` bit3 3장 진행 중, bit5 첫머리 대기 |
| 장 상자 | `dq4chapterbox.CHAPTER3`(`box3`): 맵 `3E/01`, 첫머리 대기 flag 가 켜져 있을 때 |
| 첫머리 연출 인물 | `3E/01` 의 낮 네네(셀 (54,9)). 스크립트는 DQ5 `2B/00` 인물(`05:CC73` 0번, `05:CC7A`, 80바이트)을 빌림 |
| 주인공 그림 | `05:D9A1` 훅(`dq4ch2event._hero_picture`)에 3장 갈래: 그림 `7A` |
| 아리나 일행 맡긴 칸 | 맡긴 몬스터 칸 50~55(`7E:2846`~), 칸마다 `+1` 부터 25바이트 |
| 한글 대사 | FC `031C`(서두 서술 4쪽), `031E`(네네의 부름), `031F`(네네가 깨움) |

## 2장 끝에서 옮기기

`dq4ch2ending` 의 끝내는 인물 스크립트(`28 52 3F 37 darken_song 21 end 37 … 16`)의 마지막 `37` 이 `--chapter3` 이면 끝 상자 대신 `transfer` 를 부릅니다. `transfer` 가 하는 일:

1. 일행 기록 0~2(126바이트)와 주인공 이름(8바이트)을 맡긴 칸에 둡니다(`stash_pieces`).
2. 톨네코 기록·이름을 일행 기록 0 과 이름 칸에 씁니다. 맡긴 물건·맡긴 금화를 비우고, 필드 시간 `0050`, 금화 0 으로 둡니다.
3. 귀환 자리를 FC 3장 것(교회 `16/00`, 다녀온 비트 그룹 `16`)으로 둡니다(`dq4fieldtravel.chapter_slot_code`).
4. 일행 수 1, 순서 0, 마차 비트를 끄고, 2장 flag(`2208` bit4)를 끄고 3장 flag 둘을 켭니다.
5. 엔딩 곡을 멈추고(`24:FE91`) 이벤트를 겁니다: 맵 곡 건너뛰기(`dq4ch2event` 의 `skip_song`) 뒤 `90 3E 01 36 0B 01 80`(FC (1B,05)).

3장 동안 산트하임 성 앞마당(`3D/00`)은 2장 끝의 빈 성 목록(`ch2_ending_castle`)이라 끝내는 인물이 다시 서지 않습니다.

## 첫머리

| 명령 | 하는 일 |
| --- | --- |
| `3F` | 조작 막기 |
| `37` box3 | 검은 화면에 「제3장  무기상인 톨네코」 상자 |
| `21` | 서두 서술(FC `031C`) |
| `37` reveal | 맵 곡을 틀고 맵을 밝힘 |
| `21` | 네네의 부름(FC `031E`) |
| `05` pad | 방향 키(`$4219` 아래 4비트)가 눌릴 때까지 기다림(FC 이벤트 `2F`) |
| `21` | 네네가 깨우는 말(FC `031F`) |
| `11` | 첫머리 대기 flag 끄기 |
| `40`·`16` | 조작 풀기, 멈춤 |

## 톨네코

| 기록 | 값 |
| --- | --- |
| HP·MP·すばやさ·ちから·みのまもり(FC たいりょく)·かしこさ·うんのよさ | FC 3장 시작 값(`dq4growth.first_record`): 20, 0, 5, 4, 10, 5, 3 |
| 다음 레벨 경험치 | 10 |
| 물건 | FC 소지품 표(`12:$9192` + 8 × 5)에서 DQ5 에 같은 이름이 있는 것: ぬののふく(DQ5 `42`, 장비) |

- 성장 표는 `dq4growth.TABLES` 다섯째(사람 0, 3장 flag)입니다. 표 다섯이 `57:D000`~`EFFF` 에 들어가지 않아 `57:9000` 으로 옮겼습니다(`dq4growth.GROWTH_AT`, 끝 `57:CE00` 은 장비 표).
- 장비 판정은 `dq4party.EQUIP_PEOPLE` 의 사람 0 둘째 줄(3장 flag → FC 장비 비트 5)입니다.
- 걷는 그림은 NDS 시트 `h118` 을 DQ4 가 쓰지 않는 그림 `7A`(세트 `46`)에 싣고, 팔레트 줄 7 을 3장 flag 로 3장 그룹(`3E`~`40`)과 필드에서 덮습니다(`dq4people`).
- 필드 곡은 3장 flag 가 켜져 있으면 `02` → `0E` 입니다(`dq4sound-game.args` 의 `--song-pick`).

## 검증

가드 `dq4-ch3-open`(`dq4ch3opencheck.py`)이 2장 걷기 검사의 2장 출발 상태에서 우승 뒤 빈 왕좌의 방으로 가 계단으로 성 앞마당에 내려선 뒤, A 와 아래를 번갈아 눌러 3장 첫머리를 넘깁니다. 끝에 맵 `3E/01`, 3장 flag 켜짐, 2장 flag·첫머리 대기 꺼짐, 일행 수 1, 금화 0, 주인공 기록(HP 20·ちから 4·みのまもり 10)과 이름 첫 바이트, 맡긴 칸의 아리나 HP 16 을 봅니다.
