# 조사 코드와 필드 시스템 메시지

이름·도구 이름처럼 실행 중에 들어오는 글자 뒤에, 받침을 보고 「은/는」 같은 조사를 고르는 메시지 코드의 명세입니다. 이 코드로 DQ5 필드 시스템 메시지 116개(조사·상자·문·주문·도구)와 가게·여관·교회 대사 172개를 한글로 옮겼습니다. 도구는 `sfc/dq4/tools/dq4josa.py`(엔진)와 `sfc/dq4/tools/dq4sysmsg.py`(메시지)이고, `dq4chapter1.py build` 가 1장 롬에 얹습니다.

## 코드

| 코드 | 받침 있음 | 받침 없음 | 비고 |
| --- | --- | --- | --- |
| `101E` | 은 | 는 | |
| `101F` | 이 | 가 | |
| `1020` | 을 | 를 | |
| `1021` | 으로 | 로 | ㄹ 받침도 「로」 |
| `1022` | 과 | 와 | |
| `1023` | 아 | 야 | |
| `1024` | 이여 | 여 | |

- 바로 앞에 찍힌 글자가 호환 자모·완성형 한글이면 받침 표로 고릅니다. 자음 자모(ㄱ~ㅎ)는 「비읍」처럼 이름에 받침이 있는 것으로 봅니다. 가나 이름·숫자 같은 그 밖의 글자 뒤에서는 받침 없는 쪽을 씁니다.
- 전투 메시지는 이 코드 대신 전투 글 엔진의 조사 토큰(`11` k)으로 같은 표를 고릅니다([전투 메시지](dq4-battle-text-format.md)).
- 받침 표는 글자 코드 `3DB`(ㄱ)부터 2,401바이트입니다(호환 자모 51 + 완성형 2,350, 0 없음·1 있음·2 ㄹ). 글자 코드는 `dq4menumsg.CHARS` 의 차례입니다([메뉴 메시지의 글자](dq4-menu-format.md#글자)).

## 엔진

| 자리 | 원래 | 바꾼 것 |
| --- | --- | --- |
| `24:82A1` | `PHA / SEP #$30 / LDX $0E06`(글자를 찍는 공통 입구, A = 글자 코드) | `PHA / JSL 훅 / NOP`. 훅이 A 를 `7E:1BC0` 에 적고 덮은 두 명령을 대신함 |
| `24:81D1` | `AND #$00FF / CMP #$001E / BCS 81E4`(`1000` 번대 범위 검사) | `JML 훅`. `1E` 미만은 `24:81D9`(`JMP ($8204,X)`), 조사 코드는 처리기, 그 밖은 `24:81E4` |
| `5E:8000`~ | 빈 자리 | 두 훅, 처리기 일곱, 받침 표 |

- 허프만에서 읽은 글자(`24:81E1`)와 대기열에서 꺼낸 글자(`24:8298`, 이름·도구 이름)가 모두 `24:82A1` 로 옵니다.
- 처리기는 고른 조사 글자 코드와 `FFFF` 를 대기열 `7E:0ECB` 에 쓰고 `JML $248275` 로 대기열을 꺼내 찍습니다. 이름 처리기(`24:84C3`)와 같은 길입니다.
  - 처음에는 대기열 비트(`7E:0F0B` bit0)만 켜고 고리(`24:8170`)로 돌아갔습니다. 다음 차례에 그사이 읽은 코드가 버려져(`24:8272`) 띄어쓰기·줄바꿈이 빠졌고, 「エラーダス!!」 창이 떴습니다.
- `7E:1BC0` 은 DQ5 다섯 실행에서 접근이 없던 `7E:1BBE`~(79바이트) 안입니다([한글 넣기 준비](../../dq5/docs/dq5-hangul-format.md)).
- 처음에는 메시지에 쓰이지 않는 칸(`100C`·`100E`·`101B`, `1100` 번대 `1102`·`1108`·`1109`·`110D`)을 쓰려 했습니다. `1100` 번대는 들어가기 전에 말하는 인물을 찾아(`24:81BF`) 서술문에서 「エラーダス!!」 창이 떴습니다. `1009`·`1014` 는 전투 해석기(`21:94F8`)가 이름 코드로 씁니다. 그래서 `1000` 번대 표 뒤에 코드를 새로 받습니다.

## 이름

메시지의 물건(`{100A}`)·주문(`{100B}`) 이름도 한글로 찍습니다(`sfc/dq4/tools/dq4msgnames.py`). 창 글자([dq4windowtext.py](../tools/dq4windowtext.py))와 같이 롬의 이름 표를 `nds/dq4/tables/adopt.tsv` 와 가나 키로 잇습니다. 메시지 글자에 있는 글자로만 된 이름(물건 95, 주문 119)을 씁니다. 전각 숫자가 든 「신비한 춤１」 등은 가나로 둡니다.

| 자리 | 원래 | 바꾼 것 |
| --- | --- | --- |
| `24:89BB` | `STA $43 / JSR $889F`(물건 `89A8`·주문 `89AF`·몬스터 `89B6` 이 이름 종류를 두고 번호 `$F5` 를 꺼내는 공통 자리) | `JML 훅 / NOP` |
| `5E:9000`~ | 빈 자리 | 훅, 종류마다 번호 256개 × 16비트 표(0 = 한글 없음), 글자 코드 목록(`FFFF` 끝) |

- **한글 이름이 있을 때**: 훅이 `$F5` 를 `24:889F` 처럼 꺼내 밉니다. 글자 코드를 대기열에 쓰고, `89A8` 의 `PHP`·복귀 주소와 훅의 `PHP` 를 버린 뒤 `JML $248275` 로 찍습니다. 원래 길도 `24:84C3` 에서 대기열을 채우고 `8275` 로 갑니다.
- **없을 때 또는 `$70` bit7(바이트를 그대로 옮기는 길)일 때**: 훅이 덮은 `JSR $889F`(대기열에서 번호 꺼내기)를 대신하고 `24:89C0` 으로 돌아갑니다. 처음에는 `24:89BD`(훅의 `JML` 한가운데)로 돌아가, 전투의 주문 이름(`F4`)에서 이름 길이 `$00` = 0 인 채 이름을 옮겨 큐 끝 `FF` 가 사라졌습니다(메시지가 끝없이 찍힘).
- 몬스터(종류 4)는 넣지 않았습니다. `{100F}` 는 이름 뒤에 Ａ·Ｂ 를 붙이는데, 훅이 원래 흐름을 건너뛰면 그 글자가 빠집니다.
- 이름 뒤 조사는 한글 이름의 받침대로 골라집니다. 시험 서술(커밋하지 않음)에 `$F5` 를 써 넣고 `{100A}{을} 샀다` 를 띄우자 「구리 검을 샀다」, `{100B}{은}` 은 「베기라곤은」 이었습니다.

## 시스템 메시지

`dq4sysmsg.SOURCE` 의 번호에 한글을 덮습니다.

| 묶음 | 번호 |
| --- | --- |
| 물건 건네기·버리기·장비 | `11F`~`12A`, `13C`~`141`, `14A`·`14B` |
| 조사·옷장·상자·항아리·통·팻말·책장·무덤·촛대 | `12B`~`138`, `142`~`14F`, `150`·`151`, `153`~`155`, `157`, `161` |
| 문·열쇠 | `186`~`18A` |
| 주문·도구 사용 | `18D`~`195`, `19E`~`1AE`(`1A4` 빼고) |
| 대열 바꾸기(혼자일 때) | `1CD` |
| 가게에서 장비해 줌, 교회에서 되살아남(서술) | `015`, `09B` |
| 상자가 몬스터(식인 상자·미믹) | `139`·`13A` |
| 도구 사용(세계수·씨앗·반지·하늘을 나는 구두 등) | `1A4`, `1AF`~`1CB` |
| 가게 대사(도구점·방어구점·무기점·잡화점 네 벌) | `000`~`06F`(빈 메시지 `013`·`03D`·`064`~`067` 과 글자 시험 `061` 빼고) |
| 여관 | `070`~`07D` |
| 교회(기도·되살리기·해독·저주 풀기·계시) | `07E`~`0B8`(빈 `09C`·`09D`·`0AA`·`0AB` 빼고) |
| 대화 번호 `000` 인 인물(`06:DBFD`) | `1CC` |

- 가게·여관·교회 대사(`dq4sysmsg.SPEECH`)는 원문처럼 `{1006}` 없이 써서 엔진이 ＊「 를 붙입니다. `|` 는 쪽 넘김(`1002`)이고, 서술(`SOURCE`)은 쪽마다 `{1006}` 으로 다시 엽니다. 가게 문구는 원문의 네 벌(도구점 친절한 존댓말, 방어구점 정중한 존댓말, 무기점 하게체, 잡화점 반말)을 살렸습니다. 이름 뒤 「さん」 은 「님」 으로 붙여 조사를 고정했고, 부름 조사 `{이여}`(2칸)와 `{아}` 를 더했습니다. 물건·능력치 이름은 adopt 표와 창 글자(힘·민첩·현명함·방어력·최대 HP)에 맞췄습니다.
- 자리 표시 `{L}`(1011)·`{P}`(1008)·`{I}`(100A)·`{S}`(100B)·`{N}`(1004)와 조사 `{은}`·`{이}`·`{을}`·`{로}`·`{과}` 로 적습니다. 줄 너비는 이름 4칸, 물건 9칸, 주문 8칸, 숫자 5칸으로 세어 14칸 안입니다. 롬의 가나 물건 이름(「モンスターほいほい」)과 한글 물건 이름 모두 가장 긴 것이 9글자, 한글 주문 이름은 8글자입니다. 그래서 `{I}` 뒤 같은 줄에는 4칸만 남습니다. 방어구점의 「{I} 말씀이시군요.」(`009`·`051`)는 「체인 메일」 같은 짧은 이름도 혼자 한 줄이 되어 「{I}입니까?」 로 줄였고, 도구점이 귀한 물건을 받지 않는 `054` 는 「{I} 말이죠?」 로 첫 문장을 한 줄에 끝냅니다.
- 끝 코드는 원문을 따릅니다. 21개가 `1010`(▼ 대기), 나머지는 `1001` 입니다. 모두 `1001` 로 두었을 때는 「발밑을 조사했다!」가 대기 없이 다음 메시지로 넘어갔습니다.
- `014`「다른 분이 가지시겠습니까?」는 도구점과 방어구점이 함께 씁니다(`015` 는 장비해 줌 서술). 가진 물건이 가득한 동료를 고르자 두 가게 모두 `018`·`019` 뒤 `014` 였습니다. 그래서 말투를 하나로 맞췄습니다.
- 여관 안주인(`077`~`07D`)과 교회 수녀(홀수 번호)는 대화 번호 `10`·`0F` 의 처리기가 띄우고, `1CC` 는 대화 번호 `000` 의 처리기 `06:DBFD` 가 띄웁니다. 1장 그룹의 인물은 대화 번호가 `05`(교회)·`06`(여관)·`01`~`03`(가게)과 `11` 이상의 대사뿐이라 1장에서는 나오지 않습니다(`npc-report.json`). 그래도 뒤 장의 인물에 쓰일 수 있어 덮었습니다.
- `{1005}`(일행이 둘 이상이면 「たち」)는 가나를 찍어 쓰지 않았습니다. 그래서 「일행은 …골드를 손에 넣었다」가 「(첫째)은 …」 이 되고, 교회의 「この者{1005}に」 는 「이 자에게」 로 옮겼습니다.
- DQ5 이야기에만 나오는 메시지(배에서 뛰어내림·관·포인트 레버·오브·전설 책·팻말 문구·카지노·슬라임 레이스·몬스터 할아버지 등)와 가나 「たち」 를 찍는 표현은 옮기지 않았습니다. 맡기는 곳(`0B9`~`0E7`)은 1장 그룹(`36`~`3B`)에 없어 넣지 않았습니다([가게 연결](dq4-environment-format.md#가게), `dq4shopport.py` 의 서비스 표).
- 덮은 뒤 메시지 덩어리(`65:8000`~`69:FFFF`) 끝의 빈자리는 5,204 → 3,737바이트입니다(1장 빌드).

## 남은 것

- 몬스터 이름과 adopt 표에 없는 물건·주문 이름은 가나로 찍혀 조사가 「받침 없음」 쪽이 됩니다.
