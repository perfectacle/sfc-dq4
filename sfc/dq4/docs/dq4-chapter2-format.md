# DQ4 2장 첫머리

[1장 끝](dq4-chapter1-format.md#왕에게-보고와-1장-끝)의 서술 뒤에 2장 「말괄량이 공주의 모험」으로 넘어가, 산트하임 왕좌의 방에서 2장을 시작하는 명세입니다. 무대는 [그룹 연결](dq4-environment-format.md#그룹-연결)이 그룹 `3D` 에 넣은 산트하임 성이고, 대사는 NDS 2장 대사(`MESS/ja/b0002000.mpt`)의 일본어 원문을 옮겼습니다. 도구는 `sfc/dq4/tools/dq4ch2event.py` 이고 `dq4chapter1.py build` 가 얹습니다.

| 넣는 것 | 자리 |
| --- | --- |
| 2장으로 옮기는 네이티브·아리나 기록·이름 | `5E:F000`~ |
| 주인공 그림 훅 | `05:D9A1`(주인공 갈래)을 `JSL` + `RTS` 로 |
| 깃발 | `7E:2208` bit4 2장 진행 중, bit6 첫머리 대기 |
| 첫머리 연출 인물 | `3D/01` 의 왕 자리. 스크립트는 DQ5 `21/09` 인물(`05:C6C3` 0번, `05:C6CA`)을 빌림 |
| 한글 대사 | NDS 서두 서술 3쪽, 부르는 소리 1쪽, 왕의 말 4쪽 |

## 일행: 주인공 기록을 아리나로

DQ5 사람 동료 칸(인물 번호가 이름 표·그림 표를 고름, [사람 합류](../../dq5/docs/dq5-data-format.md#일행에-들-때-join))에 아리나를 넣고 주인공(인물 `00`)을 빼면, 이름과 그림은 저절로 따라오지만 필드로 나갈 수 없었습니다. 1장 롬에서 배 선실 세이브스테이트로 일행 기록 0 만 인물 표 칸 4(ビアンカ)·5(サンチョ)·9(ヘンリー)로 덮고 `dq5warp.lua` 로 필드에 나가자 셋 모두 `01/00` 을 불러오다 멈췄습니다(3000프레임 `timeout phase=load`). 같은 덮기를 주인공 기록 뒤에 둔 일행(칸 0·4)은 필드 (78,154)까지 걸었습니다. 산트하임 왕좌의 방(`3D/01`)은 주인공 없는 일행으로도 들어가 걸을 수 있었습니다.

그래서 2장 동안 일행 기록 0 은 인물 `00` 그대로 두고, 값만 아리나로 덮습니다.

| 기록 | 아리나(FC 처음 기록 7 「ひめ」) |
| --- | --- |
| `+2`·`+E` HP, `+4`·`+10` MP | 16, 0 |
| `+6` すばやさ, `+7`~`+A` ちから·みのまもり·かしこさ·うんのよさ | 7, 12, 8, 4, 1(FC たいりょく 는 1장처럼 みのまもり 자리) |
| `+B`~`+D` 경험치, `+12` 레벨 | 0, 1 |
| `+14`·`+15` 장비 비트, `+16`~`+21` 물건 | `01 00`, きぬのローブ(DQ5 `62`) 하나 |
| `+23`~`+25` 배운 주문 | 0 |

나머지 바이트(`+1`, `+13` 최대 레벨, `+26`~`+28` 다음 레벨 경험치, `+29`)는 원래 롬의 주인공 틀(`23:C014` 칸 0)을 씁니다. 이름 `7E:2001`~ 8바이트는 「아리나」의 한글 이름 바이트([게임 안 이름](dq4-name-entry-format.md#게임-안-이름))로 씁니다.

1장의 라이안 기록과 이름 입력값은 사람 동료 칸(`7E:294A`, 32바이트 × 5)에 맡겨 둡니다. 칸 첫 바이트 bit7 이 찬 칸 표시라 칸마다 `+1` 부터 씁니다. 라이안 기록 42바이트는 칸 2 의 `+1`(`7E:298B`~, 31바이트)과 칸 3 의 `+1`(`7E:29AB`~, 11바이트)에 나눠 두고, 이름은 칸 4 의 `+1`(`7E:29CB`~)입니다. 이 칸을 쓰는 DQ5 장면(ルイーダ·결혼식·석상)은 이 해킹에 없고, 5장에서 라이안이 돌아올 때 되돌릴 자리입니다. 저장은 `7E:2000`~`2A9F` 를 옮기므로 이 칸도 저장됩니다(코드 읽기).

## 1장 끝에서 옮기기

1장 끝 인물의 스크립트는 서술 → 화면 어둡게(`darken`) 뒤 `37` 로 `transfer` 를 부릅니다. `transfer` 가 하는 일:

1. 라이안 기록·이름을 맡기고, 아리나 기록·이름을 씁니다.
2. 필드 시간 `$075E` 를 `0050`(아침), 금화 `7E:2019` 를 100 으로 둡니다(FC 2장 시작 금화).
3. 일행 수 `201D`·`201E`·`201F` 를 1, 순서 `2020`·`2028` 을 0, 마차 비트(`201C` bit7)를 끕니다.
4. 2장 깃발(`2208` bit4)과 첫머리 대기 깃발(`2208` bit6)을 켭니다.
5. 이벤트 스크립트를 겁니다: 맵 곡 건너뛰기(`21A5` bit6)를 켜는 네이티브(`A0`) 뒤 `90 3D 01 12 11 01 80`(맵 이동, FC (09,08) 왕 앞).

## 첫머리

`3D/01` 을 불러올 때 [장 제목 상자](dq4-chapter1-format.md#검은-화면과-장-제목-상자)의 맵 훅이 주화면을 BG3 만으로 둡니다. 장면 `dq4chapterbox.CHAPTER2` 는 맵 `3D/01` 에 깃발 없이 `since`(첫머리 대기 깃발)만 둡니다. 맵 훅은 장면마다 「그 맵이고, `flag` 가 있으면 꺼져 있고, `since` 가 있으면 켜져 있음」을 봅니다. 그래서 1장에 산트하임에 걸어 들어오거나 첫머리 뒤에 다시 들어와도 맵을 검게 불러오지 않습니다.

인물은 첫머리 대기 깃발이 켜져 있는 동안의 대체 목록 `ch2_opening` 입니다. [옮긴 인물](dq4-environment-format.md#인물) 목록 그대로에서 왕(FC (09,07) → 셀 (18,15))만 스크립트 인물로 바꿉니다. 왕의 스크립트:

| 명령 | 하는 일 |
| --- | --- |
| `3F` | 조작 막기 |
| `37` box2 | 검은 화면에 「제2장  말괄량이 공주의 모험」 상자 |
| `21` | 서두 서술 3쪽(NDS 2002·2003, FC 0305 앞 두 쪽) |
| `37` reveal | 맵 곡을 틀고 맵을 밝힘 |
| `21` | 「공주님! 아리나 공주님! 부왕께서 부르십니다!」(NDS 2004) |
| `21` | 왕의 말 4쪽(NDS 2008~2011, FC 0306) |
| `11` | 첫머리 대기 깃발 끄기 |
| `40`·`16` | 조작 풀기, 멈춤 |

처음에는 「2장 깃발 꺼짐 → 옮긴 목록 사본」, 「첫머리 마침 깃발 꺼짐 → 첫머리 목록」 두 대체 목록으로 1장의 걸음을 갈랐습니다. 1장 진행 대사가 들어간 뒤 대체 목록 자리 `39:9000` 이 28,676바이트로 한 뱅크(28,672바이트)를 4바이트 넘어 빌드가 멈췄습니다. 사본 목록을 없애려고 깃발 하나(첫머리 대기)를 옮길 때 켜고 끄는 꼴로 바꿨습니다.

## 주인공 그림

`05:D98F` 는 일행 순서마다의 그림 번호를 정합니다. 주인공 갈래 `05:D9A1`~`D9B5`(21바이트, `2190` bit6·`21BE` bit5 로 `2E`·`2D`·`3A`)를 `JSL` 네이티브 + `RTS` 로 덮습니다. 네이티브는 2장 깃발이 켜져 있으면 `30`(DQ5 어린 ビアンカ, 인물 04 의 그림)을, 아니면 원래와 같은 규칙으로 고른 그림을 A 에 두고 돌아갑니다. 아리나 그림은 [스프라이트](dq4-sprite-format.md) 일의 몫이고, 그때까지 이 그림을 대역으로 씁니다.

## 검증

1장 롬에서 배 선실 세이브스테이트로 `36/00` (32,72)에 보고 깃발(`2197|80`)·보스 깃발(`21B9|40`)을 켜고 내려, A 를 90프레임마다 누르며 100프레임마다 찍었습니다.

| 프레임 | 맵·셀 | `2208` | 화면 |
| --- | --- | --- | --- |
| 100 | `36/00` (32,72) | `00` | 1장 끝 서술 |
| 300 | `3D/01` (18,17) | `50` | 검은 화면의 2장 제목 상자, 이어 서두 서술 |
| 900 | `3D/01` (18,17) | `50` | 왕좌의 방이 밝아지고 「공주님! 아리나 공주님!」, 왕의 말 |
| 1500 | `3D/01` (18,17) | `10` | 조작이 풀림. 상태 창 「아리나 H 16 M 0 レ: 1」 |

- 일행 기록 0 은 `00 80 10 00 00 00 07 0C …`(HP 16, すばやさ 7, ちから 12), 일행 수 1, 금화 100, `$075E` = `0050` 이었습니다. 맡긴 칸에 원래 주인공 기록(`00 80 18 00 …`)이 남았습니다.
- 왕 아래 칸에 ビアンカ 그림의 주인공이 서고, B 로 창을 닫은 뒤 걸었습니다.
- 첫머리 뒤 왕에게 말을 걸면 옮긴 인물의 일본어 원문(「どうした アリーナ？」, FC 07A0)이 나옵니다.

## 남은 것

- 크리프트·브라이와 이야기, 성문 병사, 왕의 방 벽 걷어차기, 필드에서 두 사람 합류([FC 2장 진행](../../../fc/dq4/docs/dq4-story-format.md#장마다-진행-순서--플래그) 2~5).
- `3D` 인물 대사가 1장 시작 상태의 일본어 원문입니다. 2장 상태(`dq4npcport` 의 `"chapter": 2`)로 옮기고 한글로.
- 산트하임 성 곡: 그룹 `3D` 맵 속성은 마을 곡 `0A` 라 밝힐 때 마을 곡이 납니다(FC 그룹 `01` 은 성 곡).
- 아리나·크리프트·브라이 그림과 아리나 레벨업 성장(지금은 DQ5 주인공 성장 표), 장비할 수 있는 물건.
- 1장 가방(ふくろ) 물건과 1장 깃발은 그대로 남습니다.
- 대체 목록 자리 `39:9000` 이 거의 다 찼습니다. 2장 사건 목록은 다른 자리가 필요합니다.
- 저장을 불러온 뒤 그림 훅과 2장 깃발이 이어지는지(코드 읽기).
