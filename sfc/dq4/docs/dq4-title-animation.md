# 용과 구름이 이어지는 타이틀

[한글 타이틀 연결](dq4-title-format.md)의 로고·IV·부제를 유지하면서, 용과 구름을 한 장면으로 구성합니다. 연속 변형의 진폭을 낮추고 몇 장의 자세를 유지하는 리듬을 사용합니다. 로고 주위에 남았던 정지 하늘은 제거하고, 성 하부는 앞 구름에 부분적으로 가려집니다.

## 그림과 동작

`tools/dq4art/title-animation/title-glyph-mask.png`는 원래 실제 크기 그림에서 글자·장식·외곽선만 고르는 이진 마스크입니다. 선택된 픽셀의 RGB는 그대로 사용하고, IV의 두 획 사이와 부제 주변의 하늘은 배경 레이어가 보이게 합니다. 마스크는 10,256픽셀입니다.

용의 몸통은 고정 사각형으로 잘라내지 않고 알파 연결 요소 전체를 추출합니다. 이전 몸통 사각형은 주둥이 끝 약 3픽셀을 잘라냈습니다. 날개는 작은 진폭의 12자세를 약 10~11게임 프레임씩 유지하며, 전체 주기는 128게임 프레임입니다. 이는 새로 구성한 SFC풍 리듬이며 원작의 프레임을 추출한 것은 아닙니다. 화면 처리와 입력은 매 게임 프레임 갱신합니다.

뒤쪽 하늘은 화면 전체에서 한 속도로 왼쪽으로 흐릅니다. 화면 아래쪽만 다른 속도로 바꾸던 수평 경계를 없앴습니다. 앞 구름은 별도의 둥근 64×32 그림으로 성 하부를 가립니다. 상단 첨탑은 구름 위에 남고, 로고와 부제는 앞 구름보다 위에 표시합니다.

## SFC 표시 규격

Mode 3의 BG1 8bpp와 BG2 4bpp를 사용합니다. 일부 글자 타일은 검정을 포함해 16색을 모두 사용하므로, 4bpp에서 투명색까지 확보할 수 없습니다. BG1의 8bpp 색 번호 16을 불투명 검정으로 사용해 원래 RGB를 보존합니다.

| 요소 | 표시 | 우선순위 |
| --- | --- | --- |
| 하늘 | BG2 | 뒤쪽 |
| 성 | BG1 낮은 우선순위 | 하늘 앞, 앞 구름 뒤 |
| 용·앞 구름 | OBJ | 성 앞 |
| 로고·IV·부제 | BG1 높은 우선순위 | 앞 구름 위 |

용의 OBJ 두 페이지는 바뀐 타일만 전송합니다. 각 페이지에서 쓰지 않던 마지막 32×32 슬롯에 앞 구름의 절반씩을 보관합니다. 9개의 32×32 구름 OBJ가 가로 반복을 구성하며, 용과 구름은 서로 다른 세로 영역에 위치합니다.

미사용 OBJ는 Y=224로 숨깁니다. X=-256만으로는 타일 인출 제한을 피할 수 없으므로, 구름 반복의 끝에서 완전히 화면 밖으로 나간 OBJ도 Y=224로 보냅니다. 보이는 구름의 주사선당 타일 수를 제한 안에 유지합니다.

음악 데이터는 DQ5 원본 메뉴곡입니다. 재생 시점을 타이틀로 옮겼으며 메뉴에서도 이어집니다. A·Start 입력 후에는 암전 상태에서 원래 글꼴·팔레트·스프라이트 설정을 복원하고, 버튼 해제를 기다린 뒤 기존 메뉴로 돌아갑니다.

## 재현

```sh
uv run --locked python sfc/dq4/tools/dq4titlelayers.py --out work/dq4-title-cohesion
ASAR=/path/to/asar uv run --locked python sfc/dq4/tools/dq4titlelayerpatch.py --rom rom/dq5.sfc --input work/dq4-title-cohesion --out work/dq4-title-cohesion/dq4-title-cohesion.sfc
```

원본 롬을 덮어쓰지 않는 2MiB 결과 롬과 IPS를 만듭니다. 출력·에뮬레이터 관찰 자료는 로컬 `work/`에 보존합니다. 정지 타이틀용 도구와 전체 화면 교체 실험은 별도로 유지합니다.

## 검증 범위

그림의 기술적 일치와 장면의 시각적 채택은 구분합니다. 합성 시안에서는 머리 윤곽, 작은 날갯짓의 리듬, 글자 사이의 하늘, 성과 앞 구름의 가림 관계를 확인합니다. 실제 롬에서는 VRAM·OAM뿐 아니라 가시 화면도 비교하고 입력·리셋·메뉴 복원을 검사합니다.

MesenCE의 빠른 테스트 모드에서 화면 캡처가 최근 표시 화면을 재사용할 수 있으므로, 영상의 표시와 메모리 갱신은 별도 근거로 확인합니다. 실제 SFC 기기와 게임 후반 전체의 동작, 사용자의 최종 시각적 채택은 별도입니다.

검증한 롬 SHA-1은 `8fb4658420e02c9b0b99126ac838d370c43ddf25`입니다. 실제 화면 1,001장이 독립 합성과 전체 픽셀 일치했고, 같은 구간의 OBJ 타일·OAM·배경 스크롤도 일치했습니다. 앞 구름의 가시 주사선은 최대 9스프라이트·33타일이며, 한 프레임의 최대 전송량은 1,988바이트입니다. A·Start·버튼 유지·리셋 후 메뉴 화면과 CGRAM 512바이트가 원본과 일치하고 이름 입력까지 확인했습니다. 보고서는 `work/dq4-title-cohesion/emulator-verification.json`에 보존합니다.
