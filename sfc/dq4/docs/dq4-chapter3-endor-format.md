# DQ4 3장 엔돌

[3장 형식 문서](dq4-chapter3-format.md)의 사건 모듈 `dq4ch3endor` 문서입니다. 사건 등록·예약표·검사 틀은 그 문서, 검사 표는 `sfc/dq4/tools/dq4ch3endor_checks.py`, 가드는 `sfc/dq4/guards.d/` 에 있습니다.

## 엔돌

`dq4ch3endor`(E). FC 엔돌(그룹 `04`)은 `40/00`~`0E`(맵 번호 그대로), 은의 여신상 동굴(FC `40/00`~`05`)은 `48/02`~`07` 입니다.

| 대상 | 값 |
| --- | --- |
| flag `2205` | bit0 왕의 허락(FC `$6286`&40), bit1 가게를 삼(&20), bit2 왕의 주문(FC `$6284`&08), bit3 납품을 다 채움(FC `$6288`&10), bit4 여신상을 팖(FC `$6286`&80), bit5 아들의 「최고야」(FC `$6288`&02), bit6 굴 개통 소식(FC `$6286`&01, 굴 모듈이 켤 자리), bit7 네네에게 개통을 들음(FC `$62AA`&08) |
| flag `2206` | bit0 단추를 누름(FC `$62AA`&20), bit1·2 단추 물음의 대답·「예」(인물 스크립트가 끔), bit3·4·5 납품 한 번의 결과(칼을 받음·갑옷을 받음·다 참), bit6·7 아직 받을 칼·갑옷이 남음 |
| 변수 칸 | `+10` 납품 수(위 니블 철 갑옷, 아래 니블 강철 검, FC `$628F`), `+11`·`+12` 이번에 받은 칼·갑옷 수 |
| 인물 | 3장 동안 `40/00`·`02`·`06`·`08`·`0A` 는 대체 목록 `ch3_endor_40xx`(CHAPTER3), 가게를 산 뒤 `40/00`·`08` 은 `ch3_endor_40xx_shop`(SHOP). 옮긴 기본 목록(FC 2장 대회 중 목록)을 베껴 FC 3장 목록과 같은 칸의 사람 대화만 바꾸고, 가게를 사기 전에는 네네·아들을, 산 뒤에는 가게 주인을 뺀다(FC `1C:$A3B9`·`$A4E2`) |
| 대화 | 왕 `072`, 가게 주인 `04D`, 아들 `08B`, 네네 `075`, 납품 `03F`·안내 `03E`, 수집가 `04C`, 동굴 단추 `03B3` |
| 훅 | `2A:F7AB` 에서 금고 동굴 모듈이 둔 `JSL` 의 대상을 이 모듈 출구 루틴으로 바꾼다. 금고 갈래를 부른 뒤, 도착 출구 번호 0·그룹 `48`·맵 `03` 이고 단추를 눌렀으면 맵 `04`(FC `08:$B3C0`) |
| 사건 물건 | `48/07` 상자(FC `40/05` (06,04))가 은의 여신상 `BD`(`dq4chestport.EVENT_CHEST_ITEMS`) |

- **왕**: 납품 끝 `088D` > 가게를 삼 `088C`(주문) > 허락 `088B` > 왕의 편지(본몰 `LETTER2`) `088A`(허락) > 왕자의 편지(본몰 `LETTER1`) `0889` > 첫 알현 `0886` → `0887`·`0888`.
- **가게 사기**: `063B` 뒤 허락이 있으면 `0862` → 「예」 면 `pay` 35000 → `0865`, SHOP, 이벤트(아침으로 `40/00` 네네 옆 FC (05,1C)에 서서 `035B`·`035C`, FC 1C 이벤트 `09`). 모자라면 `0864`, 「아니요」 `0863`, 허락 전 `0861`.
- **네네**: 개통 소식이면 `08A0` → `08A2`·`08A4` → `08A3`, 개통을 들음. 낮 `0866` → 「예」 `080C` 뒤 잠(걷는 일행 HP·MP 채우기, 아침, 공용 `next_day` 가 있으면 부름) → 네네 옆 → `080D`·`080E`(도시락이 없고 칸이 비면 줌), 「아니요」 `0867`. 밤(`40/08`)은 `0811`·`080C` 뒤 잠.
- **납품**(FC `15:$A118` 실측): 주문 뒤 `0873` 「예」 면 `0874` 를 낸 뒤 톨네코 소지품(3장 일행에서 물건을 가진 사람은 톨네코뿐)에서 철 갑옷(`50`), 그다음 강철 검(`0C`)을 종류마다 7 이 찰 때까지만 빼고(넘는 몫은 소지품에 남고, 맡긴 물건은 세지 않음) 니블에 더한다. 받은 칼 수 `0875`·갑옷 수 `0876`(0 이면 빠짐) 뒤 받았으면 `0877`, 없으면 `0878`. 둘 다 7 이면 `087B`·`earn` 60000·납품 끝·`087C`, 아니면 `0879`·남은 칼·남은 갑옷(0 이면 빠짐)·`087A`. 「아니요」 면 빼지 않고 `0879` 부터. 숫자는 대화 호출 `show`·`left` 가 `$F5` 에, 「남음」 은 `deliver`(인자 1 은 세기만)가 flag 로 둔다.
- **수집가**: 여신상이 있으면 `086B` → 「예」 `086C`·`take`·`earn` 25000·팖, 「아니요」 `086D`. 없으면 `0869`·`086A`, 판 뒤 `086E`·`086A`.
- **동굴 단추**: FC `40/01` (11,02) 칸(1D 이벤트 `5E`, `1D:$AD9E`)에 서면 묻는 보이지 않는 인물(`10:8E0D` 칸 1). 「예」 면 단추 flag 를 켜고 `48/03`→`48/04`, `48/05`→`48/06` 의 열린 상자 비트를 같은 차례 상자에 옮겨 적은 뒤(FC 는 두 맵이 상자 번호를 함께 씀) `48/04` 의 같은 칸으로 옮긴다. 「아니요」 면 칸을 떠났다가 다시 서야 또 묻는다.
- **용병**(`dq4mercenary`, 엔돌 모듈이 부름): 스콧(`40/00` 낮 (05,13), FC 071)·로렌스(`40/0B` (07,08), FC 051). `0853`·`085C` → 「예」 면 스콧은 개가 따라오면(공용 `DOG`) `0854`, `pay` 400·600 이 모자라면 `0855`·`085D`, 아니면 `0856`·`085E` 뒤 `hire`: 일행 끝에 손님 기록(+0 = `C0` \| 동료 종류 `28`·`29`, 레벨 고정, FC HP·MP·능력치, かしこさ 5)을 넣고 공용 `SCOTT`·`LAWRENCE` 를 켜고 날수를 0 으로. 고용한 용병은 목록에서 숨는다(인물 스크립트가 flag 를 보고 `28`). 이름은 동료 이름 표 `0A` 의 종류 `28`·`29`(「스콧」·「로렌스」), 걷는 그림은 `05:D9E1` 의 그 칸을 DQ5 ピピン·パパス 그림으로.
  - 행동: 1장 손님 AI 훅(`21:AF1B`)의 JML 을 이 모듈 루틴으로 바꿔, 종류 `28` 은 늘 공격, `29` 는 같은 편이 HP 절반 미만이고 MP 가 되면 239/255 로 ホイミ(그 사람), 아니면 ギラ 10·ラリホー 4·공격 2(MP 가 모자라면 공격). 그 밖의 손님은 1장 루틴으로.
  - 날수: 2장 걸음 훅(`00:82CB`)의 JSL 을 이 모듈 루틴으로 바꿔 2장 훅을 부른 뒤, 3장 필드 걸음에 시간이 `01FF` 이면(그 걸음에 하루가 돎) 공용 날수 둘을 + 1. 잘 때는 공용 `next_day`. 고용한 용병의 날수가 5 이상인 필드 걸음에 `0378`·`0379` 뒤 `dismiss`(그 기록을 빼고 뒤 기록·순서를 당김).
- 다른 모듈이 볼 것: `SHOP`·`SOLD`·`ALLOWED`·`BUTTON`, 굴 모듈이 켜는 `NOTICE`(FC 는 `$6287`&80 이고 `$6282`&10 이 꺼진 채 `04/01` 에 들 때, `1C:$9C6F`). 개통 갈래와 그 뒤의 flag 는 굴 모듈(`dq4ch3tunnel.news_talk`·`OPENED`).

## 검사 구간과 사례

- 엔돌 `endor_*` 구간은 이야기 차례(왕 첫 알현 → 허락 전 가게 → 허락 → 금화 모자람·35001 골드로 가게를 삼 → 주문 → 네네 잠·개통 → 납품 없음·일부·다 참 → 수집가에게 팖 → 동굴 계단 단추 전후 → 단추)라 뒤 묶음이 앞 구간의 flag 를 이어받습니다. 걸어 다니는 낮의 수집가 대신 밤에 서 있는 자리에서 말을 겁니다(`poke` 밤).

## 남은 것

- 네네의 맡기기·매상(FC `15:$9E99`, 카운터 너머 대화 `036B`~`036D`), 3장 엔돌 마을 사람을 FC 3장 목록으로(기본 목록이 2장 대회 중 목록), 용병 전투 행동의 FC 실측(지금은 AI 레코드 코드 읽기), 스콧·로렌스 걷는 그림(DQ5 ピピン·パパス 를 빌림).
- [엔돌](#엔돌)의 왕·가게 사기·네네·납품·수집가·동굴 단추·용병과 날수가 들어감. 남은 것: 네네의 맡기기와 매상, 용병 그림과 전투 행동 FC 실측.
