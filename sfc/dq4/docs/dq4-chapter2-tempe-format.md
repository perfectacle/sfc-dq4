# DQ4 2장 텐페 뒤 절반

[2장 형식 문서](dq4-chapter2-format.md)의 사건 모듈 `dq4ch2tempe` 문서입니다. 사건 등록·예약표·검사 틀은 그 문서, 검사 표는 `sfc/dq4/tools/dq4ch2tempe_checks.py`, 가드는 `sfc/dq4/guards.d/` 에 있습니다.

## 텐페 뒤 절반

`sfc/dq4/tools/dq4ch2tempe.py`(`dq4ch2event.EVENTS` 첫 줄). 바구니에 실려 제단에 닿은 뒤 보스 전투, 아침, 괴물이 사라진 뒤의 마을까지입니다. FC 는 1C 이벤트 02 가 전투 02(あばれこまいぬ·カメレオンマン·あばれこまいぬ)를 걸고, 이기면 034D, 아침, `$627F|=80` 입니다.

| 차례 | 포팅 |
| --- | --- |
| 바구니 이벤트 끝 | 앞 절반의 `90 3D 03 2C 1F 01 80`(셀 (44,31))을 이 모듈 이벤트로 뛰는 `C3`(`hooks`)으로 덮습니다. (44,31)(FC (16,0F))은 제단 오른쪽 숲 속이라 사방이 막혀 있었습니다 |
| 제단 위 | `90 3D 03 18 07 01 80` 로 제단 위 셀 (24,7)(FC (0C,03), `ALTAR_CELL`)에 옮기고 `C2` 여덟 번 쉼 |
| 전투 | `A0` 네이티브 `fight`: 들음·대신 감·제단 flag(`2208` bit0~2)를 끄고, 이벤트 실행 비트 `7E:19AE` bit7 을 끈 뒤 `dq4ch2battle.far(0x31)`. `2208` bit7 이면 `WON` 과 `19AE` bit7 을 켬 |
| 짐 | `01:868B` 의 보통 전멸 처리. 기록한 교회(2장 시작 기록은 사란 교회 `45/02`)에서 다시 시작하고 앞 절반 flag 가 꺼져 있어 촌장에게 다시 듣습니다. 이벤트를 켠 채 지면 교회에서 같은 `A0` 을 다시 읽어 전투가 또 걸렸습니다 |
| 이김 | 서술 「괴물을 물리쳤다는…」「그리고 날이 밝았다……」(FC 034D) → `A0` `morning`(`7E:075E` = `0050`) → 같은 `90` 으로 다시 불러와 낮 색·낮 목록·낮 곡 |

| flag | 자리 | 뜻 |
| --- | --- | --- |
| `WON` | `7E:21F0` bit0 | 제단의 괴물을 이김(FC `$627F&80`). 다음 사건(프레놀)은 이 flag 와 아침의 제단 위 (24,7) 에서 시작합니다 |

| 모듈 이름 | 값 |
| --- | --- |
| `BATTLES` | 무리 `31`: `53` 카멜레온 맨 하나, `A3` 날뛰는 석상 둘. 그림은 NDS([2장 전투 몬스터 그림](dq4-sprite-format.md#2장-전투-몬스터-그림)). 플래그 `dq4ch2battle.MIDBOSS_FLAGS`(`41`): 도망칠 수 없음, 곡 `16` 立ちはだかる難敵(NDS 조우 레코드 158 의 곡 31. FC 는 보통 전투 곡) |
| `MONSTERS`·`monster_doc` | `53` ← FC `12`, `A3` ← FC `18`. FC 행동 `22`(ホイミ)·`35`(공격)는 `FC_ACTIONS` 로 더함 |
| `MONSTER_NAMES` | 몬스터 이름 표(`dq4windowtext.numbered_names`)에 덮는 한글 이름. 다른 사건 모듈도 같은 이름으로 두면 들어갑니다 |
| `npc_lists` | `WON` 이 켜진 `3D/03` 은 대체 목록 `ch2_tempe2_won`(FC `0E/00` 의 목록 플래그 `04&80` 목록 `AFTER`, 낮 10·밤 10). 낮 FC (04,1A)(셀 (8,53))에 도구점 판매자(대화 `002`), FC (08,28)(셀 (16,81))에 여관(`006`) |
| `ALTAR_CELL`·`MORNING_CELL`·`CHIEF_TALK_CELL` | (24,7), (24,7), (24,67)(이긴 뒤 촌장 FC (0C,22) 위 칸) |

이긴 뒤의 마을 사람 말은 FC `061A`~`0620`(낮), `0535`~`053B`·`05CA`(밤), 신부는 `07C9` 뒤 교회입니다. 제단 flag 는 전투 앞에서 꺼지므로 「제단으로 옮긴 뒤」의 신부 말(`0347`)을 들을 상태는 없습니다.

### 사건 전투 구간의 롬 패치

| 쓸 것 | 하는 일 |
| --- | --- |
| `dq4ch2walkcheck.battle_patch(롬 바이트, 'win' 또는 'lose')` | 등록한 모든 모듈의 `BATTLES` 몬스터를 덮는 `ROMPATCH` 문자열. `win` 은 HP 1·수비 0(1장 `boss` 와 같음), `lose` 는 HP 1000·공격 511·민첩 255 |
| 걷기 구간 선택 `battle` | `dq4ch2walkcheck.walk_unit` 이 그 구간에만 `battle_patch` 를 더함. `dq4compatcheck` 도 같은 선택을 읽음 |
| heroblock 사례 키 `battle` | `dq4heroblockcheck.rompatch` 가 같은 패치를 더함 |

| 구간(`dq4ch2walkcheck.SEGMENTS`) | 끝에 보는 것 |
| --- | --- |
| `lose_side` → `lose`(`battle: lose`) | 사란 교회 `45/02` 셀 (8,19), 앞 절반 flag 셋과 `WON` 꺼짐 |
| `rechief_side` → `rechief` | 촌장에게 다시 들음(`TEMPE_HEARD`) |
| `priest_side` → `priest`(`battle: win`, 주인공 HP 묶기) | `WON`, 앞 절반 flag 꺼짐, `3D/03` (24,7) |
| `leave_altar` → `chief_won` | 제단에서 촌장 위 (24,67) 까지 걷고 아래로 말 걸기, `WON` 그대로 |

곡 검사 `dq4mapsongcheck` 의 `tempe-basket` 은 바구니 뒤 제단의 전투 곡 `16` 을 봅니다. heroblock 신부 사례 셋은 바구니 → 전투(이김) → 아침의 (24,7) 에 선 뒤 아래로 걸을 수 있는지 봅니다. 가게 장면 `tempe-item`(`dq4shopscene`)은 `WON` 을 켜고 이긴 뒤의 도구점에서 약초를 삽니다.

### 남은 것(텐페 뒤 절반)

- FC 는 전투 앞에 괴물(제단 슬롯 08~0A·13)이 일행 양옆으로 걸어 들어옵니다. 포팅은 쉼만 둡니다. 사건 인물 그림(카멜레온 맨 `10`, 날뛰는 석상 `31`)을 제단에 세우려면 텐페 한 맵의 OBJ VRAM 512타일을 먼저 잽니다.
- 전투 몬스터 그림은 DQ5 대역입니다.
- 지고 이어 가는 전투(전멸 처리 없이)는 쓰지 않았습니다.
