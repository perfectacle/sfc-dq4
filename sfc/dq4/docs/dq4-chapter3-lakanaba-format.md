# DQ4 3장 레이크나바

[3장 형식 문서](dq4-chapter3-format.md)의 사건 모듈 `dq4ch3lakanaba` 문서입니다. 사건 등록·예약표·검사 틀은 그 문서, 검사 표는 `sfc/dq4/tools/dq4ch3lakanaba_checks.py`, 가드는 `sfc/dq4/guards.d/` 에 있습니다.

## 레이크나바

`dq4ch3lakanaba`(L). FC 실측 흐름은 [FC 3장](../../../fc/dq4/docs/dq4-chapter3-format.md#무기점-일)이고, 아래는 SFC 쪽 인터페이스입니다. 대체 목록 없이 옮긴 목록(`3E/00`·`3E/01`·`3E/02`)을 고쳐, 빌린 인물 스크립트가 flag 를 보고 숨거나 나타납니다(이 모듈이 맨 앞 차례라 뒤 모듈이 그 목록을 베끼면 함께 갑니다).

| 인물(맵 셀) | 스크립트·대화 |
| --- | --- |
| 네네 `3E/01` 낮 (54,9)·밤 (58,7) | 낮: 첫머리 직후면 080A(FC 는 장 시작이 맵 들기를 거치지 않아 `$628B` = 0, 실측). 오늘 일했거나 오늘 도시락 전이면 080B·080C 뒤 잠, 아니면 이번 방문에 잤으면 080F, 아니면 0810. 밤: 0811·080C 뒤 잠 |
| 포포로 `3E/01` 낮 (54,15)·밤 (54,15)·(32,5) | 0661 / 0554 |
| 첫 출근 주인 `3E/00` (12,53)(새 인물) | 첫 출근 전에만. 주인공이 문 칸·문 밖 (14~17, 52~54)에 서면 02F3 → 비킴 → 주인공을 카운터 안 (4,53)으로 걷게 함 → 031D → `SEEN`·`SHIFT` |
| 카운터 주인 `3E/00` (4,53) | 첫 출근 뒤·출근 전에만. 카운터 바깥(X ≥ 6)에서 0323(「예」 0324 / 「아니오」 0325), 안에서 0326(「예」 → 주인공을 (4,53)으로 → 031D → `SHIFT`, 「아니오」 0328) |
| 손님 `3E/00`(새 인물, 맵 구석 (2,1)에 대기) | `SHIFT` 이고 `DONE` 이 아니면 50 + rand(38) 차례(8프레임씩) 뒤, 주인공이 카운터 안 (4,53)에 서면 조작을 막고 (12,53)에 나타나 카운터 앞 (8,53)으로 걸어 말을 건다(조작은 손님이 사라진 뒤 풂). 사는 손님은 처음(0329·032B)과 값 제시(032D~)를 두 대화로 나눠, 다시 말을 걸 일이면 `AGAIN` 으로 스크립트가 다시 건다. 일삯이 100 이상이면 닫는 이벤트 |
| 아래층 주인 `3E/02` (14,9) | 출근 중이고 `DONE` 이 아니면 087F(「예」 일삯을 금화로 0880·0881, 「아니오」 0882), 아니면 0881 |
| 톰 `3E/00` 낮 (48,23)·밤 (44,23) | 낮 0815·0816(「예」 0817 → `TOM_PUSH`, 「아니오」 0818), 미는 중 0819, 뒤 081B. 밤 0822. `TOM_PUSH` 면 DQ5 의 비켜 주기(`1F`·`1B`)로 밀린다 |
| 톰 아들 `3E/00` (46,7) | 084B → `DOG`, 그 뒤 03AD. 여우를 쫓은 뒤(`2203` bit0)에는 0899(「예」 089A·089B → `DOG` 끔·`DOG_BACK`, 「아니오」 089C), 돌려준 뒤 089B |
| 우리의 개 `3E/00` (54,9) | `DOG` 이고 `DOG_BACK` 이 아니면 숨음 |
| 도우미(보이지 않음) `3E/00` (0,1) 낮·밤 | 맵을 필드 도착 칸 (0~1, 26~28)에서 시작하면 `BENTO_TODAY`·`SHIFT` 를 끔(FC 는 필드로 나갈 때 `$6285` 를 지움). 낮에는 `TOM_PUSH` 동안 톰이 교회 안(FC X `0C`~`10`, Y `04`~`06`)에 서면 03AE, 금화 + 2 + rand(11), `TOM_DONE` |
| 빼는 FC 인물 | `3E/00` 낮 (14,53)·(0,75)·(2,75)(FC 슬롯 11·14·15): 첫 출근 주인·손님·닫는 이벤트가 맡음 |
| 빼는 FC 인물(집) | `3E/01` 낮 (66,5)(FC 16/01 슬롯 07, 돌아다니는 둘째 네네): 첫머리 자리 (54,9) 네네만 둠 |

| flag | 뜻(FC) |
| --- | --- |
| `2200` bit0 `BENTO_TODAY` | 오늘 도시락을 받음(`$6285`&02) |
| bit1 `SEEN` · bit3 `SHIFT` | 첫 출근을 봄(`$6284`&02) · 이번에 출근함(`$6285`&01) |
| bit2 `WORKED` · bit4 `DONE` | 오늘 팔았음(`$6284`&01) · 오늘 일을 마침(`$6284`&04). 잠이 둘 다 끔 |
| bit5 `TOM_PUSH` · bit6 `TOM_DONE` · bit7 `DOG_BACK` | `$6280`&20 · `$6280`&10 · `$6286`&08 |
| `2201` | 손님 하나의 값(파는 손님, 사는 결과 넷, 흥정의 r2, 가게 닫음, 값 제시 단계). 손님이 들어올 때 지움 |
| `21A3` bit5 `FRESH`(공용) · bit6 · `21A4` | 맵을 옮기면 지워지는 칸: 첫머리 직후, r2 < 40, 이번 방문에 잤음 등 대화 사이의 값 |

| 변수 칸 | 값 |
| --- | --- |
| `+4`~`+6` | 파는 손님에게서 산 ブーメラン·くさりがま·はじゃのつるぎ 재고(FC `$62E7`~`$62E9`). 사는 손님 목록은 앞 셋(こんぼう·どうのつるぎ·いばらのムチ) 뒤에 재고가 있는 것을 붙여 rand mod 개수로 고르고, 팔면 그 재고 − 1 |
| `+7`·`+8` | 오늘 일삯(16비트). 팔 때 값 표 >> 4(웃돈 >> 3, 최소 1)를 더함 |
| `+9` | 지금 손님: bit0-2 품목, bit4-5 값 칸(그대로·깎음·웃돈·파는 손님) |

- 값과 일삯은 품목 × 값 칸 표(`prices()`·`wages()`, 칸마다 16)를 네이티브가 읽습니다. 물건 이름·값을 한 메시지에 띄우려고 `{100A}` 뒤 `{101D}`(7E:0F13~ 루틴 JSL)가 `$F5` 를 값으로 바꾸고 `{1004}` 를 찍습니다(032D·0330·0331·033E).
- 잠은 이벤트입니다: HP·MP 를 채움(살아 있는 걷는 일행) · 아침(`0050`) · `next_day` → 침대로 집을 다시 불러옴 → 080D·080E → 일행 기록 0 에 도시락이 없고 빈 칸이 있으면 줌. 가게를 닫는 이벤트는 일삯을 금화로(0341) → 밤(`00F0`) → 무기점 문 앞 (14,53).
- 일찍 그만둔 뒤 다시 일하려면 FC 처럼 필드에 나갔다 와야 합니다(`SHIFT` 를 필드 도착 칸에서 지움).
- 다른 모듈이 읽는 것: 공용 flag `DOG`(개가 따라옴. 여우 마을·용병 스콧이 봄), 변수 `+4`~`+6`(무기점 재고), `next_day`(엔돌 용병 날수). 개 돌려주기(0899 「예」 → 089A·089B, `DOG` 끔·`DOG_BACK`)는 아들 대화가 본몰 모듈의 여우를 쫓음 flag(`2203` bit0, FC `$6280`&02)를 보고 고릅니다.
- 메시지 58개, 롬 끝자리 기준 약 1.8KB.

FC 와 다르게 한 것:

- 손님 겉모습은 하나(FC 는 8가지 중 난수). FC 손님은 주인공이 카운터 안에 없어도 들어와 기다리지만, 여기서는 주인공이 카운터 안에 선 뒤에야 들어온다(걷는 길이 주인공과 겹치지 않게). 손님은 문 안 칸에 순간이동해 나타나고 나갈 때 맵 구석으로 사라집니다.
- 032B 에 「아니오」 면 FC 는 032C 를 「예」 까지 되풀이하지만, 032C 한 번 뒤 값 제시로 갑니다.
- 가게를 닫을 때 FC 는 주인(슬롯 14)이 걸어 나와 말하지만, 말(0341)만 띄우고 밤으로 문 앞에 다시 세웁니다.
- 아래층 주인은 낮이면 늘 서 있습니다(FC 는 출근 중에만). 출근 전이면 0881 만 합니다.
- 낮 네네는 첫머리 자리 (1B,04)에 서 있습니다(FC 는 첫머리 뒤 슬롯 07 이 (21,02) 둘레를 돌아다님).
- 톰은 DQ5 의 비켜 주기로 밀려, 앞이 막히면 옆으로 비켜 섭니다(돌아다니는 마을 사람에 막히기도 함).

남은 것:

- 카운터 주인의 가게(0324 뒤 FC `15:$B847`): `3E` 무기 목록(こんぼう·どうのつるぎ·いばらのむち)과 재고 품목 붙이기(`dq4shopport`, FC `15:$B26B`).
- 개 토마스가 따라 걷는 그림(동행 장치), 아들이 돌아온 뒤의 톰 대사(0844·0845·084A)·아들이 나타나는 조건(본몰 모듈).
