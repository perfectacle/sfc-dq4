# DQ4 3장 마을 사람

[3장 형식 문서](dq4-chapter3-format.md)의 사건 모듈 `dq4ch3towns` 문서입니다. 사건 등록·예약표·검사 틀은 그 문서, 검사 표는 `sfc/dq4/tools/dq4ch3towns_checks.py`, 가드는 `sfc/dq4/guards.d/` 에 있습니다.

## 마을 사람

`dq4ch3towns`(W). 다른 사건 모듈이 맡지 않은 3장 그룹 인물의 한글 대사와 FC 가 사건 flag 로 바꾸는 말입니다. 이 모듈은 flag 를 켜지 않고, 보는 flag 는 그 사건을 맡은 모듈의 것입니다.

| 대상 | 값 |
| --- | --- |
| 옮긴 대사 | `PORTED`(FC 메시지 묶음 → 한글). `dq4ch3event.ported_texts` 가 모듈마다 모아 `dq4chapter1.messages` 가 옮긴 일본어 임시 대사를 같은 메시지 번호에서 덮습니다(2장 `dq4ch2talk` 과 같음). 묶음은 3장 시작 상태(일행 없음)로 돌린 것이라 예/아니오는 「예」 갈래가 이어져 있고, 대화 `0B9` 는 3장 내내 일행에 톨네코가 있어 `0813` 뒤 `0814` 를 함께 씁니다 |
| 진행별 말 | 아래 표. 대화 스크립트의 flag 조건(제자리 `ctx.retalk`) |
| 엔돌 3장 목록 | FC 3장 동안은 `$6282`&40(2장 끝)이 켜져 `04/00`·`01`·`02`·`05`·`06` 이 flag 목록(`1C:$869A`·`$868E`·`$877D`·`$860D`·`$87EC`)을 씁니다. 옮긴 기본 목록은 2장 대회 중 사람이라, 3장 동안 걸리는 목록(앞 모듈의 `ch3_` 목록, 없으면 기본 목록을 베낀 `ch3_towns_40xx`, 3장 flag)에서 앞 모듈이 맡지 않은 칸의 대화를 FC 3장 것으로 바꾸고 성 1층의 셋을 빼며 콜로세움 문 병사 하나를 더합니다(`ENDOR`·`ENDOR_GONE`·`ENDOR_ADDED`). `40/07`·`40/0B` 는 FC 3장도 기본 목록이지만 2장 끝 우승 목록(빈 성 flag 가 3장에도 켜짐)이 걸리지 않게 같은 식으로 덮습니다 |
| 카지노 `40/01` | 공사 재개 전에는 라이안(`0681`) 하나(`ch3_towns_4001`, FC `1C:$868E`). 공사 재개(굴 모듈 `RESUMED`, FC `$6287`&80) 뒤에는 FC 처럼 기본 목록의 열린 카지노(`ch3_towns_4001_open`, 닫힌 목록보다 앞 줄). 굴 모듈의 개통 소식 인물(기본 목록에 더한 보이지 않는 사람)은 두 목록 모두에 있습니다. 놀이는 옮기지 않아 장치 사람(`CASINO_DEVICES`)은 말만: 교환소 `0350`·`03CF`(코인이 없음), 코인 판매 `0355` 뒤 「지금은 코인을 팔지 않습니다」(FC 에 없는 말), 슬롯 `038A` → 「예」 `047C`, 포커 `07F6` → 「예」 `0482` / 「아니오」 `07F7` |
| 엔돌 자리 | FC 3장 목록에서 자리·걸음이 다른 둘(`ENDOR_MOVED`): 마을 밤 (16,1E) → (17,1E), 왕좌의 방 대신 (0D,0B)은 서 있음(`STAND`). 그림은 기본 목록 그대로라 맵 그룹의 그림 배치가 바뀌지 않습니다 |
| 내보내기 | 감옥 병사 2명(`3F/00` (0A,0E)·(02,07) `066`)은 `034A` 뒤 `3F/01` FC (19,02), 엔돌 성 1층 밤 파수꾼(`40/02` (0C,1C) `028`)은 `038E` 뒤 `40/00` FC (17,0A)로(`OUT_TO`). 자리는 FC 3장 상태(`$615A` = 2)로 말을 걸어 끝난 맵·칸을 잰 것. 대화 호출 `jail_out`·`night_out` 이 이벤트 `90` 을 겁니다(코드 `5F:F800`~) |
| 유모 | `3F/01` (06,06)·(06,07) `05F`: 본몰 `PRINCE_MET` 이고 이번 방문에 켜졌으면 `03B1`, 아니면 `0836`. 3F/01 에 들 때 보이지 않는 사람(빌린 스크립트 `10:B135` 칸 6, 그림은 이 그룹에 이미 있는 병사 `06`)이 `PRINCE_MET` 를 맵 안 임시 비트 `MET_BEFORE`(`7E:21A3` bit7)에 옮겨 둡니다. FC 는 필드로 나가야 지워지고 여기서는 3F/01 을 떠나면 지워집니다 |
| 시작 표 | `start_messages`(맵, DQ5 셀, 밤), `absent`(닫힌 카지노, 성 1층의 셋, 옮긴 엔돌 밤 사람의 옛 칸), `state_messages`(flag 하나씩: `towns_son_freed`·`towns_foxed`·`towns_letter`·`towns_prince`(들 때 이미 켜짐)·`towns_chased`(든 뒤에 켬, 셋째 값 LATESET)·`towns_shop`·`towns_casino`). `dq4npccheck --chapter3 --states` 는 걷는 사람도 맵을 불러온 프레임부터 걸음을 멈춰(`dq4holdwalk.lua`) 처음 칸에서 말을 걸고, 처음 상태에서 없앤 사람도 상태 표에 들면 봅니다 |

- `3E/01` 맨 윗줄 FC (10,00)의 서비스 3 인물(대화 `003`)은 16/01 에 가게 목록이 없어 옮기면 「＜なにもない＞」 만 내므로 앞 칸의 FC 빈 사람(대화 `008`)과 같은 「그 방향에는 아무도 없다」 로 바꿨습니다. 목록에서 빼지 않습니다: 3E 그룹에서 그림 `36` 을 쓰는 유일한 사람이라 빼면 `dq4people` 의 줄·색 칸 배치가 달라져 1장 화면의 인물 그림까지 바뀝니다.
- 시설 사람(가게·여관·교회)은 DQ5 시설 대화라 이 모듈이 바꾸지 않습니다. FC 감옥 병사는 일행이 다가가면 걸어와 「なにものだっ！」(`0307`)를 먼저 말하지만 옮기지 않았습니다(말을 걸면 `034A`·내보내기).
- 엔돌의 스콧 칸 (05,13)·로렌스(`40/0B` (07,08)·(05,08))는 용병 사건 몫이라 기본 목록 사람 그대로입니다.

## 남은 것

- 위 「마을 사람」 의 한글 대사·진행별 말·엔돌 3장 목록·열린 카지노(말과 배치)·내보내기·유모의 그 방문 갈래가 들어감(가드 `dq4-ch3-towns`). 남은 것: 카지노 놀이(DQ5 코인 판매 `06:EE34`·코인 교환 대화 `0C`(목록 키 `15`)를 빌릴 수 있을지와 FC 경품 목록, FC 슬롯은 사람에게 말을 걸어 하고 DQ5 슬롯은 しらべる), 본몰 방어구 매입(물건 고르는 창·FC 값 식 실측, 지금은 묻기만), 감옥 병사가 다가와 먼저 말 거는 것. `3E/01` 맨 윗줄 빈 가게 사람(FC (10,00) 서비스 3)의 「그 방향에는 아무도 없다」 는 임시: FC 16/01 의 가운데 빈 땅(X 08~19)은 세 방(집·왼쪽 방·오른쪽 작은 방)의 어느 걸을 수 있는 칸과도 이어지지 않아(블록 속성으로 칸 잇기를 셈) 놀이 중에는 닿지 않는다. 그 앞 (10,01)도 FC 빈 사람(대화 `008`)이라 FC 가 세워 둔 자리로 보이며, 3장에 하는 일은 재지 않았다.
- [마을 사람](#마을-사람)의 한글 대사·진행별 말·엔돌 3장 목록·열린 카지노(말과 배치)·내보내기가 들어감(가드 `dq4-ch3-towns`). 남은 것: 카지노 놀이, 본몰 방어구 매입.
