# 핸드오프: 게임 안 창 글자 한글화 ① 도구 목록 (2026-10-27)

창 글자 전체를 한글로 바꾸는 작업의 첫 단계(공통 엔진 + 도구 목록 `D3`)의 인계 문서입니다. 브랜치 `feat/dq4-item-list` 는 **초안**입니다. 첫 그리기는 되지만 목록을 활성화하는 순간 메뉴 흐름이 어긋나, 그대로 머지하면 도구 메뉴가 망가집니다.

## 정한 것

- 목록 글꼴은 Galmuri9(사용자 결정, 시안: 도구 창 8줄 Galmuri9 / Galmuri7 비교).
- 한글 표는 번호가 아니라 **일본어 이름**으로 잇는다: 롬의 이름 표(`21:955D`, `BRK 88 2B`)를 `nds/dq4/tables/adopt.tsv` 의 DS 일본어와 맞추고 맞는 것만 바꾼다. 도구 256개 중 95, 주문·특기 122, 몬스터 29개가 맞음. 맞지 않는 DQ5 고유 이름은 가나로 둔다.
- 가나 칸 회수는 필드 창 고정 문구를 다 바꾼 뒤. 전투는 메시지 번역 전까지 가나 칸을 건드리지 않는다.
- 순서: ① 공통 엔진 + 도구 목록 → ② 주문 `D6` → ③ 고정 문구 → ④ 필드 가나 칸 회수 → ⑤ 전투 몬스터 목록 `C8`·`E6` → ⑥ 가게 목록.

## 실측한 것

| 항목 | 결과 |
| --- | --- |
| 이름 문자열 길 | `BRK 88 2B`(`$42` = 번호, `$43` = 이름 표: 0 일행, 3 주문, 4 몬스터, 5 도구)가 DP `$00`(길이)·`$01`~ 에 넣고, 도구는 `D3`(`04:B82F`) → `04:BADB` → `04:B808` 이 글자마다 `04:B235` 로 `($E0),Y` 에 찍는다. 주문 목록은 `D6`(`04:B8B9`), 전투 몬스터 목록은 `C8`(`04:B67B`)·`E6`(`04:BBB2`) |
| 칸 예산 | 필드 VRAM 의 BG1·BG2 글자 0~255번(BG3 칸 `200`~`3FF` 자리)은 바깥 필드에서 250칸이 차 있고, 실내도 교회처럼 낮은 슬롯을 쓰는 맵이 있어 쓸 수 없다. 걷는 메시지 캔버스는 `96` 부터 위로 채운다(두 줄 메시지가 `111` 까지). 그래서 풀은 `1D0`~`1FF` 다음 `17F`~`B0` 을 위에서부터 |
| `04:B808` 이 돌려주는 것 | Y 는 원래 문자열의 **탁점(`84`·`83`)을 뺀 바이트 수 × 2** 만큼 나아가야 하고, A 에는 마지막 글자 바이트가 남아야 한다(`04:BFF2` 는 `PLB / PLP / RTS`). 다르게 돌려주자 창 해석 흐름이 달라졌다 |
| 버퍼 훑기의 한계 | 다른 창을 여는 동안 게임이 타일맵 버퍼 `7E:5000` 의 그 자리를 0 으로 비운다(화면은 그대로). 이때 훑으면 화면에 보이는 칸을 비었다고 보고 다시 빌린다. 버퍼를 훑는 할당 대신 자리(버퍼 주소)나 이름으로 칸을 묶는 할당이 필요 |
| 막힌 것 | 그림을 NMI 전송 목록(`7E:4000`, `$0758`, `$1A` bit7)으로 올리면, 목록을 활성화하는 단계(`a` 뒤 목록을 세 번 다시 그리고 커서를 올림)로 넘어가지 못하고 메뉴가 닫힌 것처럼 된다(걸을 때 뜨는 상태 창이 열림). 전송만 빼면(`JSR WtUpload` 를 `NOP`) 「どうする」·메시지까지 원래대로 간다. 항목을 1워드로 줄여도 흐름이 달라졌다 |

`$1A` bit7 은 `04:9D41` 이 매 프레임 지우고, `00:958A` 는 `$19` bit2 를 켠 뒤 `$19` bit0 을 켜고 다른 작업(`2B:C473`)으로 넘어가 NMI 를 기다린다. 메인 쪽에서 목록을 바로 보내는 길은 `01:C515`(`JSL 00:8D76` → `00:8CF9`). NMI 는 `00:885D` 에서 `$19` bit7 로 갈린다. 게임 목록에 우리 항목을 끼우면 이 동기화가 어긋나는 것으로 본다(확정 못 함).

시도해서 안 된 것: `00:958A` 로 기다리기, 항목 수가 0 이 될 때까지 직접 기다리기(`$19` bit2 를 켜야 보내짐), 기다리지 않고 `04:9D43` 에서 우리 항목이 남아 있으면 bit7 을 지우지 않기, 항목을 두 번에 나누기, 전용 스택으로 돌리기.
