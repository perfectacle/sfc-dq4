## 실험 출발점

준비(워크트리, `$MESENCE`, `$LIBDIR`)는 [analysis 스킬](../../.agents/skills/analysis/SKILL.md#준비) 을 따릅니다.

- **세이브스테이트 `work/state/ship.mss`**: 배 선실(맵 17/00), 조작 가능. 사람마다 다시 만들어야 하면 `tools/lua/mkstate.lua` 로 만듭니다. 필드·다른 맵·전투 장면은 아래 「[장면 이동 도구](#장면-이동-도구)」(`sfc/dq5/tools/lua/dq5warp.lua`)로 이 상태에서 만듭니다.
- **세이브스테이트 `work/state/ship-wake.mss`**: 새 게임 첫 장면, 배 선실에서 주인공이 아직 자는 상태(`7E:21A1` = 0, 주인공 숨김, 버튼을 누르면 깨어남). 전원을 켜고 A 를 40프레임마다 누르다 5,770프레임에 멈추고 5,790프레임에 저장합니다(17/00 이 5,744프레임에 풀림). `ship.mss` 는 이 장면이 끝난 뒤(`21A1` = `71`)입니다.

  ```sh
  LIBDIR=$(uv run --locked krpatch sfc lua) SHOT_DIR=$PWD/work/state MAXF=5800 EVERY=0 PERIOD=40 TAP=a TAPUNTIL=5770 SAVEAT=5790 STATE=ship-wake.mss \
    "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/mkstate.lua"
  ```

- **순간이동**: 배의 사다리 출구 항목(CPU `2A:EFF5`, 파일 오프셋 `156FF5`)을 `ROMPATCH` 로 덮어 원하는 맵으로 갑니다. 사다리는 (3,11) → (3,24) → (7,24) 를 거쳐 위로 누르면 밟힙니다.

  ```sh
  STATE=$PWD/work/state/ship.mss PRE="b:4,wait:40" \
    WAYPOINTS="3,11;3,24;7,24;up:10;<새 맵에서의 경유점>" \
    ROMPATCH="156FF5=E40C2C0101" CHANGES=2 AFTER=150 MAXF=2500 \
    SHOT_DIR=$PWD/work/w1 "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/walk.lua"
  ```

  덮는 바이트는 목적지 표 종류 `60` 항목 `[E0|BD][X][Y][층][BC]` 입니다([dq5-map-format.md 「출구」](docs/dq5-map-format.md#출구-2af6b8)). bit7 은 「그 맵의 마지막 항목」 표시라 남겨 둡니다. 적힌 (X, Y) 에 그대로 섭니다. 예: `E0253C0103` → 03/00, `E40C2C0101` → 01/04 (12,44).
  `LIBDIR` 는 툴킷 Lua 폴더(`$(uv run --locked krpatch sfc lua)`)입니다. 다른 프로브와 함께 쓰려면 `tools/lua/seqlib.sh` 로 만든 폴더를 줍니다.
- **조우 끄기**: `ROMPATCH` 에 `11EA44=0000000000000000`(조우 계수 표 `23:EA44`)를 더합니다. 실내에서 320걸음 동안 조우가 없음을 확인했습니다.
- **무작위 전투 붙이기**: 사다리 출구를 `E2322B0121`(21/02 (50,43))로 덮고 `70,43;46,43` 을 왕복하면 수백 프레임 안에 전투가 붙습니다. `PRE` 의 `wait` 값을 바꾸면 다른 무리가 나옵니다. 무리를 고정하려면 구역 레코드(`23:96F3 + n*22`, 파일 오프셋 `1196F3 + n*22`)의 무게를 고칩니다([일지 2026-10-25-06](journal/2026-10-25-06-encounter.md)).
- **전수 검사 틀**: 맵 목록은 그룹 표 `0F:8ED7` 앞의 그룹 포인터 54개 간격으로 구합니다(합계 346). `sfc/dq5/tools/dq5exit.py` 의 함수(`map_exit_cells`, `map_exits`)를 그대로 써서 모든 맵을 돌 수 있습니다.
- **맵마다 게임 셀 버퍼 덤프**: 위 순간이동에 `atpc.lua` 를 끼워 `AT=15F7EE`(맵별 루틴이 끝난 직후) `FROM=300` 으로 덤프하면 맵을 푼 뒤의 최종 셀 버퍼(`7E:C000-`)를 얻습니다. 맵마다 1초쯤이라 346개를 8개씩 병렬로 돌리면 1분 반입니다(명령은 [일지 2026-10-24-12](journal/2026-10-24-12-exit-hook.md#5-표-전체를-훑고-346개-맵을-모두-확인)).
- **어디서나 순간이동**: `dq5warp.lua` 는 시작 세이브스테이트가 배 선실(17/00)이 아니면(또는 `ANYWHERE=1`) 실내에서 영역 이동 레코드 하나를 주인공 아래 칸·목적지로 써서 2A:D812 자리에 두고, 지금 맵의 레코드 위치·개수(`7E:183A`~`183D`)를 그것으로 바꾼 뒤 아래로 한 걸음 걸어 옮깁니다(아래가 막혔으면 위로 한 칸 갔다 내려옴). 도착은 맵 번호로 봅니다. 선실(`ANYWHERE=1`)·노예 시절 03/05·과거 장면 뒤 21/00 세이브스테이트에서 `TO` 로 옮겨지는 것을 보았습니다. 레코드가 없는 맵(선실 등)에서도 됩니다. 필드 세이브스테이트에서는 아직 안 됩니다(04:FD97 입구를 주인공 아래 칸으로 덮어도 들어가지지 않음, 도착 칸이 목적지보다 한 칸 아래일 수 있음).
- **그룹 `50` 이상 맵으로 순간이동**: 종류 `60` 항목은 `$BD` 를 아래 5비트에만 담아(`2A:F758` `AND #$1F`) `50`~`57` 을 못 씁니다. `dq5warp.lua` 는 `TO` 의 `$BD` 가 `1F` 를 넘으면 `2A:F769` 의 `LDA $01` 을 `LDA #$BD`(`157769=A9xx`)로 덮어 그 맵에 섭니다. 51/57·52/50·53/52 등 12곳에 이렇게 들어갔습니다.
- **패치 하나의 효과 재기**: `lua/dq5framedump.lua` 를 `dq5warp.lua` 와 함께 돌려 `ROMPATCH` 만 다른 두 번의 WRAM·VRAM·CGRAM·OAM 을 8프레임마다 덤프하고 `dq5framediff.py` 로 견줍니다. 기록용 스크립트(`dq5warptrace.lua`)를 얹은 화면은 비교에 쓰지 않습니다(일지 2026-10-25-88). 명령은 [일지 2026-10-25-102](journal/2026-10-25-102-perframe.md).
- **맵 그룹을 옮기면 `7E:219F`·`7E:21A0` 이 지워집니다**(`00:A8C5` → `A8CC`). 같은 그룹 안에서는 남고 `21A1`~`21A4` 만 지워집니다(`00:A957`). 사다리 순간이동은 그룹이 바뀌므로 `POKE` 로 고정해도 맵별 루틴은 0 을 봅니다. 켠 채로 보려면 `ROMPATCH` 에 `28D2=EAEAEAEA` 를 더합니다.

## 장면 이동 도구

`sfc/dq5/tools/lua/dq5warp.lua` 는 위 사다리 순간이동을 감싼 드라이버입니다. 사다리를 밟아 게임의 맵 불러오기를 그대로 타므로 맵별 루틴·인물 목록이 정상으로 돕니다.
도착하고 `SETTLE`(기본 150) 프레임 뒤 `SHOT_DIR` 에 세이브스테이트(`SAVE`)와 그림을 저장합니다. 저장한 세이브스테이트는 `ROMPATCH` 없이 원래 롬으로 불러 쓰면 됩니다(덮은 롬 바이트는 세이브스테이트에 들어가지 않고, 바꾼 플래그는 WRAM 에 남습니다).
만든 세이브스테이트를 다른 세션과 함께 쓰려면 원래 체크아웃의 `work/state/` 에 새 이름으로 둡니다. `work/state/field-free.mss` 가 아래 (a) 명령으로 만든 필드 (341,56) 입니다(없으면 같은 명령으로 다시 만듭니다).

```sh
export LIBDIR=$(uv run --locked krpatch sfc lua)
# (a) 조작 가능한 필드: 필드 좌표($B6,$B8) (341,56). 걷기·마을 들어가기·무작위 조우 모두 됨
STATE=$PWD/work/state/ship.mss FIELD=341,56 SAVE=field-free.mss TEST="left:40,up:40" \
  SHOT_DIR=$PWD/work/warp "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5warp.lua"
# (b) 아무 실내 맵: TO=$BC/$BD(16진),셀X,셀Y(10진)[,층]. SET 은 시작할 때 한 번 WRAM 을 고침(= 값, | OR, & AND)
STATE=… TO=04/00,27,75 SET="2194|80" SAVE=0400.mss …
# (c) 전투: 첫 필드 이벤트 전투(23:D757 의 1번)의 무리를 몬스터:마릿수(16진:10진, 최대 4종)로 바꿈
STATE=… FIELD=341,56 BATTLE="0C:2,00:1" SETTLE=300 SAVE=battle.mss …
# (d) 이벤트 전투 무리 표(23:D757, dq5encounter.py --events)의 번호로 전투. 2C = エスターク
STATE=… FIELD=341,56 GROUP=2C SETTLE=300 SAVE=battle-2c.mss …
```

- 결과는 `warp.txt`(도착 맵, 셀 또는 필드 좌표, `$BE`, `7E:2190`~`21AF`)와 `end.png`. `TEST` 입력으로 좌표가 바뀌면 `moved=yes` 입니다.
- `FIELD` 는 01/00 (32,92) 로 간 뒤 아래로 걸어 나갑니다. 이때 쓰는 입구 표 `04:FD97` 의 그룹 01 항목(파일 오프셋 `27DC9`)을 그 좌표로 덮고, 첫 필드 이벤트를 끄려고 `7E:2194` bit7 을 켭니다.
  만든 세이브스테이트를 원래 롬으로 걸으면 그룹 01 입구는 원래 자리 (331,67) 입니다.
- 필드에서 조작이 막히던 까닭: `7E:2194` bit7 이 꺼져 있으면 필드 루틴(`15:F907` 의 `FE` 항목)이 `02:A94C` 를 골라 파파스와 슬라임 전투 이벤트(`02:A775` → `01:86A7`, 무리 1번)를 돌립니다. 이 bit 를 켜면 이벤트 없이 바로 조작됩니다([일지](journal/2026-10-25-08-warp.md)).
- 세계(`$1949`, 0 지상·1 눈 덮인 땅·2 보라색 바다)가 다른 그룹에 들어가거나 다른 세계 지도에 서려면 `POKE="7E1949=01"` 처럼 매 프레임 고정합니다. `SET` 은 맵을 지날 때 `2A:FEE4` 가 다시 써서 사라집니다([dq5-field-format.md 「세계 셋」](docs/dq5-field-format.md#세계-셋-019f40)).
- 그룹 `$50` 이상 맵은 `TO` 로 못 갑니다(`$BD` 5비트). `FIELD=452,231 TEST="down:30,wait:300" ROMPATCH="1573E6=<BC>;1573EC=<BD>;27E7D=<BC>;157F2A=FF"` 로 입구 51 을 바꿔 들어갑니다. 도착 셀은 `1573F0`·`1573F4`, 도착 층은 `1573F8`(기본 `02`, 바닥이 1층뿐인 맵은 `01` 로 덮어야 움직임)로 바꿉니다. 50/50 은 `ROMPATCH="27E7D=50" SET="21BA|20"`.
- `GROUP` 은 첫 필드 이벤트가 거는 무리 번호(`02:A780 LDA #$01`, 파일 오프셋 `12781`)를 바꿉니다. `BATTLE` 과 함께 주면 그 번호의 무리를 덮습니다.
- 다른 프로브를 이 도구 뒤에 붙이려면 `tools/lua/seqlib.sh … work/warplib dq5warp.lua` 로 `LIBDIR` 를 만듭니다. 프로브 결과는 `TO` 에 쓰이므로 도구가 끝나기 전(`SETTLE` + `TEST` 안)으로 맞춥니다.
  이 도구의 `TO`(실내 맵)와 `cover.lua`·`rprof.lua` 의 `TO`(프레임)는 이름이 겹칩니다. 실내 맵에서 그런 프로브를 쓰려면 먼저 `SAVE` 로 세이브스테이트를 만들고 `seqboot.lua` 드라이버로 붙입니다.
- 필드에 멈춰 서면 뜨는 「めいれいさせろ」 창은 작전 이름 창입니다(게임 본래 화면, [dq5-text-format.md](docs/dq5-text-format.md)).
- 롬 `01:8000`·`01:8001` 은 개발용 스위치로 보입니다. `ROMPATCH=8000=00` 이면 B 를 누른 채 벽을 지나고([dq5-field-format.md 「디버그 벽 통과」](docs/dq5-field-format.md#디버그-벽-통과-00a97d)), `8000=0000` 이면 격투장에서 시합 번호를 고릅니다([dq5-data-format.md](docs/dq5-data-format.md)).
- 미니게임: 선실의 파파스를 대화 번호 `0D`(슬라임 레이스)로 바꾸고 코인을 넣으면(`POKE=7E203C=64`, 코인 `7E:203C`~`203E`) A 를 아홉 번 넘겨 레이스 화면까지 갑니다. 코인 검사를 롬으로 건너뛰려면 `ROMPATCH=37210=80`(`06:F210` 의 `BNE` → `BRA`). `0E` 는 격투장입니다.
- 탈것: 마법 융단은 `FIELD=310,60 SET=2056=CC`(첫 칸에 まほうのじゅうたん) 뒤 `TEST="a:8,wait:40,right:6,wait:20,down:6,wait:20,a:8,wait:60,a:8,wait:60,a:8,wait:160"`(どうぐ → つかう)이면 「まほうのじゅうたんを ひろげた！」 뒤 융단에 탄 채 물 위를 갑니다. 산 위(341,56)에서는 「ここでは ひろげられない！」. `$1954` 만 `POKE` 로 바꾸면(`03` 물 위, `82` 바다 위) 움직임만 바뀌고 그림은 그대로입니다.
- キメラのつばさ: 물건 번호 `A4`(`dq5items.py` 의 숨은 물건 목록). `FIELD=310,60 SET=2056=A4` 뒤 마법 융단과 같은 どうぐ → つかう 입력이면 905 프레임에 효과음 `36`(X `02`, `05:E9DF`) 뒤 965 프레임에 맵을 다시 불러옴(`01 02`). `2056=0D` 는 インパス 메시지 값이라 물건이 아님.
- ルーラ: `SET="2063=FF;2044=63;2050=63"`(이동 주문 모두, MP 99) 뒤 じゅもん → 일곱째(ルーラ). 목적지 플래그는 `7E:2030`~`2032`.
- 동료 일행: `PARTY=02,05`(동료 레코드 `23:AED1` 의 종류, 16진)면 주인공 뒤에 スラリン·ホイミン 이 들어가 필드에서 따라 걷고 전투에서 명령을 받습니다. 셋째 동료부터는 필드 그림이 빈 그림입니다. 진짜로 동료를 들이려면 dq5-spell2 방법(전투 중 `POKE=7E21B1=40;001010=80`, `ROMPATCH=138170=0100`, スライム 무리를 이김).
- 청년기·어른: `ADULT=1` 은 `7E:2190` bit6·5 와 `$1948` = 2(노예 시절 차림), `ADULT=2` 는 거기에 `7E:21BE` bit5 를 더해 망토 차림 어른 주인공입니다. `WAGON=1` 은 마차(`7E:201C` bit7)입니다. 예: `FIELD=310,60 ADULT=2 WAGON=1 PARTY=02,05` 면 어른 주인공 뒤로 마차와 スラリン·ホイミン 이 따라 걷습니다. 동료가 셋 이상이면 앞의 둘만 걷고(`7E:201E` = 3) 나머지는 마차에 탑니다.
- 배: `FIELD=328,27 SET=21BE|01 LATESET=1954=03` 이면 흰 돛단배를 타고 바다를 지나갑니다(`7E:21BE` bit0 = 배 그림 `98`, `$1954` = `03` = 배). `LATESET` 은 도착한 뒤 한 번 고치는 `SET` 입니다. `1954=80` 은 마법 융단, `81` 은 天空城, `82` 는 マスタードラゴン 입니다. 실제 게임처럼 배에 타려면 `FIELD=328,39 SET="21B5|80;21CD=48;21CE=01;21CF=25;21D0=00"`(세워 둔 배를 (328,37)에)로 가서 위로 걸어 배에 오릅니다. 마법 융단을 실제로 펴려면 `FIELD=310,60 SET=2056=CC SETTLE=60 TEST="a:8,wait:60,right:8,wait:40,down:8,wait:40,a:8,wait:80,a:8,wait:80,a:8,wait:250"` 입니다(`7E:2056` 에 아이템 `CC` 를 넣고 アイテム 창에서 고름. 잔디 위에서 A 로 내림).
- 카지노 슬롯: `TO=19/02,42,27 SET=203C=64` 뒤 위를 보고 しらべる(`TEST="up:3,wait:15,a:8,wait:60,down:6,wait:25,down:6,wait:25,down:6,wait:25,right:6,wait:25,a:8,wait:90,a:8,wait:70,a:8,wait:200"`)면 1 ドル 슬롯 화면입니다. 위로 코인을 넣고 A 로 돌립니다.

상자 내용물을 바꿔 보려면 `ROMPATCH` 에 `F6E4E + 번호*2` 오프셋을 파일 바이트 순서로 줍니다.

대화 실험 요령: 선실 세이브스테이트에서 위를 보고 A 두 번(`PRE="b:4,wait:40,up:3,wait:20,a:4,wait:30,a:4,wait:150"`)이면 파파스(슬롯 `0B`)와 대화합니다.
`POKE="7E36EB=<하위>;7E370B=<상위>"` 로 대화 번호를 바꾸면 아무 스크립트·메시지나 띄울 수 있습니다. 메시지 번호는 `CALLS=248BAF` 의 A 값입니다.
아무 메시지나 띄우려면 파파스 스크립트의 메시지 `41 2D`(파일 오프셋 `30139`)를 `ROMPATCH="30139=6xyy"` 로 덮습니다(메시지 `xyy`). 조건 코드는 `ROMPATCH="3012D=07<조건>616B0B61293F"` 로 시험합니다(참 `16B`, 거짓 `129`). 여러 쪽은 `tools/lua/shots.lua` 로 찍습니다.
