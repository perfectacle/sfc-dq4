## 사용자가 정한 것

- 곡 이름은 파일 이름을 바꾸지 않고 문서와 에셋의 `index.json`·`sound.html` 에만 넣습니다. 기준은 공식 교향조곡 곡목이고, 장면 실측으로만 짝을 짓습니다.
- 악보는 verovio SVG 로 냅니다. LilyPond 는 설치하지 않습니다.
- 전투 연출을 입구 상태 없이 롬만으로 재현하는 일은 하지 않습니다. 포팅용 연출 그림은 입구 상태 한 벌과 롬 코드로 충분합니다.
- 창 2바이트 부호를 여러 글자로 만드는 길(캔버스 빌리기 또는 BG3 타일 칸 넓히기)은 사람이 포팅 단계에서 고릅니다. 에이전트가 정하지 않습니다.
- 모든 에셋은 공개 저장소와 롬만으로 다시 뽑을 수 있어야 합니다. 도구를 바꾸면 비공개 에셋도 `dq5assets.py --only …` 로 다시 뽑아 함께 커밋합니다.

## PR 충돌 정리

트랙 세션 여럿이 같은 `README.md` 일지 목록과 `todo.md` 를 고치므로 충돌이 자주 납니다. [`tools/dq5fixconflicts.sh`](tools/dq5fixconflicts.sh) 가 열린 dq5 PR 가운데 충돌 난 것을 찾아 `origin/main` 을 merge 합니다.

- 일지 번호만 겹치면 우리 일지를 main 최대+1 로 다시 매기고, 제목·참조·「일지 …」 라벨을 고쳐 push 합니다.
- 그 밖의 충돌은 「손으로 풀 것」으로 이름만 알립니다. 손으로 풀 때는 `todo.md` 는 줄마다 더 최신·더 좁혀진 쪽을 남기고, 충돌 표시를 grep 하고, `tools/check_docs.py` 가 0 errors 인지 본 뒤 push 하고 자동 머지를 켭니다.
- push 직전에 PR 이 아직 열려 있는지 확인합니다. 이미 머지된 PR 에 push 하면 지운 브랜치가 되살아납니다.
- 임시 워크트리는 원래 체크아웃 옆 `<체크아웃>-lead-fix` 에 만들고 끝나면 지웁니다. `GH_TOKEN` 이 없으면 `gh auth token` 을 씁니다.
