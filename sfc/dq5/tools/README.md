# dq5 도구

저장소 최상위에서 `uv run --locked python sfc/dq5/tools/<스크립트>` 로 실행합니다. 롬은 첫 인자로 줍니다(`rom/dq5.sfc`). 모듈끼리는 같은 폴더에서 import 합니다.

MesenCE 프로브(`lua/`)는 [트랙 공통 도구](../../../tools/README.md) 의 `LIBDIR`·`MESENCE` 설정과 `seqlib.sh` 드라이버를 그대로 씁니다. 스크립트 경로만 `"$PWD/sfc/dq5/tools/lua/<스크립트>"` 로 줍니다.

## Python

| --- | --- |
| `dq5map.py rom BC BD` | DQ5 실내 맵 디코더. `--compare` 로 게임 셀 버퍼(속성 패스 끝)와 비교, `--png` 로 그림(팔레트도 롬에서). BC `50`~`54` 맵은 따로 된 포인터·블록·CHR 과 맵 전후 처리(슬롯 건너뛰기·블록 먼저 올리기·`+4` 찍기)를 따름 |
| `dq5field.py rom` | DQ5 필드 세계 지도 풀기. `--world 0~2` 로 `$1949` 세계 고르기, `--compare` 로 WRAM 과 비교, `--png` 회색조 지도, `--entrances` 로 입구 47개와 도착 자리 |
| `dq5trigger.py rom [BC BD]` | DQ5 실내 맵 영역 이동 레코드(맵을 빼면 전체 통계). `+4`·`+B` 는 출발·도착 층 |
| `attrgrid.py rom BC BD` | 통행 격자를 글자로 찍기(경로 잡기용) |
| `dq5exit.py rom BC BD` | DQ5 실내 맵 출구 셀·목적지·도착 자리. 맵을 푼 뒤 도는 맵별 루틴(`15:F907`)이 바꾸는 출구 셀도 반영 |

| `dq5battlewin.py rom [번호…]` | DQ5 전투 메시지 창: 메시지를 글자 격자(`24:A4A4`, `7E:1DD5`)에 두고 BG3 타일맵(`24:A5D9`)과 창 틀로 그림. `--png 폴더` 예시 창, `--compare VRAM 05E,069` 로 전투 덤프의 BG3 타일맵 21~27줄과 칸마다 비교. `--scroll` 은 둘째 메시지부터 `BRK 9E` 로 이어 찍기(셋째 줄 다음 줄 올리기). 갤러리는 `dq5gfx.py` 의 `battlewin` |

| `dq5talk.py rom 대화번호` | 대화 번호의 갈래·스크립트·메시지(조건 코드 뜻, 특수 기능 처리기, 묻기 갈래 포함). `BC BD` 를 주면 그 맵 인물 전부, `--check` 로 스크립트 574개 경계 검사, `--calls` 로 네이티브 호출 대상·갈래·하는 일, `--field` 로 `BRK 80`~`93` 필드 설명자 |

## 에셋 다시 뽑기

비공개 에셋 저장소 `sfc-dq4-assets` 의 `sfc/dq5/` 는 이 저장소와 롬(`rom/dq5.sfc`)만 있으면 다시 만들 수 있습니다. 세이브스테이트나 `work/` 의 중간물은 필요 없습니다.

```sh
export MESENCE=<MesenCE 실행 파일>      # 예: macOS 는 MesenCE.app/Contents/MacOS/Mesen
export GME_LIB=<libgme 동적 라이브러리>  # 예: Homebrew 는 $(brew --prefix)/lib/libgme.dylib
uv run --locked python sfc/dq5/tools/dq5assets.py rom/dq5.sfc --out "$ASSETS/sfc/dq5"
```

- `$ASSETS` 는 에셋 저장소 체크아웃입니다. 한 단계만 다시 뽑으려면 `--only sound` 처럼 줍니다. 모두 도는 데 MesenCE 6개를 함께 돌려 20분 남짓 걸립니다.
- MesenCE 의 Saves 폴더가 macOS 기본 자리(홈 폴더의 `Library/Application Support/MesenCE/Saves`)가 아니면 `MESENCE_SAVES` 로 알려 줍니다. 전원부터 켜는 단계가 시험용 롬 이름의 SRAM 파일을 지우고 켭니다. 남은 SRAM 이 있으면 모험의 서 메뉴가 달라져 입력이 어긋납니다.
- 사용자 설정 파일과 상관없이 같은 결과가 나오도록 결과를 바꾸는 MesenCE 설정을 인자로 고정합니다(`dq5assets.py` 의 `PINNED`). `Snes.SpcClockSpeedAdjustment` 는 0 과 40 에서 `.spc` 가 달랐습니다.
- 같은 커밋에서 두 번 돌리면 모든 파일이 바이트까지 같습니다. 숫자와 확인한 방법은 [일지 2026-10-26-34](../journal/2026-10-26-34-repro.md).
