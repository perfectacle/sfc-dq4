# dq5 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

SFC DQ5 엔진 분석. 시작점은 [handoff.md](handoff.md). 결과 문서: [dq5-map-format.md](docs/dq5-map-format.md), [dq5-field-format.md](docs/dq5-field-format.md), [dq5-text-format.md](docs/dq5-text-format.md), [dq5-data-format.md](docs/dq5-data-format.md), [dq5-graphics-format.md](docs/dq5-graphics-format.md).

- **통합 포팅 빌드의 남은 것**([통합 포팅 빌드](docs/dq5-build-format.md#통합-포팅-빌드-dq5portbuild1), [일지](journal/2026-10-27-26-portbuild.md)): 타이틀을 옮기지 않은 채 `30`~`3F` 의 빈 자리는 297,762바이트라, 맵 364개 전체(233,794바이트)·인물(44,240)·세 세계(39,269) 합계 317,303바이트는 맵을 여러 작업으로 나눠도 들어가지 않음. 그만큼 넣으려면 타이틀 자료를 상위 뱅크로 옮기는 DQ4 트랙 작업(아래 요청)이 필요. `jobs[].records`(인물 레코드)·`patch` 종류는 통합 롬에서 게임 실측하지 않음. 실제 SFC 기기, 새 게임 → 장 진행 → 저장·재개는 아직.
- **DQ4 트랙에 요청할 것**(다른 트랙 파일이라 고치지 않음): ① `sfc/dq4/tools/dq4menupatch.py` 의 `BASE_SHA1` 이 이전 서곡 `ed46db6…` 이라, 현재 문서 절차로 만든 서곡 `ccfebeb…` 위에서 메뉴 빌드가 멈춤(통합 빌드는 값을 바꿔 불러 `e102f29…` 를 만듦). ② 타이틀·서곡·이름 입력 빌드가 쓴 구간을 목록으로 내면 통합 빌드의 거울 추정(다른 바이트 묶음 ±64바이트)을 없앨 수 있음. ③ 맵 전체를 함께 넣으려면 타이틀 에셋(현재 `31`~`39` 의 219,872바이트, 코드 4,096바이트 별도)를 상위 뱅크로 옮기는 재배치와 게임 검증.
- **월드·진행 작성 경로**: 실내 출구·영역 이동 증설·재배치, 인물 슬롯을 맵을 놓은 뒤 더 쓰는 장면의 맵별 정리(인물 필드·조건 항목은 `dq5npcrecord.py`, 인물 수·순서·새 목록·조건 표 증설은 `dq5npcrelocate.py`), 맵 후처리 표는 [`dq5maphook.py`](journal/2026-10-27-18-maphook.md)로 항목·플래그 조건·루틴 연결·뱅크 15 안 재배치를, 163개 넘는 증설(뱅크 `00`~`3F`·`80`~`BF`, 로더 DB 스텁)과 `15:FF5C` 셀 읽기 루틴 표 쓰기를 게임에서 확인(`dq5maphookcheck.py`). 남은 것: 맵 고르기를 바꾼 롬·`--raw-routines` 롬의 실측, 원래 롬 빈 자리 뱅크에 둔 스텁 롬의 실측. 대화 스크립트 쓰기는 `dq5talkwrite.py`로 끝냄([일지](journal/2026-10-27-20-talkwrite.md)). 대화 번호 `900`~`FFF` 에 스크립트를 덧붙여 뱅크 30~3F 에 두는 것도 끝냄([일지](journal/2026-10-27-53-talkgrow.md)). 대화 쪽 남은 것: 원본에 없는 명령 `01`·`12`·조건 `16`·`1C` 실측, 덧붙인 뱅크에서 BRK 조회 조건의 거짓 갈래. 장별 시작/끝·파티 승계·탈것·패배 후 진행·저장 재개는 엔진/시나리오 작업으로 구분.
- **전투·그림·한글 작성 경로**: 주문 목록 증설은 [`dq5spellgrow.py`](journal/2026-10-27-60-spellclass.md)로 빈 행동 번호 `C6`~`D4` 에 새 주문을 더하고 `class: spell` 로 주문으로 다루며, 습득 메시지·필드·전투·マホトーン·저주를 게임에서 확인. 남은 것: `20:8EE8`(`$1016` bit4) 경계의 게임 실측, マホカンタ 등 세 경계 밖의 주문 처리 실측, 효과 연결 가운데 `STX $43`·`AEC6`·`AEFF`·`B657` 첫머리와 행동 전용 처리 루틴의 값(처리 루틴 연결·네 명령 첫머리·필드 MP/회복은 [`dq5spellfx.py`](journal/2026-10-27-27-spellfx.md)로 해결), AI 표 가운데 행동 AI `+0` 종류 비트·작전 `+3`~`+5`·`+A`·`+12`·`+4` 범위 `A0`/`C0`/`E0` 의 뜻·작전 3 거름(`21:DA58`)이 보는 MP·내성 배율 표 `27:8059`~`806D`·갑옷 원소 표의 원소/물건 칸(행동/물건 AI 의 값·갈래·MP·범위·내성, 작전 8칸, 학습 배율 셋, `27:8055`, 갑옷 원소의 빼는 양은 [`dq5aiwrite.py`](journal/2026-10-27-43-aiwrite.md)로 해결), 초기 파티 데이터 가운데 주인공 다음 경험치를 다시 셈하는 루틴·머리 `+30`~ 의 뜻(쓰기는 [`dq5newgame.py`](journal/2026-10-27-50-newgame.md)로 해결), 인물 스프라이트의 고유 팔레트·새 그림 번호·8타일 새 세트(세트 그림·새 6타일 세트·그림 번호 연결은 [`dq5spritewrite.py`](journal/2026-10-27-28-spritewrite.md)), 탈것·맵 OBJ 의 칸 배치·새 물체(타일은 [`dq5objtiles.py`](journal/2026-10-27-56-objtiles.md))·원래보다 큰 몬스터 그림·머리 값·색 수 늘리기(그림·색 쓰기는 [`dq5monwrite.py`](journal/2026-10-27-38-monwrite.md)), 전투 배경·실내 맵 그림은 [그림 쓰기](journal/2026-10-27-47-gfxwrite.md)(남은 것: 필드 타일·벌 수 늘리기, 실내 BG 팔레트 세트·목록 수 늘리기. 배경 목록·팔레트 옮기기와 BG 팔레트 줄 늘리기는 [일지](journal/2026-10-27-62-palgrow.md)로 해결. 그룹 50 이상 맵·필드 그림, 문·상자·이어하기는 [일지](journal/2026-10-27-57-fieldgfx.md)로 해결), 게임 안 한글 코드북·명칭·전투 메시지·창. 기존 타이틀·서곡·메뉴·이름 입력·음악/효과음/BRR 도구는 재사용.
- **소리**: 곡 이름의 빈칸 31개·추정 6개([dq5-sound-format.md 「곡 이름」](docs/dq5-sound-format.md#곡-이름)). 빈칸 곡의 장면은 대부분 찾았지만 남은 곡명(街は生きている·はめつの予感·哀愁物語·高貴なるレクイエム)과 하나로 맞지 않음. 장면을 못 찾은 곡 `1B`·`1C`·`24`·`2A`·`2C`~`2F`, `15` 의 즉위식·엔딩 실측.
- **그래픽 내보내기의 남은 것**: 범위 결정으로 닫음: 포팅용 연출 그림은 입구 상태 한 벌 + 롬 코드(`dq5fxvm --clock`)로 139/139 0 차이. 롬만 재현은 SPC700 해석기·전투 입구 상태 세우기가 필요해 하지 않기로 함([dq5-graphics-format.md](docs/dq5-graphics-format.md#롬-코드로-돌리기-dq5fxvmpy)). 해결됨: `0C`·`6F` 처리 도중 NMI, `DDDC` 를 부르는 장면.
- **텍스트의 남은 것**: 한글 넣기([dq5-hangul-format.md](docs/dq5-hangul-format.md)): 창 2바이트 부호를 여러 글자로(캔버스 빌리기 또는 BG3 타일 칸 넓히기, 두 길의 근거는 문서, 고르기는 사람 몫), 옮긴 레코드 자리 `7E:1ABC`~`1BB0` 은 접근 카운터로 841개 장면에서 원래 코드의 읽기·쓰기 0 ([일지 2026-10-27-46](journal/2026-10-27-46-wramfree.md)), 패치 뒤 통짜 진행 시험에서도 같은 카운터를 걸 것. 해결됨: `21BF.5` 를 켜는 곳 — ベネット 의 지도(`06:BAAB`)와 ブオーン 이 나타나는 장면(`06:BAFA`)이 큰 그림을 띄우는 동안만 켜고 끔([일지 2026-10-27-61](journal/2026-10-27-61-flag21bf5.md)), BG3 타일맵 자리 — 맵 무리마다 BG3SC 를 바꾸는 길(필드 `78`, 실내 대부분 `3C`, 마을 6곳 `48` 이고 전투 시작에서 `78`)을 DQ4 트랙이 구현하고 실측함([dq4-window-text-format.md](../dq4/docs/dq4-window-text-format.md#bg3-타일맵-옮기기)).
- **에셋 다시 뽑기의 남은 것**([일지 2026-10-26-34](journal/2026-10-26-34-repro.md)): Windows·Linux 판 MesenCE 에서도 `dq5assets.py` 결과가 바이트까지 같은지.
- **쓰기 도구(포팅용)**: 몬스터·물건·주문·피해량·동료 표는 `dq5tables.py`. 실내 맵은 `dq5mapwrite.py`. 배치 목록 컴파일은 `dq5mapcompile.py`, 필드 지도는 `dq5fieldwrite.py`(뱅크30~3F), 필드 블록·입구·도착 고정 표는 `dq5fieldtables.py`이며 세계0~2 지도 쓰기도 게임에서 확인. 이벤트·인물 스크립트는 `dq5eventwrite.py`·`dq5npcwrite.py`(인물은 기존 슬롯 안에서 교체). 성장·조우 구역·상점 고정 목록은 `dq5progresswrite.py`이며 레벨업·조우·상점과 물건 가격 쓰기를 게임에서 확인. 보행 대사 코드 목록은 `dq5textwrite.py`로 일괄 재압축하며 앞·뒤 메시지를 게임에서 확인. 전투 메시지는 `dq5battletextwrite.py`, 이름 문자열 표 아홉 개는 `dq5namewrite.py`(길이 변경·제자리·옮기기)이며 전투 버퍼·격자와 몬스터 이름을 게임에서 확인(`dq5battletextcheck.py`). 인물 스크립트 길이 변경과 목록 재배치는 `dq5npcrelocate.py`로 694쌍·긴 스크립트 실행 5건을 게임에서 확인. 인물 엔트리 필드·낮밤과 등장 조건 표 기존 항목은 `dq5npcrecord.py`로 쓰며 이동·대화 번호·그림·낮밤·대체 조건을 게임에서 확인. 인물 수·순서·새 대체 목록·조건 표 증설은 `dq5npcrelocate.py`로 쓰며 게임에서 확인. 입구 표 둘의 옮기기·늘리기는 `dq5fieldtables.py --entrances-at` 이며 새 보조 입구로 02/00 에 들어가고 옮긴 일반 표로 필드에 나오는 것을 게임에서 확인(`dq5entrancecheck.py`). 남은 것: 필드 블록 표 증설(번호 범위 `00:BC4E` 미확인)·도착 표와 새 맵 그룹(`36`~`4F`) 증설, 일반 입구 `2A:F247` 이 어떤 칸에서 불리는지(`00:C7DD`), 옮긴 입구 표의 일반 표 들어가기·보조 표 나올 자리·ルーラ·세계 지도 읽기 실측, 문자열 번역 편집·새 한글 글꼴 대량 삽입·전투 메시지 창(창 25) 자리·크기(다른 창 자리·크기와 24바이트 이름은 [일지](journal/2026-10-27-64-namewindow.md)로 해결), 성장·구역 표를 뱅크 23 밖에 두기는 필요해지면(지금 자리로 사람 64·구역 125개까지 들어가 DQ4 규모에 넉넉함. 성장은 레코드를 낮은 WRAM 으로 복사하는 훅이 필요한데 비어 보이던 `7E:1ABC`~ 는 DQ4 메뉴가 씀, 구역은 `23:E7C2` 의 데이터 뱅크를 바꾸면 `23:B04B`·`EA44` 도 함께 옮겨야 함. 성장·구역 레코드 더하기와 그룹 50 이상 맵 구역 연결·목록 늘리기는 `dq5progresswrite.py`·`dq5encounterwrite.py`로 끝냄, [일지](journal/2026-10-27-35-recordgrow.md)·[일지](journal/2026-10-27-42-highareas.md)). 필드 조우 격자·실내 구역 연결(그룹 00~35)·고정 무리·이벤트 전투 무리는 `dq5encounterwrite.py`이며 네 장면을 게임에서 확인(`dq5encountercheck.py`). 배의 바다 구역 직사각형 `01:85D8` 의 [X0][X1][Y0][Y1] 경계가 닫힌 구간인지(경계 칸에서 구역이 바뀌는지) 미확인. 고정 무리 하위 4비트와 이벤트 무리 `+9`~`+C` 는 `$1009`~`$100C` 로 가는데, `$100A` 의 0·1·80 말고 값의 범위와 `$100C` 의 쓰임은 미확인. `dq5tables.py`는 가격·힘·장비사람·장비몬스터·칸, 물건 플래그(쓰면없어짐·사용메시지없음·필드대상창·팔수없음·가득창·적쪽·전투대상창·상점전투설명·저주·インパス 다섯), 주문 MP·범위·적쪽·대상루틴, 피해량, 동료 다섯 필드 쓰기를 게임에서
