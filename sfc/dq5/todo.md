# dq5 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

SFC DQ5 엔진 분석. 시작점은 [handoff.md](handoff.md). 결과 문서: [dq5-map-format.md](docs/dq5-map-format.md), [dq5-field-format.md](docs/dq5-field-format.md), [dq5-text-format.md](docs/dq5-text-format.md), [dq5-data-format.md](docs/dq5-data-format.md), [dq5-graphics-format.md](docs/dq5-graphics-format.md).

- **전투**: 전투 메시지 `F9` 의 소리 `0C 32` 의 정체.
- **전투**: 바다에서 전투가 붙지 않는 까닭(배 `$1954` = `03` 으로 조우 계수를 `FF` 로 해도 안 붙음, `23:E7C2` 의 나머지 조건), 전투 메시지 `F9` 의 소리 `0C 32` 의 정체.
- **전투**: 전투 메시지 코드 중 화면으로 보지 않은 것(`F2`·`F9`·`E2`·`E4`·`EA`·`FA`), 글자표에 없는 몇 바이트(`ズ`·`ゾ`·`ダ` 로 찍히는 것). 배경의 남은 것: 실제 게임에서 배를 탈 때 `$1954` 가 `03`(걸음마다 `$1AA0` = `00`)·`80`(쓰지 않음) 중 어느 것인지, 바다 전투 화면.
- **이야기 플래그·이벤트 스크립트**: 「문맥」 사건 이름 실측(청년기는 6단계 확인, 신전·カボチ 남음), 켜는 곳이 없는 비트 30개, 제 장면에서 걸리지 않은 이벤트 4·5·7·9·6 과 `02:B705` 직접 호출 여러 곳, 명령 `C2`·`C4`·`C5`·`91` 의 뜻, パルプンテ `1D` 의 조건.
- **조우의 남은 것**: 예외 표(`1F:F921`·`1F:FA3C`) 플래그의 사건을 게임으로 확인(지금은 켜는 곳 곁의 대사로 붙인 문맥).
- **인물**: 스크립트 명령 `06`·`07`·`09`·`10`·`11`·`15`·`16`·`18`·`19`·`1D`·`20`·`21`·`22`·`2F`·`30`~`32`·`36`·`38` 을 덮어 쓰기로 실측(`20` 은 효과음으로 보임), 문 명령 넷째 바이트가 결과를 바꾸는 맵, `19AE` bit7·`33A0` bit1-3·`32A0` bit0·bit6 이 고르는 그림의 규칙. 첫 장면(깨어나기)은 새로 시작한 세이브스테이트가 있어야 재현됨.
- **맵별 루틴(`15:F907`)의 남은 것**: 매 프레임 루틴(`$1AA6`) 중 `03:D4B5`·`02:AE55` 밖의 39개가 하는 일(목록은 [dq5-map-format.md 「맵별 루틴」](docs/dq5-map-format.md#맵별-루틴-15f907)).
- **이벤트 스크립트의 남은 것**(dq5-enc2 세션이 이어 맡음): 이벤트 0~7·9 와 `02:B705` 를 직접 부르는 14곳의 장면 실측, 명령 `C4`~`C9`·`91` 이 부르는 루틴. 형식은 [docs/dq5-event-format.md](docs/dq5-event-format.md).
- **그래픽 내보내기의 남은 것**: 엔딩 스태프 롤을 게임에서 띄워 덤프와 맞추기(문자열 `1E:F5B8` 은 풀림. 매 걸음 `7E:21EA` bit7 이면 `02:FE5D`·`02:FAD8` 이 돎. 그 비트만 켜거나 타이틀 포인터를 문자열 0 으로 바꿔서는 화면에 나오지 않음. 엔딩 이벤트의 준비 루틴을 찾아야 함), 창 레코드 자리 표시(`B0`~)에 예시 값 넣기, 반탁점의 테두리·가로줄 칸 타일(`93`·`95` 로 둠), 전투 창, 반탁점의 테두리 칸 타일.
- **텍스트의 남은 것**: 네이티브 호출 「장면」 갈래 실측과 「호출」 갈래가 부르는 루틴의 뜻, 창 머리 `+0`·`+2` 위 비트와 `+4` 위 4비트, 상태 창 제목 뒤 `12 12 12`. 한글 넣기([dq5-hangul-format.md](docs/dq5-hangul-format.md)): 한글 글자 폭에 맞춘 창 너비 다시 잡기, 뱅크 24 에 트리 표를 둘지.
- **인물 스프라이트의 남은 것**: 07/02 에서 스크립트가 놓는 맵 OBJ 물체(`16:F862` 의 `00`~`07`·`0E`) 실측, 세트 `5C`·`A2` 가 쓰이는 장면.
