# dq5 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

SFC DQ5 엔진 분석. 시작점은 [handoff.md](handoff.md). 결과 문서: [dq5-map-format.md](docs/dq5-map-format.md), [dq5-field-format.md](docs/dq5-field-format.md), [dq5-text-format.md](docs/dq5-text-format.md), [dq5-data-format.md](docs/dq5-data-format.md), [dq5-graphics-format.md](docs/dq5-graphics-format.md).

- **소리**: `02`·`03`·`04` 를 부르는 실제 장면에서의 기록, `0D`·`0E`·`94`·`95`·`96`·`8B`·`93`·`09` 의 뜻(DSP 에 안 드러남, SPC 프로그램 읽기), 명령 `1A` 인자의 뜻, 天空城에서 내릴 때의 곡, 효과음·곡 번호의 이름.
- **이야기 플래그·이벤트 스크립트**: 「문맥」 사건 이름 실측(청년기는 6단계 확인, 신전·カボチ 남음), 켜는 곳이 없는 비트 8개, 번호를 바꿔 건 이벤트 4·5·6·7·9 와 `02:B705` 직접 호출들의 제 맵 연출, 명령 `C4`·`C5` 가 기다리는 것, 네이티브 `1E:DDFF`·`02:81DB`·`02:E463` 이 하는 일, パルプンテ `1D` 의 조건([docs/dq5-event-format.md](docs/dq5-event-format.md)).
- **조우의 남은 것**: 예외 표 플래그 가운데 코드가 켜는 것을 켜는 장면(`2190.6` 은 `02:9BC0` → `02:9C3D`, 본 루프 `00:8079` 가 `00:D227` 결과 2 일 때 부름. `21A8.1` 은 `05:FD08` 를 가리키는 `10:A070`, `2190.5` 는 `05:FDCB` 를 가리키는 `15:F549` 의 네이티브 호출), 필드 줄이 쓰이는 메뉴 밖 장면.
- **인물**: 주인공의 とびら 명령으로 23/00·18/00 문을 열 때 `7E:1E8E` 가 하는 일(`01:DAEF`), `01:ED05` 가 쓰이는 문.
- **맵별 루틴(`15:F907`)의 남은 것**: 매 프레임 루틴 중 01/00 의 슬롯 `11`·`10` 갈래, 31/07, 0A/00, 10/00 의 이벤트 갈래, 그룹 51 의 상태를 조건이 맞는 장면에서 실측, 14/xx 창 뒤의 `219F`·`21A5` bit7 과 조우(목록은 [dq5-map-format.md 「매 프레임 루틴 39개」](docs/dq5-map-format.md#매-프레임-루틴-39개)).
- **그래픽 내보내기의 남은 것**: 스태프 롤의 지운 줄 무늬와 줄 올리기(`FB`·`F7`·`F6`), 「THE END」 타일맵을 만드는 곳, 전투 창.
- **텍스트의 남은 것**: 네이티브 호출 「장면」 갈래를 부르는 인물·이벤트로 실행하기, 「호출」 갈래 루틴의 장면별 실행 기록, 창 머리 `+4` bit6-7·`+2` bit6-7 이 차이를 내는 창. 한글 넣기([dq5-hangul-format.md](docs/dq5-hangul-format.md)): 창(`04:B0F0`)의 2바이트 부호, 레코드를 복사하는 `7E:11A0`~ 가 비어 있는지.
- **SRAM 의 남은 것**: 모험의 서 칸 상태 바이트 `70:000F`~`0011` 의 비트 뜻(쓰는 칸 `C0`, `25:818B` 가 `40` 을 씀).
- **레벨업의 남은 것**: 레벨업 메시지에서 すばやさ·かしこさ·うんのよさ 가 빠지는 까닭, 사람 성장 레코드(`23:9E41`) 11개가 누구인지.
- **전투 계산식의 남은 것**: 일행이 맞을 때 갑옷의 주문 내성(`20:ABDC`·`27:80E3`·`27:80FC`), 일행 피하기(필드 `3D`) 실측, つうこん 상태 비트 `42` 를 켜는 곳.
