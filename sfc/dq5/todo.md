# dq5 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

SFC DQ5 엔진 분석. 시작점은 [handoff.md](handoff.md). 결과 문서: [dq5-map-format.md](docs/dq5-map-format.md), [dq5-field-format.md](docs/dq5-field-format.md), [dq5-text-format.md](docs/dq5-text-format.md), [dq5-data-format.md](docs/dq5-data-format.md), [dq5-graphics-format.md](docs/dq5-graphics-format.md).

- **상점의 남은 것**: 교회의 죽음·독·저주 상태 비트(필드 `3E` 등), 맡기는 곳 한도, 슬라임 레이스 倍率 식(`11:DF49`)과 다섯 값(`7E:12AD`)을 정하는 곳.
- **전투**: 전투 메시지 코드 중 화면으로 보지 않은 것(`F2`·`F9`·`E2`·`E4`·`EA`·`FA`), 글자표에 없는 몇 바이트(`ズ`·`ゾ`·`ダ` 로 찍히는 것). 배경의 남은 것: 실제 게임에서 배를 탈 때 `$1954` 가 `03`(걸음마다 `$1AA0` = `00`)·`80`(쓰지 않음) 중 어느 것인지, 바다 전투 화면.
- **이야기 플래그·이벤트 스크립트**: 「문맥」 사건 이름 실측(청년기는 6단계 확인, 신전·カボチ 남음), 켜는 곳이 없는 비트 30개, 번호 표 스크립트 중 부르는 곳을 못 찾은 30개, 이벤트 0·2~7·9 와 `02:B705` 직접 호출 13곳을 제 장면에서 걸기, 명령 `C2` 가 넘어가는 조건과 `C4`·`C5`·`91` 의 화면 효과, パルプンテ `1D` 의 조건.
- **조우의 남은 것**: パルプンテ 효과 32개(`20:E2B9`)의 나머지. 예외 표(`1F:F921`·`1F:FA3C`)의 이야기 플래그가 무슨 사건인지는 이야기 플래그 목록과 함께.
- **인물**: 인라인 스크립트 명령 중 처리 루틴만 읽은 것(`20`, `41`·`43` 의 넷째 바이트, `0B`·`0D`·`0F`·`12`·`1A`~`1F`·`22`·`23`·`27`·`2A`·`2C`~`2E`·`34`~`36`·`38`~`3A`·`3F`·`40`·`47`) 실측. 인물 표 `32A0` bit0·bit6, `33A0` `09` 이 화면에서 바꾸는 것.
- **맵별 루틴(`15:F907`)의 남은 것**: 매 프레임 루틴(`$1AA6`) 중 `03:D4B5`(타일 애니메이션)·`02:AE55`(버튼 → `21A1` bit0) 밖의 것.
- **필드의 남은 것**: `04:FE83` 의 `16`·`1E` 그룹을 나오는 길(그 밖의 필드 항목은 끝).
- **이벤트 스크립트의 남은 것**(dq5-enc2 세션이 이어 맡음): 이벤트 0~7·9 와 `02:B705` 를 직접 부르는 14곳의 장면 실측, 명령 `C4`~`C9`·`91` 이 부르는 루틴. 형식은 [docs/dq5-event-format.md](docs/dq5-event-format.md).
- **그래픽 내보내기의 남은 것**: 맵에 들어갈 때 `7E:21C2`~ 의 문 플래그 일부를 지우는 곳. 엔딩·스태프 롤 화면(타이틀 글자 `1E:D7E3` 을 쓰는지, 문자열 표 `02:FE12` 근처), 창 레코드 머리 `+4` 가 0 이 아닌 창(상태 창 등)과 자리 표시(`B0`~) 그리기, 반탁점의 테두리 칸 타일.
- **셀 비트**: 셀 `+1` bit6 이 겹친 인물의 앞뒤를 정하는 규칙, bit6 만 켜진 칸(18/00 (10,22)~)에서 지우면 상태 창·화면 색이 달라지는 까닭.
- **보물상자의 남은 것**: `D005` 의 빨간 빛 갈래 플래그, 두 칸 앞 표(`1E:F435`)를 실제 맵에서 열기.
- **텍스트의 남은 것**: 네이티브 호출 갈래별 대상의 실측(갈래는 코드 읽기), `05:862F` 목록 그림의 정체, `+4` 가 0 이 아닌 창의 머리, 상태 창 `D1`·`12`, `7E:3000` 의 단위. 한글 넣기([dq5-hangul-format.md](docs/dq5-hangul-format.md)): 전투 메시지 글자를 그리는 루틴, 창 글자 타일(BG3)을 올리는 곳과 남는 타일 수, 2바이트 부호를 넣을 때 창 너비·이름 길이, 늘린 롬의 SRAM 저장·불러오기.
- **인물 스프라이트의 남은 것**: 탈것 부분을 슬롯 좌표대로 한 장으로 합치기, 맵 OBJ 타일(`1F:D59A`)의 배치. 덤프에 안 나온 세트 20개(밤 목록은 `$075E` 고정, 이벤트 인물은 플래그, 17/01). 일행 표 사람 1·2 번(그림 `90`·`91`)의 이름과 주인공 그림 `3A` 를 고르는 플래그 실측, 인물 역할 이름(へいし 등).
