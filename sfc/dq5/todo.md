# dq5 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

SFC DQ5 엔진 분석. 시작점은 [handoff.md](handoff.md). 결과 문서: [dq5-map-format.md](docs/dq5-map-format.md), [dq5-field-format.md](docs/dq5-field-format.md), [dq5-text-format.md](docs/dq5-text-format.md), [dq5-data-format.md](docs/dq5-data-format.md), [dq5-graphics-format.md](docs/dq5-graphics-format.md).

- **상점의 남은 것**: 교회의 죽음·독·저주 상태 비트(필드 `3E` 등), 맡기는 곳 한도, 여관 값 bit7(`$198E` → `00:E360`)의 화면 차이(따라오는 동료가 있는 장면), 격투장 상금, 슬라임 레이스 倍率 식(`11:DF49`)과 다섯 값(`7E:12AD`)을 정하는 곳.
- **주문·몬스터 표의 남은 것(막힌 것만)**: 보통 독 비트와 キアリー(전투·필드에서 `+1` 의 남은 비트로 독이 안 드러남, 주문 칸 8 에 넣으면 멈춤), 「ー」 행동 `98`·`99`·`A0`·`A7` 와 がったいだ 를 몬스터가 쓸 때, 어른 일행 장면에서 `21:8014` 가 고르는 명령 창, `20:AEC6`·`AEFF` 에 넘기는 값, 피하기의 상태 조건 실측. 동료의 필드 A6 검사, `23:AED1 +8` bit4-7. 물건 표: k2 bit4 를 한 마리 실행 루틴 물건으로, k1 bit2·4·5·6·7, k3·k4, 장비 비트 `21:A632` 의 인물 번호 ↔ 동료.
- **전투**: 전투 모드 메시지(`24:8C39`). 배경의 남은 것: 배로 바다를 지날 때 배경 번호(`$1AA0`)를 정하는 곳(배로 가는 동안 걸음 처리 `00:82AB` → `01:84CF` 가 돌지 않음).
- **이야기 플래그**: 「문맥」 으로만 붙인 어린 시절 사건 이름을 게임으로 확인(진행한 세이브스테이트 필요), 청년기 사건 순서, 켜는 곳이 없는 비트 38개·시험하는 곳이 없는 비트 59개(상자 표 `1E:F435`·`1E:F4DF`, 찾지 못한 이벤트 스크립트), 이벤트 스크립트 명령 `C5`·`C8`·`C9` 길이.
- **조우의 남은 것**: `$1949` = 1·2 세계의 지도와 지형 대조, パルプンテ 효과 32개(`20:E2B9`)의 나머지. 예외 표(`1F:F921`·`1F:FA3C`)의 이야기 플래그가 무슨 사건인지는 이야기 플래그 목록과 함께.
- **인물**: 인라인 스크립트 명령 중 처리 루틴만 읽은 것(`05`·`20`·`41`·`43`·`4F`~`53` 등) 실측, 인물 표 `32A0`·`33A0` 의 나머지 비트를 쓰는 곳.
- **맵별 루틴(`15:F907`)의 남은 것**: 04/05 (4,66) 빈 곳 출구 셀과 짝이 되는 계단을 무엇이 만드는지(04/06 (4,5) 계단을 밟으면 04/05 빈 곳 (3,66) 에 섬. 01/05 는 파파스 스크립트가 놓음). 매 프레임 루틴(`$1AA6`) 각각이 하는 일(`02:AE55` 의 `21A1` bit0, `03:D4B5` 의 `7E:1ECE`).
- **필드의 남은 것**: `04:FE83` 실측, `24:A981` 이 석상 그림을 바꾸는 방법.
- **이벤트 스크립트의 남은 것**(dq5-enc2 세션이 이어 맡음): 이벤트 0~7·9 와 `02:B705` 를 직접 부르는 14곳의 장면 실측, 명령 `C4`~`C9`·`91` 이 부르는 루틴. 형식은 [docs/dq5-event-format.md](docs/dq5-event-format.md).
- **그래픽 내보내기의 남은 것**: 실내 맵 움직이는 타일(CHR 슬롯 `BE`~`C7`, `7E:2D00` 을 `03:D751` 이 고침)의 원본 타일과 맵마다 고르는 표, 움직이는 타일이 넘어가는 간격. 닫힌 문 등 맵 위 물체(`01:F3C9`·표 `01:D2FC`, 종류별 타일 워드와 슬롯 `001`~ 문 그림 원본, 열림 플래그 `7E:21C2`)를 dq5gfx 에 그리기. 35/03 보물상자를 지우는 곳.
- **그룹 `$50`~`$54` 맵**: `03:D3E9`·`04:8131` 의 슬롯 처리가 실내 맵에서 하는 일.
- **셀 비트**: 셀 `+0` bit3 을 막는 층 마스크 `08` 이 있는지, `+1` bit4-5·bit6 의 정확한 뜻(주인공 화면에는 드러나지 않음. 인물 이동·특수 바닥 맵에서 볼 것).
- **보물상자의 남은 것**: `D005` 의 빨간 빛 갈래 플래그, 두 칸 앞 표(`1E:F435`)를 실제 맵에서 열기.
- **텍스트의 남은 것**: 대화 번호 `000` 인물의 실제 대사, 네이티브 호출 142곳의 나머지. 창 레코드 머리 `+4`·`+5` 와 상태 창의 나머지 자리 바이트. 조건 `03` 인자 `47` 의 인물, 일행 레코드 `+1` bit6, `BRK 8C`. `1112`·`1114`·`1118` 의 모양 값. 한글 넣기: 다시 만든 트리 표·한글 그림(뱅크 `07`~`0A`)·옮긴 메시지를 둘 자리, 1바이트 부호(이름·창·전투)를 넓히는 방법([dq5-text-format.md 「한글 넣기 준비」](docs/dq5-text-format.md#한글-넣기-준비)).
- **인물 스프라이트의 남은 것**: 누운 인물 모양(`7E:31C0` bit0 → `1F:D39F` 전치·`1F:D0AC`·`1F:D1B3` 칸 표·`00:EC9B`·`00:F3CE`)을 `dq5sprite.py` 에 넣어 덤프와 맞추기, 일행 동료 몬스터의 그림 번호 표(`7E:196F + 순서`), 탈것·맵 OBJ 타일(`1F:D59A`)의 배치와 팔레트 3 을 고르는 곳(`01:9BDC` 등), 덤프에 안 나온 세트 87개 실측.
- **장면 이동 도구의 남은 것**: 마차가 있을 때 동료 셋 이상이 빈 그림이 되는 까닭, 무리 `00`·`29`·`30`~`3F` 를 쓰는 곳, 일행 레코드 `+26`~`+29` 의 뜻.
