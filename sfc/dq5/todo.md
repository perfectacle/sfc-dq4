# dq5 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

SFC DQ5 엔진 분석. 시작점은 [handoff.md](handoff.md). 결과 문서: [dq5-map-format.md](docs/dq5-map-format.md), [dq5-field-format.md](docs/dq5-field-format.md), [dq5-text-format.md](docs/dq5-text-format.md), [dq5-data-format.md](docs/dq5-data-format.md), [dq5-graphics-format.md](docs/dq5-graphics-format.md).

- **소리**: 곡 이름(사용자가 주면 들어 보기 페이지에 반영), 효과음 `3A`·`3C`·`42`·`43`·`45` 의 장면 실측(코드 읽기 자리는 [dq5-sound-format.md](docs/dq5-sound-format.md) 「효과음마다」), 즉값으로 부르는 곳이 없는 16갈래.
- **조우의 남은 것**: 22/00 ポワン 장면으로 `2199.3` 을 켠 뒤의 ルーラ(장면 끝 메시지 `25D` 창이 닫히지 않음, [dq5-data-format.md 「남은 것」](docs/dq5-data-format.md#남은-것)). 원래 순서의 ラインハット 01/04·01/00 에서 パパス 가 기다리는 `21A1.7` 을 켜는 곳([dq5-story.md 「남은 것」](docs/dq5-story.md#남은-것)).
- **일행 관리의 남은 것**: 새 모험의 서에서 주인공 이름을 넉 자 넣은 뒤 A 를 몇 번 눌러야 끝나는지 다시 재기(아기 이름과 `03:8C04` 는 おわり 를 한 번 더), `+29` bit0 이 켜진 몬스터가 나오는 장면(메시지 `0EE`), 사람 동료 칸 `7E:294A` 를 채우는 `21:A85C` 를 부르는 곳.
- **네이티브 호출의 남은 것**: `21AA.7` 을 켜는 03/07 장면(인물 스크립트 `05:9653`+30)부터 03/05 소동·`FB41` 까지 이어 걷기, `F792` 의 `BRK 8A 48`·`8A E9` 와 `21:A8C0` 이 일행에 넣는 레코드 내용.
- **그래픽 내보내기의 남은 것**: 오프닝 타이틀 연출 전체를 롬만으로 그리기(별·반짝이·HDMA 표 계산은 `dq5titlefx.py`, 남은 것은 층 겹치기와 밝히기·V 내려오기 순서), 전투 연출 `3E` 루틴으로 롬만으로 움직임 그리기(배치 표와 열 읽기는 실측, OBJ 물체·HDMA 표 루틴 흉내와 マヒャド 난수가 남음)·불리지 않은 `3E` 21곳(필드 주문, 숨의 우리 편 갈래), `2F`(ミルドラース 둘째 모습)가 쓰러질 때 HDMA 채널 4(표 `00:0DB9`, 간접 뱅크 `27`)가 몇 프레임만 OBJ 팔레트 0 의 색 하나를 덮는 까닭.
- **텍스트의 남은 것**: 한글 넣기([dq5-hangul-format.md](docs/dq5-hangul-format.md)): 창 2바이트 부호를 여러 글자로(캔버스 빌리기 또는 BG3 타일 칸 넓히기, 두 길의 근거는 문서), 옮긴 레코드 자리 `7E:1ABC`~ 의 간접·DP 접근까지 증명, BG3 칸 넓히기(타일맵을 `1C00` 에 쓰는 나머지 곳 찾기·BG1·BG2 글자 빌리기).
- **카지노·숨은 물건의 남은 것**: 슬롯 난수 `11:BC26` 이 실제 놀이에서 고른지와 기대 수익(1 넘음)을 수천 판으로 확인([dq5-data-format.md](docs/dq5-data-format.md)), 그룹 `50` 이상 맵의 아래층 상자 칸 11개가 이벤트로 열리는지와 상자 찾기 `12:F849` 가 보는 칸([dq5-map-format.md](docs/dq5-map-format.md)).
