# dq5 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

SFC DQ5 엔진 분석. 시작점은 [handoff.md](handoff.md). 결과 문서: [dq5-map-format.md](docs/dq5-map-format.md), [dq5-field-format.md](docs/dq5-field-format.md), [dq5-text-format.md](docs/dq5-text-format.md), [dq5-data-format.md](docs/dq5-data-format.md), [dq5-graphics-format.md](docs/dq5-graphics-format.md).

- **포팅 도구 점검에서 확인한 우선 작업**([지원 범위와 근거](docs/dq5-port-tool-audit.md)): 없는 맵 번호·미지원 필드 거부는 [입력 보호](journal/2026-10-26-59-mapwrite-guard.md)로 해결. DQ4 타이틀/메뉴와 맵·인물·필드·대사·이벤트 기본 배치의 충돌을 해결할 영역 배치와 통합 빌드 마련.
- **월드·진행 작성 경로**: 실내 출구·영역 이동 증설·재배치, 인물 레코드·등장 조건·대화 번호, 별도 대화 VM 분기, 맵 후처리·플래그 연결. 장별 시작/끝·파티 승계·탈것·패배 후 진행·저장 재개는 엔진/시나리오 작업으로 구분.
- **전투·그림·한글 작성 경로**: 주문 목록 증설·재배치·효과 연결·AI 표와 초기 파티 데이터, 범용 스프라이트·맵 그림·몬스터·전투 배경 작성, 게임 안 한글 코드북·명칭·전투 메시지·창. 기존 타이틀·서곡·메뉴·이름 입력·음악/효과음/BRR 도구는 재사용.
- **소리**: 곡 이름(사용자가 주면 들어 보기 페이지에 반영).
- **일행 관리의 남은 것**: 석상 장면 뒤 02/06 에서 オジロン 이 부르는 장면(석상 세이브스테이트가 `dq5warp.lua` 로 만든 것이라 플래그가 모자라 02/06 이 처음 왔을 때의 기본 목록 `10:9A2F` 로 열림), フローラ 갈래의 ヴェール·교회 단계(1F/08 의 문만 실측)([dq5-data-format.md 「사람 동료 칸」](docs/dq5-data-format.md#사람-동료-칸-7e294a) 실측 6·7, [일지 2026-10-26-51](journal/2026-10-26-51-party6.md)).
- **그래픽 내보내기의 남은 것**: 전투 연출을 입구 상태 없이 롬만으로 그리기(입구 상태와 입구 뒤 조이패드·소리 포트 값이 입력. 전투를 처음부터 세우기와 SPC700 흉내는 하지 않음). 해결됨: `0C`·`6F` 의 처리 도중 NMI — `dq5clock.Cpu` 로 명령마다 주기 0 차이, 139벌 모두 BG3 사본·연출 층·VRAM·CGRAM·OAM 같음([dq5-graphics-format.md](docs/dq5-graphics-format.md#롬-코드로-돌리기-dq5fxvmpy)). 해결됨: `DDDC` 를 부르는 장면 — 우리 편이 ぶきみなひかり·まぶしいひかり·いてつくはどう 를 몬스터에게 쓸 때.
- **텍스트의 남은 것**: 한글 넣기([dq5-hangul-format.md](docs/dq5-hangul-format.md)): 창 2바이트 부호를 여러 글자로(캔버스 빌리기 또는 BG3 타일 칸 넓히기, 두 길의 근거는 문서, 고르기는 사람 몫), 옮긴 레코드 자리 `7E:1ABC`~ 의 정적 후보 중 코드 뱅크 미실행 6,659곳(직접 피연산자는 CDL 로 걸러 569곳 미확인), BG3 타일맵 자리: 모든 장면에서 비는 칸이 없어(실내 맵 21개가 `7800`, 필드·전투가 `4800`~) 장면마다 자리를 바꾸는 길의 실측, `21BF.5` 를 켜는 곳.
- **에셋 다시 뽑기의 남은 것**([일지 2026-10-26-34](journal/2026-10-26-34-repro.md)): Windows·Linux 판 MesenCE 에서도 `dq5assets.py` 결과가 바이트까지 같은지.
- **쓰기 도구(포팅용)**: 몬스터·물건·주문·피해량·동료 표는 `dq5tables.py`. 실내 맵은 `dq5mapwrite.py`. 배치 목록 컴파일은 `dq5mapcompile.py`, 필드 지도는 `dq5fieldwrite.py`(뱅크30~3F), 필드 블록·입구·도착 고정 표는 `dq5fieldtables.py`이며 세계0~2 지도 쓰기도 게임에서 확인. 이벤트·인물 스크립트는 `dq5eventwrite.py`·`dq5npcwrite.py`(인물은 기존 슬롯 안에서 교체). 성장·조우 구역·상점 고정 목록은 `dq5progresswrite.py`이며 레벨업·조우·상점과 물건 가격 쓰기를 게임에서 확인. 보행 대사 코드 목록은 `dq5textwrite.py`로 일괄 재압축하며 앞·뒤 메시지를 게임에서 확인. 인물 스크립트 길이 변경과 목록 재배치는 `dq5npcrelocate.py`로 694쌍·긴 스크립트 실행 5건을 게임에서 확인. 남은 것: 필드 표 항목 증설·재배치, 인물 수·순서·조건 편집과 새 목록 추가, 문자열 번역 편집·새 한글 글꼴 대량 삽입·전투 메시지/창/이름 쓰기, 성장·조우 레코드와 상점 품목 수 증설, 필드 조우 격자·실내 구역 연결·고정 무리·전투 이벤트 무리 쓰기. `dq5tables.py`는 물건 가격·힘·장비사람·칸, 전투 주문 MP·대상루틴, 피해량, 동료 레벨·HP·MP 쓰기를 게임에서 확인(`dq5tablecheck.py`). 나머지 물건 플래그·주문 범위·적쪽·동료 최대레벨·장비갈래의 수정 롬 실측은 남음.

- **실내 출구·영역 이동 쓰기 후속**: `dq5exitwrite.py`로 기존 출구 569개·영역 이동 430개의 목적지·사각형·층을 편집하고, 출구 세 종류·출발층·고층 공유 목록·음수 가장자리·사각형 이동을 게임에서 밟아 확인했습니다([일지](journal/2026-10-27-03-exitwrite.md)). 플래그 bit6 은 이동 효과음이고 01/0A·2A/00 출구는 셀 속성 `33` 이 막음(오른쪽 칸을 `85` 로 바꾸면 열림)을 확인했습니다([일지](journal/2026-10-27-05-exit-flags.md)). 증설·재배치·종류 변경은 남았습니다.
- **주문 습득 쓰기 후속**: `dq5learnwrite.py`로 53종의 기존 습득 항목과 필드/전투 목록을 편집하고, 레벨업 습득·필드·전투 사용을 게임에서 확인했습니다. 항목·목록 증설과 재배치, 레벨 1 습득 항목의 초기 합류 처리 실측은 남았습니다.
- **보물상자·조사 보상 쓰기 후속**: `dq5chestwrite.py`로 고정 표 376항목을 편집하고 상자·서랍·옮긴 발밑 보상 3쌍을 게임에서 확인했습니다. 항목 증설·재배치, 맵의 상자/가구 배치와 보상 표의 통합 편집, 두 칸 앞·아래층 상자 변경 실측, 필드의 코드에 고정된 조사 보상 쓰기는 남았습니다.
