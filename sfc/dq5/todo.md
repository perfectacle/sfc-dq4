# dq5 남은 일

아직 확인하지 못한 것과 다음에 할 일입니다. 위에 있을수록 먼저 합니다. 끝낸 항목은 지우고 결과는 형식 문서와 해킹 일지에 남깁니다. 트랙과 고치는 법은 [tracks](../../.agents/skills/tracks/SKILL.md) 를 봅니다.

SFC DQ5 엔진 분석. 시작점은 [handoff.md](handoff.md). 결과 문서: [dq5-map-format.md](docs/dq5-map-format.md), [dq5-field-format.md](docs/dq5-field-format.md), [dq5-text-format.md](docs/dq5-text-format.md), [dq5-data-format.md](docs/dq5-data-format.md), [dq5-graphics-format.md](docs/dq5-graphics-format.md).

- **통합 포팅 빌드의 남은 것**([통합 포팅 빌드](docs/dq5-build-format.md#통합-포팅-빌드-dq5portbuild1), [일지](journal/2026-10-27-26-portbuild.md)): 타이틀을 옮기지 않은 채 `30`~`3F` 의 빈 자리는 297,762바이트라, 맵 364개 전체(233,794바이트)·인물(44,240)·세 세계(39,269) 합계 317,303바이트는 맵을 여러 작업으로 나눠도 들어가지 않음. 그만큼 넣으려면 타이틀 자료를 상위 뱅크로 옮기는 DQ4 트랙 작업(아래 요청)이 필요. `jobs[].records`(인물 레코드)·`patch` 종류는 통합 롬에서 게임 실측하지 않음. 실제 SFC 기기, 새 게임 → 장 진행 → 저장·재개는 아직.
- **DQ4 트랙에 요청할 것**(다른 트랙 파일이라 고치지 않음): ① `sfc/dq4/tools/dq4menupatch.py` 의 `BASE_SHA1` 이 이전 서곡 `ed46db6…` 이라, 현재 문서 절차로 만든 서곡 `ccfebeb…` 위에서 메뉴 빌드가 멈춤(통합 빌드는 값을 바꿔 불러 `e102f29…` 를 만듦). ② 타이틀·서곡·이름 입력 빌드가 쓴 구간을 목록으로 내면 통합 빌드의 거울 추정(다른 바이트 묶음 ±64바이트)을 없앨 수 있음. ③ 맵 전체를 함께 넣으려면 타이틀 에셋(현재 `31`~`39` 의 219,872바이트, 코드 4,096바이트 별도)를 상위 뱅크로 옮기는 재배치와 게임 검증.
- **월드·진행 작성 경로**: 실내 출구·영역 이동 증설·재배치, 인물 슬롯을 맵을 놓은 뒤 더 쓰는 장면의 맵별 정리(인물 필드·조건 항목은 `dq5npcrecord.py`, 인물 수·순서·새 목록·조건 표 증설은 `dq5npcrelocate.py`), 맵 후처리 표 163개 이상 증설(로더 DB 변경)과 `15:FF5C` 둘째 표 쓰기(기존 표 항목·플래그 조건·루틴 연결과 뱅크 15 안 재배치는 [`dq5maphook.py`](journal/2026-10-27-18-maphook.md)로 해결). 대화 스크립트 쓰기는 `dq5talkwrite.py`로 끝냄([일지](journal/2026-10-27-20-talkwrite.md)). 대화 쪽 남은 것: 원본에 없는 명령 `01`·`12`·조건 `16`·`1C` 실측, 스크립트 수 574 증설과 뱅크 06 밖 배치(실행기·네이티브 루틴이 데이터 뱅크 06 전제). 장별 시작/끝·파티 승계·탈것·패배 후 진행·저장 재개는 엔진/시나리오 작업으로 구분.
- **전투·그림·한글 작성 경로**: 주문 목록 증설·재배치·효과 연결·AI 표와 초기 파티 데이터, 범용 스프라이트·맵 그림·몬스터·전투 배경 작성, 게임 안 한글 코드북·명칭·전투 메시지·창. 기존 타이틀·서곡·메뉴·이름 입력·음악/효과음/BRR 도구는 재사용.
- **소리**: 곡 이름(사용자가 주면 들어 보기 페이지에 반영).
- **그래픽 내보내기의 남은 것**: 전투 연출을 입구 상태 없이 롬만으로 그리기(입구 상태와 입구 뒤 조이패드·소리 포트 값이 입력. 전투를 처음부터 세우기와 SPC700 흉내는 하지 않음). 해결됨: `0C`·`6F` 의 처리 도중 NMI — `dq5clock.Cpu` 로 명령마다 주기 0 차이, 139벌 모두 BG3 사본·연출 층·VRAM·CGRAM·OAM 같음([dq5-graphics-format.md](docs/dq5-graphics-format.md#롬-코드로-돌리기-dq5fxvmpy)). 해결됨: `DDDC` 를 부르는 장면 — 우리 편이 ぶきみなひかり·まぶしいひかり·いてつくはどう 를 몬스터에게 쓸 때.
- **텍스트의 남은 것**: 한글 넣기([dq5-hangul-format.md](docs/dq5-hangul-format.md)): 창 2바이트 부호를 여러 글자로(캔버스 빌리기 또는 BG3 타일 칸 넓히기, 두 길의 근거는 문서, 고르기는 사람 몫), 옮긴 레코드 자리 `7E:1ABC`~`1BB0`(끝 `1BB1` 은 17/01 항구 장면이 씀)의 정적 후보 중 CDL·자료 구조·리스팅으로 나누지 못한 값 모름(`TCD`·`PLD`·`MVN`·`MVP`) 446곳(명령 시작으로 읽히는 33곳 포함, [일지 2026-10-27-25](journal/2026-10-27-25-wramrefs3.md)), BG3 타일맵 자리: 모든 장면에서 비는 칸이 없어(실내 맵 21개가 `7800`, 필드·전투가 `4800`~) 장면마다 자리를 바꾸는 길의 실측, `21BF.5` 를 켜는 곳.
- **에셋 다시 뽑기의 남은 것**([일지 2026-10-26-34](journal/2026-10-26-34-repro.md)): Windows·Linux 판 MesenCE 에서도 `dq5assets.py` 결과가 바이트까지 같은지.
- **쓰기 도구(포팅용)**: 몬스터·물건·주문·피해량·동료 표는 `dq5tables.py`. 실내 맵은 `dq5mapwrite.py`. 배치 목록 컴파일은 `dq5mapcompile.py`, 필드 지도는 `dq5fieldwrite.py`(뱅크30~3F), 필드 블록·입구·도착 고정 표는 `dq5fieldtables.py`이며 세계0~2 지도 쓰기도 게임에서 확인. 이벤트·인물 스크립트는 `dq5eventwrite.py`·`dq5npcwrite.py`(인물은 기존 슬롯 안에서 교체). 성장·조우 구역·상점 고정 목록은 `dq5progresswrite.py`이며 레벨업·조우·상점과 물건 가격 쓰기를 게임에서 확인. 보행 대사 코드 목록은 `dq5textwrite.py`로 일괄 재압축하며 앞·뒤 메시지를 게임에서 확인. 전투 메시지는 `dq5battletextwrite.py`, 이름 문자열 표 아홉 개는 `dq5namewrite.py`(길이 변경·제자리·옮기기)이며 전투 버퍼·격자와 몬스터 이름을 게임에서 확인(`dq5battletextcheck.py`). 인물 스크립트 길이 변경과 목록 재배치는 `dq5npcrelocate.py`로 694쌍·긴 스크립트 실행 5건을 게임에서 확인. 인물 엔트리 필드·낮밤과 등장 조건 표 기존 항목은 `dq5npcrecord.py`로 쓰며 이동·대화 번호·그림·낮밤·대체 조건을 게임에서 확인. 인물 수·순서·새 대체 목록·조건 표 증설은 `dq5npcrelocate.py`로 쓰며 게임에서 확인. 남은 것: 필드 표 항목 증설·재배치, 문자열 번역 편집·새 한글 글꼴 대량 삽입·전투 창 쓰기·이름 표 항목 증설과 12바이트 넘는 이름, 성장·조우 레코드 증설. 필드 조우 격자·실내 구역 연결(그룹 00~35)·고정 무리·이벤트 전투 무리는 `dq5encounterwrite.py`이며 네 장면을 게임에서 확인(`dq5encountercheck.py`). 남은 질문: 그룹 50 이상 맵의 구역 연결 표 `23:FDD6` 은 코드 읽기만이라, 실제로 그 맵에서 `[BD]`+6바이트 항목을 읽는지 실측 필요. 배의 바다 구역 직사각형 `01:85D8` 의 [X0][X1][Y0][Y1] 경계가 닫힌 구간인지(경계 칸에서 구역이 바뀌는지) 미확인. 고정 무리 하위 4비트와 이벤트 무리 `+9`~`+C` 는 `$1009`~`$100C` 로 가는데, `$100A` 의 0·1·80 말고 값의 범위와 `$100C` 의 쓰임은 미확인. `dq5tables.py`는 가격·힘·장비사람·장비몬스터·칸, 물건 플래그(쓰면없어짐·사용메시지없음·필드대상창·팔수없음·가득창·적쪽·전투대상창·상점전투설명·저주·インパス 다섯), 주문 MP·범위·적쪽·대상루틴, 피해량, 동료 다섯 필드 쓰기를 게임에서 확인(`dq5tablecheck.py`). 물건 `k4하위`(뜻 모름)·`그룹무작위`(슬라임 셋 무리에서 여러 번 돌리거나 난수를 고정해 대상이 늘 같은지 견줄 것)는 남음. `k1b2` 는 정적 검색으로 읽는 길이 없음.

- **실내 출구·영역 이동 쓰기 후속**: `dq5exitwrite.py`로 기존 출구 569개·영역 이동 430개의 목적지·사각형·층을 편집하고, 출구 세 종류·출발층·고층 공유 목록·음수 가장자리·사각형 이동을 게임에서 밟아 확인했습니다([일지](journal/2026-10-27-03-exitwrite.md)). 플래그 bit6 은 이동 효과음이고 01/0A·2A/00 출구는 셀 속성 `33` 이 막음(오른쪽 칸을 `85` 로 바꾸면 열림)을 확인했습니다([일지](journal/2026-10-27-05-exit-flags.md)). 표 전체를 다시 써서 늘리고 옮기는 `dq5exitreloc.py` 로 출구·레코드 추가, 종류 변경, 새 색인 맵, 고층 목록 추가를 게임에서 확인했습니다([일지](journal/2026-10-27-24-exitreloc.md)). 새 맵 번호 연결, 고층 맵의 목록 나누기(`01:94B4` 고정), 통합 빌드의 새 뱅크 자리 정하기, 필드행 갈래(`2A:F52A`) DB 감사 실측이 남았습니다.
- **주문 습득 쓰기 후속**: `dq5learnwrite.py`로 53종의 기존 습득 항목과 필드/전투 목록을 편집하고, 레벨업 습득·필드·전투 사용을 게임에서 확인했습니다. 몬스터가 동료가 될 때 처음 레벨 항목을 배우는 것도 확인했습니다([일지](journal/2026-10-27-08-learnjoin.md)). 항목·목록 증설과 재배치, 사람이 일행에 들 때의 레벨 1 항목은 남았습니다.
- **보물상자·조사 보상 쓰기 후속**: 고정 표 376항목과 필드 조사 보상 값은 쓰고 6쌍을 게임에서 확인했습니다. 남은 것은 셋입니다. (1) 필드 조사의 칸·열림 플래그 변경: `12:E5F2` 와 같은 값을 `01:9FF9`~`A035`·`01:A055` 이하 빛 블록 코드가 따로 가지므로 함께 고쳐야 하고, `01:A02B`·`01:A055` 를 부르는 때를 먼저 확인해야 합니다. (2) 표 항목 증설·재배치와 일반 상자 수 증설: 표마다 시작 주소를 쓰는 명령·뱅크를 세고, 상자 비트 `7E:2210`~`2224` 뒤의 새 비트 자리를 정해야 합니다. (3) 맵의 상자/가구 배치와 보상 표의 통합 편집.
- **인물 목록 쓰기 후속**: 기존 엔트리 필드와 조건 표 항목은 `dq5npcrecord.py`([일지](journal/2026-10-27-14-npcrecord.md)), 인물 수·순서·새 대체 목록과 대체 표 옮기기·빈 맵 표 63항목까지는 `dq5npcrelocate.py`로 쓰고 02/06·01/01·21/00 10장면과 물체 있는 맵 33곳을 게임에서 확인했습니다([일지](journal/2026-10-27-19-npclists.md)). 남은 질문: 맵을 놓은 뒤 `7E:1983` 부터 슬롯을 더 쓰는 `04:FB1C`(부르는 곳 `02:AE7B`·`02:AFB8`·`02:AFE5`·`02:B0F3`·`05:E806`·`05:E852`·`06:D716`)·`01:BA95` 는 어느 맵·장면에서 몇 슬롯을 쓰는가. 슬롯 번호를 직접 쓰는 이벤트 코드(`02:AE7F` `LDX #$0C`, `02:AFBC` `LDX #$12` 등)는 어느 맵의 어느 인물을 가리키는가. 슬롯 `20` 이상이 실제로 다음 칸을 덮는가. 원본도 `1F` 까지 차는 19/02·03/05 에서 `01:BA95`(네 슬롯)가 도는 장면이 있는가, `--allow-growth` 한도를 `1F` − 4 로 낮춰야 하는가. 그 밖에 기타 bit4-7 의 뜻, 02/06 에 들어가면 잡히는 메시지 `1D1` 의 호출 위치.
- **이야기 진행의 남은 것**: 첫 필드 이벤트의 `21A1.x` 를 항구 → 필드 장면으로 실측(17/01 도착 장면 뒤 멈춤, [일지 2026-10-27-21](journal/2026-10-27-21-chest-leftovers.md)), `12:EF46` 의 창 갈래(사람 동료 일행 필요).
