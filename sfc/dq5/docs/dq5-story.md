# DQ5(SFC) 이야기 진행 지도

유년기부터 끝까지 이야기 사건을 순서대로 놓고, 사건마다 켜지는 플래그·그 사건을 거는 곳·그 플래그로 바뀌는 인물 목록과 맵 표를 한 표로 엮은 문서입니다. 사건 목록과 근거는 [tools/dq5story.py](../tools/dq5story.py) 에 있고, 「바뀌는 인물·맵」 칸은 같은 도구가 [dq5flags.py](../tools/dq5flags.py) 의 인물 목록 표(`12:839C`·`12:8449`)·맵별 루틴 표(`15:F907`)·맵 조건 표(`01:9A12`·`02:CAF6`)에서 그 비트를 보는 곳을 찾아 붙입니다. 플래그 자리와 출처는 [dq5-flags.md](dq5-flags.md), 이벤트 스크립트는 [dq5-event-format.md](dq5-event-format.md) 에 있습니다.

- [2026-10-25-159: 이야기 진행 지도](../journal/2026-10-25-159-story.md)

```sh
uv run --locked python sfc/dq5/tools/dq5story.py rom/dq5.sfc            # 아래 사건 순서표

```

## 단계

큰 단계는 `$1948`(이야기 단계)과 `7E:2190` 의 위 비트로 갈립니다([dq5-data-format.md](dq5-data-format.md)).

| 단계 | 바뀌는 것 | 근거 |
| --- | --- | --- |
| 유년기 | `$1948` = 0, `2190.6` 꺼짐 | |
| 청년기 전반 | `02:9C3D` 가 `2190.6` 을 켜고 `$1948` = 1(07/02, パパス 가 죽은 뒤) | 실측 |
| 청년기 후반 | `05:FDD7` 이 `2190.5` 를 켜고 `1E:DE8E` 가 `$1948` = 2(석상이 된 뒤 8년, 이벤트 번호 `3B` 끝) | 실측 |
| 끝 | `2190.7`(山奥の村 대화 `1AF` 의 「世界に　平和が もどってきた」 갈래, ルーラ·リレミト·낮밤 바꾸기를 막음) | 실측 |

`00:A72A` 는 `2190` 의 bit6·5·4 로 `$1948` 을 다시 정합니다(bit6 꺼짐 → 0, bit6 만 → 1, bit5 까지 → 2).
