# DQ5(SFC) 이벤트 스크립트 형식

이야기 장면에서 주인공을 입력 대신 움직이는 스크립트(이하 이벤트 스크립트)를 정리한 문서입니다. 찾아낸 과정은 [2026-10-25-47 일지](../journal/2026-10-25-47-event.md) 와 [2026-10-25-55 일지](../journal/2026-10-25-55-event2.md)·[2026-10-25-64 일지](../journal/2026-10-25-64-event3.md)·[2026-10-25-84 일지](../journal/2026-10-25-84-event4.md) 에 있습니다. 구현은 [tools/dq5event.py](../tools/dq5event.py).
인물이 스스로 움직이는 인라인 스크립트([dq5-map-format.md 「인라인 스크립트」](dq5-map-format.md#인라인-스크립트-01c800))와 대화 스크립트([dq5-text-format.md](dq5-text-format.md))와는 다른 바이트코드입니다.

## 시작 (`02:B705`, `23:E29A`)

`02:B705` 는 `$00`·`$01` = 목표 X·Y, `$02`~`$04` = 스크립트 주소를 받아 `7E:1A0D` 에 짧은 스크립트를 만듭니다.

```
7E:1A0D  [가로 방향][칸 수] [세로 방향][칸 수]   지금 자리($C1,$C2)에서 목표까지(캐리 플래그로 가로·세로 순서)
         C3 [스크립트 24비트]                    그 스크립트로 점프
$19B3~$19B5 = 00:1A0D, $19AE |= 80               주인공이 입력 대신 이 스크립트로 움직임
```

`23:E29A`(A = 이벤트 번호)는 `23:E2C2` 의 5바이트 항목 `[X][Y][스크립트 24비트]` 10개 중 하나를 `02:B705` 에 넘깁니다. `02:B705` 를 직접 부르는 곳도 14곳 더 있습니다.

| 이벤트 | 목표 | 스크립트 | 부르는 곳 |
| --- | --- | --- | --- |
| 0 | (18,82) | `15:F150` | `06:C928`(번호를 계산) |
| 1 | (51,53) | `15:F2F1` | `06:CCA0` |
| 2 | (42,25) | `15:F5F6` | `06:D817` |
| 3 | (40,19) | `15:F79E` | `06:D6FF` |
| 4 | (99,58) | `15:F7A3` | `05:E7DF` |
| 5 | (42,6) | `15:F580` | `1E:DDAA` |
| 6 | (32,51) | `15:F34B` | `06:C005` |
| 7 | (45,47) | `15:F369` | `06:CE38` |
| 8 | (26,15) | `15:F702` | `06:DB81`(52/50 석상, [dq5-field-format.md](dq5-field-format.md#순간이동-칸-00c99e-039b9c)) |
| 9 | (31,11) | `15:F70B` | `02:F6A6`(54/50 전투 뒤) |

`dq5flags.py` 는 아래 「시작 주소 모으기」의 98개 스크립트에서 플래그 명령(`10`·`20`·`B0`)을 모읍니다. 스크립트는 `15:F150`~`15:F7CF` 에 `FF` 로 끝나며 86개가 이어져 있고, 명령 길이로 읽어 모두 경계가 맞습니다(모르는 명령 0개). 일부는 `02:81D6`·`02:9720`·`25:88xx` 에 있습니다.

## 스크립트 번호 표 (`23:E325`, `23:E2F4`)

`23:E2F4`(A = 번호)는 `23:E325 + 번호*3` 의 24비트 주소를 바로 `$19B3`~`$19B5` 에 넣고 `$19AE` bit7 을 켭니다. 걷기를 앞에 붙이지 않는 것만 이벤트 표와 다릅니다.
번호는 `00`~`52` 의 83칸입니다. 롬에서 `LDA #n / JSL $23E2F4` 로 부르는 곳의 가장 큰 번호가 `52` 이고, 그 뒤는 코드입니다. `1A`·`1B`·`1C`·`3C` 는 `23:E41E`(코드)를 가리키는 빈 칸이고, `33`·`34` 와 `44`·`4A` 는 같은 스크립트입니다.

```
번호 41: 15:F60B  부르는 곳 06:B6A3
  15F60B a0 c7 8e 03          네이티브 호출 03:8EC7
  15F60F a0 e3 e4 1e          네이티브 호출 1E:E4E3
  15F613 60 42 04             메시지 442 「わが名は　マスタードラゴン。 世界のすべてを 統治する者なり……」
  15F616 10 25 10             플래그 켜기 7E:21B5 10
  15F619 ff                   끝
```

서로 다른 스크립트 77개 가운데 40개는 `LDA #n / JSL $23E2F4`(또는 `TDC / JSL`)로 부르는 곳이 나오고, 거의 모두 뱅크 06(대화 스크립트의 네이티브 호출 대상, `06:B3AD`~`C501`·`F646`~`FDEB`)입니다. 나머지 37개는 이 꼴로는 부르는 곳이 나오지 않습니다. 아래 「`02:B705` 를 직접 부르는 곳」과 받침 루틴·계산 호출을 더하면 16칸만 남고, 그 16칸은 롬에서 쓰지 않는 칸입니다.

## 시작 주소 모으기

`dq5event.py --starts` 는 시작 주소를 넷에서 모아 `C3` 을 따라갑니다.

| 길 | 개수 |
| --- | --- |
| 이벤트 표 `23:E2C2` | 10(9 번은 번호 `4B` 와 같은 스크립트) |
| 스크립트 번호 표 `23:E325` | 79(빈 칸 4 제외) |
| 코드 안의 `LDA # / STA $19B3`·`$19B4`·`$19B5` | 14(그중 하나는 `02:B705` 의 `7E:1A0D` 버퍼라 뺌) |
| `02:B705` 를 직접 부르는 곳의 `LDA # / STA $02`~`$04` | 13(아래) |
| `C3` 점프 | |

겹치는 것을 빼면 스크립트 98개, 명령 970개이고 모르는 명령은 없습니다. 아래 `02:B705` 직접 호출을 더하면 106개, 명령 1,039개입니다. 태어나는 장면(`15:F000`, `02:A988`), 첫 필드 이벤트(`15:EF40`, `02:A951`)는 코드에서 시작하는 것입니다. `--list` 는 스크립트마다 부르는 곳과 첫 메시지를 한 줄로 찍습니다.

## `02:B705` 를 직접 부르는 곳

이벤트 표를 거치지 않고 `$00`~`$04` 를 채워 `02:B705` 를 부르는 곳입니다. `dq5event.py` 가 `JSL $02B705` 앞의 `LDA # / STA $00`~`$04`(16비트 `LDA #` 포함)로 찾습니다. 목표가 비어 있으면 `$C1`·`$C2`(지금 자리)를 넘기는 것입니다.

| 부르는 곳 | 목표 | 스크립트 | 비고 |
| --- | --- | --- | --- |
| `02:81D1` | 지금 자리 | `02:81D6` | 2개 명령 |
| `02:944C`·`02:971B` | 지금 자리 | `02:9720` | 1개 |
| `02:A3D8` | X 60 | `25:889C` | 「どうやら　着いたようだな。」 |
| `02:E57B` | 지금 자리 | `15:F630` | |
| `02:F717` | (38,29) | `15:F713` | 번호 `4C` 와 같은 스크립트 |
| `02:F84F` | (17,26) | `15:F753` | |
| `05:F45E` | (18,17) | `15:F43B` | 번호 `2D` |
| `05:FAF0` | 지금 자리 | `15:F5C1` | 27개 명령 |
| `05:FC5C` | (40,11) | `15:F652` | |
| `06:B510` | (37,53) | `15:F701` | |
| `06:BD94` | (14,11) | `15:F0CB` | 번호 `01` |
| `25:FEB6` | (20,11) | `15:F360` | 번호 `17` |
| `1E:E86B` | 계산 | `1E:E8A5`·`E8AA` 근처 | 주소를 계산해 넘김(목록에 없음) |

이 길을 더하자 스크립트가 106개가 되었고, 번호 표에서 부르는 곳을 못 찾은 스크립트는 37개에서 30개로 줄었습니다. `25:889C`·`15:F652`·`15:F5C1` 을 `$19B3` 에 넣어 걸자 앞의 명령들이 디코더의 경계대로 실행되었습니다(`15:F652` 는 끝까지 14개).
롬에서 `JSL $23E2F4` 앞이 즉값이나 `TDC` 가 아닌 곳은 없고, 표 `23:E325` 를 다른 곳에서 읽는 코드도 없습니다.

`JSL $23E2F4 / RTL` 로 된 받침 루틴을 `LDA #n / JMP 받침` 으로 부르는 곳도 있습니다. `05:F116` 을 받침으로 번호 `2A`·`36`·`38`·`39`·`3A`·`3F`·`42`·`43` 을 부르고, `dq5event.py` 가 이 꼴도 찾습니다. 번호 `3F`(`15:F59A`)는 02/08 에 들어설 때 `05:FA95` → `05:F116` → `23:E2F4` 로 불렸습니다(`23:E2F4` 에 들어올 때 스택의 돌아갈 주소 `05:F119`, A = `3F`).
`05:F143` 은 A = `20` + (`0D` − 주인공 Y) 로 번호를 계산해 `05:F116` 에 넘깁니다. 번호 `20`~`25` 는 한 스크립트(`15:F38E`~)의 중간 시작점들이라, 주인공이 선 줄에 따라 걷는 길이가 달라집니다.

이렇게 해도 부르는 곳이 없는 것은 번호 `07`~`0B`·`14`·`1D`·`1E`·`2E`~`33`·`3E`·`4D` 의 16칸입니다. 그중 `1D`·`1E`·`2E`~`33` 은 `FF` 하나뿐인 빈 스크립트입니다. 롬 전체에서 `JSL $23E2F4`·받침 호출·`$19B3` 쓰기를 모두 보았으므로, 지금 롬에서는 쓰지 않는 칸으로 봅니다.

## 명령 (`00:BEC3`)

매 걸음 `00:BED2` 가 명령 하나를 읽습니다.

| 명령 | 길이 | 뜻 |
| --- | --- | --- |
| `00`~`0F` d n | 2 | 방향 d 로 n 칸. `01` 오른쪽, `02` 왼쪽, `04` 아래, `08` 위 |
| `10` i m | 3 | `7E:2190+i` 에 m 을 OR |
| `20` i m | 3 | `7E:2190+i` 를 m 과 AND |
| `B0` i m | 3 | `7E:2190+i & m` 이 켜질 때까지 기다림 |
| `60` lo hi | 3 | 메시지(`24:8157`) |
| `90` BC BD X Y 층 v | 7 | 맵 옮기기(`$198E` = v) |
| `A0` l h b | 4 | 네이티브 호출 |
| `C1` v | 2 | 바라보는 방향 `7E:31E0` = v(`C1 10` 을 걸자 `7E:31E0` 이 `44` → `10`) |
| `C2` | 1 | 한 걸음(8 프레임) 쉼. `C2 10 25 10 10 25 FF` 를 21/00 에서 걸자 656 프레임에 `C2`, 664 프레임에 다음 명령으로 넘어감(입력 없음·A·B·방향 모두 같음). 지난번 「넘어가지 않음」은 장면이 그 전에 끝난 것 |
| `C3` l h b | 4 | 스크립트 점프 |
| `C4` / `C5` x y c | 4 | 문 열기 / 닫기(인라인 명령 `41`·`43` 과 같은 루틴 `01:D915` / `01:F117`). 세 바이트를 `7E:1E8C`~`1E8E` 에 두고 `BRK 09 10`(16 프레임) 쉰 뒤 루틴을 부르고 `BRK 09 0F`(15 프레임) 쉽니다. 루틴은 지금 맵(`$BC`·`$BD`)의 문 표 `01:D2FC` 에서 (x,y) 를 찾아 그 문을 바꿉니다. 01/00 에서 `C4 1F 33 02` 를 걸자 성문 계단 위 아치 문이 열린 입구로 바뀌었고(666 → 713 프레임에 다음 명령), 이어 `C5 1F 33 02` 를 걸자 입구가 나무 문 모양으로 닫혔습니다(처음의 붉은 아치 문과는 그림이 다름). 02/00 의 `C4 1C 43 01` 도 성 문을 열었습니다. 찾는 루프(`01:DE9F`)에는 끝 검사가 없어, 표에 없는 (x,y) 면 그 자리에서 끝없이 돕니다(21/00 에서 `C4 1F 33 02` 를 걸었을 때 멈춘 까닭). `c` 는 인라인 `41`·`43` 의 넷째 바이트와 같이 `7E:1E8E` 로 가는 층 값입니다([dq5-map-format.md](dq5-map-format.md#인라인-스크립트-01c800) 의 `41`·`43` 줄). 문 표 종류가 `C4` 인 문(7곳)에서만 `01:ED05` 가 문 아래 칸 `+1` 에 `c` 를 OR 해 문을 연 뒤 그 칸의 층이 되고, `01:DAEF` 의 23/00·18/00 특례는 주인공 층 `$C3` 과 견줍니다. 01/00 성문(종류 `41`)에서 `01`·`02`·`04` 로 바꿔도 셀 버퍼 쓰기 116개가 같았던 것은 이 때문입니다 |
| `C6` / `C9` | 1 | `23:FE69`(`$1D8B` 로 소리 명령 `24:FEC7`) / `23:FE8F`(맵 곡 `$194B` 로 되돌리고 `7E:21DF` = 0) |
| `C7` v / `C8` v | 2 | 곡 v 를 틂(`24:FE91` 소리 명령 `1A` + `24:FE9A`) / v \| 80 을 `7E:21DF` 에 두고 틂. `C8 0C` 를 걸자 `24:FE91` 의 A 가 `8C`, `7E:21DF` = `8C` |
| `91` | 1 | `00:CC04` 뒤 `00:D267`·`23:FE69`. 21/00 (56,49) 에서 `C1 88 91 FF` 를 걸자 마을 밖 필드 (277,99) 로 나감(`C1 88 FF` 만 걸면 그대로). 맵을 떠나 필드로 나가는 명령으로 보임 |
| `FF` | 1 | 끝(`$19AE` bit7 을 끔) |

방향 값은 `02:B705` 가 만드는 걸음에서 정했습니다. 목표 X 가 작으면 `02`, 크면 `01`, 목표 Y 가 작으면 `08`, 크면 `04` 입니다.

## 실측

이벤트 8 을 걸었습니다(52/50 에서 `7E:21D8`~`21DA` 를 채우고 (24~29,13~15) 에 들어섬). 주인공은 (24,16) 에서 (24,15) 로 들어선 뒤 949·952·956 프레임에 X 가 24 → 25 → 26 으로 늘었고, 957 프레임에 스크립트의 `06:D0E0`, 961 프레임에 `03:A29B` 가 불린 뒤 1452 프레임에 30/00 에 섰습니다.
`7E:1A0D` 를 읽기 감시하니 `01 02 C3 02 F7 15`(오른쪽 2칸, `15:F702` 로 점프)였습니다.

스크립트를 직접 걸어서도 보았습니다. 21/00 에서 `$19B3`~`$19B5` 에 시작 주소, `$19AE` 에 `80` 을 넣고(`dq5warptrace.lua` 의 `LATE`), 명령을 읽는 `00:BED2` 에서 `$80` 을 기록했습니다.

| --- | --- | --- |
| 번호 41 | `F60B F60F F613 F616 F619` | `21B5=10`(`00:BFB3`) |
| 이벤트 1 | `F2F1 F2F4 F2F6 F2F8`(여기서 `21A2.6` 을 기다림) | `21A4=80` |

| 번호 10 | `F2A6 F2AA`(`21A1.6` 을 기다림) | |
| `15:F763` | `F763 F764 F768 F76A F76C F76E`(`91` 이 1바이트) | |

다섯 모두 `dq5event.py` 가 푼 명령 경계와 같았습니다.

롬의 스크립트 106개에 `C7`·`C8`·`C9` 는 나오지 않고, `C6` 은 번호 `13` 에 한 번, `C4` 는 7번, `91` 은 11번 나옵니다. `C7`·`C8`·`C9` 는 `7E:1A0D` 에 직접 써 넣어 확인했습니다.

## 제 장면에서 걸기

이벤트를 거는 것은 대부분 인물 인라인 스크립트의 네이티브 호출(`37`)입니다. 인물이 플래그를 기다리거나(`09`) 주인공이 범위에 들어오기를 기다린 뒤(`08`), 이벤트 번호를 넣고 `23:E29A` 나 `02:B705` 를 부르는 루틴을 부릅니다.
그 인물의 맵에 `dq5warp.lua` 의 `TO` 로 가고, 인물 목록 조건 플래그는 `SET`, 인물이 기다리는 플래그는 도착 뒤 `LATE` 로 넣어 걸었습니다. 명령 읽기 `00:BED2` 의 `$80` 으로 실행된 스크립트를 보았습니다.

| 이벤트 | 거는 인물 | 넣은 것 | 결과 |
| --- | --- | --- | --- |
| 0 | 21/00 대체 목록(`219A.4`) | `SET 219A\|10`, `LATE 21A1=80` | `23:E29A` A = 0, `7E:1A0D` 걷기 뒤 `15:F150` 실행 |
| 1 | 17/01 대체 목록(`2192.7`) | `SET 2192\|80`, `LATE 21A1=80` | A = 1, `15:F2F1`~`F301` |
