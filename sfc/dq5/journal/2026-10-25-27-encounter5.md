# 2026-10-25-27: 조우의 남은 것 4

조우 주제의 마지막 두 가지를 풀었습니다. 하나는 ルーラ·リレミト·낮밤 바꾸기를 그룹별로 막는 예외 루틴 `1F:F921`·`1F:FA3C` 이고, 다른 하나는 にげる 를 바로 성공시키는 `$1018` 입니다. 결과는 [dq5-data-format.md 「전투 조우」](../docs/dq5-data-format.md#전투-조우-23e7c2) 의 예외 표와 にげる 항목에 있습니다.

## 1. 예외 루틴 풀기

두 루틴은 `$BC` 를 차례로 비교하고 `BRK 0B mask idx`(`7E:2190 + idx & mask`)로 이야기 플래그를 시험합니다. 끝은 셋 중 하나입니다. `1F:FA38` 은 결과 `$1E99` 를 2(막음)로, `1F:FA2E` 는 0(허용)으로 바꾸고, `RTS` 면 맵 항목 `+4` 로 정한 결과를 그대로 둡니다.
`BRK 0B` 가 4바이트라 툴킷 디스어셈블러로는 줄이 어긋납니다. 그래서 이 루틴에 나오는 명령만 아는 작은 디스어셈블러를 `work/` 에 만들어 읽었습니다.

```
1F:F975  CMP #$01
1F:F979  BRK 0B mask=80 idx=43  ; 7E:21D3 & 80
1F:F97D  BEQ F95D                ; 꺼져 있으면 → 2190 & 40 이 꺼져 있을 때 막음
1F:F97F  BRK 0B mask=20 idx=42  ; 7E:21D2 & 20
1F:F983  BNE F974                ; 켜져 있으면 그대로
1F:F985  BRL FA38                ; 막음
```

그룹 01·02·04·06·1A·1F·21·22·23·29·35(ルーラ·낮밤)와 07·0F·10/02·35·06·01/0A·51/53(リレミト)이 있었습니다. `7E:2190` bit7 은 둘 다에서 어디서나 막습니다.

## 2. 플래그를 바꿔 확인

[2026-10-25-24](2026-10-25-24-encounter4.md) 에서 01/04 의 やみのランプ 가 실패한 까닭이 위 그룹 01 갈래입니다(`21D3.7`·`2190.6` 모두 꺼짐).

| 넣은 값 | 결과 |
| --- | --- |
| 없음 | 「何も おこらなかった」 |
| `7E:21D3` = `80`, `21D2` = `20` | 밤이 되고 01/0C (30,41) 에 섬 |
| `7E:21D3` = `80`, `21D2` = `00` | 「何も おこらなかった」 |
| `7E:2190` = `8A` 에서 필드 ルーラ·21/02 リレミト | 결과 2 |

01/0C 는 그룹 01 의 들어가는 곳 01/00 (32,92) 이 아닙니다. `2A:F363` 뒤의 `2A:F28D` 가 밤의 그룹 01 을 01/0C (30,41) 로 바꿉니다. 같은 루틴이 21(`2190.6` 켜짐·bit7 꺼짐 → 21/05)과 28(`$B6` = `40` → 28/02)도 따로 다룹니다.

## 3. `$1018`

`$1018` 을 쓰는 곳은 `20:8D8E`(bit0-1 을 턴마다 하나 줄임), `20:8DCF`(bit2-3), `20:E9C2`(bit0-1 = 3), `20:EDA3`(bit4), `20:9BFD`(bit5) 입니다.
몬스터 행동 `01`~`AA` 를 하나씩 슬라임 행동 6칸에 넣고 `7E:1017`~`1018` 쓰기를 보았습니다. 값이 바뀐 것은 モシャス(`25`, bit5)뿐이었습니다. bit0-4 를 켜는 두 곳은 무리별 전투 사건 루틴(`20:E197` 이 부르는 쪽)과 같은 `20:E000`~`EF00` 구역에 있어, 사건 전투가 켜는 것으로 보입니다.

효과는 직접 넣어 보았습니다. [2026-10-25-24](2026-10-25-24-encounter4.md) 의 무작위 전투(기다림 10, 두 번 실패하던 난수)에서 `POKE` 로 값을 고정했습니다.

```
고정 안 함   c r NG  c r NG
1018=01      c OK               ← 난수 판정(r = 20:9644) 없이 성공
1018=10      c OK
1018=04      (にげる 창까지 가지 않음)
```

## 남은 것

- `$1018` bit0-4 를 켜는 무리별 사건과 bit2-3 의 효과 — 해결됨: `$1018` 은 パルプンテ 효과 카운터([dq5-data-format.md](../docs/dq5-data-format.md) 「전투 조우」 의 にげる)
- 예외 표의 이야기 플래그가 각각 무슨 사건인지(이야기 플래그 목록에서 함께 봄) — 해결됨: [dq5-data-format.md](../docs/dq5-data-format.md) 「낮밤·ルーラ·リレミト」 의 켜는 곳 표
