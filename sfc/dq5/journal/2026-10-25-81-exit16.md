# 2026-10-25-81: 16·1E 를 나가는 길과 셀 +1 bit6 재현

필드 항목의 마지막인 16·1E 그룹을 나가는 길을 찾고, 지난 일지에서 셀 `+1` bit6 을 지웠을 때 나온 상태 창·화면 색 차이를 다시 돌려 보았습니다. 필드 항목은 이로써 닫습니다.
결과는 [dq5-field-format.md](../docs/dq5-field-format.md) 의 「마을 입장」(`04:FE83`)과 [dq5-map-format.md](../docs/dq5-map-format.md) 의 「셀 버퍼」에 있습니다.

## 1. 16 그룹

출구 목적지 표를 보니 16/00 의 넷째 출구가 특수 항목(`2A:F7B2`)이었고, 그 셀은 (103,61) 이었습니다. `2A:F7B2` 는 `2A:F80A` 뒤 `2A:F425`(필드로)를 부릅니다. (102,63)·(104,61)·(100,61)·(102,59) 에서 그 칸 쪽으로 걷자 모두 세계 2 필드 (63,37) 에 섰습니다. `04:FE83` 의 16 항목 (63,36) 에 1 을 더한 자리입니다.

## 2. 1E 그룹

1E/00~02 도 특수 항목이 하나씩 있지만, 맵을 푼 뒤(`15:F7EE`)의 셀 버퍼에 출구 속성 셀이 하나도 없었습니다. 맵별 루틴 `23:E5FE` 도 출구를 만들지 않습니다. 대신 영역 이동이 동굴로 이어집니다.

```
1E/00 (8,45) 위로        → 0D/03 (36,75)
1E/00 (110,27) 층 2 오른쪽 → 0A/0B → 이어 걸어 필드 (403,399)
```

## 3. リレミト

リレミト 로 나가면 `04:FE83` 을 쓸 것이라 보고 16/00 에서 외웠더니 (0,1) 바다에 섰습니다. `11:80FC` 를 읽으니 들어갈 때 남긴 필드 자리 `$0B50`·`$0B52` 를 쓰고, 그룹 16 은 Y 에 1 을 더할 뿐이었습니다. 장면 이동 도구로 바로 들어가 그 자리가 비어 있었던 것입니다.

## 4. 셀 `+1` bit6 다시 돌리기

18/00 (10,29) 에서 위로 걷는 실험을 시작 대기 0·7·15프레임으로 바꿔 지운 쪽과 지우지 않은 쪽을 2프레임마다 비교했습니다. 상태 창·화면 색 차이는 세 번 모두 나오지 않았고, 두 쪽 모두 `00:8090` 이 265번(빠진 프레임 13) 불려 처리 시간 차이도 없었습니다.
남은 차이는 440프레임부터 같은 방의 병사 둘과 주인공 그림 일부(다리 쪽)였습니다. 지난번의 상태 창 차이는 다시 나오지 않는 일회성으로 보았습니다.

## 틀렸던 것들

- 16·1E 를 「도착 자리에서 걸어서 나가지지 않는다」고만 적었습니다. 16 은 특수 출구 칸, 1E 는 동굴로 가는 영역 이동이었습니다.
- リレミト 가 `04:FE83` 을 쓴다고 보았습니다. 들어갈 때 남긴 자리를 씁니다.

## 남은 것

- `04:FE83` 의 1E 항목을 쓰는 길 — 해결됨: ルーラ 행선지로만 쓰임([dq5-field-format.md](../docs/dq5-field-format.md) 「`04:FE83`」)
- 셀 `+1` bit6 이 그림 우선순위를 정하는 정확한 규칙 — 해결됨: 층 2·4 인물이 조건 맞는 칸에 서면 bit6 이 OBJ 우선순위를 3 으로 올리는 갈래를 건너뜀, 18/00 에서 OAM 속성 `20` ↔ `30` 실측([dq5-map-format.md](../docs/dq5-map-format.md) 「셀 버퍼」 의 `+1` bit6)
