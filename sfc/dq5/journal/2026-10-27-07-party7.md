# 2026-10-27-07: オジロン 이 부르는 장면과 フローラ 의 ヴェール·교회

[일지 2026-10-26-51](2026-10-26-51-party6.md)의 남은 것 둘을 실측했습니다. 석상 뒤 02/06 이 엉뚱한 목록으로 열린 것은 세이브스테이트에 `21AD.4` 가 빠져서였고, 이 비트를 켜자 オジロン 이 「暗黒の魔界に ゆかれる おつもりか？」 를 묻는 장면이 나왔습니다. フローラ 갈래는 ヴェール 를 받아 교회에서 식을 올리고 일행에 들어오기까지 걸었습니다. 결과는 [dq5-data-format.md 「사람 동료 칸」](../docs/dq5-data-format.md#사람-동료-칸-7e294a)의 실측 9·10 에 있습니다.

## 1. 02/06 의 목록 순서

`dq5npc.py rom/dq5.sfc 02 06` 이 찍는 덮어쓰기 줄은 이 순서입니다.

```text
override: flag 00 mask 80 -> 109B81   2190.7
override: flag 1D mask 10 -> 109B57   21AD.4
override: flag 00 mask 20 -> 109A2F   2190.5
…
```

앞 일지에서 열린 `10:9A2F` 는 `2190.5`(석상 뒤 8년) 줄입니다. 그보다 앞에 `21AD.4` 줄이 있는데, 이 비트는 석상이 되는 이벤트 `3B` 가 기다리는 플래그라 실제 게임에서는 이미 켜져 있습니다. 석상 세이브스테이트를 `dq5warp.lua` 의 `SET` 으로 만들 때 이 비트를 넣지 않았던 것입니다. `10:9B57` 의 (36,11) 인물이 대화 `10F` 이고, `dq5talk.py` 로 읽으면 オジロン 의 말입니다.

```text
10F  if 21B7.5            ← 석상 장면이 켜는 「아내가 돌아옴」
       B4D·B4E·B4F, はい → B51, いいえ → B50
     else  ABC·ABD(석상에서 깬 직후, マーサ 의 고향 발견)
```

## 2. オジロン 에게 말 걸기

앞 일지가 남긴 02/07 세이브스테이트(병사의 `57F` 를 넘긴 뒤)에서 `21AD` bit4 만 켜고 02/06 으로 옮겼습니다. 같은 그룹 안이라 플래그는 남습니다.

```sh
STATE=$PWD/work/state/dq5-wife-0207.mss TO=02/06,36,13 SET="21AD|10" SAVE=oji0206.mss SETTLE=60 \
  SHOT_DIR=$PWD/work/p1 "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5warp.lua"
STATE=$PWD/work/p1/oji0206.mss PRE="up:12,wait:30,a:4,wait:90,…" CALLS=248BAF MAXF=1350 \
  SHOT_DIR=$PWD/work/p2 "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5msg.lua"
```

(36,14) 에 서자 바로 위가 옥좌의 オジロン 이었습니다. 메시지 루틴 `24:8BAF` 에 들어온 번호입니다.

```text
152 B4D  オジロン「おお ああああ王！
240 B4E  オジロン「親子水いらずの所を お呼びたてして 本当に 申しわけないのじゃが……
334 B4F  オジロン「…暗黒の魔界に ゆかれる おつもりか？
616 B51  (はい) オジロン「それは なりませぬぞ！…
652 B50  (いいえ, 창에서 아래를 누름) オジロン「それを間いて 安心した。…
```

이 세이브스테이트는 원래 체크아웃의 `work/state/dq5-oji-0206.mss` 로 두었습니다.

## 3. フローラ 를 고르기 전에 칸 0 을 만들기

앞 일지들은 칸 0 의 ビアンカ 를 ルイーダ 에서 본 칸 꼴로 손으로 만들어 썼습니다. 이번에는 게임의 루틴으로 만들었습니다. `06:FD21`(ピピン)은 `LDA #$06 / JSL $218923 / RTS` 이므로, 선실 세이브스테이트의 `7E:1A40` 에 같은 꼴(`08 E2 30 A9 03 22 23 89 21 28 6B`)을 써 넣고 이벤트 버퍼 `7E:1A0D` 에 네이티브 호출 `A0 40 1A 7E FF` 를 두어 `$19B3` 이 가리키게 했습니다. 5프레임에 `21:8923` 이 A = `03` 으로 돌았고, 칸 0 이 실측 3 에 적힌 칸과 32바이트 모두 같았습니다.

처음에는 이 칸 없이 フローラ 를 골랐습니다. 2,054프레임에 `21:A8C0` 이 `201D` 를 2 로 쓰고 그대로 남아, 빈 레코드 하나를 데리고 다녔습니다. 칸을 두고 고르면 같은 프레임에 `21:AA63`·`21:A89F`(1 → 2)와 `21:9F9F`(2 → 1)가 이어서 돌고 칸 0 이 비었습니다. [dq5-text-format.md](../docs/dq5-text-format.md) 에 적힌 차례와 같습니다.

신부 앞까지 걷는 입력도 다시 맞췄습니다. 도착 인사(`35F`~`361`)를 넘기는 A 가 남으면 명령 창이 열려 걸음이 먹히지 않았습니다. A 를 스무 번 누른 뒤 B 를 세 번 눌러 창을 닫고, 왼쪽 두 칸·위 세 칸(`left:16` 씩)을 걸으면 (4,11) 에서 フローラ 를 보고 `981`「フロー…」가 떴습니다.

## 4. ヴェール 에서 교회까지

먼 길(23/07, 1F/00 의 별장 앞, 교회 앞)만 `dq5warp.lua TO=` 로 건너뛰고 나머지는 걸었습니다. 각 단계는 앞 단계에서 저장한 세이브스테이트로 이어 돌렸습니다.

```text
23/07 (6,19)  위를 보고 A      114 991 → 210 06:F7E4 → 221 369, 21AC 80 → A0
1F/00 (32,52) 위로 두 칸, A    164 06:F808 → 165 36D「花嫁の 着がえは 終わりましたわ。…」
              위로 걸어 문 앞, とびら → 1F/05
1F/05 계단을 올라 오른쪽, A    567 36F「…フローラに シルクのヴェールを かぶせた。」 → 669 06:F874, 21B3 42 → 46
1F/00 (66,28) 위로 세 칸, A    175 998「教会の準備が やっと 終わりましたよ」
              한 칸 더 올라 とびら → 1F/01
              1533 05:F594(372·373) … 3589 05:F60B … 4099 05:F648 → 1F/0A
1F/0A         4662 05:F6AF(51D~520) … 6138 05:F6D8 → 21:8042(A = 47), 201D 1 → 2
```

1F/00 의 하녀(대화 `1CD`)는 ヴェール 를 받기 전이면 `98A`「花嫁は まだ 着がえ中ですわ。」 이고, 받은 뒤(`21AC.5`)에는 `06:F808` 을 부릅니다. ビアンカ 갈래와 같은 별장 1F/05 로 들어가고, 신부는 2층에 있었습니다. 교회 앞에서는 문지기에게 말을 건 (66,25) 에서 とびら 를 고르면 「その方向には トビラがない！」(`186`)였고, 위로 더 걸어 문 바로 앞에서 고르자 열렸습니다.

일행에 들어온 레코드 `47 80 48 00 23 00 1C 19 1F 23 17 …` 은 앞 일지가 1F/0A 로 바로 건너뛰어 본 フローラ 레코드와 같았습니다.
