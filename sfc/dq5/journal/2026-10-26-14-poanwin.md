# 2026-10-26-14: 22/00 ポワン 장면 끝 창을 이어 재기

[2026-10-26-03](2026-10-26-03-exflag4.md) 에서 22/00 장면으로 `2199.3` 을 켠 뒤 ポワン 의 창이 닫히지 않아 ルーラ 를 못 쟀습니다. 창이 무엇을 기다리는지 좁히려고 장면을 더 길게 적었습니다. 닫는 조건은 아직 못 찾았고, 결과는 [dq5-data-format.md 「남은 것」](../docs/dq5-data-format.md#남은-것) 에 적었습니다. 함께 [이야기 진행 지도](../docs/dq5-story.md) 의 대화 `234`·`22A` 두 줄([2026-10-26-09](2026-10-26-09-papas0100.md) 에서 잼)의 근거를 「실측」 으로 고쳤습니다.

## 1. 장면 흐름

`dq5warp.lua` 로 `TO=22/00,35,55` 에 들어가 40 프레임마다 A 를 45번 누르고, `tools/lua/wlog.lua` 로 ベラ(슬롯 9, `7E:3029`·`3089`)와 플래그를 적었습니다. `dq5warp.lua` 를 `tools/lua/seqlib.sh … dq5warp.lua` 로 만든 폴더에 두고 `LIBDIR` 로 주어 프로브 뒤에서 돌렸습니다.

```sh
T="wait:40"; for k in $(seq 1 45); do T="$T,a:4,wait:40"; done; T="$T,wait:2500"
LIBDIR=$WARPLIB STATE=$PWD/work/state/ship.mss TO=22/00,35,55 TEST="$T" \
  WLOG="bx=7E3029;by=7E3089;a1=7E21A1;s99=7E2199;a6=7E21A6;f9f=7E219F;ae=7E19AE" MAXF=5000 \
  SHOT_DIR=$PWD/work/poan "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/wlog.lua"
```

| 프레임 | 일 |
| --- | --- |
| 398 | `21A1` = `80`, ベラ 가 (35,47) 에서 걷기 시작 |
| 623 | `21A1` = `C0`(메시지 `0258` 뒤) |
| 944 | ベラ 가 (34,13) 에 닿아 `21A1` = `E0` |
| 952 | `2199` = `10` |
| 2082 | `2199` = `18`, ベラ 가 (34,13) 에서 아래로 걸어 나감 |
| 3755 | ベラ 슬롯이 (128,128) 로 숨겨짐 |
| 5000 | 메시지 `25D`「…無事にフルートを とりもどせるよう 祈っていますわ。」 창 그대로, `$19AE` = `80` |

`25D` 는 대화 `04D`(ポワン)가 `2199.3` 이 켜진 뒤 고르는 갈래의 메시지입니다(`06:844F`). 창이 떠 있는 동안 B·A 를 30 프레임 간격으로 열 번씩 더 눌러도 플래그·주인공 자리 어느 것도 바뀌지 않았습니다.

## 2. 21A6.6 을 켜 보기

같은 맵의 인물 `05:C848` 은 `21A6.6` 을 기다렸다가 메시지 `0269` 를 띄우고 `219F.0` 을 켭니다. 2300 프레임(창이 뜬 뒤)에 `7E:21A6` 에 `40` 을 OR 로 써 넣는 작은 프로브를 앞에 두고 같은 장면을 돌렸습니다. `21A6` 은 `C0` 이 되었지만 3843 프레임까지 `219F` 는 `80` 그대로였고 창도 남았습니다. 창이 이 줄을 기다리는 것은 아니라고 봅니다.
