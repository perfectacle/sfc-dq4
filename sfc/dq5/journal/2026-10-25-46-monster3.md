# 2026-10-25-46: 몬스터 필드 6D·68 과 시작 상태 39, 저주 효과음

여러 번 미뤄 온 몬스터 필드 `6D`·`68` 과 시작 상태 `39` 를 코드로 따라가고 전투로 확인했습니다. 저주 장비를 고를 때의 화면도 프레임마다 찍었습니다.
결과는 [dq5-data-format.md 「몬스터」](../docs/dq5-data-format.md#몬스터-238000)·[「물건 표」](../docs/dq5-data-format.md#물건-표-23b081) 에 있습니다.

## 1. 6D 는 대상 고정

필드 `6D`(바이트12 bit6)를 읽는 `20:8F5D` 는 몬스터가 행동할 때마다 `20:8439` 에서 불렸습니다. 1 이면 `$118F + 슬롯` 의 bit7 을 보고, 꺼져 있으면 지금 고른 일행 한 명(`BRK #8A 46`)을 적어 두고, 켜져 있으면 그 사람이 아직 일행에 있는지 찾아 대상으로 돌립니다.

두 그룹 전투(앞 일지들의 세이브스테이트)에서 슬라임·ドラキー 의 `6D` 를 0 과 1 로 하고 9,000프레임 싸워, 몬스터 공격 메시지 때의 `$10F5`(행동하는 쪽)·`$10F6`(대상)을 모았습니다. `00` 은 파파스, `01` 은 주인공입니다.

```
6D = 0 : 주인공 8번, 파파스 10번
6D = 1 : 주인공 24번, 파파스 1번(파파스 합류 직후)
```

## 2. 68 은 행동 거르기

필드 `68`(바이트8 bit0-1)은 행동 고르기에서 `$1103` 에 들어가고, `21:B2D6` 이 0 이 아닐 때만 후보 행동 마스크(`$1102`)를 거릅니다. `$1016` bit7 이거나 자신이 상태 `33`(マホトーン)이면 MP 를 쓰는 행동(`26:838C`)을 빼고, 뒤의 루틴 셋도 비슷하게 조건으로 뺍니다. `21:ADCE` 는 이 값이 0 이 아니면 행동할 때 다시 고릅니다.

슬라임에게 メラ 행동과 MP 를 주고 파파스에게 マホトーン 을 걸게 해 0·1 을 비교하려 했지만, 슬라임이 처음부터 メラ 를 고르지 않아 차이를 보지 못했습니다.

## 3. 시작 상태 39

필드 `70` = 1 일 때의 시작 상태 `39` 를 켜는 다른 곳 `20:F973` 은 이 비트를 켜면서 메시지 `18B`「うれしそうに ばしゃへと はしっていった！」를 띄웠습니다. 동료가 된 몬스터가 마차로 간 표시로 보입니다.
장면 이동 도구로 슬라임 셋 전투를 만들 때 바이트9 = `D7`(반드시), 바이트12 = `80`(상태 39)을 주었더니, 셋 모두 보통대로 행동했습니다. 같은 조건에서 바이트12 = `00`(잠)이면 「ねむっている」가 나왔습니다.

## 4. 저주 효과음

[2026-10-25-33](2026-10-25-33-exec3.md) 의 저주 장비 벗기 장면에서 A 를 누른 앞뒤(924~1040프레임)를 4프레임마다 찍었습니다. `25:FD00` 이 불린 932프레임 뒤로 화면은 한 점도 바뀌지 않았습니다.
`25:FD00` 은 `24:FE91`·`FE9A`·`FE44`·`FF0F` 를 부르고, 이들은 `24:FF83` 에서 소리 명령 대기열(`7E:1D95`)에 명령을 넣습니다. 깜박임이나 문구 없이 효과음만 내는 것으로 정리했습니다.
