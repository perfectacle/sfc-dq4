# 2026-10-25-47: 이벤트 스크립트

52/50 석상 이벤트에서 본 「이벤트 8」(`23:E29A`)을 따라가, 이야기 장면에서 주인공을 움직이는 스크립트의 표와 명령을 풀었습니다. 결과는 [dq5-event-format.md](../docs/dq5-event-format.md) 에 있고, 디코더는 `sfc/dq5/tools/dq5event.py` 입니다.

## 1. 이벤트 번호에서 스크립트로

`23:E29A` 는 번호 × 5 로 `23:E2C2` 표를 읽어 `$00`~`$04` 를 채우고 `02:B705` 를 부릅니다. `02:B705` 는 지금 자리에서 `$00`·`$01` 까지의 걸음을 `7E:1A0D` 에 쓰고 `C3` 와 `$02`~`$04` 를 붙인 뒤, `$19B3` 을 그곳으로 두고 `$19AE` bit7 을 켭니다.
이벤트 8 을 걸며 `$19B3`·`7E:1A0D`~ 를 읽는 곳을 지켜보자 `00:BEC6`~`00:C132` 가 읽었습니다.

```
19B3 pc=00:BEC6 / 1A0D pc=00:BED4 v=01 / 1A0E pc=00:BEEE v=02 / 1A0F pc=00:BED4 v=C3 / 1A10 pc=00:C126 v=02 …
```

## 2. 명령

`00:BED2` 의 비교 사다리에서 명령 22가지를 읽었습니다. `10` 보다 작으면 방향과 칸 수이고, 나머지는 플래그·메시지·맵 옮기기·네이티브 호출·점프 등입니다. 방향 값은 `02:B705` 가 걸음을 만드는 코드(`02:B765`·`B786`)로 정했습니다.
이 길이로 `15:F150`~`15:F7CF` 를 처음부터 읽으면 `FF` 마다 나뉘어 스크립트 86개가 나오고, 모르는 명령은 하나도 없습니다. `15:F7D0` 부터는 맵별 루틴 코드입니다.

```
이벤트 8: (26,15) 까지 걸은 뒤 15:F702
  15:F702 a0 e0 d0 06   네이티브 호출 06:D0E0
  15:F706 a0 9b a2 03   네이티브 호출 03:A29B
  15:F70A ff            끝
```

## 3. 실측

이벤트 8 을 다시 걸어 주인공 좌표와 네이티브 호출을 적었습니다. (24,15) 에서 오른쪽으로 두 칸 걸어 (26,15) 에 선 바로 뒤 `06:D0E0`·`03:A29B` 가 차례로 불렸고, 그 뒤 30/00 으로 옮겨졌습니다.

```
949 3020 v=18 / 952 v=19 / 956 v=1A
957 06D0E0 / 961 03A29B / 1452 00BC v=30
```

## 4. 석상 루틴

석상 인라인 스크립트가 부르는 `06:DAC3`·`DB28`·`DB40` 은 각자 `7E:21D8`·`21D9`·`21DA` 가 0 이면 메시지만 띄우고, 아니면 `06:DADB`(그 물건 이름을 넣은 확인 창과 물건 돌려받기로 보임, 코드 읽기) 뒤 `24:A981`(X = `0B`·`09`·`0A`)을 부르고 그 바이트를 지웁니다.
