# 2026-10-25-186: 남은 곡 줄이기 장면과 맵 곡 346곳 전부

[맵 곡 346곳 실측](2026-10-25-177-sound9.md) 에서 남긴 두 가지를 닫았습니다. 하나는 이야기 이벤트 안에서 `02`·`03`·`04` 를 부르는 여덟 곳이고, 다른 하나는 들어가지 못한 맵 넷입니다. 여덟 곳 가운데 셋을 실제 장면에서 걸었고, 하나는 끝까지 가지 않는 갈래, 넷은 부르는 곳이 없음을 근거로 닫았습니다. 맵 곡은 346곳 모두 표와 같았습니다. 결과는 [dq5-sound-format.md](../docs/dq5-sound-format.md) 「곡 줄이기·키우기를 부르는 곳」「맵 곡」에 있습니다.

## 1. 장면에서 건 셋

- **`03:EC2F`(ミルドラース)**: [이야기 진행 지도](../docs/dq5-story.md) 의 54/53 숨은 인물 2 방법을 썼습니다. `SET="2190|20;21E0|01"` 로 (17,20) 에 들어가 위를 보고 A 를 누르니 834 프레임에 `02:F884` → `03:EC1C` 가 돌았습니다. 맵 곡 `09` 를 X `08` 로 줄이고(`04 09`), 이어 `0C 3D` 가 나갔습니다.
- **`23:DE18`(トロッコ)**: `02:866C` 는 장치 루틴이 아니었습니다. 51/54 의 맵별 루틴 `02:8654`([dq5-map-format.md](../docs/dq5-map-format.md) 의 トロッコ) 안이었고, 8프레임마다 주인공이 (10,6) 인지 봅니다. 네 방향에서 (10,6) 에 들어서자 500 프레임에 다음이 나갔습니다.

  ```
  500 cmd=02 arg=44 from=00:92B9
  500 cmd=02 arg=44 from=00:92B9
  500 cmd=04 arg=09 from=23:DE18
  500 cmd=0C arg=41 from=00:92E9
  ```

  `BRK 12 44` 가 명령 `02 44`, 곧 トロッコ 가 구르는 소리(시퀀스 `44`)를 멈추는 것이었습니다.
- **`06:E0EC`(교회)**: 근처 루틴이 메시지 `086`·`08D`·`08F`·`091` 을 띄우는 것을 보고 교회 おいのり 로 짐작했습니다. 선실 파파스의 대화 번호를 교회(`05`)로 바꿨습니다. 처음에는 はい/いいえ 를 고르는 방향 입력이 늦어 기록까지 갔습니다. 그대로 이어 「まだ 冒険を つづけられる おつもりか？」에 いいえ 를 고르자 메시지 `091`「おお神よ！ この者に ひとときの 休息を…」 뒤 2094 프레임에 `04 00` 이 나가고 화면이 어두워졌습니다. 기록할 때는 1105 프레임에 `1A 20`·`01 20` 이 나가, 곡 `20` 이 기록 곡임을 알았습니다.

## 2. 끝까지 가지 않는 갈래 하나

`29:80D1` 이 든 루틴은 앞에서 본 `29:80A0` 이 아니라 `29:804D` 였습니다. `29:8044` 는 `BRK 16 3F` 뒤 `RTL` 로 끝나는 짧은 루틴이었습니다. `29:804D` 의 포인터는 `01:8D3E` 의 `JSL` 에 있었고, 이 자리는 맵을 불러올 때마다 지납니다. 346곳을 다시 들어가며 `WATCH` 를 걸자 `29:804D` 는 346곳 모두에서 돌았지만, 모두 `29:806E`(건너뜀)로 갔습니다. レヌール城(04/09) 에 밤·`2196` 비트·`21B6.0` 을 바꿔 들어가도 같았습니다. 앞 일지의 「`1A:85A7` 의 포인터」는 다른 자료 속에 우연히 같은 바이트가 있던 것입니다.

## 3. 부르는 곳이 없는 넷

`02:AAE8`·`03:9833`·`03:9964`·`0F:FC49` 는 들어 있는 루틴과, 그것을 부르는 같은 뱅크 루틴의 주소를 롬 전체에서 찾았습니다. 24비트 포인터와 같은 뱅크의 `JSR`·`JMP`·`JSR (abs,X)`·`JMP (abs,X)` 를 모두 보았지만, 실제 코드 안에서 부르는 것은 없었습니다. 346곳 맵 들어가기에서도 이 넷은 실행되지 않았습니다. `0F:FC49` 쪽의 `07:AA74`·`07:D070` 은 압축 그림 자료 속 우연한 바이트였습니다. キメラのつばさ 로 ルーラ 장면을 만들어 보려 했지만, `SET 2056=0D` 로는 가방에 넣지 못했습니다.

## 4. 맵 넷과 17/00

통행 격자에 `o` 가 없는 `03/09`·`06/07`·`2B/02`·`32/04` 는 `.` 칸에 `TO` 의 넷째 값(층)을 2 로 주자 섰습니다. 곡은 표대로 `0A`·`0D`·`0C`·`0A` 였습니다. `17/00` 은 시작 세이브스테이트(배 선실 17/01)와 같은 그룹이라, 장면 이동 도구가 사다리 단계에서 기다리다 「arrived」 줄을 찍지 못했습니다. 그래도 「end map 17/00」 으로 맵은 불러와졌고 곡 `04` 가 나갔습니다. `dq5mapmusic.py` 에 층 2 와 「end map」 을 더해 346곳을 다시 돌리니 모두 표와 같았습니다.
