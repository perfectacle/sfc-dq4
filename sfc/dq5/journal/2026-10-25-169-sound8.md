# 2026-10-25-169: 곡 줄이기·키우기를 부르는 장면, 남은 SPC 명령, 붙임의 KON

[긴 시퀀스·새 샘플 넣기와 남은 명령](2026-10-25-162-sound7.md) 에서 남긴 것을 닫았습니다. 하나는 명령 `02`·`03`·`04` 를 부르는 실제 장면이고, 다른 하나는 SPC 명령 `06`~`08`·`11`·`12`·`14` 의 처리 루틴입니다. 붙임(`4F`)이 언제 다시 KON 을 내는지도 정했습니다. 결과는 [dq5-sound-format.md](../docs/dq5-sound-format.md) 「곡 줄이기·키우기를 부르는 곳」「SPC 로 가는 명령」「시퀀스 형식」에 있습니다.

## 1. 파파스가 쓰러지는 장면

부르는 곳의 바이트를 다시 읽으니 모두 `LDA $194B`(맵 곡)나 `LDA $1D8B`(지금 곡) 뒤 `LDX #속도` 였습니다. 상수를 주는 곳은 `02:9BAF` 의 `13` 하나였습니다. 그중 `06:CD6E`·`02:9C18`·`02:9BAF` 는 [dq5-field-format.md](../docs/dq5-field-format.md) 에 적힌 「노예 시절 시작」 이벤트(`02:9B90` → `06:CD62` → `02:9C23`) 안에 있었습니다. 그 방법(`TO=07/02,12,8,1`, `SET="219C|01;075E=10;075F=00"`, `LATESET="21A3|01"`)으로 A 를 120번 누르며 돌렸습니다. 처음에는 장면 이동 도구가 3213 프레임에 끝나 기록이 없었고, 기다림을 늘리자 장면이 끝까지 돌았습니다.

```
2903 exec 06CD62
3248 exec 06CD6E
3248 cmd=04 arg=0B from=06:CD6E
3372 exec 029C18
3372 cmd=03 arg=09 from=02:9C18
3508 cmd=01 arg=09 from=00:CEA2
```

장면 곡 `0B` 를 X `20` 으로 줄이고, 03/05 로 옮기기 전에 다음 맵 곡 `09` 를 `03` 으로 키운 뒤, 맵을 불러오며 `01 09` 를 보냈습니다. 앞 일지의 여관(`06:E419`, `04 05`)과 합쳐 `04` 둘, `03` 하나를 장면에서 확인했습니다. 나머지 아홉 곳은 이야기 이벤트 안이라 그 진행 상태를 만들지 못했고, 문서 표에 인자·속도와 함께 「돌리지 못함」으로 두었습니다.

## 2. 남은 SPC 명령

처리 루틴을 읽었습니다.

- `06`·`11`: 샘플·시퀀스 n 의 칸 플래그를 0 으로(`249C`·`24BC`).
- `12`: 시퀀스 n 의 참조 수를 하나 줄임(`2746`).
- `07`: 주 음량 페이드 아웃(`03F6`·`03F7` 을 두면 `1FDB` 가 틱마다 DSP `0C` 를 줄임).
- `08`: 드라이버 다시 시작(`09DB`).
- `14`: 모든 곡을 줄여 멈춘 뒤 자리 정리.

메뉴 효과음을 바꿔 보내 SPC RAM 을 견줬습니다.

```
11 33  시퀀스 33 칸 플래그 10 -> 00
12 33  10 -> 10 (참조 수가 이미 0)
06 1F  샘플 1F 칸 플래그 10 -> 00
07 00  APU 포트에 아무것도 쓰지 않음
```

대기열 명령 `07`·`08` 은 2B 처리 루틴이 칸만 비우고(`2B:C164`), 대기열 `14` 는 곡 자료 올리기로 바뀝니다(`2B:C02F`). 롬의 입구 14개에 `06`·`11`·`12` 도 없으므로 이 여섯 SPC 명령은 게임이 보내지 않습니다.

## 3. 붙임은 언제 다시 치나

앞 일지에서 만든 시퀀스의 붙임이 KON 을 냈습니다. `1593` 을 보니 음표든 붙임이든 기다림 `15` 가 `FF` 가 아니면 `1A58`(KON)을 부릅니다. `15` 는 앞 음을 읽을 때 비율 `0204` 가 `00` 이면 `FF` 가 됩니다. 곧 비율 `00` 뒤의 음만 KON 없이 이어집니다. 곡 `0A` 트랙 0 은 `gate_preset 00` 의 음 `35` 뒤에 붙임이 있었는데, KON 은 643 다음이 723 으로 붙임 자리(673)에는 없었습니다. 만든 시퀀스는 `gate_preset FF` 라 붙임에서 KON 이 났습니다.

## 4. dq5-warp 에게 넘긴 것

효과음 갈래 수 표(32~46, `E0` 값으로 셈)와 쓰인 장면, 곡 장면 설명을 dq5-warp 에게 보냈습니다. 원래 롬을 입력 없이 켜서 찍으니 곡 `10` 은 「DRAGON QUEST V」 글자가 뜨는 타이틀 화면의 곡이었습니다(1647 `01 10`, 1700 글자, 2000 ぼうけんのしょ 메뉴). 효과음 X 는 스크립트 `00`~`14` 만 곡 변수를 넣으므로 갈래는 X `14` 까지만 만들도록 알렸습니다.

## 남은 것

- 곡 이름(들어 보기 페이지가 나오면 함께).
