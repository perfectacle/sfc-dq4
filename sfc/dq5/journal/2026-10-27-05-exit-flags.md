# 2026-10-27-05: 영역 이동 플래그 bit6 과 열리지 않는 출구

[출구 쓰기 일지](2026-10-27-03-exitwrite.md)에서 남긴 두 가지를 풀었습니다. 영역 이동 레코드 `+5` bit6 은 발동 조건이 아니라 효과음 비트였고, 01/0A·2A/00 의 다른 그룹 출구는 표가 아니라 셀 속성 `33` 이 막고 있었습니다.

## bit6 은 효과음

형식 문서는 `+5` bit6 이 꺼져 있으면 「추가 조건 검사(`2A:F4CA`)」를 한다고 적고 있었습니다. 그래서 조건이 맞지 않아 막히는 경우를 실측해야 한다고 남겨 두었습니다. 영역 이동을 실행하는 `2A:F47D` 가 부르는 `2A:F4B9` 를 읽으니 다음과 같았습니다.

```
2A:F4C2  LDY #$05 / LDA ($00),Y / BIT #$40 / BNE $F4D5
2A:F4CA  LDA $1954 / CMP #$04 / BEQ $F4D5
2A:F4D1  BRK #$19 34 02          ; 효과음 34
2A:F4D5  … JSL $00CE49 / JSL $00CD44 …
```

bit6 이 꺼진 레코드도 결국 `F4D5` 로 가고, 그 사이에 하는 일은 효과음 `34`(갈래 `02`) 하나뿐입니다. 코드로는 탈것 상태 `$1954` 가 4 이면 그 소리도 건너뜁니다(실측하지 않음). 효과음 `34` 는 [소리 형식](../docs/dq5-sound-format.md)에서 「맵을 옮길 때로 보임」 으로 적어 둔 소리입니다.

01/06 영역 0(`flags` `80`)을 `C0` 으로 바꾼 롬과 원본에서 같은 자리를 밟았습니다. 두 롬 모두 01/04 (16,6) 에 섰고, `2A:F4D1` 은 원본에서만 한 번 실행됐습니다.

## 01/0A 의 출구를 막는 셀 속성

01/0A (9,10) 과 2A/00 (19,11) 은 서로를 가리키는 다른 그룹 출구입니다. 표와 reader 의 도착 칸은 맞는데, 원본 롬에서 네 방향으로 밟아도 출구 처리 `2A:F6FD` 가 한 번도 불리지 않았습니다.

셀 버퍼를 덤프해 작동하는 출구와 견주었습니다.

| 맵 | 출구 블록 `+4` (위 줄 / 아래 줄) | 걸어서 |
| --- | --- | --- |
| 21/02 (111~112, 6~7) | `05 05` / `05 85` | 발동 |
| 01/0A (8~9, 9~10) | `33 33` / `33 B3` | 지나감 |
| 2A/00 (18~19, 10~11) | `33 33` / `33 B3` | 지나감 |

원본 롬에서 01/0A 에 서서 (9,10) `+4` 만 `85` 로 바꾸고 같은 걸음을 걷자 2A/00 (18,11) 에 섰습니다. reader 가 계산한 도착 칸과 같습니다. 출구 표는 맞고, 셀 속성 `33` 이 출구 처리를 막습니다.

처음에는 계단 판정(`00:E2C5`)이 막는다고 보았습니다. 코드를 다시 읽으니 이 판정은 두 칸 모두 `+4` 가 `05`·`33`·`4C` 이거나 `+7` 이 `05` 이면 통과라, 속성 `33` 도 받습니다. 형식 문서에 「왼쪽만 `33`·`4C`」 로 적혀 있던 것도 이 코드에 맞게 고쳤습니다. 막는 곳은 판정 뒤입니다. `00:C9E5` 가 속성 `33` 일 때 `02:BB37` 을 부르는 갈래가 후보이지만 아직 따라가지 않았습니다. 포팅에서는 출구 블록 속성을 `05` 계열 계단으로 칠하면 연결이 살아난다는 것까지 알면 됩니다.

## 재현

`dq5exitcheck.py` 에 장면 4개를 더해 24장면이 됐습니다. 효과음 장면은 Lua 가 `2A:F4D1` 실행 횟수를 세고, 속성 장면은 `dq5warp.lua` 의 `LATESET` 으로 도착 직후 셀을 고칩니다.

## 남은 것

- 속성 `33` 출구 블록에서 출구 처리를 막는 곳(`00:C9E5` → `02:BB37` 후보)과, 이 블록을 바꾸는 이벤트가 있는지.
- 출구·레코드 증설과 재배치, 출구 종류 변경.
