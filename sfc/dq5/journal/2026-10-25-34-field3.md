# 2026-10-25-34: 세계를 오가는 길, 조우를 켜는 $194A, 영역 이동 24개

[2026-10-25-26 일지](2026-10-25-26-field2.md) 의 남은 것을 이어 풀었습니다. 주문을 외워 `$1A33` 을 다시 지켜보고, 필드로 나가는 길을 다른 맵으로 바꾸는 표를 찾아 세계 1 에서 돌아오는 길을 밟았으며, `$194A` 가 실내 조우를 켜는 값임을 확인했습니다.
그룹 `$50` 이상 맵의 영역 이동은 25개 중 24개를 밟았습니다. 결과는 [dq5-field-format.md](../docs/dq5-field-format.md) 의 「필드로 나가는 길 바꾸기」·「마을 입장」과 [dq5-map-format.md](../docs/dq5-map-format.md) 의 「영역 이동」에 있습니다.

## 1. 주문을 외우며 `$1A33` 지켜보기

[2026-10-25-17](2026-10-25-17-encounter3.md) 처럼 주인공의 배운 주문 비트 `+23`(`7E:2063`)을 `FF`, MP(`+4`·`+10`)를 99 로 두면 필드 じゅもん 에 이동 주문 8개가 나옵니다. 일행이 하나라 인물 고르기 없이 바로 목록이 뜹니다.

```sh
STATE=$PWD/work/state/ship.mss TO=21/02,50,43 SET="2063=FF;2050=63;2044=63" ROMPATCH="11EA44=0000000000000000" \
  TEST="a:8,wait:40,right:6,wait:20,a:8,wait:40,down:6,wait:20,down:6,wait:20,down:6,wait:20,down:6,wait:20,a:8,wait:250" \
  RWATCH="1A33-1A33,1949-1949" WFROM=600 SHOT_DIR=$PWD/work/sqrel "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5warptrace.lua"
```

リレミト 로 21/02 에서 21/00 으로 나갔고, ルーラ 는 21/02 에서 「どこへ?」 목록까지 간 뒤 천장에 막혔으며, 필드 (341,56) 에서는 ラインハット 로 날아가 MP 가 99 에서 91 이 되었습니다. 세 실행 모두 `$1A33` 은 한 번도 읽히지 않았습니다.

## 2. 필드로 나가는 길을 바꾸는 표

`$1949` 에 쓰는 곳 다섯을 다시 보았습니다. `11:8186` 은 リレミト·ルーラ 쪽에서 `$BC` 가 `54` 면 `15` 로 보고 세계를 정하고, `02:9779`·`02:B9D8` 은 이벤트에서 0 으로 되돌립니다.
`$BC` 에 즉값을 넣는 코드를 롬 전체에서 찾다가 `2A:F5C0` 의 `LDA #$54 / STA $BC` 를 만났습니다. 감싼 루틴 `2A:F52A` 는 영역 이동이 「필드로」일 때 맵마다 필드 대신 다른 맵을 고르는 표였습니다.

```
12/02·03·04 → 53/51, 12/06 → 53/52, 0F → 52/50, 15/0A·0D·06 → 54/50, 15/01 → 54/51
22 → 11/00 (86,13)  (7E:2190 bit5 가 켜졌을 때)
05 → 50/50, 11 → 05:E87C
```

15/0A 의 왼쪽·오른쪽 출구를 밟자 54/50 의 (31,25)·(53,24) 에 섰습니다. 22/00 은 11/00 에서 영역 이동으로 들어간 뒤 `LATE="900:7E2190=2A"` 로 bit5 를 켜고 걸어 나가자, `2A:F601` 이 `$BC` 를 `11` 로 바꿔 11/00 에 섰습니다(켜지 않으면 세계 1 필드). 세계 1 에서 세계 0 으로 돌아오는 길입니다.

세계 2 로 들어가는 길은 찾지 못했습니다. `00:C6B7`(맵 옮기기)을 부르는 22곳 중 세계 2 그룹으로 가는 것은 `02:F670`(54/50 → 54/50) 하나였고, 이 루틴은 54/50 대체 인물 목록의 인라인 스크립트(`10:82B5`)가 전투 뒤에 부르는 것이었습니다.

## 3. `$194A` 는 실내 조우 스위치

`00:8309` 는 `$194A & 7F` 가 3 이면 바로, 아니면 `00:8340` 이 실내이고 4 일 때만 조우 걸음 루틴으로 갑니다. 01/00 에서 같은 입력으로 걸으며 `LATE="500:7E194A=.."` 로 값을 바꿨습니다.

```
00  008309 207번, 조우 루틴 0번
03  008309 207번, 008317 183번, 2182E2 22번, 2183CF 45번

```

그룹별 값을 `0F:EA97` 에서 뽑으면 4 는 07·08·09·0E·10·11·12·14·33, 3 은 31·32·34·35 이고, 마을·성 그룹은 0·1·2 입니다.

## 4. 영역 이동 나머지

그룹 `$50` 이상 맵의 영역 이동 14개를 자동으로 돌렸습니다. 레코드 사각형 바로 위(막히면 아래·왼쪽·오른쪽)에 레코드 `+4` 의 층으로 세워 사각형 쪽으로 걷게 하고, 맵이 바뀌는지 보았습니다.
그룹 50 은 `2A:F3B9` 갈래를 `1573BA=FF` 로 건너뛰어 51 입구 경로로 들어갔습니다. 8개씩 나란히 13초에 끝났습니다.

```
50/50 → 05/01 (32,47)   51/52 → 51/56   51/53 → 51/54   51/54 → 51/53   51/55 → 51/51
53/51 → 12/03, 12/04    53/52 → 12/06, 12/09    54/50 → 15/0A, 15/0D, 15/06   54/51 → 15/01
```

53/51 이 아닌 53 맵의 목록은 53/50 에서는 그 자리가 벽이라 53/52 에서만 밟혔습니다. 54/52 의 위쪽 레코드는 사각형 칸이 모두 `+1` = `84`(bit7 가구)라 바로 아래 줄(y=18)에서 더 올라가지 못했습니다.
