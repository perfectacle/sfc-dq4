# 2026-10-25-144: 코드가 켜는 예외 플래그 장면과 필드 줄을 실제로

[$19AE 일지](2026-10-25-113-19ae.md)에서 부르는 곳까지만 거슬러 올라간 세 플래그를 켜는 장면을 돌리고, 필드 줄이 막는 것을 실제 장면에서 보았습니다. 실험은 모두 선실 세이브스테이트에서 `dq5warp.lua` 로 장면을 옮겨 했습니다.

## 1. `21A8.1`: 왕비가 끌려간 밤

`05:FD08` 을 가리키는 `10:A070` 은 02/07 대체 목록(`21A8.2` 일 때)의 인물 `10:A048` 스크립트였습니다. 밤에만 서는 인물이라 `075E` = `F8` 로 두고, 맵에 들어설 때 지워지는 `21A1` 은 들어선 뒤에 켰습니다(`LATESET`).

- 앞 인물이 「王さま！ 申しわけありません！ 王妃さまが…さらわれて！」 뒤 `21A1.6` 을 켭니다.
- 그다음 인물이 방을 돌아 걸어가 `05:FD08` 을 부르고, 2064프레임에 `05:FD3F` 가 `21A8.1` 을 켭니다.
- サンチョ「な なんということだ！ これでは まるで 20年前の あの日と……」 뒤 02/02 회의 장면입니다.

회의가 끝나고 ルーラ 를 외우자 결과는 0 이었습니다. 같은 흐름에서 `05:FD3F` 만 `EA` 로 덮으면 2(かき消された)였습니다. 그룹 02 줄(`21A8.1` 켜짐·`2190.5` 꺼짐이면 허용)이 장면에서 켠 비트로도 맞습니다.

## 2. `2190.6`: 파파스가 쓰러진 뒤

본 루프의 `00:D227` 은 레지스터와 스택을 `$1A72`~ 에 저장해 두는 곳이고, `00:D265` 가 거기로 값을 들고 돌아갑니다. 값 2 로 돌아가는 곳은 `02:9C7D` 하나이고, 그 주소는 07/02 대체 목록(`219C.0`)의 인물 `10:AE67` 스크립트 끝에 있습니다.

07/02 에서 `21A3.0` 을 켜자 파파스가 ゲマ 에게 쓰러지는 장면이 돌았습니다. 3790프레임에 `06:CD9E` 가 `2190.6`·`.0` 을, 4030프레임에 `02:9C3D` 가 `2190.6` 을 켜고 03/05 (34,43) 에 섰습니다.

## 3. `2190.5`: 석상이 된 뒤 8년

`05:FDCB` 를 가리키는 `15:F549` 는 이벤트 번호 `3B` 스크립트 안이고, `3B` 는 대화 `1A4`(31/10 의 신부) 가운데 신부가 フローラ 인 갈래가 겁니다. 31/10 에 들어가 말을 걸어 보았지만 신부가 서지 않아 걸지 못했습니다.

그래서 이벤트 형식 문서의 「[번호를 바꿔 걸기](../docs/dq5-event-format.md#번호를-바꿔-걸기)」처럼 롬을 고쳐 걸었습니다. 선실 파파스의 대화 번호를 `1A4` 로 바꾸고, 스크립트 앞의 네이티브·기다림(`15:F523`~`F547`)을 「한 걸음 쉬기」(`C2`)로 덮었습니다. `05:FDCB` 가 `2190.5` 를 켜고 02/06 의 「…王の ゆくえは まだ わからんのか」로 갔고, 계속 넘기자 2B/02 에서 석상을 경매에 붙이는 장면이었습니다. `05:FDD7` 을 덮으면 02/06 에 그대로 머물렀습니다.

## 4. 필드 줄은 전투의 キメラのつばさ 에서

`1F:F8D3` 을 부르는 네 곳 가운데 `20:BFF0` 은 전투에서 キメラのつばさ 를 쓸 때의 처리기(`20:BFEB`)였습니다. 첫 필드 이벤트 뒤 파파스와 걷는 동안(`$19AE` = `80`, `2192` = `08`)의 무작위 전투에서 주인공 가진 물건 첫 칸을 キメラのつばさ 로 두고 던졌습니다.

- 그대로: 「しかし なにも おこらなかった！」. `20:BFEB` 가 `$1015` bit7 을 보고 `1F:F8D3` 을 부르지 않았습니다.
- Lua 로 `20:BFEB` 에서 `$1015` 를 0 으로: `1F:F8D3` 이 2 를 돌려주고 같은 메시지.
- `$19AE` 도 0 으로: 0.

필드 줄이 막는 것은 이 장면에서 보았습니다. 원래 흐름에서는 그 앞의 `$1015` bit7 이 먼저 막습니다.
