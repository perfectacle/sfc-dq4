# 2026-10-25-39: 마을 상점 팔기, 피하기 필드 6E, 전투 도구 bit4

앞 일지들에서 미뤄 온 것 셋을 했습니다. 마을 도구점에서 팔 수 없는 물건(k1 bit3)을 팔아 보았고, 몬스터 필드 `6E` 를 공격받는 쪽의 피하기로 확인했고, 전투 도구 k2 bit4 를 부르는 곳을 읽었습니다.
결과는 [dq5-data-format.md 「물건 표」](../docs/dq5-data-format.md#물건-표-23b081)·[「몬스터」](../docs/dq5-data-format.md#몬스터-238000) 에 있습니다.

## 1. 마을 도구점

인물 목록에서 대화 번호 `002`(도구점)인 인물을 찾으니 01/00 의 (12,78) 이었습니다. 장면 이동 도구로 카운터 앞 (12,80) 에 서게 했는데, 처음에는 주인공이 보이지 않고 움직이지도 않았습니다.
도착 항목의 넷째 값이 방향이 아니라 층이라서([2026-10-25-26](2026-10-25-26-field2.md)), 상점 앞 칸의 층 2 로 주자(`TO=01/00,12,80,2`) 걸을 수 있었습니다.

```sh
STATE=$PWD/work/state/ship.mss TO=01/00,12,80,2 SAVE=shop.mss … sfc/dq5/tools/lua/dq5warp.lua
# 그 세이브스테이트에서: 위를 보고 はなす → うりにきた → 첫 물건
PRE="wait:20,up:16,wait:30,a:8,wait:60,a:8,wait:120,down:8,wait:30,a:8,wait:150,a:8,wait:200,a:8,wait:200"
POKE="7E2056=18;7E2054=02"   # 가진 물건 첫 칸 = パパスのつるぎ, 장비 표시는 둘째 칸만
```

| k1(`23:B171`) | 메시지 |
| --- | --- |
| `1C`(bit3 켜짐) | `054`「パパスのつるぎ ですか。それは 手ばなさない方が よろしいのでは？」 |
| `00` | `050`「パパスのつるぎ ですね。すこし お待ちを！」 |

[2026-10-25-19](2026-10-25-19-target.md) 에서 선실 도구점의 「お買い上げですね」를 팔기로 보았는데, 그것은 사기(かいにきた)였습니다. 선실에는 상점 목록이 없어 사기 목록이 비어 멈춘 것이었습니다.
고르기 목록에서 아래 입력이 한 번에 한 칸씩만, 그것도 목록이 다 뜬 뒤에야 먹어서, 팔 물건을 첫 칸에 넣는 쪽이 확실했습니다.

## 2. 몬스터 필드 6E

`20:C763` 의 필드 읽기 뒤(`20:C76E`, `LDX $46` 다음)에서 X 를 적으니, 슬라임을 3 으로 고친 롬에서 3, ドラキー 쪽은 2 가 나왔고 슬라임을 0 으로 고쳐도 2 가 나오는 경우가 있었습니다. 2 는 파파스(몬스터 `DC`)의 값으로, 공격받는 쪽(`$10F6` 의 슬롯)의 필드입니다.
앞 일지에서 피한 수가 그대로였던 것은 1/4 정도로는 몇 번의 공격에서 차이가 드러나지 않아서였습니다. 그래서 확률 표 `27:8051` 의 3 칸(`27:8054`)을 1(늘)로 바꿨습니다.

```
슬라임 6E = 3, 27:8054 = 1 : 05E 060 05E 060 05E 0A3 … 05E 0A3   (주인공 공격을 「ひらりと みをかわした」)
슬라임 6E = 0, 27:8054 = 1 : 05E 060 05E 060 05E 069 … 05E 069
```

이후 파파스의 공격 일부는 피하지 않고 맞아, 공격하는 쪽에 따라 이 갈래로 오지 않는 경우가 있는 것으로 보입니다(`20:C6F0`~ 의 앞 조건, 아직 안 읽음).

## 3. 전투 도구 k2 bit4

`BRK #94 0E` 로 bit4 를 보는 곳은 전투 도구 사용의 `20:9531`·`956B`·`A541` 이었습니다. 적 그룹 고르기 창(`4C`)에서 그룹을 고른 뒤 bit4 가 켜져 있으면 `20:A917` 로, 그 그룹에서 살아 있는 몬스터 마스크를 만들어 난수로 한 마리를 골라 대상으로 합니다. 꺼져 있으면 그룹을 그대로 대상으로 둡니다.
いかずちのつえ 는 실행 루틴이 그룹(`9771`)이라 bit4 를 꺼도 맞는 수가 같았습니다.

## 남은 것

- 몬스터 필드 `68`·`6D`(`20:8F5D` 는 `$118F` 에 일행 한 명을 적어 두는 갈래), 시작 상태 `39`, `6E` 갈래의 앞 조건
- 저주 장비: 프레임마다 화면을 찍어 저주 문구·깜박임 잡기, 커서 위치를 RAM 으로
- 되살리기·독 풀기, 「ー」 행동·がったいだ 를 몬스터 쪽에서(두 명 일행 장면)
- k2 bit4 를 한 마리 실행 루틴 물건으로 실측
