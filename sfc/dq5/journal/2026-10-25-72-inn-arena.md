# 2026-10-25-72: 따라오는 일행을 놓는 방법($198E)과 격투장 상금

상점의 남은 것 가운데 둘을 dq5-shop2 세션과 나눠 맡았습니다. 여관 값 bit7 이 화면에서 무엇을 바꾸는지와, 격투장 상금 계산입니다. 여관 값과 일행 수 곱셈은 [2026-10-25-41](2026-10-25-41-shop3.md) 과 그 뒤 shop2 의 PR 에 있습니다.

## 1. `$198E` 를 읽는 곳

여관 값의 bit7 은 잘 때 `$198E` bit7 로 갑니다. `$198E` 를 읽는 곳은 `00:E209` 와 `00:E360` 둘이고, `00:E360` 은 맵을 불러올 때 따라오는 일행마다 도는 반복입니다.

```
00:E360  LDA $198E / BPL → JSR $E5B0   ; 주인공 뒤로 줄 세움
                         → JSR $E59F   ; bit7: 주인공 자리에 겹쳐 놓음
```

## 2. 보통은 늘 겹친다

`dq5warp.lua` 로 `PARTY=02,05` 를 넣고 04/00 에 가면서 `$198E` 를 `00`·`80`·`82` 로 바꿔 보았지만, 셋 다 동료가 주인공에 겹쳐 있었습니다. `00:E360` 을 추적하니 셋 다 그 순간 `$198E` = `82` 였습니다. 쓰는 곳을 `wwatch.lua` 로 잡자 사다리 출구에서는 `2A:F243`(출구마다 `2A:F6B8` 이 돌려주는 값), 필드로 나올 때는 `00:CBF1`(늘 `82`)이었습니다.

## 3. 출구의 값을 덮어 비교

`2A:F240` 의 `JSR $F6B8` 을 `LDA #$00 / NOP`(`ROMPATCH=157240=A900EA`)과 `LDA #$80 / NOP` 으로 바꿔 같은 장면 이동을 했습니다.

| 덮은 값 | `00:E360` 다음 | 화면 |
| --- | --- | --- |
| `00` | `00:E5B0` 두 번 | 주인공 아래로 ホイミスライム·スライム 가 한 줄 |
| `80` | `00:E59F` 두 번 | 둘이 주인공 위에 겹침 |

덮은 롬에서는 출구 목적지를 고르는 쪽도 바뀌어 17/00 의 사다리 자리에 그대로 남았지만, 놓는 방법의 차이는 분명했습니다. 여관 아침 장면 자체는 아직 보지 않았습니다.

## 4. 격투장 상금

`$115A`(倍率 정수)·`$115E`(소수)를 읽는 곳을 찾으니 `06:F31F`·`06:F337` 이었습니다.

```
06:F31C  상금 = 건 코인($0AFE~$0B00) × (정수*10 + 소수)        ; 24회 덧셈 곱
06:F393  ÷ 10 (하드웨어 나눗셈 $4204/$4206)
06:F3DF  나머지 >= 5 면 +1
06:F3F2  $F5~ 에 두고 「おめでとうございます！！ みごと {F5}枚の コインを…」 → はい/いいえ
```

파파스를 대화 번호 `0E` 로 바꾸고 코인을 한 번만 100 으로 넣은 뒤, 시합 ダンスニードル·ドラキーマ(둘 다 1.9)에서 1장 걸었습니다. 코인 바이트의 쓰기를 모두 적었습니다.

| 이긴 뒤 고른 것 | `7E:203C` 쓰기 |
| --- | --- |
| A 만 누름(はい) | 631프레임 `63`(99)뿐. 「スライムAに 2枚ですね」 로 다음 시합 |
| 아래 + A(いいえ) | 631프레임 `63`, 2153프레임 `65`(101) |

1 × 19 ÷ 10 = 1, 나머지 9 라 올려서 2 입니다. はい 를 고르면 상금이 다음 시합에 그대로 걸립니다.

## 틀렸던 것들

- 처음엔 `$198E` 를 장면 이동 전에 `SET` 으로 바꾸면 될 줄 알았습니다. 출구를 지날 때 다시 써서 늘 `82` 였습니다.
- 이긴 뒤 코인이 늘지 않아 상금이 없는 줄 알았습니다. A 를 누르면 はい 가 골라져 다음 시합에 걸린 것이었습니다.
