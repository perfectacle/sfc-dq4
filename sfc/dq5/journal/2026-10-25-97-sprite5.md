# 2026-10-25-97: 인물 스프라이트 마무리

인물 스프라이트의 마지막 남은 것 셋을 닫았습니다. 결과는 [dq5-graphics-format.md](../docs/dq5-graphics-format.md) 의 「맵 OBJ 물체」「검증」 에 있습니다.

## 1. 07/02 의 맵 OBJ 물체

07/02 물체 8개는 자리가 128 이라 맵을 풀 때 놓이지 않고 스크립트가 놓습니다. 그림과 칸 배치만 확인하려고 `16:F862` 항목의 X·Y 를 `ROMPATCH` 로 맵 안 자리로 바꿔 들어갔습니다. 8개 모두 칸 목록이 슬롯과 같았고, OAM 묶음 48개가 배치·반전·팔레트까지 맞았습니다.

```
맵 OBJ 물체 8개: 칸 목록이 16:F862 항목과 같은 덤프 48개, OAM 묶음 48개가 칸 배치·반전·팔레트까지 같음 00 01 02 03 04 05 06 07
```

04/0A 의 `0E` 는 슬롯이 생기지만 가로·세로가 0 으로 지워져 그려지지 않습니다. 칸 바이트가 04/00 의 `0D` 와 같아 그림은 `0D` 로 확인한 셈입니다.

## 2. 세트 36 은 맵 밖에 있었다

15/0B 의 인물 12명(그림 `12`)은 (72,6)~(99,6) 처럼 맵 밖에 놓여 있었습니다. 인라인 스크립트를 보면 주인공이 사각형에 들어가면 `2B` 로 맵 안으로 옮겨 옵니다. (12,18) 에서 왼쪽으로 걸어 (8,18) 에 들어가자 두 명이 (4,8)·(6,8) 로 옮겨 와 그려졌고, OAM 이 디코더와 맞았습니다.

## 3. 세트 5C 와 A2

dq5-warp 세션이 찾은 대로, 마차에 탄 동료(`7E:1978` bit7)가 걷는 슬롯에 오면 그림 `35` 를 씁니다. `SET=201E=04` 로 걷는 수를 일부러 넷으로 두자 슬롯에 `35` 가 올라와 세트 `5C` 가 맞았습니다. 세트 `A2` 는 그림 번호 표 어디에도 없어 쓰이지 않습니다.

## 틀렸던 것들

- 세트 `36` 인물을 「숨은 상태라 그려지지 않는다」 고 보았습니다. 실제로는 맵 밖에 놓였다가 스크립트로 나타나는 인물이었습니다.

## 남은 것

- 07/02 물체를 실제로 놓는 스크립트와 04/0A 의 `0E` 를 지우는 곳.
