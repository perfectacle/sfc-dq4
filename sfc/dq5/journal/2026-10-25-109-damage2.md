# 2026-10-25-109: 몬스터 かいしん, ぼうぎょ, 회심 앞 조건

[앞 일지](2026-10-25-106-damage.md)에 코드 읽기로 남긴 전투 계산식을 이어서 실측했습니다. 결과는 [dq5-data-format.md 「전투 계산식」](../docs/dq5-data-format.md#전투-계산식-20b030) 에 있습니다.
실험은 앞 일지와 같이 슬라임 한 마리 전투 세이브스테이트에서 A 를 누르며 값을 `POKE` 로 고정하고, 처리 루틴 안의 PC 에서 A 와 `$10F5`·`$10F6`·`$10F7` 을 기록했습니다.

## 1. 몬스터 かいしん１·２

슬라임 레코드의 행동 여섯(파일 오프셋 `118011`~`118016`)을 모두 `74`(かいしん１)로 덮고, 슬라임 공격력 100·주인공 수비력 255 로 두었습니다.

```
20:B5A7 (특수 갈래)   13번  100~105
20:B0C3 (보통 공격)   22번  0~29
```

`20:B579` 는 난수(0~3)가 0 일 때 공격력 + 난수 0~(공격력 × 5 / 100) 를 수비력 없이 줍니다. 공격력 100 이면 100~105 이고, 수비력 255 앞에서도 그대로였습니다.
13/35 는 1/4 보다 조금 많지만 몇십 번의 표본이라 판정 식을 바꿀 근거는 아니라고 보았습니다.

모두 `75`(かいしん２)로 하고 공격력 40 이면 43번 모두 200 이었습니다. `20:B5BB` 는 공격력에 5 를 곱할 뿐입니다.

## 2. ぼうぎょ

주인공이 たたかう → ぼうぎょ 를 고른 턴마다 슬라임(공격력 100, 주인공 수비력 0)에게 맞게 했습니다. `20:AF9D`(방어 상태 `$49` 를 읽은 직후)와 `20:AFC1`(줄인 뒤)의 `$10EC` 를 견주었습니다.

```
$49 = 0   49 → 49, 52 → 52 …   (ぼうぎょ 를 고르지 않은 판 8번)
$49 = 1   46 → 23, 44 → 22, 52 → 26 …   (7번)
```

방어 상태 1 은 `LSR` 로 절반입니다. 2 는 `00:95BA` 에 5 를 넘기는 갈래인데 이번에는 만들지 못했습니다.

## 3. 회심 앞 조건

`20:C697` 의 바이트를 다시 풀자, 난수 판정 앞에 두 가지 검사가 있었습니다. 필드 `41`(`$43` = `1A`) 상태가 켜져 있으면 회심이 없고, `26:8D0A` 가 carry 를 돌려주면 회심이 없습니다.
`26:8D0A` 는 주인공의 가진 물건 일곱(`7E:2056`~)이 `26:8D33` 의 일곱과 같은지 보는 루틴으로, 동료 확률 쪽 일지에서 「반드시 동료가 되는 가진 물건」으로 확인된 표입니다.

판정 난수를 `LDA #$02`(1/2)로 덮자 주인공 공격 47번 중 16번이 회심이었습니다. 앞 일지의 `01`(늘 회심)에서도 39번 중 19번만 회심이었으니, 공격 중 절반쯤은 이 판정에 닿지 않는 것으로 보입니다. 까닭은 찾지 못했습니다.

## 남은 것

- 회심 판정에 닿지 않는 공격이 섞이는 까닭과 1/32 의 실측.
- `20:C464` 의 つうこん 갈래(공격하는 몬스터의 상태 `42`), 방어 상태 2.
