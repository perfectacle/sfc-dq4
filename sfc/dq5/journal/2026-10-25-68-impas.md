# 2026-10-25-68: インパス 와 마차 조건

물건 설명 메시지(k3·k4)를 띄우는 곳이 필드 주문 インパス 라는 것을 찾아 화면으로 확인했습니다. 몬스터 행동 `A0`·`A7` 이 마차가 있을 때 고르는 행동이라는 것도 확인했습니다.
결과는 [dq5-data-format.md 「물건 표」·「주문과 행동」](../docs/dq5-data-format.md#물건-표-23b081) 에 있습니다.

## 1. 설명 루틴을 부르는 곳

설명 루틴 `11:83B1` 은 `11:8384` 부터 이어지는 함수 안에 있었습니다. 필드 주문 처리 표 `11:8024`(주문 번호 − `27`)를 풀어 보니 インパス(`35`)의 처리기가 `11:82E8` 이고 그대로 `11:8384` 로 이어졌습니다.

주인공 일행 레코드 `+23` 을 `FF`(ホイミ·キアリー·ベホイミ·インパス 등), MP 를 99 로 하고, 가진 물건에 キメラのつばさ 를 넣은 뒤 필드 じゅもん → インパス → キメラのつばさ 를 골랐습니다.

```
18D 「…は インパスを となえた！」
451 「…は キメラのつばさを 手に取り インパスを となえた！」
456 「キメラのつばさは 道具らしい。」
49B 「これを 使うと さいごに 立ちよった ところに もどることが できるようだ。」
```

롬을 바꿔 두 번 더 보았습니다.

| 바꾼 것 | 메시지 |
| --- | --- |
| k3 = `CC`(설명 번호 `0C`) | `451` `456` `49A`「これは くすりのようだ。」 |
| k4 = `13`(bit7 끔) | `451` `49B` `457`「１回 使ったら なくなって しまうらしい。」 |

k4 bit7 이 켜져 있으면 종류 메시지 뒤 설명으로 끝나고, 꺼져 있으면 설명 뒤에 k3 bit7·k1 bit5 갈래로 「なくなる / なくならない」(`457`·`458`)를 붙입니다.

## 2. 마차가 있을 때의 98·A0·A7

[2026-10-25-63](2026-10-25-63-ai-filter.md) 에서 `68` = 1 인 몬스터는 셋을 고르지 않았습니다. 장면 이동 도구로 마차와 동료 둘(`PARTY=02,03 WAGON=1 ADULT=2`)이 있는 전투를 만들어 다시 돌렸습니다.

```
A0 : 108 109 108 109   (두 마리가 일행을 마차로 밀어 넣음)
A7 : 180               (한 마리가 마차 문을 닫음)
98 : 고르지 않음
```

조건 루틴을 읽으니 `13`(`A7`)은 마차가 있고 `$1017` bit5(문이 닫힘으로 보임)가 꺼져 있을 때, `14`(`A0`)는 마차가 있고 일행이 둘 이상일 때, `11`(`98`)은 주인공 레벨 + 4 와 구역 레벨을 비교하는 것이었습니다. 문을 한 번 닫은 뒤 `A7` 을 더 쓰지 않은 것과 맞습니다.
