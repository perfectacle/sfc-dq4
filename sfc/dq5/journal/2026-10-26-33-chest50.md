# 2026-10-26-33: 그룹 50 이상 맵의 아래층 상자 11개는 다섯째 표 1E:F4DF 로 열림

[2026-10-26-10](2026-10-26-10-hidden50.md) 에서 그룹 `50` 이상 맵의 아래층(`+4`) 상자 칸 11개를 「어느 표에도 없어 열리지 않는다(코드 읽기)」고 적었습니다. 열립니다. 위층 상자 검사 뒤에 `$BC` ≥ `32` 일 때만 도는 아래층 상자 검사가 따로 있고, 그 표 `1E:F4DF` 에 11칸이 그대로 들어 있습니다. 결과는 [dq5-map-format.md 「아래층 상자」](../docs/dq5-map-format.md#아래층-상자-12ed62) 에 적었고, `dq5chest.py`·`dq5items.py` 가 이 표를 읽게 했습니다.

## 1. 상자 찾기가 보는 칸

상자 검사 `12:E63B` 는 `$0F` = `84` 를 두고 방향마다 `12:F849`(위)·`F8B8`·`F87E`·`F8A7` 을 부릅니다. 넷 다 `12:FE87` → `25:F9F4` 를 A = 1 로 부르는데, `25:F9F4` 는 A 가 0 이 아니면 셀 `+7`(위층)을, 0 이면 `+4`(아래층)를 돌려줍니다. 위를 볼 때 `12:F849` 는 주인공 칸 (x, y) 에서 (x+1, y-2) 를 먼저 보고, 다음에 (x, y-1) 과 그 오른쪽 두 칸을 봅니다.

54/50 (89,16) 에서 위를 보고 しらべる 하며 `12:F84E`(첫 칸)와 `25:FA10` 에 실행 감시를 걸었습니다.

```
f243 hook 12F84E A=0001 X=005A Y=000E      ; (90,14)
f243 hook 25FA10 A=8400 X=005A Y=0007      ; B = +4 = 84, 이어 +7 을 읽어 견줌
f243 hook 12E669                           ; 위층 상자 없음
```

첫 칸이 바로 상자 칸 (90,14) 이고 `+4` 가 `84` 지만, `+7` 과 견주니 찾지 못하고 `12:E669` 로 끝났습니다.

## 2. 아래층 상자 검사 12:ED62

같은 목록(`12:E4C9` 이 부르는 차례)에서 `$0F` 에 `84` 를 두는 곳은 둘입니다(`A9 xx 85 0F` 를 훑음). 둘째 `12:ED6B` 앞의 `12:ED62` 는 `$BC` < `32` 면 그냥 돌아가고, 아니면 `F8C9`·`F96B`·`F936`·`F95E` 로 찾습니다. 이 넷은 `TDC` 로 A = 0 을 두어 아래층을 봅니다. 찾으면 `12:FD46` 이 `1E:F4DF` 를 훑습니다.

```
12:FD4B  LDA 1E:F4DF,X / CMP #FFFF / BEQ 끝
         CMP $BC        ; +0 BC·BD
         ...  CMP $1E71 ; +2 X·Y
         +4 → $1E73(내용물), +6 → $1E80, $1E80 |= 80
         LDA 7E:2190,X(X = $1E80) / AND $1E81   ; 열렸는지
```

표는 8바이트 11개이고, 칸이 앞의 11칸과 하나도 어긋나지 않습니다(`dq5items.py --check`: 「아래층 상자 칸 11개, 표 1E:F4DF 11개, 서로 없는 것: 없음」). 열림 비트는 `7E:2228` bit0~7 과 `7E:2229` bit0~2 입니다.

1절과 같은 실행에서 `12:ED62`·`12:ED6B`·`12:ED99`·`12:FD46` 이 차례로 불렸고, 메시지 131「宝箱を　開けた！」, 「なんと！ オーガシールドを 見つけた！」, 132 뒤 `7E:2229` = `04` 였습니다.

## 3. 11개 모두 열기

상자 칸 (x, y) 마다 `dq5warp.lua` 로 (x-1, y+2) 에 내려 위를 8 프레임 누르고 しらべる 했습니다. 11개 모두 `12:FD46` 을 지나 131 이 나왔고, 열 개는 표의 비트가 켜졌습니다(51/51 (17,35) 의 ちいさなメダル 는 메시지가 길어 A 를 더 눌러 `2228` = `10`).

54/52 (28,21) 만 131 뒤 물건을 주지 않고 조작이 막혔습니다. 여는 루틴 `12:EEF7` 이 내용물 `34`(オリハルコンのキバ)이고 `21BF.1` 이 꺼져 있으면 `21A1.7` 을 켜고 `03:BA49` 를 부른 뒤 끝나기 때문입니다(`12:EF17`). 그 다음은 청년기 후반(`2190.5`) 목록 `10:8339` 의 인물이 맡아, 어린 시절 플래그로 간 세이브스테이트에는 받을 사람이 없었습니다. `ADULT=1` 로 다시 들어가 주인공 HP 를 999, 힘을 `FF` 로 두고 열었습니다.

| 프레임 | 일 |

HP 를 그대로 두면 전멸해 교회(02/01)로 갔습니다.
