# 2026-10-27-21: 표에 없는 상자 칸과 53/52 상자 뒤 갈래

[dq5-map-format.md 「보물상자」](../docs/dq5-map-format.md) 에 코드 읽기로 남은 두 줄을 게임으로 쟀습니다.

## 1. 표에 없는 맵의 상자 칸

`dq5items.py --check` 가 「상자 칸 5개, 표 0개」 로 보이는 19/00 의 (6,45) 를 (5,46) 에서 위를 보고 しらべる 로 보았습니다.

```
f249 12:E66F (A=84) → 25:FAB0 → 12:E669
f250 메시지 12B「足もとを　調べた！」, f370 12C「しかし　何も　見つからなかった。」
```

`25:FAB0` 이 맵을 표에서 못 찾아 C 를 켜고 돌아가면 `12:E66F` 는 상자가 아닌 것으로 보고 다음 검사로 넘어갑니다.

## 2. 53/52 아래층 상자를 연 뒤

`12:EF46` 은 내용물을 준 뒤 지금 맵이 53/52 이고 `21AB.2` 가 꺼져 있으면 `21B8.0` 을 켜고, 인물 `03`·`00` 을 `BRK 8A DB` 로 조회해 창을 띄웁니다. 필드 입구 51 을 53/52 (60,29) 로 바꿔 들어가(handoff 의 그룹 `50` 이상 방법) 상자 (61,27) 를 열었습니다.

```
그대로         f571 131, f690 14C, f724 2228=04, f776 12:EF46·EF4C, f777 21B8=01
SET 21AB|04    f724 2228=04, f776 12:EF46 (EF4C 없음), 21B8=00
```

주인공 혼자라 창은 뜨지 않았습니다.
