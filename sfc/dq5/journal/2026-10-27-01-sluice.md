# 2026-10-27-01: 10/00 의 수문과 바위

[2026-10-25-112](2026-10-25-112-perframe2.md) 가 남긴 「10/00 의 이벤트 갈래」 를 풀었습니다. 맵별 루틴 `03:EA62` 의 `21D1.5`·`.4` 갈래는 물이 찬 방 아래 수문을 とびら 로 열었을 때 물이 복도로 흘러 내려가고(`.5`), 바위로 길을 막아 두었으면 방의 물까지 빠지는(`.4`) 장치였습니다. 결과는 [dq5-map-format.md 「맵별 루틴」](../docs/dq5-map-format.md) 의 `03:EA62` 줄과 [dq5-flags.md](../docs/dq5-flags.md) 의 「뜻을 아는 플래그」 에 넣었습니다.

## 1. 켜는 곳이 없어 보이던 비트

`dq5flags.py rom/dq5.sfc 21D1` 의 `21D1.5` 는 처음에 「봄 `03:EA91`」 만 보였습니다(앞 40줄로 자른 출력이라 켜는 줄이 잘렸음). 그래서 먼저 값을 넣어 갈래를 돌렸습니다. 10/00 (29,45) 세이브스테이트를 `dq5warp.lua` 로 만들고 `dq5seqtrace.lua` 의 `WR` 로 `21D1` = `20`, `$CB` = `0E` 를 넣었습니다.

```
f2    21D1=20 CB=0E
f412  hook 03EAD3  (CB = 42)       → f413 21D1=10 CB=0E
f832  hook 03EAFA  (CB = 42 다시)  → f833 21D1=00
```

`$CB` 는 8프레임마다 1씩 늘었고, `21D1` 을 넣지 않으면 그대로였습니다. 주인공을 (29,47), 곧 바위(슬롯 8, (29,49)) 두 칸 위로 걸어 두면 `$19AE` = `01` 이 된 54프레임부터 아래를 눌러도 움직이지 않다가 844프레임에 `$19AE` = 0 이 되자 바위를 밀며 내려갔습니다. 같은 입력을 원래대로 주면 54프레임 뒤 곧바로 바위를 밀었습니다. 다만 화면은 바뀌지 않았습니다. WRAM 을 견주니 줄 16~65 셀의 `+5`·`+6`(위층 워드)만 0 이 되어 있었습니다. 이때 `$CF` 가 그 장면에 남아 있던 `60` 이라 위층만 옮겼기 때문입니다.

## 2. 수문 바퀴

롬에서 `00 0C` 뒤 `41` 을 다시 찾자 바로 앞 `03:EA42 BRK 0C 20 41` 이 나왔습니다. 이 루틴(`03:EA23`)은 `$CB` = `1A`, `$CF` = `0C`(아래층 워드) 로 두고 이벤트 스크립트 `03:EA57` 을 겁니다. 부르는 곳은 `01:EC3A` 하나이고, 거기까지는 문 열기 `01:DFAB` 의 `$1E76` = `D7` 갈래(`BRL 01:EBF8`)로 옵니다. `$1E76` = `D7` 은 とびら 의 앞 칸 속성이 `D7` 일 때 `01:DCEE` 가 둡니다. 10/00 셀 버퍼에서 속성 `D7` 은 수문 블록(X 28~35, Y 24~27, 위층 속성 `57`)의 오른쪽 아래 (35,27) 하나였습니다.

(34,28) 에서는 「その方向には トビラがない!」, (35,28) 에서도 열리지 않았고, (33,28) 에서 위를 보고 とびら 를 고르자 열렸습니다.

```
f222  hook 01DFAB          → f223 1E76=D7, hook 01EBF8
f272  hook 03EA23          → f273 21D1=20 21A5=80 19AE=80 CF=0C
f307~ 주인공이 한 칸씩 아래로(스크립트 04 24)
f578  hook 03EA9D (Y=3F)   → f579 21D1=00 21A5=00
f588  10/04 (20,9)
```

물은 주인공 뒤를 따라 복도를 채우고(셀 아래층이 (36,16) 의 물 무늬로 바뀜), 주인공은 맨 아래까지 밀려 10/04 로 나갔습니다.

## 3. 바위로 막기

바위가 주인공과 같은 X 로 두 칸 아래에 있으면 `$19AE` bit7 을 끄고 bit0 을 켭니다. 바위를 수문 줄 X 33 으로 옮기려면 왼쪽에서 밀어야 합니다. 10/00 (29,45) 에서 왼쪽으로 두 칸, 아래로 네 칸 가서 오른쪽으로 네 칸 밀자 바위가 (33,49) 에 섰습니다(`SEQ="wait:10,left:24,wait:10,down:32,wait:10,right:36,wait:20,up:200,wait:10,right:16"`). 그 자리에서 (33,28) 로 올라가 수문을 열었습니다.

```
f272   hook 03EA23
f451   19AE=01 (Y=2F, 바위 두 칸 위)
f587   hook 03EAD3·03EADF (CB=42) → f588 21D1=10
f1005  hook 03EAFA → f1006 21D1=00 21A5=00 19AE=00
f1538~ 위로 걸어 (32,16)
```

587프레임 덤프에서 줄 26~65 의 X 26~37 이 물 무늬(`0BE`·`0BF`·`0C0`·`0C1`)였고, 1010프레임에는 방(줄 16~22)과 복도가 바닥 타일 `0E3`, 줄 64 가 `0ED` 였습니다. 섬 둘레의 물도 바닥이 되어 방 안 (32,16) 까지 걸어 들어갔습니다. 바위 없이 열면 물에 밀려 방을 떠나고, 바위로 막아 두면 물이 방에서 빠지는 수수께끼입니다.

## 틀렸던 것들

- 「`21D1.4` 갈래는 슬롯 8 이 주인공과 같은 칸이면」(dq5-map-format.md): 같은 칸이 아니라 같은 X 로 두 칸 아래(`DEC`·`DEC` 뒤 `$C2` 와 견줌)였고, 이 판정은 `21D1.4` 가 아니라 `21D1.5` 갈래에 있습니다. `$CB` = `42` 에서 `21D1.4` 는 꺼지는 것이 아니라 먼저 켜지고, 두 번째로 `42` 에 이를 때 꺼집니다.
- 「`21D1.5` 를 켜는 곳이 없다」: `dq5flags.py` 출력을 앞 40줄로 잘라 보아 켜는 줄을 못 보았습니다.
