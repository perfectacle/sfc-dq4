# 2026-10-25-65: 누운 인물, 동료 그림 번호, 세트 124개 확인

[2026-10-25-32 일지](2026-10-25-32-sprite.md) 에서 남긴 인물 스프라이트의 남은 것 셋을 풀었습니다. 누워 있는 인물의 모양, 동료 몬스터와 사람 일행이 쓰는 그림 번호 표, 화면에 안 나왔던 세트입니다.
결과는 [dq5-graphics-format.md 「필드 인물 스프라이트」](../docs/dq5-graphics-format.md#필드-인물-스프라이트-1fcf1e) 의 「일행의 그림 번호」「누운 모양」「검증」 에 있습니다.

## 1. 동료가 있는 필드

`dq5warp.lua` 의 `PARTY=02,05` 로 スラリン·ホイミン 을 데리고 필드에 서서 걸었습니다. 일행 슬롯 1·2 의 그림 번호는 `50`·`5B` 였고, 세 슬롯 모두 4방향 × 2프레임이 디코더와 픽셀째로 같았습니다.

```
['0x2e', '0x50', '0x5b', '0xff'] 0x3 ['0x2e', '0x50', '0x5b', '0x0']
세트 3개, VRAM 타일 2632/2632 같음
OAM 묶음 84개 중 84개가 디코더 프레임과 픽셀째로 같음
```

종류 `02` → `50`, `05` → `5B` 인 바이트 표를 롬에서 찾으니 `05:D9E1` 하나가 나왔고, 그 표를 읽는 `05:D98F` 가 일행 레코드의 인물 번호로 그림 번호를 정했습니다. bit7 이 켜진 번호는 동료 몬스터(`05:D9E1`), 0 은 주인공(플래그로 `2E`·`3A`·`2D`), 나머지는 사람 표 `05:D9D5` 입니다.
동료 둘씩 21번(종류 `01`~`29`)을 같은 방법으로 세우자 41종 모두 표의 그림 번호대로 VRAM 에 올라왔습니다.

## 2. 사람 일행 표와 이름

사람 표 `05:D9D5` 의 8번은 `2C` 로, 배 선실의 파파스(슬롯 `0B`)의 그림과 같습니다. 이름 표 0 의 5번이 パパス 이니 인물 번호 n 은 이름 표의 n-3 번째로 보았습니다. 이렇게 짝지으면 サンチョ(`29`)·フローラ(`97`)·ヘンリー(`3B`)·ビアンカ(`2F`) 도 앞 일지에서 대화 화자로 고른 이름과 같았습니다.
세트 `1B`(파란 갑옷)를 ヘンリー 로 붙인 것이 의심스러웠는데, 일행 표도 같은 답을 냅니다.

## 3. 누운 인물

앞 일지에서 코드만 읽어 둔 누운 모양을 디코더에 넣었습니다. `1F:D413` 은 비트 평면마다 8바이트를 `ASL`·`ROR` 로 전치하므로, 타일 하나를 시계 방향으로 90도 돌린 것입니다. 칸은 `1F:D0AC`·`1F:D1B3` 표로 다시 고르고, 원래 칸의 좌우 반전이 상하 반전으로 바뀝니다.
처음 비교에서는 누운 인물이 하나도 안 잡혔습니다. 첫 타일을 구할 때 누운 칸 대신 원래 칸을 써서 첫 타일이 어긋났기 때문입니다. 고치자 덤프에 나온 누운 인물 8세트의 돌린 타일과 칸 48개가 모두 같았습니다.

```
0307_16_12_1A slot 0A gfx 43 set 0E cells 48 vram 29/29 ['80DE', '80E0', '80E2', '80DD', '80DF', '80E1']
누운 모양 (세트, 방향) 9개: 01right 0Eright 15right 15up 1Aright 82right 8Fright 94right A0right
```

## 4. 화면에 안 나온 세트

인물 목록에서 세트마다 놓이는 맵과 자리를 뽑고, 덜 본 세트를 가장 많이 덮는 맵부터 골라 53곳으로 순간이동했습니다. 대체 목록에만 있는 세트는 그 목록을 고르는 플래그를 `SET` 으로 켰습니다. 17/01 셋은 순간이동이 안 됐습니다.
처음에 OAM 이 19묶음 맞지 않았는데 원인이 셋이었습니다.

- 2B/00 의 이벤트에서 세트 `80` 인물이 팔레트 4 로 그려짐. 색 번호는 같아 팔레트를 따로 세게 바꿈.
- 오른쪽 끝(x=248)에 반쯤 걸친 인물이 OBJ 4개만 내서 뒤 인물과 묶음이 어긋남. 맞지 않으면 한 칸씩 밀어 다시 보게 바꿈.
- 00/02 에서 머리는 아래, 몸은 옆을 본 프레임. 머리는 `7E:3260`, 몸은 `7E:3240` 방향을 따로 본다는 것을 리스팅에서 확인하고 조합을 더함.

장면 97곳 덤프 1,605개를 다시 비교하자 VRAM 타일 269,111/269,111(세트 124개), OAM 묶음 5,639/5,639 가 맞았습니다.

## 틀렸던 것들

- 동료가 있는 장면을 만들려고 `7E:1967`(일행 수)과 `7E:1970` 을 `SET` 으로 고쳤지만 맵을 지나며 1 로 되돌아갔습니다. 일행 레코드째 넣는 `PARTY` 가 있어야 했습니다.
- OAM 이 다르면 그림이 틀렸다고 보았는데, 12묶음은 팔레트만, 나머지는 묶는 방법과 머리·몸 방향 조합 문제였습니다.
