# 2026-10-25-119: 주인공 とびら 명령과 위쪽 문

[인물 그림 고르기와 문 명령 넷째 바이트](2026-10-25-114-npc-script5.md)에서 남긴 「주인공의 とびら 명령으로 23/00·18/00 문을 열 때 `7E:1E8E`」를 닫았습니다. 결과는 [dq5-map-format.md 「인라인 스크립트」](../docs/dq5-map-format.md#인라인-스크립트-01c800)의 `41`·`43` 줄에 있습니다.

## 1. 문 앞에 서기

23/00 의 문(속성 `C5`, (41,21))은 Y < `20` 이라 `01:DAEF` 의 조건에 맞습니다. 장면 이동 도구로 (40,26) 에 내려 위로 8프레임씩 늘려 가며 걷고, 명령 창에서 とびら(아래 세 번)를 골랐습니다.
문 칸 판정 `01:DA96` 은 (40,22) 에서 위를 볼 때만 한 번 돌았습니다.

## 2. 늘 거절

(40,22) 에서 とびら 를 고르니 `01:DADB` → `01:DAEF` → `01:DAF5`(n = 1 이면 PLA PLA CLC)를 지나 「その方向には　トビラがない！」가 떴습니다. `7E:1E8E` 를 `SET`·`LATESET` 로 `00`·`02` 로 써 두거나 `POKE` 로 매 프레임 써도 판정에서는 `01` 이었고 결과가 같았습니다.
쓰기 감시(`7E:1E8C-1E8E`, `00:1E8C-1E8E`)에는 아무 쓰기도 걸리지 않았습니다.

`ROMPATCH="DAF3=80"`(`BNE` → `BRA`)으로 이 거절을 건너뛰자 같은 자리에서 문이 열려(셀 (40,19) `+2` `5D` → `57`, (41,21) `+5` `27` → `00`) 화면의 문이 검게 열렸습니다.
인물 스크립트의 `41` 은 `01:D915` 로 바로 가서 이 판정을 지나지 않으므로 같은 문을 열 수 있습니다(앞 일지). 23/00·18/00 의 위쪽 문은 이야기 진행에 맞춰 인물·이벤트만 여는 문입니다.

## 남은 것

- 판정 때 `7E:1E8E` 를 `01` 로 두는 곳(쓰기 감시에 걸리지 않음), `01:ED05` 가 쓰이는 문 — 해결됨: `01:D9CE` 가 미러 주소로 씀, `C4` 문에서 `01:ED05`([dq5-map-format.md](../docs/dq5-map-format.md) 「인라인 스크립트」)
