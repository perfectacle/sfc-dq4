# 2026-10-26-52: 이벤트 07~0B·14 를 부르는 곳, 1A/02 의 パパス 에게 말 걸기

일지들의 「남은 것」 을 문서와 맞춰 보다가 두 가지를 다시 쟀습니다. [dq5-event-format.md](../docs/dq5-event-format.md) 가 「부르는 곳이 없어 쓰지 않는 칸」 으로 둔 16칸 가운데 07~0B·14 는 쓰이는 칸이었고, [2026-10-25-139](2026-10-25-139-event8.md) 의 「1A/02 의 パパス 에게 말을 걸 수 없음」 은 서는 자리 탓이었습니다.

## 1. LDA #n / BRA 로 모이는 호출

앞서 부르는 곳은 `LDA #n / JSL $23E2F4`, `TDC / JSL`, 받침 루틴(`JSL / RTL`)을 `LDA #n / JMP` 로 부르는 꼴로 찾았습니다. `JSL $23E2F4` 바로 앞으로 `BRA` 하는 `LDA #n` 을 더 찾자 여덟 곳이 나왔습니다(`dq5event.py` 에 이 꼴을 더함).

```
06:CBA4  LDA $C2 / CMP #5 / BCC → 08 / BEQ → 09 / CMP #7 / BCC → 0A / BEQ → 0B / CMP #9 / BCC → 0C / 나머지 07
         LDA #n / BRA CBD0 ; CBD0 JSL $23E2F4
29:8231  LDA $C2 / CMP #1F / BEQ → 18 / CMP #10 / BNE 끝 / LDA #14 / BRA → JSL $23E2F4
```

`06:CBA4` 는 01/05 의 パパス 가 납치 소식을 들은 뒤 부르는 네이티브이고, (42,8)·(44,8) 에서 시작한 장면에서 `23:E2F4` 에 A = `0C` 가 들어왔습니다([2026-10-26-25](2026-10-26-25-papas21a1.md)). `29:8231` 은 06/05 의 プサン(목록 `10:AAC3`, `21AC.1` 대체 목록)의 스크립트가 `21D5.7` 이 꺼져 있을 때 부릅니다. `dq5warp.lua` 로 `SET="21AC|02"` 를 두고 06/05 에 들어가며 `23:E2F4` 에 실행 감시를 걸었습니다.

| 들어간 Y | 도착 칸 | 388 프레임 `23:E2F4` |
| --- | --- | --- |
| 16 | (22,29) | A = `14`, `$C2` = `10` |
| 31 | (22,29) | A = `18`, `$C2` = `1F` |

들어설 때의 Y 로 고르고, 번호 `14` 는 오른쪽 8·아래 13·왼쪽 8 칸, `18` 은 위 2 칸을 걸은 뒤 `21A1.7` 을 켭니다. 이제 쓰지 않는 칸은 `FF` 뿐인 `1D`·`1E`·`2E`~`33` 과 `3E`·`4D` 의 10칸입니다.

## 2. 1A/02 의 パパス

`SET 2195|0C` 로 1A/02 (10,11) 에 내려 오른쪽을 보고 A 두 번(명령 창 → はなす)을 누르자 124 프레임에 메시지 `77F`「パパス「待たせたな…」, 259 프레임에 `06:BD7F` → `06:BD94` 가 불렸고, 주인공과 パパス(슬롯 `0A`)가 함께 오른쪽으로 걸었습니다. 앞서는 (11,11), 곧 パパス (12,11) 바로 옆에서 걸었습니다. 가로로 말을 걸 때는 두 칸 떨어져야 합니다.

## 틀렸던 것들

- 「번호 `07`~`0B`·`14` 는 부르는 곳이 없어 쓰지 않는 칸」(dq5-event-format.md): `LDA #n / BRA` 꼴을 찾지 않아 놓쳤습니다.
- 「1A/02 의 パパス 에게 말을 걸 수 없다」(2026-10-25-139): 옆 칸에서 걸었기 때문입니다.
