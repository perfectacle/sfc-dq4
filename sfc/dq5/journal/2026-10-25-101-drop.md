# 2026-10-25-101: 떨어뜨리는 물건 표

몬스터가 떨어뜨리는 물건과 확률을 뽑는 도구를 만들고, 판정 루틴의 디버그 갈래를 실측했습니다. 결과는 [dq5-data-format.md 「몬스터」](../docs/dq5-data-format.md#몬스터-238000) 의 필드 `75` 줄에 있습니다.

## 1. 도구

`sfc/dq5/tools/dq5drop.py` 는 몬스터 레코드 바이트23(필드 `75`, `FF` 면 없음)과 바이트9 bit3-5(필드 `74`)로 `27:8218` 의 N(1·8·16·32·64·128·256·4096)을 찾아 적습니다. 떨어뜨리는 물건이 있는 몬스터는 220종입니다.

```
00 スライム やくそう(A1) 1/16
02 せみもぐら やくそう(A1) 1/8
```

## 2. 판정 루틴

전투 뒤 `25:8956` 은 `$1116`(떨어뜨릴 후보 몬스터, `FF` 면 없음)을 보고, 필드 `78` 이 그 몬스터인 슬롯을 찾아 필드 `74` 로 N 을 고른 뒤 난수(`00:953E`)가 0 이면 필드 `75` 를 상자로 떨어뜨립니다. `20:A363` 은 쓰러뜨린 몬스터가 앞의 후보와 다르면 `$1116` 을 `FF` 로 합니다(코드 읽기).
그 앞에 `20:8000` bit5 를 보는 갈래가 있어, 선실 → 슬라임 이벤트 전투에서 슬라임 등급을 7(1/4096, 바이트9 = `3F`)로 두고 비교했습니다.

| `20:8000` | 결과 |
| --- | --- |
| `00` | 상자 없음 |
| `20` | 「たからばこを おとしていった」 → 「やくそうを みつけた」 |

가진 물건이 가득할 때의 처리는 [2026-10-25-89](2026-10-25-89-aicond2.md) 에서 본 대로입니다.

## 남은 것
