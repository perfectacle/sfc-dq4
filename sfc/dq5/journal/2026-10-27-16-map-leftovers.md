# 2026-10-27-16: 맵 문서의 코드 읽기 넷을 게임으로

[dq5-map-format.md](../docs/dq5-map-format.md) 의 「남은 것」 은 비어 있지만, 본문에 「코드 읽기」 로만 적힌 줄이 남아 있었습니다. 그중 장면을 만들 수 있는 넷을 쟀습니다. 문 잠금 종류 4·5·6·7·9·10·12, 01/00 ドラゴンキッズ 의 메시지, 31/07 ばくだんいわ 전투 뒤 플래그, 시대가 다른 집이 함께 쓰는 タンス 입니다.

## 1. 문 잠금

`dq5warp.lua` 로 문 앞에 서서 とびら 를 고르고, 메시지 루틴 `24:8BAF` 의 A 와 문 열기 `01:DFAB` 실행을 `dq5seqtrace.lua` 로 기록했습니다. 열쇠는 `SET 2056=<물건>`(주인공 첫 칸), 플래그는 `SET` 으로 넣었습니다.

| 잠금 | 선 자리 | 결과 |
| --- | --- | --- |
| 4 | 04/00 (26,62) 위 | 없음 `21B`, `2196.5` 189, `21E6.4`·`2198.6` 열림 |
| 5 | 04/03 (29,68) 아래, 밤 | 열림, `21E6` = `10` |
| 6 | 01/04 (48,2) 위 | 없음 187, `B8` 188, `C9` 열림 |
| 7 | 33/00 (35,70) 위 | 없음 `2FA`. `21BF.6` 이면 `2FA`·`013`·`2FB`, `03:8E86`, 열림, `2FC` |
| 9 | 00/00 (7,12) 위 | 없음 187, `B8`·`B9`·`2199.1` 188 |
| 10 | 32/00 (24,71) 위 | 없음 `2EC`, `21E6.3` 열림 |
| 12 | 32/02 (24,50) 위 | 없음 188, `21E6.3` 열림 |

큰 문(종류 `42`)은 표의 좌표와 선 자리가 달랐습니다(04/00 (26,58) 은 (26,62), 32/00 (24,67) 은 (24,71), 32/02 (24,48) 은 (24,50) 에서 위로). 04/03 은 낮에 들어가면 주인공이 보이지 않고 움직이지도 않아, 밤(`POKE 7E075E=F8`)으로 들어가 아래로 걸어 문 앞에 섰습니다.

## 2. 01/00 의 ドラゴンキッズ

`06:D1CA` 가 띄우는 메시지를 `0ED`「そんなことを　いったら…」로 적어 두었는데, 화면에는 「ガルルー！」가 떴습니다. `SET 2190|40` 으로 (30,30) 층 2 에 선 세이브스테이트에서 슬롯 `11` 을 (31,30) 으로 옮기자 3프레임에 `24:8BAF` A = `2ED`(「ガルルー！」), 46프레임에 `01:86C3` A = `11` 이었습니다.

## 3. ばくだんいわ 와 싸운 뒤

31/07 의 슬롯 `0C` 를 (36,15) 로 옮기면 ばくだんいわ 와 싸웁니다. 몬스터 `62` 의 HP 아래 바이트(파일 오프셋 `118995`)를 `01` 로 덮고 A 를 눌러 이기자 경험치 120 을 받고 1558프레임에 `21F8` = `01` 이 되었습니다. HP 를 그대로 두고 にげる 를 고르며 버티자 31/01 에서 「おい　大丈夫かい？」(메시지 `3ED`)로 이어졌고 `21F8` 은 0 그대로였습니다.

## 4. 시대가 다른 집의 タンス

`12:FBFD` 는 내용물이 `44` 이고 그룹 21 이면 `21E2.4`, `B0` 이고 그룹 1F 이면 `21E2.2` 를 보고 켜져 있으면 빈 것으로 칩니다. 표에서 그 내용물을 찾으니 21/0B·21/0D (25,4) 의 ておりのケープ 와 1F/05·1F/0A (10,9) 의 かしこさのたね 였습니다. 같은 집의 다른 시대 맵입니다.

```
21/0B (24,5) しらべる          12F 12E 132 → 21E2=10 2234=01
21/0B, SET 21E2|10             12F 130「とくに　何も　見つからなかった。」
1F/05 (9,10) しらべる          12F 12E 132 → 21E2=04 2233=08
1F/05, SET 21E2|04             12F 130
```

한쪽 시대에서 꺼내면 다른 시대의 같은 タンス 는 비어 있습니다.

## 틀렸던 것들

- 「`06:D1CA` 의 메시지 `0ED`」: 실제로 띄우는 것은 `2ED` 였습니다.
