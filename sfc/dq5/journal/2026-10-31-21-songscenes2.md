# 2026-10-31-21: 장면을 못 찾았던 짧은 곡과 즉위식·엔딩의 15

[2026-10-27-48](2026-10-27-48-songscenes.md) 에서 장면을 찾지 못한 곡이 `1B`·`1C`·`24`·`2A`·`2C`~`2F` 였고, `15` 의 즉위식·엔딩은 코드로만 읽었습니다. 부르는 곳을 다시 모아 그 코드에 닿는 장면을 찾고, 모두 헤드리스로 띄워 곡 번호를 쟀습니다. `1B`·`2F` 는 이번에도 부르는 곳이 없었습니다. 결과는 [dq5-sound-format.md 「곡 이름」](../docs/dq5-sound-format.md#곡-이름)의 장면 표에 넣었습니다.

## 1. 부르는 곳에서 장면으로

`LDA #n` 바로 뒤 `JSL 24:FE9A`·`JSL 25:FD00`, `BRK 0F n`·`BRK 11 n`, `21DF` 쓰기를 롬 전체에서 다시 모으고, 앞뒤를 디스어셈블해 코드인 것만 남겼습니다. 그다음 그 코드를 누가 부르는지 거슬러 올라갔습니다. 대화 스크립트의 네이티브 호출(`00 lo hi`), 인물 인라인 스크립트의 네이티브 호출(`37 lo hi bank`), 필드 물건 처리기 셋 가운데 하나에 닿았습니다.

```
1C  05:F00A(메시지 5D9 「…が 仲間に くわわった！」 뒤 25:FD00)  ← 대화 1B3·170·24D 의 네이티브 06:F646·B4B1·B45C
24  06:F792 BRK 0F 24                                          ← 대화 1F6(ビアンカ)·1FF(フローラ)의 はい 갈래
2A  03:94E4 BRK 0F 2A  ← 06:CB29                               ← 22/00 대체 목록 인물 05:C848 의 37 29 CB 06
2B  11:8DD4 LDA #2B / JSL 25:FD00                               ← ようせいのホルン 처리기 11:8D93
2C  03:ABA4 BRK 11 2C  ← 11:8DCD                                ← 같은 처리기, 맵 50/51 이고 $C1 10~2D·$C2 28~43 일 때
2D  23:E4ED LDA #2D / JSL 25:FD00                               ← 08/00 대체 목록(219A.7) 인물 10:AFF2 의 37 ED E4 23
2E  03:BDD0 BRK 0F 2E  ← 12:ECB6 ← 06:D3E8                      ← 10/02 인물 05:A323 의 37 E8 D3 06
15  25:FED1 BRK 0F 15  ← 25:FEBB                                ← 02/06 대체 목록(21A8.3) オジロン 10:98AE
    02:F6FF LDA #15 / JSL 24:FE9A                               ← 02/06 엔딩 목록(2190.7) 인물 10:9B81
```

`1B`·`2F` 의 `00 0F n`·`00 11 n` 꼴은 뱅크 `1D`·`1E`·`2E` 의 그림 자료 안에 있었고, 즉값으로 부르는 곳도 없었습니다.

## 2. 게임에서 띄우기

새 검사 도구 `dq5songscenecheck.py` 가 아홉 장면을 띄웁니다. 대화 장면은 배 선실 パパス 의 대화 번호를 바꿔 `dq5msg.lua` 의 `CALLS=24FE9A,248157` 로, 순간이동 장면은 `dq5songtrace.lua` 로 쟀습니다.

```
join      1C  메시지 5D9 뒤 289프레임(25:FD07)
bride     24  메시지 980 뒤 519프레임, 그다음 맵 곡 06
horn-ship 2B  메시지 1C7 「ようせいのホルンを 吹いた！」 뒤 222프레임, 끝에 「しかし ここでは 何も おこらなかった！」
horn-5051 2C  맵 곡 0D 뒤 899프레임(03:ABA4)
flute     2A  ベラ 의 메시지 269 뒤 1189프레임(03:94E4)
queen     2D  맵 곡 09 뒤 414프레임, 이어 메시지 268 「…女王は 怪物に 姿を 変えた！」
stone     2E  메시지 2F1 에 はい 뒤 870프레임(03:BDD0), 끝나면 맵 곡 09 로 돌아감
crown     15  オジロン 의 3D8 「その王座に すわるがよい」 뒤 (38,9) 로 걸어가 2422프레임(25:FED1)
ending    15  엔딩 목록 인물이 219F.6 을 기다려 416프레임(02:F6FF)
9장면 곡 확인 통과
```

`join` 은 대화 1B3 의 조건을 맞추지 못해, 대화 스크립트 012 를 네이티브 `06:F646` 부르기 하나로 바꾼 롬(`dq5talkwrite.py`)으로 쟀습니다. 대화 170 의 `06:B4B1`, 24D 의 `06:B45C` 도 같은 롬 꼴로 1C 가 나오는 것을 손으로 확인했습니다. `bride` 는 실제 대화 1F6 을 그대로 썼고, 1FF 도 손으로 같은 결과였습니다.

전투 뒤 슬라임이 동료가 될 때(`dq5tablecheck.py` 의 동료 장면, 전투 메시지 `0A4`·`0A5`)는 곡을 틀지 않았습니다. 그래서 1C 는 사람이 일행에 들 때의 곡입니다. 교회에서 기록할 때는 원래 표대로 `20` 이었습니다.

## 3. 곡명

남은 곡명은 街は生きている·はめつの予感·哀愁物語·高貴なるレクイエム 입니다. 새로 찾은 `1C`·`24`·`2A`~`2E` 는 모두 장면 끝에 맵 곡으로 돌아가는 짧은 곡이라 이 넷과 맞지 않습니다. `15` 는 즉위식과 엔딩 둘에서 울리는 긴 곡이지만, 남은 곡명 넷 가운데 하나로 정할 근거가 장면에 없어 빈칸으로 두었습니다. 판정은 확정 13·추정 6·빈칸 31 그대로입니다.

## 틀렸던 것들

- 처음 즉위식에서는 オジロン 의 말을 넘기려고 A 를 너무 많이 눌러, 3D8 뒤 명령 창이 열린 채로 걸으려 했습니다. B 로 창을 닫고 나서 걷게 했습니다. 걸음은 한 칸 8프레임이라 `right:112` 는 일곱 칸이 아니라 열네 칸이었습니다.
- 순간이동 장면에서 대체 목록을 고르는 플래그와 인물이 기다리는 플래그를 둘 다 `SET` 으로 켜자 2D 가 나오지 않았습니다. 기다리는 플래그는 들어선 뒤(`LATESET`) 켜야 했습니다.
