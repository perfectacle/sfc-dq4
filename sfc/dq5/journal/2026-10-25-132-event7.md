# 2026-10-25-132: 신전·カボチ 대화, 직접 호출의 자리, 네이티브 셋

[2026-10-25-120](2026-10-25-120-event6.md) 에서 남긴 것을 닫으러 갔습니다. 청년기 신전·カボチ 단계의 대화, `02:B705` 직접 호출 셋의 원래 자리, 네이티브 `1E:DDFF`·`02:81DB`·`02:E463`, `C4`·`C5` 셋째 바이트입니다. 결과는 [dq5-flags.md 「청년기 사건 순서」](../docs/dq5-flags.md#청년기-사건-순서) 와 [dq5-event-format.md 「원래 맵에서 걸기」](../docs/dq5-event-format.md#원래-맵에서-걸기) 에 있습니다.

## 1. 신전 08E·カボチ 17A

지난번에는 이 둘만 창이 보이지 않았습니다. 이번에는 선실 세이브스테이트에서 パパス 의 대화 번호를 바꿔 걸고, 메시지 루틴 `24:8BAF` 의 A 와 화면을 함께 보았습니다. 여덟 갈래 모두 대화 스크립트대로 골라졌고 창도 떴습니다.

```
08E  플래그 없음        82E 「ヘンリー「どうしようもないな。…」
     21BB.5             82F 「ヘンリー「しかし　いつまで ここに　入れておく気かなあ。…」
     21BB.5 + 21B0.4    2BF 「ヘンリー「いったい　なんだろう？ おい　いってみようぜっ。」
17A  플래그 없음        8E3 「おお　あんたは！ オラだよ！ ほれ　ポートセルミで。」
     21B2.4             8E5 「あんたを信用した　オラの目に くるいは　なかっただな！」
     21B2.6             8F5 「話は　聞いただ……。 あんたは　化け物と グルだったんだってな。」
     21B2.6 + 2190.5    B20 「おや？　お客さんだよ。…」
```

신전 쪽 ヘンリー 의 말은 `21BB.5` → `21B0.4` 순서로 바뀌고(앞 두 갈래가 각각 그 비트를 켬), カボチ 에서 「化け物と グル」라는 갈래를 고르는 것은 `21B2.6` 입니다. 지난번에 창이 보이지 않은 까닭은 따로 가리지 않았습니다.

## 2. 1E:DDFF 는 아이의 말

이벤트 5(01/05)에서 `1E:DDFF` 가 띄우는 것은 메시지 `4F6` 이었습니다. `BRK 0B 04 42` 로 `21D2.2` 를 보고, 꺼져 있으면 「アニー」, 켜져 있으면 「クーパー」가 같은 말을 합니다. 말하는 사람 이름만 고르는 갈래입니다.

## 3. 직접 호출 셋의 자리

- `06:BD94`: 대화 `029`, アルカパ 여관의 パパス 입니다. レヌール城 를 치운 뒤(`2195.2`) 「さて　そろそろ サンタローズの村に 帰ることにしよう！」 다음에 `06:BD7F` 가 `21AF.6` 을 켜고 번호 `01` 을 겁니다. 선실에서 대화 `029` 로 걸어 이 길을 확인했지만, 1A/02 에서는 パパス 를 찾지 못했습니다.
- `02:81D1`: 그룹 `32` 의 장치입니다. 32/00 탑 꼭대기에서 `$1A38` 을 켜고 아래를 누르자 주인공이 (25,4) 로 걸어 32/09 의 방으로 옮겨졌습니다. 네이티브 `02:81DB` 가 `03:B351`·`12:8B3E`(A = `00`)를 부르고 일행 슬롯의 층 마스크 `7E:31A0` 을 `$C3` 으로 채우는 것은 코드에서 읽었고, 일행이 주인공 하나라 화면에서는 달라지는 것이 없었습니다.
- `02:E57B`: 앞 칸 속성이 `E3` 일 때 걷기 처리가 부르는 방 격자 문입니다. 15/01 에 가 보았지만 `E3` 칸을 밟지 못했습니다.

## 4. C4·C5 셋째 바이트

01/00 의 성문을 셋째 바이트 `01`·`02`·`04` 로 열어 셀 버퍼 쓰기를 모두 잡았습니다. 116개가 바이트까지 같았습니다. 이 값을 읽는 곳은 23/00·18/00 만 따로 다루는 `01:DAEF` 와, 이 문을 열 때는 지나지 않는 `01:ED05` 둘뿐이었습니다.
