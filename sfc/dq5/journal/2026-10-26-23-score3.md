# 2026-10-26-23: 판각 악보를 verovio 로

[2026-10-26-20](2026-10-26-20-score2.md) 에서 직접 그린 시간 비례 SVG 를 fc/dq4 트랙과 같은 verovio 판각 악보로 바꿨습니다. 결과는 [dq5-sound-format.md](../docs/dq5-sound-format.md) 의 「악보 내보내기」 에 있습니다.

## 1. verovio 를 쓸 수 있는지

앞 일지에서는 verovio 의 Python 3.15 휠이 없어(6.2.1 까지 cp314) 쓰지 못한다고 보았습니다. 그런데 `fc/dq4/tools/dq4score.py` 가 이미 verovio 로 SVG 를 그리고 있었고, 저장소 `pyproject.toml`·`uv.lock` 에 verovio 6.3.0 이 sdist 로 들어 있었습니다. `uv sync --locked` 뒤 `import verovio` 가 되었습니다(`6.3.0-425dd7b`). 새 의존성은 없습니다.

## 2. 그리기

`dq4score.py` 의 `svg_pages` 와 같은 설정(쪽 2100x2970, 크기 40, `xmlIdSeed` 1)으로 우리 MusicXML 을 그렸습니다. 셋잇단 묶음 표시가 없는 우리 MusicXML 도 그대로 읽혔습니다. 가운데 음이 60 아래인 트랙은 낮은음자리표로 바꿨습니다.

```
02.musicxml  4쪽   4.2초
0F.musicxml  63쪽  12.2초
37-05        1쪽
193벌 모두   644쪽, 한 프로세스로 11분 32초
```

느려서 `--jobs` 프로세스로 나눠 그리게 했습니다(여덟이면 2분 35초). 프로세스 여덟로 낸 결과가 한 프로세스로 낸 결과와 파일마다 바이트까지 같았습니다.

## 3. 파일

`<줄기>-score-NN.svg`(쪽 번호 두 자리)로 fc/dq4 와 같은 이름 꼴입니다. `index.json` 의 `score.svg` 는 쪽 파일 목록이고, 들어 보기 페이지는 「악보(n쪽)」 로 첫 쪽에 링크합니다. 앞의 시간 비례 `.svg` 는 없앴습니다.

## 틀렸던 것들

- verovio 를 휠이 없어 못 쓴다고 보았습니다. 저장소 lock 이 sdist 로 빌드해 이미 쓰고 있었습니다.

## 남은 것

- 박자를 들어서 정하기, MusicXML 셋잇단 묶음.
