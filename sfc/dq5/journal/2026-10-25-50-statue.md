# 2026-10-25-50: 석상에서 반지 빼기와 셀 비트 대조 실험

[2026-10-25-43 일지](2026-10-25-43-field5.md) 의 석상 루틴 `06:DADB`·`24:A981` 을 실제로 돌려 보고, 셀 비트를 성 안뜰 가장자리에서 지워 보는 대조 실험을 했습니다. 결과는 [dq5-field-format.md](../docs/dq5-field-format.md) 의 「순간이동 칸」과 [dq5-map-format.md](../docs/dq5-map-format.md) 의 「셀 버퍼」에 있습니다.
이벤트 스크립트([dq5-event-format.md](../docs/dq5-event-format.md))는 이 트랙의 다른 세션이 이어 맡습니다.

## 1. 석상에서 반지 빼기

52/50 어른 시절 장면을 `SET="2190|40;21D9=9E"` 로 만들고 (26,21) 에서 위로 한 칸 걸어 석상 앞 (26,20) 에 섰습니다. 메시지 번호(`24:8BAF`)와 루틴 호출, 물건 칸 쓰기를 적었습니다.

```
939 06DADB A=D09E X=0009
940 248BAF A=04D2        「女神像の指に ほのおのリングが はめられている。ほのおのリングを はずしますか？」
1100 2058 pc=21:9DE4 v=9E
1100 248BAF A=0132       「あああああは ほのおのリングを 手に入れた。」
1260 24A981 X=0009
1260 21D9 pc=06:DB3F v=00
```

はい 를 고르자 반지가 물건 칸 셋째(`7E:2058`)로 돌아왔고, 이어 `24:A981` 이 불린 뒤 석상 손가락의 붉은 점이 화면에서 사라졌습니다.

## 2. 셀 비트 대조 실험

01/00 의 안뜰 남쪽 가장자리는 (x, 37) 줄이 `+1` = `0A`(층 2, 가려짐)·`+0` bit3, (x, 38) 줄이 `+1` = `0A` 입니다. `TO=01/00,40,35,2` 로 서서 아래로 1~3칸 걷는 동안 매 프레임 셀 비트 하나를 지우고, 지우지 않은 쪽과 화면을 비교했습니다.

```
지운 비트          (40,36)  (40,37)            (40,38)
+0 bit3            같음     같음               같음
+1 bit3            -        주인공이 성벽 위로   주인공이 성벽 위로
+1 bit4-6          -        같음               다른 인물 쪽만 다름
```

`+1` bit3 이 「위층에 가려짐」이라는 것은 이 방법으로 바로 보였지만, `+0` bit3 과 `+1` bit4-6 은 주인공 화면에 드러나지 않았습니다.
이동 판정 `00:AC57` 의 `+1 & $98` 에서 `$98` 은 걸을 때 `0E`·`0F` 였으니 bit4-6 은 여기서도 보지 않습니다.

## 남은 것

- `24:A981` 이 석상 그림을 바꾸는 방법
- 셀 `+0` bit3·`+1` bit4-6 의 뜻(인물 이동 쪽, 특수 바닥 맵)
- `$194A` bit7(마차가 있는 장면)
