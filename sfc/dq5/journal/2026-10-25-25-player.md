# 2026-10-25-25: 주인공이 주문·도구를 쓰는 전투

어린 주인공이 전투에서 주문을 쓰게 하는 길을 찾아, 플레이어가 고르는 주문의 범위 비트와 전투 도구 플래그(k2 bit4~7)를 실측했습니다.
결과는 [dq5-data-format.md 「주문과 행동」](../docs/dq5-data-format.md#주문과-행동-268765)·[「물건 표」](../docs/dq5-data-format.md#물건-표-23b081) 에 있습니다.

## 1. 전투 명령 창을 고르는 곳

선실 → 슬라임 이벤트 전투에서 창 번호를 쓰는 `$0A00` 을 WRAM 쓰기 감시로 보니, 명령 창은 `BRK #95 87`(`20:90E3`)이었습니다. 그 앞 `20:8FEC` 가 필드 `45`(일행 수)를 읽어 1 이면 창 `87`(たたかう·にげる)로 가고, 아니면 `21:8014` 에 따라 `19`(たたかう·さくせん·にげる)나 `88`(たたかう·いれかえ·にげる)로 갑니다.

어른 일행이라서가 아니라 일행이 주인공 하나라서 たたかう·にげる 였습니다. たたかう 를 고르면 인물 창이 뜨고, `20:931A` 가 필드 `87` 이 0 이면 `1E`(こうげき·ぼうぎょ·どうぐ), 아니면 `1C`(こうげき·じゅもん·ぼうぎょ·どうぐ)를 엽니다.

## 2. 필드 87 과 주문 칸

필드 `87` 의 후처리 `21:9D21` 은 칸 8~19 를 돌며 `21:92BD` 로 비트를 세었습니다. 비트는 일행 레코드 `+23`·`+24`·`+25`(하위 4비트)에서 읽습니다(`21:9CA6`).
[2026-10-25-17](2026-10-25-17-encounter3.md) 에서 `+23` 을 켜면 필드 주문(칸 0~7)만 늘었던 까닭이 이것입니다.

장면 이동 도구로 전투를 만들 때 `SET="2064=01;2050=63;2044=63"`(칸 8, MP 99)을 주자 인물 창에 じゅもん 이 생겼고, 주문 목록에서 고른 주문은 ホイミ(`27`)였습니다(`20:AA98` 의 A). 주인공 주문 목록(`23:BDBD` → `23:BE30`)의 둘째 바이트입니다.
그 바이트를 メラ(`01`, 파일 오프셋 `11BE31`)로 덮어 주인공이 メラ 를 쓰게 했습니다. `+22`~`+27` 을 모두 `FF` 로 하면 주문 목록 창(`2B`)에서 멈췄습니다.

```sh
STATE=$PWD/work/state/ship.mss FIELD=341,56 BATTLE="00:3,03:2" \
  ROMPATCH="118001=00;118003=C8;11804C=00;11804B=C8" SET="2064=01;2050=63;2044=63" \
  SETTLE=300 SAVE=cast.mss SHOT_DIR=$PWD/work/b "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5warp.lua"
# 그 세이브스테이트에서: たたかう → じゅもん → 첫 주문
PRE="a:4,wait:60,down:8,wait:30,a:8,wait:60" LOOP="a:3,wait:40"
```

## 3. 플레이어 쪽 범위 비트

メラ 의 `26:8766` 만 바꿔 같은 입력으로 돌리고, 열린 창(`BRK #95` 의 번호)과 메시지를 적었습니다.

```
A2 (적 하나)    2B 4C … 070 069
C2 (적 그룹)    2B 4C … 070 069
E2 (적 전체)    2B    … 070 069
82 (적·자신)    2B    … 070 069
22 (우리 하나)  2B 4A … 070 06A
```

범위가 대상 고르기 창(`4C` 적 그룹, `4A` 우리 편)을 정하고, 맞는 수는 실행 루틴 표(`26:8865`, メラ 는 한 마리)대로였습니다. 「우리 하나」로 하면 주인공 자신이 メラ 를 맞았습니다.

## 4. 전투 도구 플래그

주인공 가진 물건 첫 칸(`7E:2056`)에 いかずちのつえ(`27`, k2 = `F0`)를 넣고 どうぐ → 첫 물건 → A 로 썼습니다. 「いかずちのつえを ふりかざした」「つえから いかずちが ほとばしる！」 뒤 세 마리가 맞았습니다.
k2 를 바꾼 결과입니다(파일 오프셋 `11B258`).

```
F0 / E0 (bit4 끔) / 70 (bit7 끔)   4C 창 → 069 069 069
B0 (bit6 끔)                       창 없음 → 069 069 069
D0 (bit5 끔)                       4A 창 → 06A (주인공이 맞음)
00                                 창 없음 → 06A
```

bit6 은 대상 고르기 창, bit5 는 적 쪽이었습니다. bit7 은 상점 설명 메시지에만 쓰이고, bit4 는 이 물건에서는 달라진 것이 없었습니다.

## 틀렸던 것들

- 전투 명령 창이 たたかう·にげる 뿐인 것을 「어린 주인공이라서」로 보고 어른 일행 장면을 만들려 했지만, 일행 수로 고르는 창이었고 주문은 인물 창에서 고르는 것이었습니다.
- k2 bit7 을 앞 일지에서 「전투에서 도구로 쓰면 효과」로 적었는데, 그것은 상점이 보여 주는 설명일 뿐이고 실제로 쓰는 것과는 관계없었습니다.

## 남은 것

- 어른 일행 장면(시대 전환 뒤의 일행 레코드), `21:8014` 가 고르는 창
- 마을 상점에서 k1 bit3 물건 팔기, 저주 메시지·벗을 수 없음
- k2 bit4 의 뜻, 몬스터 필드 `68`·`6D`·`6E`, 시작 상태 `39`
