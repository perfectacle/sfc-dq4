# 2026-10-25-110: 곡 명령의 반응과 세계별 필드 곡

[소리 명령과 맵 곡](2026-10-25-96-sound.md) 에서 남긴 명령의 뜻을 DSP 레지스터로 보고, 대기열 기다림(`24:FE44`)과 세계 1·2 의 필드 곡을 확인했습니다. 결과는 [dq5-sound-format.md](../docs/dq5-sound-format.md) 에 있습니다.

## 1. 소리를 녹음하는 대신 DSP 를 읽기

MesenCE Lua 의 `emu` 에는 오디오 녹음 함수가 없었습니다. `emu.memType` 을 모두 찍어 보니 소리 쪽은 `spcDspRegisters`·`spcRam`·`spcRom` 이었습니다. 그래서 `dq5sndlog.lua` 에 `DSP=1` 을 더해 프레임마다 주 음량·메아리 음량·8채널 ENVX 합·KON·KOF·FLG·채널 0 음량을 적었습니다.

```sh
LIBDIR=$(tools/lua/seqlib.sh "$(uv run --locked krpatch sfc lua)" work/warplib ../../sfc/dq5/tools/lua/dq5warp.lua)
mkdir -p work/s/bat
env LIBDIR=$LIBDIR STATE=$PWD/work/state/ship.mss FIELD=341,56 BATTLE="00:1" SETTLE=300 \
  TEST="wait:200,a:4,wait:30,a:4,wait:30,…" DSP=1 MAXF=1900 SHOT_DIR=$PWD/work/s/bat \
  "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5sndlog.lua"
```

```
1564 cmd=1A arg=A0 from=20:80DF
1564 cmd=01 arg=1F from=00:92A2
1566 … env=548 v0=0F,09
1578 … env=464 v0=09,05
1594 … env=596 v0=00,00
1602 mvol=5C,5C evol=00,00 env=254 … v0=10,18
```

승리 때 `1A A0`·`01 1F` 를 보내자 전투 곡의 채널 0 음량이 30프레임에 걸쳐 0 으로 줄고, 1602 에 새 곡이 다른 음량으로 시작했습니다. 전투 시작(`1A 01`·`0C 17`)과 선실 → 필드(`1A 02`·`01 02`)에서도 앞 곡이 끝난 뒤 KON 과 함께 새 곡이 시작했습니다.

## 2. 1A 와 01

맵을 불러오는 `00:CE9A` 는 곡 번호를 `00:CEAB` 에 넘기는데, 거기서 `$1D8B`(지금 올린 곡)와 같으면 `1A` 를 건너뛰고 늘 `01` 만 보냅니다. 그래서 `1A` 는 곡 자료 올리기, `01` 은 곡 틀기로 정리했습니다.

## 3. 기다림 24:FE44

`24:FE44` 는 대기열 칸 `$1D93`~`$1D91` 이 모두 `FF` 가 될 때까지 한 프레임씩 쉽니다. `probe/trace.lua` 로 들어오고 나가는 프레임을 재니, 효과음(`BRK 16 33`·`16 37`)은 다음 프레임에 나왔고 승리의 `BRK 0F 1F` 는 33프레임 머물렀습니다. 곡을 줄이는 동안 대기열이 다음 명령을 넘기지 않는 것입니다.

```
941 24FE44 A=0033 … 7E1D91=000E 7E1D93=000C
942 24FE79 …
1564 24FE44 A=001F … 7E1D91=0003 7E1D93=0000
1597 24FE79 …
```

## 4. 세계 1·2 의 필드 곡

`$1949` 를 매 프레임 고정하고 필드에 나가 맵을 불러올 때의 명령을 기록했습니다.

```
세계 0  444 cmd=1A arg=02 / cmd=01 arg=02
세계 1  448 cmd=1A arg=05 / cmd=01 arg=05
세계 2  448 cmd=1A arg=0E / cmd=01 arg=0E
```

마법 융단은 장면 이동 도구의 메뉴 입력(handoff 의 `TEST`)이 이번에는 「はなす」로 들어가 띄우지 못했습니다. 탈것의 곡은 명령 `1A` 를 보내는 자리(`01:82DD`·`01:BC87`·`01:BE38`·`01:C213`)만 적었습니다.

## 틀렸던 것들

- `01` 의 인자를 곡을 줄이는 프레임 수로 보았습니다. 맵을 불러올 때는 곡 번호와 같은 값을 보내고, `1A` 와 짝을 이루는 곡 틀기였습니다. 승리 때 33프레임 걸린 것은 대기열이 기다린 시간입니다.
