# 2026-10-25-55: 이벤트 스크립트 번호 표와 청년기 순서

[2026-10-25-47](2026-10-25-47-event.md) 에서 이벤트 표 `23:E2C2` 와 명령을 풀었습니다. 이번에는 이벤트 스크립트를 시작하는 다른 길인 스크립트 번호 표 `23:E325` 를 찾았습니다. 그다음 시작 주소를 모두 모아 스크립트를 직접 걸어 확인하고, 이야기 플래그 목록에 청년기 순서를 더했습니다. 주인공 パルプンテ 의 효과 32개도 모두 돌렸습니다.
결과는 [dq5-event-format.md](../docs/dq5-event-format.md), [dq5-flags.md](../docs/dq5-flags.md), [dq5-data-format.md 「전투 시작 때 쓰는 값」](../docs/dq5-data-format.md#전투-시작-때-쓰는-값) 에 있습니다.

## 1. 스크립트 번호 표

[2026-10-25-44](2026-10-25-44-flags2.md) 에서 이벤트 스크립트 시작 주소를 `LDA # / STA $19B3·$19B4·$19B5` 묶음으로만 찾았습니다. 빠진 길이 있는지 `STA $19B3` 18곳을 모두 보니, `23:E30B` 는 `LDA $E325,X` 로 표에서 읽은 값을 넣고 있었습니다. 그 앞 `23:E2F4` 는 A × 3 으로 표를 고릅니다.
롬에서 `LDA #n / JSL $23E2F4` 를 찾으니 50곳 남짓이었고, 가장 큰 번호가 `52` 였습니다. 표 `23:E325` 를 83칸으로 읽으면 앞 79칸이 `15:F0xx`~`F7xx` 를 가리키고, `1A`·`1B`·`1C`·`3C` 는 `23:E41E` 를 가리킵니다. `23:E41E` 를 스크립트로 읽으면 두 번째 바이트에서 모르는 명령 `F3` 이 나와 코드로 보았습니다.

부르는 곳은 거의 모두 뱅크 06 이었습니다. 대화 스크립트의 네이티브 호출 대상이 모인 곳이라, 사람과 이야기하면 그 대화가 이벤트 스크립트를 거는 구조로 보입니다. `TDC / JSL` 로 0 번을 부르는 곳(`06:C50B`·`06:C927`)도 있었습니다.

## 2. 모두 모으기

`dq5event.py` 에 번호 표, 이벤트 표, 코드 안 묶음, `C3` 점프를 시작점으로 따라가는 `--starts`·`--list` 를 더했습니다. 겹치는 것을 빼면 스크립트 98개, 명령 970개이고 모르는 명령은 없었습니다.
`dq5flags.py` 의 이벤트 스크립트 출처도 이 목록을 쓰게 바꿨습니다. 그러자 이벤트 스크립트에서 다루는 플래그가 33개에서 70개(참조 260개)로 늘었습니다. 켜는 곳이 없는 비트는 38개에서 30개로 줄었습니다.

## 3. 직접 걸어 확인

장면마다 조건을 갖추는 대신 스크립트를 직접 걸었습니다. 21/00 에 선 뒤 `LATE` 로 `$19B3`~`$19B5` 에 시작 주소, `$19AE` 에 `80` 을 넣고, 명령을 읽는 `00:BED2` 에서 `$80` 을 찍었습니다.

15:F763  15F763 15F764 15F768 …                 (91 이 1바이트)

실행된 주소가 모두 `dq5event.py` 가 나눈 명령 경계와 같았습니다. 이벤트 1 은 `B0 12 40` 에서, 번호 10 은 `B0 11 40` 에서 멈춰 플래그를 기다렸습니다.

## 4. 청년기 순서

켜는 곳이 대화인 비트를 대사 흐름으로 늘어놓아 14단계 표를 만들었습니다. 순서는 신전 노예 생활 → 수도원 → オラクルベリー → サンタローズ 폐허 → カボチ → サラボナ → 山奥の村 → 신부 고르기 → グランバニア → マスタードラゴン 입니다.
맵 그룹 이름(03 신전, 29 수도원, 20 オラクルベリー, 1B カボチ, 1F サラボナ, 23 山奥の村, 02 グランバニア, 00 テルパドール)은 모두 대사로 붙였습니다. 게임으로 확인한 것은 신부 플래그 `21B3.3` 뿐이라 나머지는 「문맥」입니다.

## 5. パルプンテ 32개

[2026-10-25-44](2026-10-25-44-flags2.md) 의 방법(주인공 주문 목록에 パルプンテ, `20:C0EF` 를 `A9 nn EA EA` 로 덮어 효과 고정, 무작위 전투)으로 `00`~`1F` 를 모두 돌려 화면을 찍었습니다.

```
02 スライムの　MPが　なくなった        0D スライムは　くだけちった
12 やまのように　おおきな　まじんが…  13 おおきな　りゅうに　すがたをかえた
16 てんくうから　りゅうせいが…        1A スライムは…メタルスライムに　なってしまった
```

`00`·`15`·`1C`~`1F` 는 「こえは　やまびことなって…ひびきわたった」(아무 일 없음)였습니다. `00`·`1F` 는 루틴이 `20:E368` 하나지만, `15`·`1C`~`1E` 는 루틴이 따로 있어 조건이 맞지 않았던 것으로 보입니다.
