# 2026-10-26-38: 고정 시퀀스 곡의 샘플과 ミルドラース 둘째 모습의 HP

[2026-10-26-34](2026-10-26-34-repro.md) 의 남은 것 가운데 둘을 닫았습니다. 결과는 [dq5-sound-format.md](../docs/dq5-sound-format.md) 의 「곡 자료」 와 [dq5-data-format.md](../docs/dq5-data-format.md) 의 「몬스터」 에 있습니다.

## 1. 곡 17 은 2B:C1AE 를 타지 않음

대기열 처리기 표(`2B:C43B`)에서 명령 `01` 의 처리기 `2B:BF2B` 를 16비트로 다시 풀고, 갈래마다 `EXEC` 를 걸어 `01 15`·`01 17` 을 견줬습니다(`FULLSET` 을 준 `dq5spcdump.lua` 를 드라이버로).

```
곡 15  14 BF6F·BF84(대답 80) → BF98·BF9D → C1AE → 30~106 샘플 보냄 → 182 BF57(대답 40) → C1BA
곡 17  14 BF57·BF64·BF6B(대답 C0) → BF98·BFA3 → C1BA → C20C(0개)
```

`$2140` 의 대답(`$08D8`) bit6 은 「시퀀스가 SPC 에 있음」 이고, 곡 17 은 전원을 켤 때 `93` 으로 올리는 고정 시퀀스라 처음부터 켜져 있습니다. 그래서 시퀀스와 「곡 앞」 샘플을 보내는 `2B:C1AE` 를 건너뛰고 「곡 뒤」 샘플을 보내는 `2B:C1BA` 로만 갑니다. 곡 묶음 둘째 바이트(「곡 앞」 수)를 샘플 수로 바꾸는 `FULLSET` 아래에서는 「곡 뒤」 가 0개라 아무것도 보내지 않았습니다.
`FULLSET` 없이 `01 17` 만 보내자 `2B:C1BA` 의 고리(`2B:C1E3`)가 14·103·210·228·278·292 프레임에 「곡 뒤」 여섯을 보냈고, 300 프레임 뒤 SPC 색인 `03FF` 에 여덟 샘플이 모두 있었습니다. `2B:C20F` 는 고리 안에서 대기열 칸이 `FF`(명령이 끝남)면 보내기를 그만두는 검사이고, 곡 17 에서는 고리에 들어가지도 않았습니다.

## 2. E8 과 4500

필드에서 `GROUP=2F` 로 전투를 붙이며 `7E:07C0`~`07C3` 쓰기를 감시했습니다. 612 프레임에 `26:814B` 가 `07C0` 을, `21:912B` 가 `07C2`·`07C3` = `94 11`(4500)을 썼습니다.
`26:8138` 은 무리 몬스터가 `EA` 면 `00:953A`(A = 3)로 0~2 를 뽑아 `E8` 을 더합니다. 난수 상태 `7E:075B`~`075D` 를 `SET` 으로 여덟 가지로 바꾸자 `EA` 넷·`E9` 둘·`E8` 둘이었습니다. 셋 다 이름은 ミルドラース 이고 민첩·공격만 다릅니다. 앞 일지에서 `E8` 을 본 것도, [2026-10-26-31](2026-10-26-31-bossfade2.md) 에서 `EA` 를 본 것도 이 난수의 결과입니다.
HP 는 필드 `55` 를 읽는 `21:A2FA` 갈래가 `07FE` 를 `1194` 로 바꾼 값입니다(`21:A30C` 를 A = `07FE` 로 지남). 같은 갈래가 `07FD` 는 9000, `07FC` 는 3000 으로 읽습니다. 레코드 HP 가 2046 인 몬스터는 ゲマ·ブオーン·イブール·ミルドラース 둘째 모습 셋, 2045 는 エスターク 입니다.

## 틀렸던 것들

- 곡 17 의 샘플이 빠진 것을 「`2B:C20F` 가 대기열 칸을 `FF` 로 보아 건너뜀」 으로 보았습니다. `FULLSET` 이 모든 샘플을 「곡 앞」 으로 옮겼는데, 고정 시퀀스는 그 묶음을 보내는 `2B:C1AE` 를 지나지 않는 것이었습니다.
