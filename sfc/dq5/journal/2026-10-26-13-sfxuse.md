# 2026-10-26-13: 효과음을 부르는 곳 전부와 동굴 전투 곡

효과음 21개(`32`~`46`)의 137갈래가 게임 어디서 나오는지 모았습니다. 지금까지 본 네 길(코드의 `BRK 16`·`BRK 19`·`JSL 24:FEAC`, 인물 명령 `20`, 전투 메시지 `F9`)에 더해 전투 연출의 효과음 표를 찾았고, 다섯 길을 한꺼번에 모으는 [sfc/dq5/tools/dq5sfx.py](../tools/dq5sfx.py) 를 썼습니다. 장면이 없던 효과음 열 가운데 `35`·`3B`·`3E`·`40`·`46` 은 장면을 띄워 확인했습니다. 동굴에서 마주친 전투의 곡 갈래도 실측했습니다. 결과는 [dq5-sound-format.md](../docs/dq5-sound-format.md) 의 「효과음 쓰임」·「전투 곡」 에 있습니다.

## 1. 전투 연출의 효과음 표

앞 일지에서 `28:804E` 의 효과음은 「X 는 레지스터」 로만 적었습니다. 위를 읽으니 `28:8000` 이 A 를 `28:8074` 표로 소리 칸으로 바꾸고, `28:811E[칸*2]` 에서 효과음과 갈래를 꺼내 `24:FEAC` 를 부릅니다. 칸이 `FE` 면 `$0DA7` 로 `26:8A65` 를 읽어 `28:816E` 에서 고릅니다.
A 는 연출 번호입니다. 연출 스크립트 명령 `3A` 의 처리기 `22:DB9E` 가 `LDA $0D14 / JSL 28:8000` 이고, `26:8B59` 도 `$100E` bit7 이면 연출 대신 같은 번호로 `28:8000` 을 부릅니다.

```
연출 01 メラ  → 38-00      연출 17 ラリホー → 46-01      연출 1E マホカンタ → 3A-00
연출 27 ホイミ → 36-00     연출 39~65 몬스터 주문 → 37-0E  연출 73 たたかう → 무기 종류마다 37-05·07·0A·10·08·09·11
```

`26:8A65` 의 bit2-5 로 물건을 묶어 보니 0 이 くだものナイフ·どうのつるぎ 등, 1 이 ひのきのぼう·こんぼう, 2 가 채찍, 3 이 부메랑, 4 가 발톱, 5 가 창, 6 이 철퇴였습니다. 7 부터는 갑옷·투구라 たたかう 에 쓰이지 않습니다.

## 2. 주문으로 표 확인

주인공 주문 칸 8 의 주문(파일 오프셋 `11BE31`)을 바꿔 슬라임 하나에게 외우며 `lua/dq5sndlog.lua` 로 기록했습니다. 연출 쪽은 `24:FEAC` 를 바로 부르므로 `brk=` 가 붙지 않아 갈래가 보이지 않았습니다. 명령 `0C` 를 바로 부르면 X 레지스터를 함께 적게 고쳤습니다.

```sh
STATE=$PWD/work/state/ship.mss FIELD=341,56 BATTLE="00:1" SETTLE=300 SET="2064=01;2050=63;2044=63" ROMPATCH="11BE31=17" \
  TEST="a:8,wait:40,down:6,wait:20,a:8,wait:40,a:8,wait:40,a:8,wait:600,wait:5000" MAXF=1300 \
  LIBDIR=<lib.lua·probe 와 boot.lua = dq5warp.lua 를 둔 폴더> SHOT_DIR=$PWD/work/sp17 \
  "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5sndlog.lua"
```

```
930 cmd=0C arg=37 from=00:92DF brk=26:8AFF X=0E     ← 주문을 외우는 소리(모든 주문)
973 cmd=0C arg=46 from=00:92DF brk=20:F7C9 X=01     ← 전투 코드
977 cmd=0C arg=46 from=28:804E X=01                 ← 연출 표
```

ニフラム·ラリホー·マヌーサ·メダパニ·ルカニ·メガンテ·メラ 일곱이 모두 표의 효과음·갈래와 같았습니다. スカラ 와 マホカンタ 는 연출 쪽 소리가 없었습니다.
`TEST` 끝에 긴 `wait` 를 붙인 것은 `dq5warp.lua` 가 `TEST` 를 마치면 바로 멈추어 `dq5sndlog.lua` 가 `MAXF - 1` 프레임에 기록을 쓰지 못하기 때문입니다.

## 3. 장면을 띄운 효과음

부르는 곳의 앞뒤를 읽고, 그 루틴을 부르는 곳(롬에서 `JSL`·인물 스크립트 네이티브 호출 `37 lo hi bank` 를 찾음)을 따라 장면을 골랐습니다.

| 효과음 | 장면 | 기록 |
| --- | --- | --- |
| `35-01` | 23/00 (40,22) 에서 とびら(`POKE=7E00C3=04`) | 792 프레임 `brk=01:E01B X=01`, 화면의 문이 검게 열림 |
| `3B-00`·`01`·`02` | 19/02 카지노 슬롯 | 1157 코인 넣기 `11:B4EB`, 1193 시작 `11:B673`, 1441~1927 릴이 멈출 때마다 `11:B6C3` 다섯 번 |
| `3E-05` | 31/0B 에서 (13,13) 에 들어섬 | 인라인 명령 `2D`(`03:AE8D`)로 몬스터 셋이 나타날 때 596·705·805 프레임, 뒤이어 전투 |
| `40-00` | 03/02, `SET=21BB\|04`(ラマダ 를 쓰러뜨린 뒤의 대체 목록) | 「ラマダ「こ この オレさまが…」 를 넘긴 뒤 787 프레임 `brk=02:BBA3`, 주인공이 (80,19) 로 옮겨짐 |

`42`(02/07 밤, `23:E7A9`)와 `45`(54/53, `23:E6A4` → `02:EF10`)는 같은 식으로 인물 스크립트를 찾아 플래그를 켜고 들어갔지만, 스크립트가 기다리는 다음 조건까지 가지 못해 코드 읽기로 남겼습니다. `43` 은 `0F:FDD7` 이 `$1954` 를 `03`(배)으로 둔 뒤라 배에 오를 때로 보았지만, 필드에서 세워 둔 배에 실제로 올라 보니 `01:82E1` 의 배 곡(`0C 04 01`)만 나가고 `43` 은 나가지 않았습니다.

## 4. 다섯 길로 모으기

`dq5sfx.py` 는 연출 표(105개 연출), 인물 스크립트(22곳), 코드 바이트 꼴(274곳, 정적 후보)을 효과음·갈래로 묶습니다. 137갈래 중 121갈래에 부르는 곳이 있었습니다. 남은 16갈래는 즉값으로 부르는 곳이 없습니다. `42-19` 는 갈래가 아닌 값이라 `03:AD9A` 의 바이트는 데이터입니다.
들어 보기 페이지(`dq5spcfile.py` 의 장면 문구)는 확인한 장면에 더해 연출 표·인물 명령에서 나온 쓰임을 롬에서 붙이게 했습니다.

## 5. 동굴에서 마주친 전투

`00:833C` 는 `$194A & 7F` = 4 인 맵 말고도 21/01~04 를 따로 봅니다. 21/02 (50,43) 에서 좌우로 걷자 998 프레임에 마주쳐 `1A FF`·`0C 17 01` 이 나갔습니다. 앞서 03/02 에서 오래 걸어도 마주치지 않던 것과 달리 바로 붙었습니다.
DSP 는 전투 앞뒤 모두 주 음량 `4D`·메아리 `40`/`40` 이었습니다. 맵 곡 `09` 가 이미 같은 설정이라, 곡 변수 1 로 스크립트 `16` 을 건너뛰어도 값이 그대로입니다.
이벤트 무리의 곡 등급은 `dq5sound.py --battle` 로 뽑았습니다. 등급 1(곡 `16`)이 13무리, 등급 2(곡 `18`)가 エスターク·ミルドラース 둘째 모습의 2무리입니다.

## 틀렸던 것들

- `43` 을 세워 둔 배에 오를 때의 소리로 보았습니다. 필드에서 배에 오르면 배 곡만 나갑니다.
- 처음에는 `dq5warp.lua` 뒤에 `dq5sndlog.lua` 를 붙여도 `snd.txt` 가 생기지 않았습니다. `TEST` 가 `MAXF` 보다 먼저 끝나 드라이버가 멈춘 것이었습니다.
