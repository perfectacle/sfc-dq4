# 2026-10-25-64: 이벤트 스크립트 부르는 곳과 명령, 청년기 단계 실측

[2026-10-25-55](2026-10-25-55-event2.md) 에서 남긴 것을 이어서 했습니다. 번호 표 스크립트를 부르는 곳, `02:B705` 를 직접 부르는 곳, 명령 `C1`·`C4`~`C9`·`91` 의 뜻, 청년기 단계 실측, パルプンテ `15`·`1C`~`1E` 의 조건입니다. 결과는 [dq5-event-format.md](../docs/dq5-event-format.md), [dq5-flags.md 「청년기 사건 순서」](../docs/dq5-flags.md#청년기-사건-순서), [dq5-data-format.md](../docs/dq5-data-format.md#전투-시작-때-쓰는-값) 에 있습니다.

## 1. 부르는 곳

먼저 `JSL $23E2F4` 앞이 즉값이 아닌 곳을 찾았는데, `TDC` 하나(`06:C50C`)뿐이었습니다. `23:E2F4` 의 중간이나 표 `23:E325` 를 다른 곳에서 읽는 코드도 없었습니다.
그래서 방향을 바꿔 `JSL $02B705` 를 모두 찾았습니다. 이벤트 표(`23:E2BB`) 말고 14곳이 나왔고, 앞에서 `$02`~`$04` 를 즉값으로 채우는 곳이 13곳이었습니다(`05:FAF0` 은 `REP #$20 / LDA #$F5C1 / STA $02`).

```
02:F717 (38,29) 15F713 = 번호 4C     05:F45E (18,17) 15F43B = 번호 2D
06:BD94 (14,11) 15F0CB = 번호 01     25:FEB6 (20,11) 15F360 = 번호 17
02:A3D8 X 60    25889C 「どうやら　着いたようだな。」
```

번호 표 스크립트 몇 개는 표가 아니라 이 길로 쓰이고 있었습니다. `dq5event.py` 에 이 길을 더하자 스크립트가 98개에서 106개로 늘고, 부르는 곳을 못 찾은 번호 표 스크립트는 37개에서 30개로 줄었습니다. 남은 30개 중에는 명령 하나짜리(번호 `2E`~`33`)가 많아, 지금 롬에서 쓰지 않는 칸일 수 있습니다.

`25:889C`·`15:F652`·`15:F5C1` 을 `$19B3` 에 넣어 걸어 보니 명령이 디코더의 경계대로 실행되었습니다. `15:F652` 는 끝까지 14개가 실행되었습니다.

## 2. 명령

`23:FE69`~`23:FE9F` 를 읽으니 `C6`~`C9` 는 소리 쪽이었습니다. `C7 v` 는 `24:FE91`(소리 명령 `1A`)·`24:FE9A` 로 곡 v 를 틀고, `C8 v` 는 v | 80 을 `7E:21DF` 에 두고 틀며, `C9` 는 맵 곡 `$194B` 로 되돌리고 `7E:21DF` 를 지웁니다.
롬의 스크립트에는 `C7`·`C8`·`C9` 가 없어서 `7E:1A0D` 에 직접 써 넣고 걸었습니다.

```
C8 0C:  656 23FE80 A=000C / 656 24FE91 A=008C, 7E21DF=008C
C1 10:  7E31E0 44 → 10
```

`C2` 를 넣은 스크립트는 21/00 에서 그 명령 뒤로 넘어가지 않을 때가 있었습니다. 같은 스크립트에 이동 입력을 섞자 넘어갔는데, 조건은 아직 모릅니다.

## 3. 청년기 단계

[2026-10-25-35](2026-10-25-35-flags.md) 의 요령으로, 선실 파파스의 대화 번호를 청년기 마을 사람의 번호로 바꾸고 단계 플래그를 넣고 빼며 말을 걸었습니다. 수도원·オラクルベリー·サンタローズ·テルパドール·グランバニア·山奥の村 의 여섯 단계에서 갈래가 바뀌었습니다.
그중 山奥の村 대화 `1AF` 는 `2190.7` 을 켜자 「今日は　とびきりの ごちそうを　作らなきゃね。」였습니다. 스크립트에서 이 갈래 앞 메시지는 「さあて　世界に　平和が もどってきたんだ。」 입니다. `2190.7` 이 ルーラ 를 어디서나 막는 비트이기도 해서, 엔딩 뒤 상태로 보입니다.
신전(`08E`)은 말을 걸어도 첫 쪽이 뜨지 않았습니다. カボチ(`17A`)는 플래그를 넣은 쪽 화면이 비어 갈래를 비교하지 못했습니다.
