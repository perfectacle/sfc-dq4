# 2026-10-25-67: BC 50 이상 맵의 움직이는 타일과 바다 위 배경 번호

[실내 맵의 움직이는 타일](2026-10-25-58-anim.md) 에서 남긴 종류 7·11·12 를 BC `50` 이상 맵에 들어가 확인하고, 바다를 지날 때의 배경 번호(`$1AA0`)를 다시 봤습니다. 결과는 [dq5-graphics-format.md](../docs/dq5-graphics-format.md) 의 「실내 맵의 움직이는 타일」「번호를 정하는 곳」에 있습니다.

## 1. BC 50 이상 맵에 들어가기

`dq5warp.lua` 의 `TO` 는 목적지 항목의 `$BD` 가 5비트라 BC `50` 이상 맵으로 갈 수 없습니다. 두 길을 썼습니다.

- `2A:F52A` 의 대체 표([2026-10-25-34 일지](2026-10-25-34-field3.md)): 12/02 의 아래 출구로 나가면 53/51, 15/06 의 아래 출구로 나가면 54/50 에 섭니다. 15/0A 의 왼쪽 출구는 세계 2 필드로 나갔습니다.
- 필드 입구 51 을 덮는 방법([handoff](../handoff.md)): 52/50 은 `ROMPATCH="1573E6=52;1573EC=50;27E7D=52;157F2A=FF"`, 50/50 은 `ROMPATCH="27E7D=50" SET="21BA|20"`.

```sh
LIBDIR=$(tools/lua/seqlib.sh "$(uv run --locked krpatch sfc lua)" work/warplib ../../sfc/dq5/tools/lua/dq5warp.lua)
mkdir -p work/an/e156
env LIBDIR=$LIBDIR STATE=$PWD/work/state/ship.mss TO=15/06,10,25 SETTLE=30 TEST="down:300,wait:200" \
  DUMPF=$(seq -s, 860 1 930) MAXF=1400 SHOT_DIR=$PWD/work/an/e156 \
  "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5gfxdump.lua"
uv run --locked python sfc/dq5/tools/dq5anim.py rom/dq5.sfc --check work/an/e156 860 930
```

## 2. 종류 11·12

```
52/50  종류 11: 주기 24 → 3/3 맞음, 1ECE [120, 144, 168], 블록 CHR 12개와 [7]줄 돌린 꼴
       종류 12: 주기 2 → 39/39 맞음
53/51  종류 12: 주기 2 → 34/34 맞음, 블록 CHR 2개와 [3]줄 돌린 꼴
50/50  종류 11: 주기 24 → 3/3 맞음
```

처음 53/51 을 견줄 때 블록 CHR 과의 비교가 비어 나왔습니다. BC `50` 이상 맵은 블록 표(`7E:A000`)와 CHR 뱅크(`1F`)가 따로라, `dq5anim.py` 가 `$BC` 를 보고 그쪽 표를 쓰게 고쳤습니다.

## 3. 종류 7 은 가로 돌림

54/50 의 종류 7 은 2프레임마다 바뀌는데, 한 줄 아래로 돌린 것과는 33번 모두 달랐습니다. `03:D5EC` 를 읽으니 `1ECE % 4 == 0` 이면 첫 타일의 바이트를 하나씩 오른쪽으로 돌리고(`LSR A` 로 bit0 을 carry 에 넣고 `ROR`), 매번 타일 1·2, 3·4 를 짝지어 두 바이트에 걸쳐 오른쪽으로 돌렸습니다. 이 식을 `slide7` 로 넣자 33/33 이 맞았습니다.

## 4. 바다 위의 배경 번호

배를 띄운 채(`LATESET=1954=80`) 바다를 2,400프레임 저으며 `$1AA0` 쓰기를 지켜봤더니 하나도 없었습니다. 같은 자리에서 `LATESET=1954=03` 으로 바꾸자 걸음마다 `01:84EA`(지형을 쓰는 `01:84CF` 의 `STA $1AA0` 바로 뒤)가 `$1AA0` = `00` 을 11번 썼습니다. 배경 00 은 바다 그림입니다.

```sh
mkdir -p work/sea/w3
env LIBDIR=$LIBDIR STATE=$PWD/work/state/ship.mss FIELD=328,27 LATESET=1954=03 SETTLE=30 \
  TEST="left:60,left:60,down:20,left:60,down:20" WATCH=001AA0-001AA1,7E1AA0-7E1AA1 FROM=480 MAXF=2900 \
  SHOT_DIR=$PWD/work/sea/w3 "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/tools/lua/wwatch.lua"
```

```
001AA0-001AA1 pc=0184EA first=500 n=11 addr=001AA0 val=00
```

두 경우 모두 전투는 붙지 않아, 바다 전투 화면은 보지 못했습니다.
