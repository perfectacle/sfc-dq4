# 2026-10-25-136: 상태 이상, 몬스터 행동 칸 고르기, 전투 도구

상태 이상이 풀리는 확률, 몬스터가 행동 여섯 칸 중 하나를 고르는 무게, 전투에서 쓰는 도구의 효과를 확인했습니다. 앞 일지의 자투리(SRAM bit5, サンチョ 의 HP·MP)도 실측했습니다.
결과는 [dq5-data-format.md](../docs/dq5-data-format.md) 의 「상태 이상」「몬스터 행동 칸 고르기」「전투 도구」와 「SRAM 세이브」「레벨업 성장」에 있습니다.

## 1. 자투리 둘

타이틀 메뉴(ぼうけんをする·せっていをかえる·つくる·うつす·けす)에서 위를 눌러 けす 로 가 칸 2 를 지웠습니다. 1CE·1CF 뒤 칸 상태 `0010` 이 `20`, 쓰는 칸 비트 `000E` 가 `01` 이 되었습니다.
サンチョ 는 최대 HP 50·MP 20 으로 두고 레벨 5 → 6 을 두 번 올리자 51·21, 51·20 이었습니다. 표 값이 0 이라 지금 값이 1.5배 문턱(0) 이상이 되어 늘 난수 0·1 갈래입니다.

## 2. 상태 이상

행동할 차례마다 `20:8909` 가 상태를 차례로 봅니다. 잠은 `BRK 89 80 44` 로 카운터를 줄인 뒤 `20:8A49` = `04 03 02 01` 에서 카운터 칸을 꺼내 난수(0~3)와 견줍니다.
주인공을 재우고(`7E:0765` = `80`, `7E:0768` = `30`) 판 여덟을 돌려 비교 직전의 카운터·난수와 결과를 모았습니다.

```
카운터 2: 난수 0·1 → 깸 3번, 2·3 → 잠 5번
카운터 1: 난수 0·2 → 깸 2번, 3 → 잠 3번
카운터 0: 난수 2·3 → 깸 3번
```

카운터는 처음 3 이고 차례마다 줄어 셋째 차례에는 반드시 깹니다. 몬스터도 같은 표를 씁니다(카운터 필드 `4E`).
마비는 이 루틴에서 메시지만 내고 차례를 넘기며 풀지 않습니다. 「すくみ」「みぶるい」「つられて踊る」 같은 것은 비트를 끄고 한 차례 쉬는 것이고, 저주는 1/4 로 움직이지 못합니다(56번 중 12번).

## 3. 몬스터 행동 칸 고르기

`21:AFAE` 가 읽는 필드 `69` 가 `21:BB32` 의 여덟 루틴 중 하나를 고릅니다. 1~4 는 `28:82BB` 의 6바이트 무게 표 넷을 쓰고, 남은 칸의 무게만 더한 합에서 난수를 뽑습니다.
슬라임 넷 전투에서 처음 잰 값은 무게 표와 맞지 않았습니다. 슬라임 행동 `73 73 98 73 73 98` 중 `98` 칸이 조건에서 빠져 남은 칸이 바뀌었기 때문이라, 행동을 모두 `73` 으로 하고 필드 `68` 을 0 으로 해 다시 쟀습니다.

```
69=1  72번  68 57 75 18 25 14   (표 68 58 48 38 27 17)
69=2  72번  188 39 11 7 11 0    (표 210 29 10 4 2 1)
69=3  72번  60 57 64 28 21 25   (표 64 64 64 21 21 21)
69=4  72번  68 60 25 32 25 46   (표 64 64 32 32 32 32)
```

손님 파파스의 고르기도 같은 루틴을 지나 `$1105` = 0 으로 섞여 들어와, `21:B4D6` 의 `$1105` 로 나눠 셌습니다.

## 4. 전투 도구

やくそう 를 쓰자 `$10F7` 이 `A1`(물건) 다음에 `27`(ホイミ)이 되었습니다. 쓰는 곳을 감시하니 `20:BC65` 의 `LDA #$27 / STA $10F7` 이었고, 그 처리기를 고르는 표가 `20:C162`, 물건 목록이 `27:819A` 였습니다.
회복량은 34·38 로 ホイミ 의 30~40 안이었습니다. いかずちのつえ 는 `05`(ベギラマ), ほのおのリング·マグマのつえ 는 `07`, けんじゃのいし 는 이름 표 밖의 `E2` 였습니다.

## 틀렸던 것들

- 행동 칸 무게를 슬라임 원래 행동으로 재면 된다: 조건 루틴이 칸을 빼서 남은 칸이 달라졌다. 모든 칸을 같은 행동으로 하고 재야 무게 표와 견줄 수 있다.
