# 2026-10-25-151: 공격 두 배, 몬스터 혼란·アストロン, 마비를 끄는 곳

[앞 일지](2026-10-25-145-status3.md)에 남긴 것과 코드로만 읽어 둔 것을 실측했습니다. 결과는 [dq5-data-format.md](../docs/dq5-data-format.md) 의 「상태 이상」「전투 도구」에 있습니다.

## 1. たたかいのドラム 의 두 배

필드 `10` 이 있는 주인공 전투 칸 `+6` 을 읽는 곳을 보려고 읽기 감시를 걸었습니다. 그러나 읽는 곳이 모두 상태 읽기 공통 루틴(`21:915F`)이라, 같은 장면에서 `+6` bit7 만 켜고 끈 두 판을 실행 커버리지로 견주었습니다.

```
켰을 때만  20:B02B  ASL $46
껐을 때만  20:B088~  (작은 공격력 쪽 갈래)
주인공 たたかう 피해  켬 10·9·9   끔 5·4·4
```

`20:AFFE` 가 공격하는 쪽의 상태(일행 `10`, 몬스터 `38`)와 공격력을 읽고, 상태가 켜져 있으면 공격력을 두 배로 한 뒤 피해 계산에 넘깁니다.

## 2. 몬스터 혼란과 アストロン

몬스터 상태 `n` 의 바이트는 칸 `+A` 부터 셉니다. 그래서 `46` 은 `+D` bit0-1, `2D` 는 `+A` bit2, `4D` 는 `+F` bit6-7 입니다.

```
+D = 3         턴마다 3 → 2 → 1 → 0, 셋째 턴 끝에 09E「われにかえった」
+A = C4, +F = C0  행동 대신 011「てつのかたまり」, +F 가 C0 → 80 → 40 → 00, 셋째 턴 끝에 09F 와 +A = C0
```

## 3. 몬스터 마비를 끄는 곳

`BRK 88 7B`(몬스터 상태 끄기) 67곳에서 앞의 `$43` 을 모았습니다. `2A` 는 `20:FBF8` 하나였습니다. 이곳은 `2A`~`4F` 를 줄줄이 끄는 `20:FBF4` 의 첫 줄입니다. 이것을 부르는 10곳은 모두 0A1「やっつけた」·065·07F「くだけちった」·080 같은 쓰러뜨림 메시지 뒤이거나 살아 있음(`29`)을 끈 다음입니다.
몬스터의 변신·주문 효과를 거두는 `20:D772` 의 목록에도 `2A` 는 없습니다. 몬스터 마비는 쓰러질 때까지 이어집니다.

## 4. まもりのたね·ふしぎなきのみ

```
まもりのたね ×2    みのまもり 3 → 11
ふしぎなきのみ ×2  최대 MP 0 → 8
```

## 틀렸던 것들

- 롬에 상태 `2A` 를 끄는 곳이 없다: `20:FBF4`(모두 끄기)에 있었다. 다만 쓰러뜨린 뒤에만 불려 결론(턴 끝에 풀리지 않음)은 같다.
- 공격 두 배는 칸의 공격 값을 바꾼다: 칸 값은 그대로이고 피해 계산 앞(`20:B02B`)에서 두 배로 한다.
