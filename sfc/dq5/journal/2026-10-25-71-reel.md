# 2026-10-25-71: 슬롯 릴이 멈출 자리

[앞 일지](2026-10-25-69-slot3.md)의 남은 것인 「릴이 멈출 자리를 고르는 곳」 을 보았습니다.

## 1. 그림 줄을 읽는 곳

1 ドル 슬롯 세이브스테이트에서 한 판 돌리는 동안 그림 줄(`11:9162`~`11:9306`) 읽기를 `rwatch.lua` 로 감시하니, 읽는 곳은 `11:B772` 하나로 7,012번이었습니다. 이 루틴(`11:B73F`)은 릴 위치 `$1294,X` 로 그림 줄의 칸을 골라 화면에 그리는 쪽입니다.

## 2. 릴 상태 기계

그 위의 `11:B6A2` 가 릴 다섯 개(`X` = 0·2·…·8)의 상태 `$12B2,X` 로 갈라집니다.

```
0  11:B709  돌기 시작. $12A8 이 8 이 되면 상태 1
1  11:B6EB  $12BC 가 0 이 되면 상태 2.  LDA #$08 / BRK 20 → (난수+1)*3 을 $12BC 에
2  11:B6C9  11:907A 표로 느려짐
3  11:B6B2  칸이 딱 맞으면(11:BDA6) 멈춤
```

롬에서 슬롯 코드(뱅크 11)가 난수(`BRK 20`)를 부르는 곳은 `11:B6F5` 하나뿐입니다.

## 3. 난수를 막아 보기

`11:B6F3` 의 즉값 `08` 을 `01`(난수가 늘 0)로 바꾸고, A 를 누르는 프레임만 10 과 37 로 달리해 두 번씩 돌렸습니다.

| 롬 | 화면을 픽셀로 비교했을 때 다른 곳 |
| --- | --- |
| 원래 | x 81~199(1번 릴부터) |
| `8B6F4=01` | x 113~199(3번 릴부터) |

난수를 막으면 1·2번 릴은 같은 그림에 섰습니다. 3~5번 릴은 여전히 달랐으니, 뒤 릴은 돌기 시작한 때와 앞 릴이 멈춘 때에도 영향을 받는 것으로 보입니다.

## 틀렸던 것들

- 그림 줄을 읽는 `11:B772` 를 처음엔 멈출 자리를 고르는 곳으로 보았습니다. 실제로는 화면에 그리는 쪽이었습니다.
