# 2026-10-25-190: 전투 곡과 효과음 쓰임

[남은 곡 줄이기 장면](2026-10-25-186-sound10.md) 까지는 곡이 어디서 나는지를 보았습니다. 이번에는 전투의 곡(보통·보스·마지막 보스, 승리·전멸·도망)과 효과음 21개가 게임 어디서 나는지를 모았습니다. 결과는 [dq5-sound-format.md](../docs/dq5-sound-format.md) 「전투 곡」「효과음 쓰임」에 있습니다.

## 1. 전투 곡

전투 곡을 고르는 `26:8F5B` 는 [dq5-data-format.md](../docs/dq5-data-format.md) 에 이미 등급 표(`17`·`16`·`18`)로 적혀 있었습니다. 그 뒤의 `00:833C` 를 보니, 실내이면서 `$194A & 7F` 가 4(마주치는 동굴)이거나 맵 21/01~04 이면 X 를 1 로 두고 `0C 곡 X` 를 보냈습니다. 세 전투 곡은 첫 트랙이 모두 `fe 19 / if_flag 01 / fe 16` 으로 시작합니다. 곡 변수가 0 이면 스크립트 `16` 이 `19` 의 설정을 덮습니다. 메뉴 효과음을 `0C 17 00`·`0C 17 01` 로 바꿔 보내 DSP 를 비교했습니다.

```
X=0: mvol=5C,5C evol=14,EC  EFB=0C
X=1: mvol=4D,4D evol=40,40  EFB=00
```

동굴에서는 주 음량이 낮고 메아리가 양쪽 같은 크기로 커집니다. 03/02 를 오래 걸어도 마주침이 없어, 실제 동굴 전투는 걸지 못했습니다.

장면 이동 도구의 `GROUP` 으로 무리 `20`·`2C`·`2F` 를 걸자 `0C 16`·`0C 18`·`0C 18` 이 나갔습니다. `2C`(エスターク)에게 기절하자 1170 프레임에 `20:8149` 의 `1A` 와 `BRK 11 0B`(`01 0B`)가 나갔습니다. 곡 `0B` 는 파파스가 쓰러지는 장면에서 줄어들던 그 곡입니다. 도망은 처음 세 번 모두 명령 창이 뜨기 전에 입력해 실패했습니다. 화면을 찍어 보니 「たたかう·にげる」 창은 전투 시작 뒤 한참 뒤에 떴습니다. 기다림을 늘리자 1785 프레임에 「ああああは にげだした！」 뒤 필드 맵 곡(`1A 02`·`01 02`)만 나왔습니다. 도망 곡은 없습니다.

## 2. 효과음이 나는 곳

`BRK 16`·`19` 로 나는 효과음은 부른 곳이 `00:92E9`·`00:92DF`(소리 서비스)로만 찍혀 자리를 알 수 없었습니다. 그래서 `dq5sndlog.lua` 가 BRK 입구 `00:8F80` 에서 스택의 PB·PC 로 BRK 자리와 둘째 인자(X)를 잡아, 다음 소리 명령에 붙이게 했습니다.

```
941 cmd=0C arg=33 from=00:92DF brk=04:CCAA X=00
1029 cmd=0C arg=37 from=00:92DF brk=26:8B11 X=01
```

이 기록으로 앞에서 걸었던 장면(エスターク·ボス 전투, ミルドラース, 파파스 장면, トロッコ, レヌール城)을 다시 돌려 자리를 모았습니다. 롬 전체의 정적 후보 290곳(`00 16 n X`·`00 19 n X`, `LDA #n … JSL 24:FEAC`)과 모든 맵 인물 인라인 명령 `20 n X` 11곳도 함께 표에 넣었습니다. キメラのつばさ(물건 `A4`)를 써 보니 905 프레임에 효과음 `36` X `02`(`05:E9DF`)가 나갔습니다. 앞에서 넣지 못했던 것은 `0D` 가 물건 번호가 아니라 インパス 메시지 값이어서였습니다.
