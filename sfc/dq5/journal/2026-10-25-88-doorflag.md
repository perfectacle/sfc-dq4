# 2026-10-25-88: 문 플래그를 지우는 곳, 04:FE83 의 다른 쓰임, 셀 +1 bit6 다시 재기

세 가지를 정리했습니다. 맵에 들어갈 때 `7E:21C2`~ 문 플래그를 지우는 조건, `04:FE83` 을 읽는 곳 모두와 1E 항목이 쓰이는 길, 그리고 셀 `+1` bit6 이 정말 화면을 바꾸는지입니다.
결과는 [dq5-map-format.md](../docs/dq5-map-format.md) 의 「닫힌 문」·「셀 버퍼」와 [dq5-field-format.md](../docs/dq5-field-format.md) 의 「마을 입장」에 있습니다.

## 1. 문 플래그

`00:A940` 이 `21C2`~`21C5` 에 0 을 쓰는 루틴이고, 부르는 곳은 `00:A8C5` 하나, 그 위는 `01:8F2E`(맵을 옮길 때)와 `01:9FC1`(필드로 나갈 때)입니다. `01:8F26` 은 마지막 그룹 `7E:21C7` 과 새 `$BC` 가 같으면 부르지 않고, `00:A8E0` 은 실내 그룹 `0F`·`52` 면 건너뜁니다.
`21C2`~`21C6` 을 `FF` 로 두고 맵을 옮기며 쓰기를 지켜보았습니다.

```
17/02 (같은 그룹)  쓰기 없음
0F/00              21C7 = 0F, 문 플래그 그대로
00/00              00:A949~A955 가 21C2~21C5 = 0   (21C6 은 그대로)
필드로             375·456프레임에 지움. 21A5 bit6 을 켜면 456 에서는 지우지 않음
```

## 2. `04:FE83` 을 읽는 곳

롬에서 `04:FE83`~`FE86` 을 읽는 명령은 `2A:F444`(필드로 나가는 자리), `2A:FE11`(걸어서 들어가는 입구), `1E:E59B`(ルーラ 행선지) 셋이었습니다.

- `2A:FDCB` 는 필드에서 걸어 다닐 때 주인공 자리가 표의 (X, Y) 와 같으면 그 그룹에 들입니다. 필드 (234,439) 에서 위로 걸어 2E 의 (234,437) 을 밟자 2E/00 에 들어갔습니다. 1E 의 (396,399) 은 사방이 산이라 걸어서는 닿지 않았습니다.
- `1E:E545` 는 ルーラ 행선지 표 `25:85D5`(22개, 1E 는 열아홉째)의 그룹을 `04:FD97`, 없으면 `04:FE83` 에서 찾아 `$0B50`·`$0B52` 에 (X, Y+1) 을 둡니다. 행선지 첫 칸(01)을 `1E` 로 덮고 ルーラ 를 외우자 `$0B54` = `1E`, (396,400) 에 내렸습니다.

1E 항목을 쓰는 길은 ルーラ 하나입니다.

## 3. 셀 `+1` bit6 다시 재기

지금까지 bit6 을 지운 실험은 장면 이동 도구에 기록용 Lua(`dq5warptrace.lua`)를 얹고 그 화면을 비교했습니다. 이번에는 `dq5warp.lua` 만 드라이버로 두고 프레임마다 OAM·VRAM·CGRAM·화면을 직접 덤프했습니다.

```
18/00 (10,29) 에서 위로, bit6 지움      291프레임: OAM 0, VRAM 0, CGRAM 0, 화면 0 다름
18/00 계단 (4,52), 동료 둘, bit6 지움   291프레임: 모두 같음
18/00 계단, bit4-5 지움                 OAM 140프레임 다름(주인공 OBJ 우선순위 3 → 2), VRAM 0
31/00 (30,57), +0 bit3 지움             OAM 93프레임 다름(우선순위 3 → 2)
```

bit4-5 와 `+0` bit3 은 같은 방법에서도 OBJ 우선순위를 바꿨고, bit6 은 아무것도 바꾸지 않았습니다. 앞 일지들에서 bit6 때문으로 본 차이(동료 앞뒤, 병사 다리, 상태 창)는 기록용 Lua 를 얹은 쪽의 화면에서만 나온 것입니다.

## 틀렸던 것들

- 셀 `+1` bit6 이 겹친 인물의 앞뒤를 바꾼다고 적었습니다. 직접 덤프한 실험에서는 OAM·화면이 그대로였습니다.
- 1E 의 `04:FE83` 항목을 쓰는 길이 없다고 보았습니다. ルーラ 행선지가 씁니다.

## 남은 것

- 셀 `+1` bit6 이 쓰이는 장면이 있는지(`2B:B909` 의 갈래가 바뀌는 조건) — 해결됨: 층 2·4 인물이 조건 맞는 칸에 서면 bit6 이 OBJ 우선순위를 3 으로 올리는 갈래를 건너뜀, 18/00 에서 OAM 속성 `20` ↔ `30` 실측([dq5-map-format.md](../docs/dq5-map-format.md) 「셀 버퍼」 의 `+1` bit6)
