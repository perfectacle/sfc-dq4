# 2026-10-26-36: 03/05 절벽 위에서 소동 자리까지 걷는 길

[2026-10-26-29](2026-10-26-29-slave07.md) 에서 남긴 「03/05 의 도착 칸 (18,20) 에서 소동 자리 (42,39) 까지 걷는 길」 을 찾아 걸었습니다. 같은 때 다른 작업이 03/07 에서 이어 걸어 같은 길(03/06 → 03/01 → 03/03 → 03/05 오른쪽 위)을 문서에 적었으므로, 이 일지는 도착 칸 (18,20) 에서 출발해 막혔던 두 곳(03/06 계단 칸을 밟는 방향, 통로의 노예)을 풀어 적습니다. 결과는 [dq5-text-format.md 「네이티브 호출」](../docs/dq5-text-format.md#네이티브-호출) 의 `FB41` 항목에 더했습니다.

## 1. 맵 그림과 영역 이동

`dq5map.py --png` 로 03/05 를 그려 보니 (18,20) 은 두 동굴 문 사이의 턱이고 사방이 절벽입니다. 맵 안에서 아래로 내려가는 길은 없습니다. `dq5trigger.py`·`dq5exit.py` 로 이웃 맵을 읽었습니다.

```
03/05 영역 이동  (18,19) → 03/06 (22,33)   (8,21) → 03/06 (8,36)   (56~58,23) → 03/03 (4,34)
03/06 출구 칸   (25,21) → 03/01 (15,16)
03/01 출구 칸   (34,15)·(36,15) → 03/03 (4,21)·(6,21)   (16,16) → 03/06 (24,21)
03/03 영역 이동  (4~6,34) → 03/05 (56,23)
```

03/05 오른쪽 위의 동굴 (56~58,23) 아래로 통로와 계단이 소동 자리가 있는 바닥으로 이어집니다. 그래서 길은 03/05 → 03/06 → 03/01 → 03/03 → 03/05 오른쪽 위입니다.

## 2. 맵마다 따로 시험

`dq5warp.lua` 로 맵마다 내려 한 구간씩 걸었습니다. 03/01 → 03/03 과 03/03 → 03/05 는 바로 넘어갔습니다. 03/06 의 출구 칸 (25,21) 은 (25,23) 에서 위로 걸면 (25,19) 까지 지나가기만 했고, (24,19) 에서 아래로, (26,21) 에서 왼쪽으로 걸 때 03/01 (15,16) 로 갔습니다.

## 3. 통로의 노예

이어 걸으니 03/05 오른쪽 통로 (57,31) 에서 막혔습니다. 화면에 노예가 통로 가운데 서 있었습니다. 03/05 인물 목록에서 화면 밖 (94,31) 에 놓인 인물 `05:92AC` 의 스크립트(`05:92B4`)는 `21A1` 비트를 기다렸다가 (42,42) 에서 계단을 한 칸씩 올라 (48,37) → (56,37) → (56,23) 으로 걷고 순간이동으로 빠집니다. 다른 노예들도 `21A1` 비트를 서로 넘기며 같은 길을 오갑니다. 주인공이 통로에 서 있으면 올라오는 노예와 서로 막혀 둘 다 멈췄습니다. 통로 위 (58,24) 에서 900프레임 기다리자 노예가 지나갔고, 그 뒤 내려갈 수 있었습니다. 계단은 노예가 걷는 칸을 그대로 따라 내려갔습니다.

```

f00808 map 03/01 -> 03/03     f01143 map 03/03 -> 03/05
```
