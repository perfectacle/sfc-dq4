# 2026-10-25-48: 슬롯머신, 배, 마차와 망토 차림 어른 주인공

[앞 일지](2026-10-25-38-party.md)에서 막혔던 장면 넷을 모두 만들었습니다. 슬롯머신은 しらべる 로 열렸고, 배·天空城·マスタードラゴン 은 도착한 뒤 탈것 값만 바꾸면 되었습니다. 마차와 망토 차림 어른 주인공은 그림을 고르는 루틴에서 플래그를 찾았습니다.

## 1. 슬롯머신

앞 일지는 메시지 `4E8` 을 단서로 뱅크 05 의 `… F1 FF E8 04 …` 를 바이트코드로 보았습니다. 다시 보니 그 앞뒤가 `F1 FF EB 33`·`EA 33`·`E9 23`·`E8 04` 로 한 칸씩 줄어드는 표였고, `rwatch.lua` 로 슬라임 레이스 동안 뱅크 05 읽기를 감시해도 그 자리를 읽는 곳은 없었습니다. 메시지 번호가 아니었습니다.

그래서 카지노 19/02 에 직접 들어갔습니다. 슬롯 기계 앞(42,29)에서 말을 걸면 「その方向には 誰もいない。」 였고, (42,27) 에서 위를 보고 しらべる 하자 「1ドル スロットマシンが あります。」 가 나왔습니다. A 를 두 번 더 넘기자 「1回 1まいの コインで あそべます。 やってみますか？」 → はい 뒤 슬롯 화면(코인 100)이 떴습니다.

`probe/calls.lua` 로 메시지 루틴 `24:8BAF` 를 보니 A = `0583`·`0584` 였고, `BRK 9C 83`·`9C 84` 는 `06:D163`·`06:D169` 에 있었습니다.

```
12:ED19  ... LDY #$0A / ... / LDY #$01 / STY $F5 / JSL $06D14A    ; 슬롯 칸 조사: 10 ドル 또는 1 ドル
12:ED3D  LDX #$64 / STX $F5 / JSL $06D14A                          ; 100 ドル
06:D158  BRK 95 00 / BRK 9C 83 / BRK 9C 84 / BRK 95 32 / JSL $04A42A / LDA $E8 / ... JSL $02A8BC
```

메시지 `4E8` 을 띄우는 곳은 끝내 없었습니다. 쓰이지 않는 메시지로 보입니다.

## 2. 배·天空城·マスタードラゴン

앞 일지에서는 선실에서 처음부터 `$1954` 를 바꾸다가 사다리를 못 내려갔습니다. 그래서 `dq5warp.lua` 에 도착한 뒤 한 번만 고치는 `LATESET` 을 더했습니다.

| 명령(바다 (328,27)) | 결과 |
| --- | --- |
| `LATESET=1954=80` | 돛단배 그림으로 바다를 지나감((328,27) → (313,14)) |
| `LATESET=1954=81` | 그림자를 드리운 성(天空城으로 보임)이 날아감 |

## 3. 주인공 그림과 망토 차림

롬에서 `LDA #$3A`(노예 시절 그림 번호) 둘레에 플래그 검사가 있는 곳은 `05:D9B0` 이었고, 그 위가 걷는 그림을 고르는 루틴(`05:D98F`)이었습니다.

```
BRK 0B 01 2E   ; 7E:21BE bit0 → 98
BRK 0B 40 00   ; 7E:2190 bit6 꺼짐 → 2E
BRK 0B 20 2E   ; 7E:21BE bit5 꺼짐 → 3A, 켜짐 → 2D
```

`7E:2190` bit6·5 와 `7E:21BE` bit5 를 켜자 필드·실내 모두 망토 차림 어른이 걸었습니다(`ADULT=2`). `7E:21BE` bit0 은 주인공을 배 그림(`98`)으로 바꿨습니다.
앞 일지에서 실내 망토 차림으로 본 `7E:2190` bit7 장면은 WRAM 을 보니 주인공 그림은 `2E` 그대로이고 일행 수 표시가 4, 따르는 그림이 `9A`·`90`·`91` 이었습니다. 주인공이 아니라 뒤따르는 일행을 본 것입니다.

## 4. 마차

동료 셋이면 빈 그림이 되던 것을 풀려고, 동료 둘과 셋인 상태의 WRAM 을 비교했습니다. 따르는 그림 표 `7E:1970`~ 가 `50 5B` 에서 `35 35 35` 로, `7E:1979`~ 가 `80 80 C0` 으로 바뀌었습니다. 이 표를 채우는 `02:C6F0` 는 `7E:1978` bit7 인 일행을 모두 그림 `35`(관으로 보임) 칸으로 보냅니다.
그 앞의 `02:C788` 은 `BRK 88 91` 로 마차가 있는지 묻고 있으면 `$1954` 를 1 로 둡니다. 필드 `91` 은 `7E:201C` 였습니다.

| `7E:201C` | 결과(`PARTY=02,05,01`) |
| --- | --- |
| `01`·`02` | 마차 없음, 빈 그림 셋 |
| `80`·`FF` | 말이 끄는 마차, 옆에 빈 그림 둘 |

`PARTY=02,05` 나 `02` 에 마차를 주면 마차와 그 옆을 걷는 동료가 제대로 나왔습니다. 동료 셋 이상이면 마차가 있어도 빈 그림이 남았습니다(`05,01,02` 는 キラーパンサー 하나만 제 그림). `WAGON=1` 로 넣었습니다.

## 5. 일행 레코드 `+6`

つよさ → つよさをみる 로 スラリン 의 창을 열었습니다. `+6`(`7E:2070`)을 `30` 으로 바꾸자 すばやさ 가 3 에서 48 이 되었습니다. 들인 スライム 의 3 은 몬스터 スライム 의 민첩(필드 `5F`)과 같습니다. `+26`~`+29` 는 바꿔도 창의 어느 값도 변하지 않았고, Ex 는 0 그대로였습니다.
