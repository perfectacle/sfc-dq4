# 2026-10-25-17: 조우의 남은 것 2

[2026-10-25-14](2026-10-25-14-encounter2.md) 에서 남긴 것을 이어서 풀었습니다. 다룬 것은 몬스터 `6A` 가 7마리로 줄어드는 까닭, 기습을 막는 조건, `$7E21C9` 를 넣는 물건과 주문을 실제로 써 보기, 무리의 줄(`$0D1B`)과 여러 종 무리의 마릿수, `$1010`, 맵 항목 `+4` 입니다. 도중에 구역 레벨이 にげる 에도 쓰이는 것을 찾았습니다. 결과는 [dq5-data-format.md 「전투 조우」](../docs/dq5-data-format.md#전투-조우-23e7c2) 에 있습니다.

실험은 모두 `sfc/dq5/tools/lua/dq5warptrace.lua` 로 했습니다. 전투는 `BATTLE`(이벤트 무리 1번 덮기)이나 구역 `0D` 레코드 덮기로 붙였습니다.

```sh
  SHOT_DIR=$PWD/work/a1 "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5warptrace.lua"
```

## 1. 몬스터 `6A` 가 7마리가 되는 곳

[2026-10-25-12](2026-10-25-12-event-battle.md) 에서 무리 `3E` 의 スライム(`6A`) 8마리가 7마리만 나온다고 남겼습니다. `$1005` 에 쓰는 곳을 보니, 너비로 줄이는 `22:9284` 보다 먼저 `22:8A3B` 가 8 → 7 로 바꿨습니다.

```
548 1005 pc=26:8E2D v=08     ← 무리 레코드에서
601 1005 pc=22:8A3B v=07
```

`22:89E5` 는 첫 무리 몬스터 번호로 갈래를 탑니다. `E7`·`EA`(ミルドラース)이면 무리를 통째로 다시 쓰고, `6A` 면 마릿수가 짝수일 때 1 을 뺍니다. `6A` 를 6·7·8마리 넣자 5·7·7마리였고, 둘째 무리에 둔 `6A` 8마리는 그대로였습니다.

## 2. 기습을 막는 조건

`26:835B` 가 칸 16개를 돌며 `BRK 88 79` 를 부릅니다. `BRK 88 xx` 는 `21:8AF8` 의 필드 함수 `xx` 를 부르는 것이고, `79` 는 묶음 3(`7E:07C0 + 칸*16`, 전투 중 몬스터)의 `+A` 부터 비트 `$43` 을 시험합니다(`21:9176`, 바이트·마스크 표 `21:91F9`).
`$43` = `28`·`2A`·`30` 은 `+A` bit7·`+A` bit5·`+B` bit7 입니다. 전투 중 몬스터 칸을 보니 있는 슬라임 칸은 `+A` = `C0` 이었습니다.

`30` 이 잠이라면 잠든 몬스터만 있을 때 기습이 없어야 합니다. 그래서 기습 확률을 `20` 으로 덮고, 슬라임 레코드의 시작 상태를 「반드시」(바이트9 = `C1`)로 바꿨습니다.

| 덮은 것 | 칸 `+A`·`+B` | `$1000` bit0 | 화면 |
| --- | --- | --- | --- |
| 기습 확률만 | `C0 00` | 1 | 기습(bit0 남음) |
| + 시작 상태 잠 | `C0 80` | 0(`26:8386` 이 지움) | 「しかし スライムBは ねむっている！」 |
| + 상태 종류 `39` | `C0 00` | 1 | 기습(bit0 남음) |

## 3. 물건과 주문을 실제로 쓰기

물건 처리기는 `11:88C4` 가 물건 번호 − `A1` 로 `11:8F5B` 표를 골라 뜁니다. `$7E21C9` 를 넣는 처리기의 자리에서 번호를 거꾸로 구하니 `A3` せいすい, `AA` においぶくろ, `BB` まもののエサ 였습니다.

가진 물건은 일행 레코드 `+16` 부터입니다. 주인공(`7E:2040`)의 `+16`·`+17` 에 ぬののふく·ひのきのぼう 가 있었고, どうぐ 창에 `+18` 에 넣은 물건이 셋째 줄로 나왔습니다. 첫 칸에 물건을 넣고 `+14`(E 표시 비트로 보임)를 0 으로 한 뒤 どうぐ → つかう 를 눌렀습니다.

| 물건 | 메시지 | `7E:21C9` | `$1A9C` |
| --- | --- | --- | --- |
| せいすい | 「せいすいを ふりまいた！」 | 2 | `80` → 줄어 감 |
| においぶくろ | 「においぶくろを あけた！」 | 3 | `40` → |
| まもののエサ | 「まもののエサを ふりまいた。」 | 4 | `40` → |

せいすい 를 쓴 뒤 조우율은 주인공 레벨 1 에서 `0C` 그대로, 레벨 9(구역 `0D` 와 같음)에서 0 이었습니다. においぶくろ·まもののエサ 뒤에는 `60` 이었습니다.

トヘロス 는 주인공이 배우지 않았습니다. `+23` 을 `FF` 로 하자 じゅもん 에 ホイミ·キアリー·ベホイミ·インパス·リレミト·ベホマ·ルーラ·ザオラル 8개가 나왔고, `+22`~`+27` 을 모두 켜도 같았습니다.
대신 주문 표 `11:8024` 의 ホイミ 칸(파일 오프셋 `88024`)을 トヘロス 처리기 `11:8797` 로 덮었습니다. ホイミ 를 외우자 「ホイミをとなえた！」 뒤 `7E:21C9` = 1, `$1A9C` = `80` 이 되었고, 레벨 9 에서 조우율이 0 이었습니다.

## 4. 줄과 여러 종 무리

`22:9284` 의 시작 값 `7E:2FCD + X` 를 누가 쓰는지 보니 `22:935A` 가 무리마다 너비 × 마릿수를 더했습니다. X 는 `22:92AE` 가 `$0D1B` 로 고르는 0·1·2 입니다.
이벤트 무리 1번을 두 무리로 바꾸고, 둘째 무리의 `$100A` 를 무리를 옮긴 뒤(`LATE=570:7E100A=..`) 바꿨습니다.

```
キングスライム 8 + 8       2FCD=15        둘째 무리 0마리, 화면에 キングスライム 3
スライム 4 + 4             2FCD=10        한 줄에 8마리
  둘째 $100A=1             2FCD=08 2FCE=08  둘째 무리가 뒷줄(위쪽)
  둘째 $100A=80            2FCD=08 2FCF=08  둘째 무리가 하늘 높이
スライム 4 + ドラキー 4     2FCD=08 2FCF=0C  ドラキー 는 하늘 줄
```

줄마다 폭 28 을 따로 채우고, 같은 줄의 무리는 앞 무리가 쓴 폭을 이어받습니다. ドラキー 는 그림 머리 `+0` bit7 이 켜져 있어 `$0D1B` 가 `80` 이 됩니다(`22:9062`). 이런 몬스터가 15종이고 모두 날거나 떠 있는 몬스터입니다. 실제 데이터의 고정 무리·이벤트 무리는 줄 값이 모두 0 입니다.

## 5. 맵 항목 `+4`(`$194D`)

`$194D` 를 읽는 `1F:F8D3` 을 부르는 곳은 ラナルータ(`11:826F`), やみのランプ(`11:8C18`, 물건 `B4`) 등 5곳입니다. 21/02(`+4` = `01`)에서 やみのランプ 를 썼습니다.

| `+4` | 결과 |
| --- | --- |
| `01`·`08`·`09` | 「しかし 何も おこらなかった。」 |
| `00`·`02` | `$075E` = `0190`, 맵을 다시 불러옴 |
| 필드(`$194D` = 2) | `$075E` = `0190` |

bit0·bit3 이 켜진 맵에서는 낮밤을 바꿀 수 없습니다. 21/02 에서 바꾸기를 허용하자 동굴 대신 숲 장면이 나왔습니다. 원래 바꿀 수 없는 맵이라 되돌아갈 곳이 맞지 않는 것으로 보입니다.

## 6. `$1010` 과 にげる

`$1010` 은 전투 시작·승리 화면·にげる 에서는 읽히지 않았습니다. 같은 날 [2026-10-25-16](2026-10-25-16-recruit.md) 이 동료 판정(`20:C1F6`)에서 읽는 것을 찾았습니다.
구역 `0D` 를 スライム 1마리만 나오게 하고 플래그 `7E:21B1` bit6 을 켠 채 이겼습니다. `+8` bit7 이 꺼져 있으면 `20:C203` 에서 끝나고, 켜면 `$1010` = 1 로 `20:C241`(확률 판정)까지 갔습니다.

にげる 를 고르며 `$1000`·`$100F` 를 읽는 곳을 찾다가 `20:9623` 을 만났습니다. 선제이거나, 주인공 레벨이 구역 레벨 + 5 이상이면 바로 성공합니다. 아니면 시도 횟수별 `27:8008` = `02 02 04 08` 로 난수를 굴립니다.
구역 `0D`(레벨 9)에서 주인공 레벨 14 는 첫 시도가 바로 성공 갈래(`20:965F`), 13 은 `20:966E` 로 가서 몬스터가 공격한 뒤 둘째 시도에 성공했습니다.
