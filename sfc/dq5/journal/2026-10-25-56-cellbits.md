# 2026-10-25-56: 셀 +0 bit3·+1 bit4-5 는 인물을 앞에 그리는 비트

오래 남아 있던 셀 비트 둘의 뜻을 실측으로 찾았습니다. 둘 다 그 칸에 선 인물을 위층보다 앞에 그리게 하는 비트였고, 인물이 걷는 길에는 영향이 없었습니다. 석상 그림을 바꾸는 `24:A981` 도 확인했습니다.
결과는 [dq5-map-format.md](../docs/dq5-map-format.md) 의 「셀 버퍼」와 [dq5-field-format.md](../docs/dq5-field-format.md) 의 「순간이동 칸」에 있습니다.

## 1. 인물이 걷는 길

인물 슬롯 1~31 의 X·Y 가 바뀔 때마다 적으면서, 매 프레임 셀 비트를 지우는 Lua 를 장면 이동 도구 위에 얹었습니다. 1F/00 과 01/00 에서 3,000프레임 동안 서 있었습니다.

```
1F/00  기본 392줄 = +0 bit3 지움 = +1 bit4-6 지움 = +1 bit3 지움
01/00  기본 143줄 = +0 bit3 지움 = +1 bit4-6 지움
```

어느 비트를 지워도 인물의 길은 한 걸음도 달라지지 않았습니다. 앞 일지에서 화면 비교 때 다른 인물 쪽이 달랐던 것은 길이 아니라 그림 쪽 차이였습니다.

## 2. 걸을 수 있는 칸에 비트가 있는 맵

346개 맵에서 걸을 수 있는 칸(`+1` 아래 3비트가 있고 bit3·bit7 이 없는 칸)의 비트를 셌습니다. `+0` bit3 은 31/00(357칸)·10/00·34/00 에, `+1` bit4-6 은 18/00·01/00·1D/00 에 많았습니다.
그림에 찍어 보니 31/00 은 다리 아래 성벽 앞 칸, 18/00 은 계단과 사다리 칸이었습니다.

## 3. 31/00 의 `+0` bit3

31/00 다리 아래에서 주인공을 세우고 bit3 을 매 프레임 지운 쪽과 비교했습니다.

```
(30,62)  차이 (123,101)-(135,112)   주인공 머리 위쪽
(24,68)  차이 (123,101)-(128,104)
```

지우지 않은 쪽은 주인공 머리가 성벽 턱 앞에 다 보였고, 지운 쪽은 머리 윗부분이 턱 뒤로 가려졌습니다. `+0` bit3 은 그 칸에 선 인물을 위층보다 앞에 그리는 비트입니다.

## 4. 18/00 계단의 `+1` bit4-5·bit6

18/00 의 계단 (4,32)~(4,48) 은 `+1` 이 `32`·`02`·`12`·`52`·`53` 이고, 층 1·2 가 바뀌는 자리입니다. 계단 아래 (4,52) 에서 위로 오르며 6프레임마다 화면을 찍었습니다.

```
지운 비트      다른 화면
bit4-6 (8F)    7장, 주인공이 계단 뒤로 가려짐
bit4-5 (CF)    9장, 같음
bit6   (BF)    2장, 계단 쪽은 같음(다른 자리)
```

bit4-5 를 지우면 계단을 오르는 주인공이 계단 그림 뒤로 숨었고, bit6 만 지우면 계단에서는 달라지지 않았습니다. `2B:B8F3` 등이 매 프레임 `AND #$30` 으로 모으는 값이 인물 그림의 우선순위입니다.

## 5. `24:A981`

석상에서 반지를 뺄 때 `24:A981` 이 불린 1260프레임에 인물 표 쓰기를 지켜보니 `24:AC97` 이 `7E:31E9`(슬롯 9 의 방향)에 `88`(위)을 썼습니다. 석상은 방향마다 그림이 다르고, 반지 없는 그림이 위 방향입니다.

## 틀렸던 것들

- `+0` bit3 을 「위층이 인물을 덮음」으로 적어 두었다가, 지난 일지에서 「8층 차지 표시」로 보았습니다. 실제로는 인물을 위층보다 앞에 그리는 비트입니다. 안뜰 가장자리에서는 그 칸에 선 주인공 둘레에 턱이 없어 차이가 보이지 않았습니다.

## 남은 것

- `+1` bit6 의 뜻 — 해결됨: 층 2·4 인물이 조건 맞는 칸에 서면 bit6 이 OBJ 우선순위를 3 으로 올리는 갈래를 건너뜀, 18/00 에서 OAM 속성 `20` ↔ `30` 실측([dq5-map-format.md](../docs/dq5-map-format.md) 「셀 버퍼」 의 `+1` bit6)
- 반지를 놓을 때 석상 방향을 바꾸는 쪽 — 해결됨: `23:DD3F` 뒤 `24:A98F` → `24:AC9F`([dq5-data-format.md](../docs/dq5-data-format.md))
