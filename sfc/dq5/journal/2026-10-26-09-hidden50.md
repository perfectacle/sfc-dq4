# 2026-10-26-09: 그룹 50 이상 맵의 숨은 물건 칸

[앞서](2026-10-25-184-hidden-items.md) `dq5items.py --check` 는 그룹 `50` 이상 맵 15개를 풀지 못해 건너뛰었습니다. 이번에 이 맵들까지 칸을 세고, 상자 무늬 칸이 실제로 열리는지 보았습니다. 결과는 [dq5-map-format.md](../docs/dq5-map-format.md) 의 「보물상자와 タンス·ツボ·タル」 에 넣었습니다.

## 1. 풀지 못한 까닭

`dq5items.py` 는 모든 맵을 `Decoder(rom, 0xBE)` 로 풀었습니다. 그룹 `50` 이상 맵은 블록 표가 따로 있어 `Decoder` 의 `high` 를 켜야 하는데([「그룹 `$50` 이상」](../docs/dq5-map-format.md#그룹-50-이상-01933d)), 그것을 빠뜨려 블록 번호가 표 밖으로 나가 `IndexError` 가 났습니다. `high` 를 켜자 364개 모두 풀렸습니다.

```text
$ uv run --locked python sfc/dq5/tools/dq5items.py rom/dq5.sfc --check | head -2
맵 364개를 셈(풀지 못한 맵 0개)
칸: {'상자': 198, 'タンス': 108, 'ツボ': 93, 'タル': 104}
```

## 2. 새로 나온 칸

그룹 `50` 이상 18개 맵에는 タンス·ツボ·タル 칸이 하나도 없고, 상자 속성 `84` 가 있는 칸이 7개 맵에 11개 나왔습니다. 실내 맵의 상자 칸 187개는 모두 위층(`+7`)인데, 이 11개는 모두 아래층(`+4`)입니다. 상자·タンス 류·발밑·두 칸 앞 네 표 어디에도 그룹 `50` 이상 맵은 없습니다. 상자 번호를 찾는 `25:FAB0` 은 `1E:EF90` 에서 `$BC`·`$BD` 를 못 찾으면 C 를 켜고 돌아가므로, 이 칸들은 표의 상자로는 열리지 않습니다(코드 읽기).

## 3. 열어 보기

`dq5warp.lua` 의 `TO=51/51,x,y,2` 로 51/51 의 (7,31) 둘레에 서서 조사하고, `12:E642`(상자 찾기 시작)·`12:E66C`(상자 갈래)·`12:E669`(상자 아님)에서 값을 적었습니다. 여덟 자리(6,32 위·오른쪽, 8,31·8,32·8,33 왼쪽, 7,30 아래, 6,31·5,32 오른쪽) 모두 `12:E669` 로 끝났습니다. 같은 입력으로 01/02 에 서자 `12:E66C` 에 닿아 상자 (39,29)를 찾았습니다.

## 남은 것

- 51/51 화면에서 주인공 왼쪽 위에 보이는 상자 그림이 셀 버퍼의 (7,31) 칸인지, 이벤트로 열리는 상자인지
- 상자 찾기(`12:F849` 등)가 주인공 칸에서 어느 칸을 보는지. 01/02 에서는 (36,29)에 선 주인공이 (39,29)의 상자를 찾았습니다
