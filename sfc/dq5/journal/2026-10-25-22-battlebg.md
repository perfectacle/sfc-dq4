# 2026-10-25-22: 전투 배경

전투 화면에서 몬스터 뒤에 깔리는 그림 띠(하늘·풀밭·동굴 벽 등)를 롬에서 풀었습니다. 번호를 정하는 곳, 그림·목록·팔레트 형식을 찾고 배경 11개를 게임 덤프와 맞췄습니다. 결과는 [dq5-graphics-format.md 「전투 배경」](../docs/dq5-graphics-format.md#전투-배경) 에 있습니다.

## 1. 셋업 코드에서 출발

이벤트 전투의 780~858프레임 동안 모든 뱅크의 실행 명령을 `cover.lua` 로 모았습니다(명령의 `battle` 함수는 [「전투 몬스터 배치와 그림자」 일지 1절](2026-10-25-21-mongfx-layout.md#1-머리-값이-가는-곳)). 850~857프레임의 DMA 기록에서 `7E:6000`·`6B00`·`7600` → VRAM `$4000`·`$4580`·`$4B00`, `7E:4B00`·`5600` → `$5580`·`$5B00` 이 배경 타일, `7E:5000` → `$1C00` 이 매 프레임 보내는 타일맵이었습니다.

```sh
mkdir -p work/cov3
battle tools/lua/cover.lua SHOT_DIR=$PWD/work/cov3 LO=000000 HI=3FFFFF FROM=780 TO=858 MAXF=870 POKE="7E1001=0F;7E1005=1"
uv run --locked python tools/listing.py rom/dq5.sfc work/cov3/cover.txt > work/cov3/list.txt
```

`22:85EE` 가 `7E:1AA0` 을 읽어 `22:8983` 표를 보고, 팔레트(`22:8801`), 타일맵(`22:8878`), 타일 복사(`22:870D`)를 차례로 부릅니다. `7E:4000` 의 타일 재료는 845프레임에 몬스터 그림과 같은 타일 압축 풀기(`22:99B7`~`9D8E`)가 쓰는데, 부르는 쪽은 `22:CA81` 이었습니다.

## 2. 그림과 목록

`22:CA81` 이 읽는 그림은 몬스터 그림 머리를 줄인 꼴입니다. `+0` 의 두 니블이 가로·세로 칸 수, 그 뒤 칸 비트맵, 그리고 칸마다 타일 하나입니다. 조각 니블이 없고 모두 8x8 이라, 타일 풀기는 `dq5mongfx.py` 의 `tile()` 을 그대로 썼습니다.

그림은 두 장입니다. 그림 B 는 위 띠 타일로 VRAM `$5000` 에 바로 가고, 그림 A 는 목록 3 이 타일을 골라 BG 타일 `$200`~`$2FF` 를 만드는 재료입니다. 목록 1·2 는 BG1·BG2 의 위 띠 타일맵을 `[타일][개수·반전·팔레트]` 로 줄여 적은 것입니다.

```sh
uv run --locked python sfc/dq5/tools/dq5battlebg.py rom/dq5.sfc            # 49개 목록
uv run --locked python sfc/dq5/tools/dq5battlebg.py rom/dq5.sfc 06 --png work/bg06.png
```

## 3. 번호를 정하는 곳

`7E:1AA0` 쓰기를 `wwatch.lua` 로 지켜봤습니다. 필드에서는 걸음마다 `01:84CF` 가 지형 값(`03:CB1B`)을 그대로 쓰고, 실내 맵은 들어갈 때 `01:83E6` 이 맵 표 `23:FD6A` 의 `+3` 에 `80` 을 OR 해 씁니다. 첫 필드 이벤트(`02:A77B`)는 `06` 을 씁니다.
실측 값은 필드 세 곳 (321,56)·(340,62)·(344,81) 모두 `02`, 배 17/00 은 `80`, 21/02 는 `87` 이었습니다.

## 4. 게임 덤프와 맞추기

이벤트 전투에 `POKE` 로 `7E:1AA0` 을 바꿔 여러 배경을 띄우고, 띠가 다 펴진 뒤의 VRAM·CGRAM·화면을 `dq5battledump.lua` 로 덤프했습니다.

```sh
mkdir -p work/bg/ev
battle sfc/dq5/tools/lua/dq5battledump.lua SHOT_DIR=$PWD/work/bg/ev MAXF=1020 POKE="7E1001=00;7E1005=1" \
  DUMPF=870,890,1000 FROM=780 TO=1000 AT=22CA91
uv run --locked python sfc/dq5/tools/dq5battlebg.py rom/dq5.sfc 06 --compare work/bg/ev 890
```

```
  BG1 $0CC0 위 8줄: 256/256 칸 같음
  BG1 $0DC0 아래 8줄: 256/256 칸 같음
  BG2 $04C0 8줄: 256/256 칸 같음
  팔레트 5: 15/15 색 같음
  팔레트 6: 8/8 색 같음
  팔레트 7: 12/12 색 같음
  화면: 102줄이 띠의 줄과 맞음(y 55~156 ← 띠 줄 10~127), 그중 102줄은 256픽셀 모두, 픽셀 26112/26112
```

다른 번호는 `POKE` 에 `;7E1AA0=0E` 처럼 더하고, 밤은 `;7E1AA1=1` 과 `--alt` 로 봤습니다. 21/02 의 15번은 사다리 출구를 `E2322B0121` 로 덮어 무작위 전투를 붙였습니다([일지 2026-10-25-06](2026-10-25-06-encounter.md#3-던전에서-무작위-전투-잡기)).
06 낮·밤, 0D·0E·13·17·1A·22·29·30, 15, 02 의 11개 모두 타일맵·타일·레코드 색이 같았습니다. 화면은 1A 만 112줄 중 88줄이 다 맞고 나머지는 덜 맞았습니다.

## 틀렸던 것들

- 목록 3 의 `[t][c]` 를 처음에는 「t 부터 c 개 연속」으로 읽어 타일이 8/256 만 맞았습니다. 실제로는 타일 t 하나를 c 번 되풀이합니다.
- 실내 배경의 일부 팔레트가 레코드에 없어서 표를 덜 찾은 줄 알았습니다. 셋업이 전투 직전 맵의 색 사본(`7E:3914`)을 먼저 깔아 두는 것이라, 그 색은 맵마다 다릅니다.

## 남은 것

- `$1949` = 1·2 의 팔레트 오프셋과 `28:FD64` 목록(코드 읽기만. `$1949` 를 고치면 이벤트 전투가 열리지 않음).
