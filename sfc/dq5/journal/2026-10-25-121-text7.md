## 1. 「장면」 갈래를 부르는 인물

대화 스크립트 574개에서 「장면」 대상을 부르는 대화 번호를 모으고, 그 번호를 가진 인물 엔트리를 찾았습니다(`dq5talk`·`dq5npc` 모듈).

```
B91C ← 19E 31/00(48,21)    FB8F ← 091 03/02(28,49)    C310 ← 05B 08/00(29,28)    B417 ← 170 0B/03(10,7) …
```

`19E` 의 스크립트는 조건 없이 메시지 `A52` 를 띄우고 `B91C` 를 부릅니다. `dq5warp.lua TO=31/00,48,23 SAVE=s31.mss` 로 그 인물 앞에 간 세이브스테이트를 만들고, 위를 본 뒤 말을 걸었습니다.

```sh
STATE=$PWD/work/s31/s31.mss PRE="wait:30,up:6,wait:30,a:4,wait:40,a:4,wait:200,a:4,wait:100,a:4,wait:100,a:4,wait:200,a:4,wait:200,a:4,wait:300" \
  MAXF=1500 CALLS=06B91C,0185EC,00C6D8,00954A,248BAF,0582C0 SHOT_DIR=$PWD/work/scene/b91c \
  "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5msg.lua"
```

```
123 0582C0   125 248BAF A=0A52   468 06B91C   523 0185EC
```

「しかし これ以上は このオレさまを たおさぬと 進めぬぞ。」 뒤 전투 화면으로 바뀌어 オーク 한 마리와 싸움이 시작됐습니다. 처음 두 번은 도착하자마자 누른 위 입력이 먹지 않아 주인공이 아래를 본 채 말을 걸었고 「誰もいない」(`129`)였습니다. 30프레임 기다린 뒤 위를 누르자 `7E:31E0` 이 `80`(위)이 되고 인물이 잡혔습니다.
「장면」 24곳 가운데 15곳이 같은 `01:85EC`·`01:86C3` 을 부르고, 나머지 9곳은 맵을 다시 그리는 루틴만 부릅니다(코드 읽기).

## 2. 「호출」 갈래 45곳

파파스 스크립트를 `00 <대상> 3F` 로 덮고 말을 걸며, 그 대상의 실행(`CALLS`)과 메시지, `7E:2190`~`220F` 쓰기(`WWRANGE`)를 기록했습니다. 45곳 모두 실행됐고, 말을 걸 때마다 쓰이는 `7E:21A1` = `71` 을 빼면 플래그를 쓰는 곳이 19곳, 메시지를 띄우는 곳이 10곳이었습니다.

```
B4B1 메시지 5D9, 21AA=06 21B1=02 21B2=40 21B7=18
C017 플래그 2196=0C
FD40 메시지 606, 21A1=F1
```
