# 2026-10-25-155: FD34 는 곡 38 을 잠깐 틀기

[동료 레코드와 임시 칸](2026-10-25-152-native4.md)에 이어, 선실에서만 본 `FD34` 를 원래 장면에서 돌렸습니다. 결과는 [dq5-text-format.md](../docs/dq5-text-format.md#네이티브-호출)의 칸 표 `1DA5` 줄에 있습니다.

## 1. 원래 인물

`FD34` 를 부르는 대화 195 는 00/02 (8,38) 의 병사(「今　人形を相手に　戦いの訓練を　しているのだ」)입니다. (8,40) 에 서서 위를 누르면 한 칸 걸어 버려 말이 걸리지 않았고, 도착 뒤 `7E:31E0` = `80` 을 써 두고 A 를 누르자 말이 걸렸습니다.
`FD34` 와 `25:FD00` 이 기합 소리마다 3번 실행됐습니다.

## 2. APU 로 나간 것

`$2140`~`$2143` 쓰기를 바뀔 때마다 적는 Lua 로 보았습니다.

```
f00702 2141=04 2143=7E 2142=01 2141=15 2141=09     ; 지금 곡을 빨리 줄이고 멈출 때까지
f00728 2141=16 2141=0A 2141=01 2142=38             ; 정리 뒤 곡 38
f00763 2141=04 2143=7E 2142=FF 2141=15 … 2141=01 2142=01   ; 다시 멈추고 맵 곡 01
```

`FD34` 는 `LDA #$38 / JSL $25FD00` 이 전부이고, `25:FD00` 이 대기열(`24:FE91`·`FE9A`·`FE44`·`FF0F`)로 「지금 곡 멈추기 → 곡 38 → 맵 곡으로」를 넣습니다. 앞 일지에서 선실에서 본 `04 FF 7E` 는 그중 되돌리는 쪽이었습니다.
