# 2026-10-30-31: 움직이는 바다 원본과 세계마다 고르기

dq4 트랙이 「바다가 아직 DQ5 그림」이라고 알려 왔습니다. 움직이는 바다 타일 4·5·20·21 은 `01:A719` 의 128바이트에서 만들어지는데, `dq5fieldgfxwrite.py` 가 이 자리를 쓰지 못했습니다. 이 원본이 어떻게 16벌이 되는지 풀고, 도구가 원본을 입력으로 받아 세계마다 따로 쓰게 했습니다. 형식은 [필드 형식 「움직이는 바다」](../docs/dq5-field-format.md#움직이는-바다-01c5c8)와 [쓰기 형식 「필드 그림」](../docs/dq5-build-format.md#필드-그림-dq5fieldgfx1)·[움직이는 바다 실측](../docs/dq5-build-format.md#움직이는-바다-실측)에 있습니다.

## 1. 코드 읽기

`01:C5C8` 을 디스어셈블했습니다. 롬에서 이 루틴을 `JSL` 하는 곳은 필드 불러오기 안의 `01:9FD2` 하나였습니다.

```
01:C5CB  LDA #$19 / STA $A5 / LDA #$A7 / STA $A6 / LDA #$01 / STA $A7   원본 01:A719
01:C5D7  LDA #$00 / STA $06 / LDA #$C0 / STA $07 / LDA #$7E / STA $08   대상 7E:C000
01:C5E3  LDA $1949 / CMP #$02 / BEQ → JSR $C66B,  아니면 JSR $C746
01:C5F2  DMA 목록($1C0D~): 7E:C000·C400 → VRAM 워드 2040·2140, 64바이트씩 / JSL $2B8000
```

`01:C746` 은 16번 돌며 `01:C774` 로 한 벌을 만들고, 방금 만든 벌을 다음 벌의 원본으로 삼습니다(`$A5` ← `$06`, `$06` += `80`). `01:C774` 는 바이트 i 와 i + `20`(타일 4 와 5, 또 20 과 21)을 이어 16비트로 보고 한 픽셀 돌립니다. `$1949` 가 0 이면 오른쪽(`LSR` / `ROR` / `ROR`, `01:C7B7`), 아니면 왼쪽(`01:C7C5`)입니다. 세계 2 의 `01:C66B` 는 돌리지 않습니다. 네 타일의 첫 줄을 모아 두고 줄 r 에 줄 r+1 을 옮긴 뒤, 위 타일 맨 아래 줄에 아래 타일 첫 줄을, 아래 타일 맨 아래 줄에 모아 둔 첫 줄을 넣습니다. 16×16 을 위로 한 줄 미는 것입니다.

원본 128바이트는 필드 타일 RLE(`12:B1A8`)를 풀어 얻은 타일 4·5·20·21 과 바이트까지 같았습니다. RLE 안의 그 네 타일과 따로 된 사본이라, `tiles.bin` 에서 고쳐도 바다는 바뀌지 않습니다.

## 2. 누가 언제 읽나

배 선실 세이브스테이트에서 세계 0 (341,56), 세계 1·2 (50,28) 로 내리며 `lua/dq5rangewatch.lua` 로 `01:A719`~`A798` 과 `7E:C000`~`C7FF` 의 CPU 접근을 모았습니다.

```
세계 0  r 01C78E·01C797  457프레임  01A719~01A798
세계 1  r 01C78E·01C797  448프레임
세계 2  r 01C677~01C73A  448프레임
7E:C000~C7FF  w 01C7AC·01C7B5(세계 0·1), 01C69D~01C73E(세계 2), 그 뒤 r 008F75(DMA)뿐
```

원본은 필드를 불러올 때 한 번만 읽힙니다. 이벤트 전투(スライム 하나)를 이기고 돌아온 뒤(1,790프레임)에도 다시 읽지 않았고, `7E:C000`~`C7FF` 는 전투 전(500프레임)과 같았습니다.

## 3. 벌 만들기를 셈으로

1절을 그대로 옮긴 `dq5gfx.water_frames(원본, 세계)` 를 썼습니다. 벌 k(0~15)는 원본을 k + 1 만큼 민 것이고, 마지막 벌은 원본과 같습니다. 원본 게임 덤프의 끝 프레임 `7E:C000`~`C7FF` 2,048바이트가 세 세계 모두 이 셈과 같았습니다. 880~1030프레임 매 프레임 VRAM 워드 `2040`·`2140` 도 16벌 가운데 하나였고, 16벌이 모두 차례로 보였습니다(대개 8프레임마다).

## 4. 도구

`dq5fieldgfxwrite.py` 에 `water_files` 를 더했습니다. `world0`·`world1`·`world2` 마다 128바이트 파일(타일 4·5·20·21 을 이 차례로 이은 4bpp, `tiles.bin` 과 같은 꼴)이고, `dump` 는 셋 모두 `water.bin` 을 가리킵니다. 키가 없는 세계는 원래 원본을 씁니다. 그래서 `water_files` 가 없는 예전 JSON 도 그대로 쓰기 0개입니다.

- 세 세계가 같으면 `01:A719` 제자리에 씁니다.
- 다르면 `--water-at` 자리에 고르기 훅(26바이트)·고르기 표(`[하위 바이트 4][상위 바이트 4][뱅크 4]`)·새 원본을 두고, `01:C5CB` 의 12바이트를 `JSL` / `BRA` / `NOP` 여섯으로 바꿉니다. 훅은 `LDA $7E1949 / AND #3 / TAX` 뒤 세 표를 읽어 `$A5`~`$A7` 에 둡니다. 원래 원본을 쓰는 세계는 `01:A719` 를 가리킵니다.

X 를 바꾸지만 그 뒤 `01:C746`·`C66B` 는 X 를 먼저 다시 둡니다. 단위 시험이 해석기로 세계 0·1·2·3 마다 `$A5`~`$A7`·P 를 봅니다. `tiles.bin` 의 타일 4·5·20·21 을 고치면 `water_files` 를 고치라고 경고합니다.

원본 롬 `dq5fieldgfxwrite.py check` 는 내보낸 그대로 patch 해 쓰기 0개였습니다.

## 5. 게임에서 확인

`dq5watercheck.py` 가 원본으로 시험 롬 셋을 만들어 같은 장면을 돌립니다. 필드 불러오기 프레임은 `lua/dq5framelog.lua` 로 프레임마다 `$7F`·`$BE`·좌표를 적어, 둘 다 그대로인 마지막 구간과 세계 2 바다 (62,64) 에서 왼쪽으로 밀 때의 첫걸음으로 셉니다.

```
                    세계 0     세계 1     세계 2     세계 2 첫걸음
원본                462~492   453~483   451~481   822
sea(세계 0 만)       462~492   453~483   451~481   822
sea3(세 세계 따로)    462~492   453~483   451~481   822
same(제자리)         462~492   453~483   451~481   822
```

- `sea`: 세계 0 은 136프레임(880~1015) 모두 바다 타일 넷이 새 16벌 가운데 하나였고 16벌이 모두 보였습니다. VRAM `0000`~`7FFF` 의 나머지는 원본 게임과 매 프레임 같았습니다. 세계 1·2 는 VRAM `0000`~`7FFF` 가 원본 게임과 매 프레임 바이트마다 같았습니다.
- `sea3`·`same`: 세 세계 모두 그 세계 원본의 16벌이 보였고, 바다 타일 넷 말고는 원본 게임과 같았습니다.
- `sea` 로 이벤트 전투를 이기고 돌아온 뒤에도 새 벌이 차례로 돌았습니다(대사가 끝난 2,078프레임부터 2,140프레임까지 9벌).

13건 모두 통과했습니다. 원본은 불러오기에서 한 번만 읽히므로, 훅이 수십 사이클을 더해도 불러오기 프레임은 같습니다.

## 틀렸던 것들

- 필드 형식 문서와 `dq5gfx.rotate_pair` 는 세계 1·2 가 왼쪽으로 돈다고 적었습니다. 세계 2 는 `01:C5E3` 에서 갈라져 `01:C66B` 로 위로 밉니다. 세계 1 만 왼쪽입니다.
- 필드 형식 문서는 바다 벌을 `7E:C400-` 로 적었습니다. 덤프한 순간 그 벌이 올라 있었을 뿐이고, 벌은 `7E:C000`~`C7FF` 의 16개입니다.
- 이벤트 전투 뒤 확인 창은 처음에 `dq5fieldgrowcheck.py` 처럼 1975~2140 에서 16벌을 모두 보려 했습니다. 이 장면은 대사가 2,077프레임까지 이어져 벌이 9개만 돌고, 2,160프레임쯤 무작위 전투가 붙습니다. 그래서 8벌 넘게 차례로 도는지만 봅니다.

## 남은 것

- `01:C62B`(`02:A2F9` 가 부름)는 `01:C66B` 와 같은 위로 밀기를 `$1C33` 의 포인터 넷으로 모은 `7E:3D14` 에 하고 `$1841` 이 가리키는 곳에 씁니다(코드 읽기). 어느 장면인지는 재지 않았습니다.
- 세계를 오가는 이벤트·ルーラ·キメラのつばさ·탈것 장면에서 바다를 그 세계 원본으로 다시 만드는지는 보지 않았습니다.
