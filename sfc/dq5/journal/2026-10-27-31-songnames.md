# 2026-10-27-31: 공식 음반 곡명을 곡 시퀀스에 짝짓기

곡 시퀀스 50개(`00`~`31`)에 공식 음반의 곡명을 붙였습니다. 소리를 들어 맞춘 것이 아니라, 지금까지 실측한 장면이 곡명과 맞는지로만 짝지었습니다. 확정 13·추정 6·빈칸 31 입니다. 결과는 [dq5-sound-format.md 「곡 이름」](../docs/dq5-sound-format.md#곡-이름)에 있습니다.

## 1. 공식 곡명 찾기

교향조곡 「ドラゴンクエストV」天空の花嫁 의 곡목에서 곡명을 모았습니다. 1992년 음반은 메들리 안의 곡까지 부제로 적어 두었습니다([위키백과(일본어)](https://ja.wikipedia.org/wiki/交響組曲「ドラゴンクエストV」天空の花嫁)).

```
序曲のマーチ / 王宮のトランペット / 街角のメロディ～地平の彼方へ～カジノ都市～街は生きている / 空飛ぶ絨毯～大海原へ /
愛の旋律 / 洞窟に魔物の影が～死の塔～暗黒の世界 / 戦火を交えて～不死身の敵に挑む / 高貴なるレクイエム～聖(ひじり) /
大魔王 / 天空城 / 結婚ワルツ
```

2015년 영상판 곡목에는 「淋しい村～はめつの予感～さびれた村」 과 「哀愁物語」 가 더 있습니다([inside-games](https://www.inside-games.jp/article/2015/03/02/85484.html)). 모두 23곡명입니다.

처음에는 게임 음원 그대로의 곡목을 찾으려 했습니다. 오리콘의 게임 음원 모음 페이지는 1·2·3·6편 곡목이었고, 5편은 「ゲーム・オリジナル・サウンド・ストーリー」 라는 장 구분 없는 메들리 하나뿐이었습니다. 그래서 곡마다의 공식 이름은 교향조곡의 곡명밖에 없습니다. 여관·승리 같은 짧은 곡의 이름은 이 곡목에 없습니다.

## 2. 장면과 맞추기

곡마다의 장면은 [「곡 번호와 장면」](../docs/dq5-sound-format.md#곡-번호와-장면) 표와 에셋 저장소 `sound/songs/index.json` 의 `scene`·`maps` 입니다. 맵 곡은 맵 번호를 다른 일지의 실측과 맞춰 장면을 좁혔습니다.

- `07` 은 맵 19/02 하나의 곡입니다. 19/02 는 카지노 슬롯을 돌린 맵이라([2026-10-26-28](2026-10-26-28-slotrng.md)) カジノ都市 입니다.
- `0F` 는 맵 1F/01 의 곡입니다. 1F/01 은 결혼식이 열리는 교회입니다(`05:F594`, [2026-10-27-07](2026-10-27-07-party7.md)). 結婚ワルツ 입니다.
- `11` 은 맵 1F/0A 의 곡이고, 결혼식 뒤 장면이 시작되는 방입니다(`05:F648`). 愛の旋律 로 보았지만 추정입니다.
- `13` 은 21/05·21/0D·0E/02 의 곡입니다. 21/05 는 `7E:2190` bit6 이 켜진 청년기의 サンタローズ 입니다. さびれた村 으로 보았지만, 0E/02 가 어디인지 몰라 추정입니다.
- 마을 맵 60곳의 `06` 은 「街角のメロディ」 와 「街は生きている」 둘 다 마을 곡이라 추정으로 두었습니다.

## 3. 넣은 곳

- 공개 저장소: 형식 문서의 「곡 이름」 표(곡명·판정·근거 장면과 출처).
- `dq5spcfile.py` 의 `SONG_NAMES`. `--index-only` 로 에셋 저장소의 `sound/songs/index.json` 에 `name`·`name_status`·`name_source` 를 넣습니다. 다시 넣기 전과 견주면 이 세 칸 말고는 바뀐 것이 없었습니다(24항목, 갈래 포함).
- `dq5soundpage.py` 의 들어 보기 페이지에 「곡명」 칸을 더했습니다. 추정은 곡명 뒤에 「(추정)」 을 붙입니다.
- 파일 이름은 바꾸지 않았습니다.
