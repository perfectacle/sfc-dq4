# 2026-10-25-196: 마차 순서, 맡긴 동료, 이름 입력 창

일행 관리 체계의 나머지를 장면마다 실측했습니다. 결과는 [dq5-data-format.md 「일행 관리」](../docs/dq5-data-format.md#일행-관리)의 세 절(일행 순서와 마차, 맡긴 동료, 이름 입력 창)에 있습니다.

## 1. ならびかえ 는 목록만 바꾼다

`PARTY=02,05,03 WAGON=1` 로 필드에 서서 그 세이브스테이트를 떠 두고, `seqboot.lua` 로 A → さくせん → ならびかえをする 를 골랐습니다. 처음에는 입력 간격이 짧아 명령 창이 열리기 전에 방향키가 지나갔고, 40프레임씩 띄우자 들어갔습니다.
창에는 걷는 셋에 1·2·3 번호가, 마차의 ドラきち 에는 번호가 없었습니다. ドラきち·ホイミン·スラリン 을 고르자 셋째에서 창이 닫히고 `7E:2020`~ 가 `03 02 01 00` 이 되었습니다. 레코드(`7E:2040 + n*42`)는 그대로라, 순서는 목록에만 있습니다. 주인공이 남은 쪽이 되어 마차에 들어갔고 필드 맨 앞에는 ドラキー 가 섰습니다.
`wwatch.lua` 로 쓰는 곳을 잡아 `05:D7E0` 과 사본을 만드는 `21:A0C9` 를 읽었습니다. 걷는 수의 한도 3 은 `05:D7C4` 의 `CMP #$03` 입니다.

## 2. 마차가 가득 차면 맡긴다

동료 8명(`PARTY=03,04,05,06,07,08,09 WAGON=1`)으로 スライム 을 들이자 「しかし ばしゃは いっぱいだった！ だれを あずかりじょに おくりますか？」가 나왔고, 기본 커서인 ドラきち 가 맡겨졌습니다.
들이기 전후 WRAM 을 견주니 ドラきち 레코드가 `7E:2332` 로 옮겨 가고 뒤 레코드가 하나씩 당겨졌습니다. 쓰는 곳 `21:A7B2` 에서 거슬러 `21:AA8E` 의 표(`21:AB9C`)를 읽자 칸 크기 `1A`, 칸 수 `38`(56), 시작 `2332` 였고, 둘째 줄은 사람 동료 칸(`294A`, `20` × 5)이었습니다.

## 3. モンスターじいさん

메시지 `0E8`「わしが 有名な モンスターじいさんじゃ。」 근처의 `BRK 97` 을 찾아 `06:E962` 를 얻었고, 특수 기능 표에서 대화 번호 `007` 의 처리기였습니다. 선실 파파스의 대화 번호를 `007` 로 두고, 첫 프레임에 일행 둘과 맡긴 칸 하나를 써 넣은 채 말을 걸었습니다.
あずけにきた 는 「どの モンスターを 預けるつもりじゃ？」 뒤 A 를 한 번 더 눌러야 목록이 떠서, 처음 두 번은 주인공을 골라 「わしが めんどうをみるのは モンスターだけじゃ。」만 보았습니다.
맡기기·데려오기·놓아주기 모두 레코드와 칸이 바뀌는 것을 보았고, 칸 50개를 채우면 목록 전에 「これいじょうは わしの手に あまるのう」, 49개면 50째 칸에 들어갔습니다. 56칸이 있어도 한도는 50입니다.

## 4. 이름 입력 창

롬을 새 이름으로 복사해 빈 SRAM 으로 켜고 ぼうけんのしょをつくる → 1번까지 갔습니다. 처음에 `seqboot`·`dq5msg.lua` 를 다른 라이브러리 폴더로 돌린 것은 아무 파일도 남기지 않았고, `walklib` 로 돌리자 되었습니다.
이름은 넉 자이고 넷째 글자에서 바로 말 빠르기로 넘어갔습니다. 빈 이름으로 おわり 를 누르면 창이 그대로였습니다. 금지어 검사는 찾지 못해 남은 것으로 두었습니다.

## 남은 것

- 물건을 가진 몬스터를 맡길 때 `21:A82C` 가 물건을 어디로 보내는지.
- 맡긴 칸 `+14`~`+17` 을 만드는 `21:995C` 의 변환.
- 사람 동료(`294A` 칸)를 モンスターじいさん 에게 맡기려 할 때의 갈래(메시지 `0EE`).
- 이름 입력의 금지어 검사 유무.
