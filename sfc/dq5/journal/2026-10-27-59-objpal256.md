# 2026-10-27-59: 필드 OBJ 팔레트 표는 여덟 줄이고, 롬만으로 연출 재현은 닫음

[2026-10-27-51](2026-10-27-51-objpalette.md)이 짚은 대로 그래픽 형식 문서의 필드 OBJ 팔레트 크기를 다시 재고 고쳤습니다. 함께 전투 연출을 롬만으로 그리는 남은 것을 범위 결정으로 닫았습니다. 결과는 [dq5-graphics-format.md 「팔레트」](../docs/dq5-graphics-format.md#팔레트)와 「롬 코드로 돌리기」 의 남은 것에 있습니다.

## 1. `04:96D6` 의 크기

`1F:D463` 을 읽었습니다.

```
1F:D46B  LDX #$3A14 / STX $2181      WRAM 포트 주소 7E:3A14
1F:D476  LDA #$00 / STA $4370        DMA 채널 7, 꼴 0
1F:D47B  LDA #$80 / STA $4371        목적지 $2180(WRAM 포트)
1F:D480  LDA #$04 / STA $4374        원본 뱅크 04
1F:D485  LDX #$96D6 / STX $4372      원본 04:96D6
1F:D48B  LDX #$0100 / STX $4375      256바이트
```

세이브스테이트 셋에서 CGRAM 의 OBJ 쪽(색 128~255)과 WRAM `7E:3A14`~ 를 `04:96D6` 256바이트와 줄마다 견줬습니다(색 0 은 투명이라 줄마다 색 1~15).

```
ship        CGRAM OBJ 줄 0~7 모두 같음, WRAM 도 같음
shop3       CGRAM OBJ 줄 0~7 모두 같음, WRAM 도 같음
field-free  줄 0·1·2·5·6·7 같음. 줄 3·4 는 맵마다 덮는 줄(01:996A)
```

그래서 표는 OBJ 팔레트 0~7 여덟 줄입니다. 세트 레코드의 팔레트 칸은 두 비트라 그중 0~3 만 고릅니다.

## 2. 롬만으로 연출 재현

`dq5fxvm.py --clock` 은 연출 입구 상태 한 벌과 입구 뒤 조이패드·소리 포트 값을 입력으로 139벌 모두 0 차이입니다. 입구 상태 없이 롬만으로 하려면 SPC700 해석기(저장소의 `spc700.py` 는 디스어셈블러뿐)와 전투 입구 상태를 세우는 일이 필요합니다. 비용을 따져 본 뒤 포팅에 쓰는 연출 그림은 지금 방식으로 충분하다고 보고 하지 않기로 했습니다.

## 틀렸던 것들

- 그래픽 형식 문서는 `04:96D6` 을 OBJ 팔레트 0~3 의 네 줄(128바이트)로 적었습니다. 세트가 0~3 만 고르는 것을 보고 표도 네 줄로 본 것이었고, DMA 길이는 `0100` 입니다.
