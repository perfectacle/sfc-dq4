# 2026-10-25-59: 필드 독 피해와 물건 플래그

보통 독이 필드에서 HP 를 줄이는 곳과, 남아 있던 물건 표 플래그(k1 bit5·6·7, k3 하위 6비트, k4 bit7)를 풀었습니다.
결과는 [dq5-data-format.md 「물건 표」](../docs/dq5-data-format.md#물건-표-23b081)·[「주문과 행동」](../docs/dq5-data-format.md#주문과-행동-268765) 에 있습니다.

## 1. 필드 독 피해

[2026-10-25-54](2026-10-25-54-poison.md) 에서는 독을 켜고 걸어도 HP 가 줄지 않았는데, 잰 곳이 틀렸습니다. 일행 레코드를 직접 읽는 곳(`LDA $7E2041,X` 등)을 찾다가 `21:831F` 에서 `LDA $2041 / AND #$20 / … LDA $2042 / DEC / STA $2042` 를 보았습니다. 일행마다 하나씩 같은 루틴이 이어집니다.
`+2` 가 지금 HP 이고 `+E` 는 최대 HP 였습니다(`21:82B1` 이 `+2` 에 10 을 더하고 `+E` 로 자름). 앞 일지들에서 HP 로 적은 `7E:204E` 는 최대 HP 입니다.

```
+1 = A0, 600프레임 좌우로 걷기 : 7E2042 = 24 → 22
+1 = 80                        : 7E2042 = 24
```

HP 가 1 이면 줄이지 않습니다(`DEC` 뒤 0 이면 쓰지 않음).

## 2. 물건 조회 (k3·k4)

`BRK #94` 의 번호 20(k3 하위 6비트)과 16(k4 bit7)을 부르는 `11:83B1`·`11:83DB` 는 물건을 「しらべる」 때의 설명이었습니다. k4 bit7 이 켜져 있으면 장비 칸에 따라 메시지 `452`~`456`「…は 武器らしい」~「道具らしい」를 띄우고, 이어 k3 하위 6비트 n 으로 메시지 `48E + n` 을 띄웁니다(n 이 `38`~`3C` 면 따로 갈래).

```
ひのきのぼう  n=01 → 48F 戦いのとき 道具として 使っても 特別な 効果は ないようだ。
いかずちのつえ n=02 → 490 戦いのとき 道具として 使うと 特別な 効果が あるようだ。
やくそう      n=0C → 49A これは くすりのようだ。
キメラのつばさ n=0D → 49B これを 使うと さいごに 立ちよった ところに もどることが できるようだ。
```

물건마다 맞는 설명이 나와 이 대응으로 정리했습니다. 화면에서 しらべる 를 눌러 보지는 않았습니다.

## 3. 필드에서 쓰기 (k1 bit5·6·7)

필드 도구 사용 `11:88A8` 은 k1 bit6 이면 일행이 둘 이상일 때 대상 고르기 창(`38`)을 열고, bit7 이 꺼져 있으면 「…は …を 使った！」(`1A2`)를 띄운 뒤 물건 처리기(`11:8F5B`)로 가고, 끝나고 bit5 면 그 물건을 없앱니다.
주인공 가진 물건 첫 칸에 やくそう 를 넣고 どうぐ → やくそう → つかう 로 썼습니다(파일 오프셋 `11B1FA` 가 やくそう 의 k1).

| k1 | 메시지 | 쓴 뒤 가진 물건(`7E:2056`) |
| --- | --- | --- |
| `60`(원래) | `1A2` → `18F`「キズが かいふくした！」 | `00 FF`(やくそう 없어짐) |
| `40`(bit5 끔) | `1A2` → `18F` | `00 A1`(남음) |
| `E0`(bit7 켬) | `18F` 만 | `00 FF` |

## 남은 것

- 행동 `98`·`A0`·`A7` 을 몬스터가 고르지 않는 까닭
- 동료 조건의 필드 A6(코드 읽기만), `23:AED1 +8` bit4-7, 장비 비트 `21:A632` 의 인물 번호 ↔ 동료
- k1 bit2·bit4, k3 bit6·7, k4 bit6 의 뜻(부르는 곳은 앎)
