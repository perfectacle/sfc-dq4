# 2026-10-25-141: 독·혼란·마비가 풀리는 곳, 전용 도구 수치

[앞 일지](2026-10-25-136-status.md)에 남긴 상태 이상과 전투 도구의 나머지를 실측했습니다. 결과는 [dq5-data-format.md](../docs/dq5-data-format.md) 의 「상태 이상」「전투 도구」에 있습니다.

## 1. 턴 끝의 상태

턴 끝에는 `20:8B74`(일행)·`20:8C73`(몬스터)이 살아 있는 쪽마다 상태를 봅니다. 혼란이라 여겼던 필드 `1D`(`20:8D72`)는 시간 정지 카운터 `$1017` 이 0 이 될 때 끄는 것이라 시간 정지 쪽이었고, 09E「われにかえった」 를 띄우는 곳은 필드 `1E`(전투 칸 `+7` bit0-1)였습니다.

```
주인공 +7 = 3   턴 1 끝 → 2, 턴 2 끝 → 1, 턴 3 끝 → 0 과 함께 09E
```

몬스터 쪽은 같은 꼴로 `46` 이 혼란, `2D`·`4D` 가 アストロン 입니다.

## 2. 독

맹독은 턴 끝에 최대 HP 를 6 으로 나눈 만큼 줄입니다(`20:8BD4`). 주인공(최대 HP 24)을 맹독으로 두자 여섯 턴 모두 4 였습니다. 보통 독은 턴 끝 처리에 갈래가 없어, 주인공을 보통 독으로 둔 판에서는 독 피해 처리가 한 번도 돌지 않았습니다.
필드에서는 `00:8317` 이 걸음 카운터 `$1A9B` 의 아래 3비트가 0 일 때 보통 독, 아래 2비트가 0 일 때 맹독 루틴을 부릅니다.

```
보통 독  21:8332  67프레임마다 24 → 23 → 22 → 21
맹독     21:8596  35프레임마다 24 → 20 → 16 → 12
```


## 3. 몬스터 마비

슬라임 `+A` 를 `A0` 으로 써서 마비를 걸자 「いなくなった」 로 빠졌습니다. 원래 값이 `C0` 이고 bit6 이 「살아 있음」 이어서, `E0` 으로 다시 걸었습니다. 그러자 24턴 내내 017「からだがしびれて　うごけない」 였습니다.
롬에서 `LDA #$2A / STA $43` 뒤 `BRK 88 7B`(비트 끄기)가 오는 곳은 없어, 몬스터 마비를 풀어 주는 곳은 없습니다.

## 4. 전용 도구

물건 넷씩을 가진 장면을 만들어 전투에서 썼습니다.

```
ちからのたね ×2      ちから 11 → 16
いのちのきのみ ×2    최대 HP 24 → 34
せいすい ×2          슬라임에 12, 10 피해
ばくだんいし          행동 08(イオラ)
```

처리기는 씨앗이 1~3(`20:BCF7`, まもりのたね 만 4), きのみ 가 4~6·3~5(`20:BD40`), せいすい 가 10~15 이고 메탈 셋에게는 1 입니다.

## 틀렸던 것들

- 혼란은 필드 `1D` 다: `1D` 는 시간 정지와 함께 끄는 것이었고 혼란은 `1E` 였다.
- 몬스터 마비는 `+A` 를 `A0` 으로 쓰면 된다: bit6(살아 있음)을 지워 몬스터가 빠졌다.
