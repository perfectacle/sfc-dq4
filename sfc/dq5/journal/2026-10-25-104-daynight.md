# 2026-10-25-104: 걸음으로 가는 낮밤과 ラナルータ

낮밤을 정하는 시간대 `$075E` 가 언제 오르는지, 밤 문턱이 어디인지, ラナルータ·やみのランプ 가 무엇을 바꾸는지 실측했습니다. 결과는 [dq5-field-format.md 「낮밤」](../docs/dq5-field-format.md#낮밤-0082d3) 에 있고, 도구는 `sfc/dq5/tools/dq5daynight.py` 입니다.

## 1. 아무리 걸어도 오르지 않는 시간대

`field-free.mss` 에서 조우를 끄고(`11EA44` 8바이트 0) 6000프레임을 걸으며 `$075E` 쓰기를 WRAM 감시로 보았는데 한 번도 쓰지 않았습니다. 읽는 곳만 `01:A134`(필드 색)·`21:8004`(밤 판정)이었습니다.

롬에서 `8D 5E 07`(STA $075E)을 찾으니 걸음마다 도는 `00:8290` 안에 `INC A`·`AND #01FF` 가 있었습니다. 앞에 세 조건이 붙어 있습니다.

```
00:82C2  LDA $BE        ; bit7 이면 건너뜀
00:82C6  LDA $1949      ; 0 이 아니면 건너뜀
00:82CB  LDA 7E:2190 / AND #02   ; 켜져 있으면 건너뜀
00:82D3  REP #$20 / LDA $075E / INC A / AND #$01FF / STA $075E
```

`00:82C2` 에서 값을 찍으니 `7E:2190` = `0A` 로 bit1 이 켜져 있었습니다. 여러 이벤트(`BRK 0C` 11곳, `BRK 0D` 3곳)가 켜고 끄는 비트입니다.

## 2. 한 걸음에 하나

`POKE 7E2190=08` 로 bit1 만 끄고 좌우로 걸었습니다.

| | 값 |
| --- | --- |
| `00:82C2` 를 지난 횟수(걸음) | 98 |
| `$075E` | `0050` → `00B2`(+98) |

마을 01/00 에서는 `$BE` 가 `80` 이라 같은 조건에서도 170걸음 동안 오르지 않았습니다. 밤 판정 `21:8000` 은 `CMP #00F0` 이므로 한 바퀴 512걸음 가운데 낮이 240걸음, 밤이 272걸음입니다.

```
$ uv run --locked python sfc/dq5/tools/dq5daynight.py rom/dq5.sfc --start 50 --steps 98
0050 + 98걸음 = 00B2 낮
```

## 3. ラナルータ 와 やみのランプ

필드 주문 처리기 ラナルータ(`11:826F`)는 `21:8000` 결과로 갈라 밤이면 `0050`, 아니면 `0190` 을 쓰고 `06:D905` 로 맵을 다시 불러옵니다.
주인공에게 주문을 주려고 일행 레코드 `+23`(필드 주문 칸 0~7)을 `FF` 로 켜니 じゅもん 목록에 ホイミ·キアリー·ベホイミ·インパス·リレミト·ベホマ 가 나왔습니다. 주인공 필드 주문 목록 `23:BE2C`(`27 2C 28 35 33 29 32 2E`)의 첫 바이트를 `37` 로 바꾸자 リレミト 자리에 ラナルータ 가 나왔습니다.

| 외우기 전 | 외운 뒤 |
| --- | --- |
| `0050`(낮) | `11:82A4` 가 `0190` 을 씀, 밤 필드 |
| `0190`(밤) | `11:82AC` 가 `0050` 을 씀, 낮 필드 |

やみのランプ(물건 `B4`)를 가진 물건 첫 칸에 넣고 どうぐ → つかう 로 썼습니다. 낮에는 「火を ともした！」 뒤 `11:82A4` 가 `0190` 을 썼고, 밤에는 「しかし 何も おこらなかった。」로 쓰지 않았습니다. 램프는 `11:8C28` 에서 밤이면 건너뛰기 때문입니다.

## 남은 것

- 여관 루틴 안의 `06:E43A`(`0050`)를 자고 나서 실측하는 것. 01/00 여관 주인 앞에 서 보았지만 말 걸기가 닿지 않았습니다.
- `7E:2190` bit1 이 꺼지는 이야기 시점, `$075E` 를 읽는 `02:D399`·`06:B74A`·`06:CE9D`
