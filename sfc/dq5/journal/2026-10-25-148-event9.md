# 2026-10-25-148: 이벤트·플래그의 남은 것 닫기

[2026-10-25-139](2026-10-25-139-event8.md) 뒤에 [dq5-event-format.md](../docs/dq5-event-format.md) 와 [dq5-flags.md](../docs/dq5-flags.md) 의 「남은 것」 을 하나씩 닫았습니다.

## 1. 1A/02 의 パパス

지난번에는 パパス 바로 옆 (11,11) 에서 말을 걸어 「その方向には　誰もいない。」가 나왔습니다. dq5-npc2 가 밝힌 대로 대화 상대는 주인공 두 칸 앞에서 골라집니다. 그래서 두 칸 아래 (12,13) 에서 위를 보고 말을 걸었습니다.

```
724 248BAF A=077F   パパス「待たせたな　ああああ。 ダンカンの病気は…
863 06BD94          21AF.6 켜고 02:B705 → 15:F0CB
```

주인공이 (12,11) 을 거쳐 (14,11) 로 걷고, 스크립트가 `21A3.7` 을 켠 뒤 네이티브 `02:AE69` 까지 갔습니다.

## 2. 일행을 거두는 루틴

32/00 의 장치를 동료 둘을 데리고 다시 걸었습니다. `12:8B3E` 는 일행 슬롯의 `7E:33A0` 에 A 를 씁니다(`02:81B5` 에서 `B0`, `02:81DB` 에서 `00`). `03:B351` 동안에는 동료가 주인공 칸으로 모였습니다(슬롯 1 의 Y 6 → 4).

## 3. 21D7.7 을 게임에서

`02:89E6` 은 그룹 `51` 의 매 프레임 루틴 안이었습니다. 51/53 은 레일과 광차가 놓인 맵이고, `21E2.7` 을 켜고 들어가자 823 프레임에 `02:8B27 TSB $21D7` 이 실행되었습니다.

## 4. 청년기의 장소와 대사

장소 이름을 ルーラ 목적지 목록과 이름 표의 짝으로 다시 맞추다가, 대화 `153`·`155`·`16C` 를 쓰는 그룹 `20` 을 オラクルベリー 로 잘못 적어 둔 것을 찾았습니다. 그룹 `20` 은 ポートセルミ 이고 オラクルベリー 는 `19` 입니다.

대화로 재지 않았던 단계는 선실에서 대화 번호를 바꿔 걸고, 쓰기 감시로 비트가 켜지는 순간을 잡았습니다.

```
13B  882 뒤                              21BC = 02   (06:B0CA)
1E8  「ご結婚を　お望みですか？」 はい  21B4 = 80
1F6  ビアンカ「こんな私で　いいの？」 はい  21AC = 80, 21B3 = 08
번호 2C (29/00)  21B0 = 04 (00:BFB3), 메시지 2F9 「マリア…………！」
```

アルカパ 의 `0D7` 만은 일행에 인물 `03` 이 있어야 켜는 갈래로 가는데, 일행 레코드를 고쳐도 조건이 맞지 않았습니다.

## 5. 시험하는 곳이 없는 비트

`dq5flags.py` 의 짧은 주소 출처에, 읽은 뒤 `AND #`·`BIT #`·`BPL`·`BMI` 로 가르는 꼴과 `BIT $21xx` 뒤 `BVC`·`BVS` 를 더했습니다. 예를 들어 `21E2.7` 은 `02:8AEB LDA $21E2 / BPL` 이 봅니다. 시험하는 곳이 없는 비트는 57개에서 37개가 되었습니다. 그중 19개는 바이트를 통째로 읽는 값 바이트의 일부이고, 18개는 어디서도 보지 않습니다.

## 6. 쓰지 않는 스크립트

「부르는 곳을 찾지 못한 37개」 는 그 뒤 직접 호출과 받침 루틴, `05:F143` 의 계산 호출(번호 20~25)을 더해 이미 16칸으로 줄어 있었습니다. 16칸은 롬 어디서도 부르지 않습니다. dq5-flags.md 의 남은 것에 옛 수가 남아 있던 것을 지웠습니다.
