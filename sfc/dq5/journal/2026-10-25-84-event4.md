# 2026-10-25-84: 이벤트를 제 장면에서 걸기

[2026-10-25-64](2026-10-25-64-event3.md) 까지는 이벤트 스크립트를 `$19B3` 에 직접 넣어 명령 경계만 보았습니다. 이번에는 이벤트를 거는 인물을 찾아, 그 인물이 스스로 이벤트를 걸게 했습니다. 부르는 곳을 못 찾은 번호 표 스크립트도 마저 정리했습니다. 결과는 [dq5-event-format.md 「제 장면에서 걸기」](../docs/dq5-event-format.md#제-장면에서-걸기) 에 있습니다.

## 1. 누가 이벤트를 거나

이벤트 0~9 와 `02:B705` 직접 호출의 앞 루틴이 어디서 불리는지 찾았습니다. 대화 스크립트의 네이티브 호출(`00`), 인물 인라인 스크립트의 네이티브 호출(`37`), 맵별 루틴 표를 모아 가장 가까운 앞 주소와 맞췄습니다.
대부분 인물 인라인 스크립트였습니다. 인물은 플래그를 기다리거나(`09`) 주인공이 범위에 들어오기를 기다린 뒤(`08`) 루틴을 부릅니다.

```
06/08  09 44 02 (21D4.1 꺼짐) / 08 a5 10 26 15 (주인공이 (37,16)-(38,21) 안) / 37 fd d6 06 → 이벤트 3
21/00 대체(219A.4)  09 91 80 (21A1.7 켜짐) / 37 27 c9 06 → 이벤트 0
```

## 2. 장면 만들기

`dq5warp.lua` 의 `TO` 로 그 인물의 맵에 가서, 인물 목록 조건 플래그는 `SET`, 인물이 기다리는 플래그는 도착 뒤 `LATE` 로 넣었습니다. `LATE` 를 쓴 것은 `21A1`·`219F` 가 맵에 들어설 때 지워지기 때문입니다.
14장면 중 7장면에서 인물이 이벤트를 걸었습니다(이벤트 0·1·2·3, `02:F717`·`05:F45E`·`25:FEB6`).

```
s_ev0  23E29A A=0000 / 02B705 / 1A0D 1A0F 15F150 15F152 …
s_ev3  23E29A A=D003 / 02B705 / 1A0D 1A0F 1A11 15F79E 15F7A2
s_b25FEB6        02B705 / 1A0D 15F360 15F361 …
```

`02:B705` 가 `7E:1A0D` 에 만든 걷기를 먼저 실행하고, `C3` 으로 이벤트 스크립트에 뛰는 것이 그대로 보였습니다. 이벤트 2 장면에서는 그 끝에 이벤트 3 까지 이어졌습니다.

걸리지 않은 것도 있습니다. 이벤트 4·5·7·`05:FC5C` 는 플래그를 넣고 오래 기다려도 루틴이 불리지 않았고, 01/05·02/06 에서는 주인공이 움직이지도 않았습니다. 그룹 `54` 맵(이벤트 9·`02:F84F`)은 `TO` 로 가지 못했습니다.

## 3. 맵에 들어설 때 걸린 번호 3F

`05:FAF0` 을 보려고 02/08 에 들어서자, 그 인물보다 먼저 `15:F59A` 가 실행되었습니다. 번호 표의 `3F` 로, 부르는 곳을 못 찾았던 칸입니다.
`$19B3` 쓰기를 지켜보니 `23:E30E`(`23:E2F4` 안)였습니다. 그래서 `23:E2F4` 에 들어올 때 스택의 돌아갈 주소를 찍었습니다.

```
A=D03F ret=05F119
```

`05:F116` 은 `JSL $23E2F4 / RTL` 받침이고, `05:FA95` 가 `LDA #$3F / JMP $F116` 으로 이 받침을 불렀습니다. 같은 꼴로 `2A`·`36`·`38`·`39`·`3A`·`42`·`43` 도 불렸습니다.
`05:F143` 은 A = `20` + (`0D` − 주인공 Y) 로 번호를 계산해 넘깁니다. 번호 `20`~`25` 는 한 스크립트의 중간 시작점들이었습니다.
`dq5event.py` 가 받침 호출을 찾게 하자, 부르는 곳이 없는 칸이 30개에서 22개로 줄었습니다. 계산 호출(`20`~`25`)까지 빼면 16칸이 남고, 그중 8칸은 `FF` 하나뿐인 빈 스크립트입니다.

## 4. 명령과 단계

- `C4 1F 33 02`(이벤트 0 이 쓰는 값)를 21/00 에서 `7E:1A0D` 로 걸자, 오른쪽 인물의 자리와 방향이 걸지 않았을 때와 달랐습니다. 인물을 움직이는 명령으로 보이지만 확인은 못 했습니다.
- 신전(`08E`)·カボチ(`17A`)는 400~900 프레임을 25 프레임마다 찍어도 메시지를 잡지 못했습니다.
- パルプンテ `1D` 는 마차에 동료 몬스터(`PARTY=02`)까지 넣어도 메아리였습니다.
