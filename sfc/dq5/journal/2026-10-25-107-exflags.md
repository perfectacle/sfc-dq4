# 2026-10-25-107: ルーラ·リレミト 예외 표를 줄마다 실측, 배에서 내리기

[앞 일지](2026-10-25-92-boarding.md)는 예외 표(`1F:F921`·`1F:FA3C`)가 보는 플래그에 켜는 곳 곁의 대사만 붙였습니다. 이번에는 표의 줄마다 플래그를 켜고 끄며 주문을 외워 결과를 읽었고, 대화로 켜는 플래그는 그 대화를 실제로 돌렸습니다. 코드 읽기로만 알던 `01:82F5`·`01:832A` 도 배에서 내리는 장면에서 잡았습니다.

## 1. 결과를 읽는 곳

ルーラ·リレミト 는 공통 루틴 `11:8090` 에서 갈립니다. `$0F18` bit7(リレミト)이면 `1F:F8F2`, 아니면 `1F:F8D3` 을 부르고 바로 `CMP #$01` 로 결과를 봅니다. `11:80A0`·`11:80AC` 에 실행 감시를 걸어 그때의 A(0 됨, 1 천장·何も, 2 かき消された)를 적는 프로브를 만들었습니다. ルーラ 는 목적지를 고른 뒤에 이 검사를 하므로 A 를 한 번 더 누릅니다.

```
TO=<맵>  SET="2063=FF;2050=63;2044=63;<플래그>"  TEST="a:8,…,じゅもん → ルーラ(일곱째)·リレミト(다섯째),a:8,…,a:8"
```

## 2. 줄마다

50번 가까이 돌렸습니다. 결과는 [dq5-data-format.md](../docs/dq5-data-format.md) 의 예외 표 아래 「확인한 것」 에 표로 있습니다. 표에 적힌 조건은 모두 그대로 맞았습니다. 눈에 띄는 것만 적습니다.

- 그룹 1F 의 둘째 조건(`21B3.2` 켜짐·`21B4.0` 꺼짐이면 막음)은 첫 조건(`21AB.1`·`21AC.7`)을 지난 뒤에만 봅니다. `21B3.2` 만 켜면 0, `21AB.1`·`21AC.7` 과 함께면 2 였습니다.
- 그룹 35 는 그대로 두면 ルーラ 가 1(천장)이고, `21C0.3` 을 켜면 2, `21C1.2` 까지 켜면 다시 1 입니다. 예외는 「막음」 만 덮고 원래 결과는 `$194D` 를 따릅니다.
- 22/00·29/00·1F/00 은 도착하자마자 사건(ベラ, 수도원, サラボナ 의 개)이 돌아 주문을 외울 수 없어서, 같은 그룹의 22/01·29/02·1F/02 에서 했습니다.
- 필드 줄은 `$19AE` bit7 이 켜져 있어야 보는데, 도착 뒤 한 번 켠 값은 주문을 외울 때 0 이었고 매 프레임 고정하면 명령 창이 열리지 않았습니다. `1F:FA19` 의 `BPL` 을 `EA EA` 로 넘기고 보니 `2195.5` → 2, `2192.2`·`.3` 이 켜지고 `.1` 이 꺼지면 2 였습니다.

## 3. 대화로 켜는 플래그

선실의 파파스 대화 번호를 바꿔 말을 걸고, 끝난 뒤 플래그 바이트를 읽었습니다.

| 대화 | 켜진 것 |
| --- | --- |
| `1F6`(ビアンカ 를 고름) | `21AC.7`, `21B3.3` |
| `1FF`(フローラ 를 고름) | `21AC.7`, `21B3.1` |
| `1F7`·`1FE`(シルクのヴェール) | `21B3.2` |
| `234`(ヘンリー「…子どもが いるんだろう？」) | `21D3.7` |
| `204`(ルドマン), 신부 비트 없음 | 없음 |
| `204`, `21B3.3` 을 켜 둠 | `21B4.0`(「…ポートセルミにある　私の船も 自由に…」 뒤) |

코드가 켜는 비트(`2190.6`·`2190.5`·`21A8.1` 등)는 켜는 장면을 돌리지 못했습니다.

## 4. 배에서 내리기

배에 탄 채 땅 쪽으로 가면 `01:830F` 가 `$1954` 를 0 으로 두고 그 칸을 걸을 수 있는지 봅니다(`01:8387`).

| 장면 | 실행된 곳 | 결과 |
| --- | --- | --- |
| 세운 배에 오른 뒤 아래 해안으로 | 746프레임 `01:830F` → `01:832A` | (328,41) 에 내림, 배는 물가에 남음 |
| `SET=21BF|10`(배에 탄 채 시작) 뒤 위(산) | 658프레임 `01:830F` → `01:82F5` | 배에 남음 |
| 같은 장면에서 왼쪽·오른쪽·아래 | `01:832A` | 내림 |

`01:832A` 는 내릴 수 있을 때, `01:82F5` 는 내릴 칸을 못 걸을 때 `03` 을 되돌리는 갈래입니다. 앞 일지의 배에 오르는 장면에서 이 둘이 돌지 않은 것은 내리지 않았기 때문입니다.

## 틀렸던 것들

- 처음 돌린 표에서 「그대로」 칸의 결과가 비었습니다. 탭으로 나눈 칸이 비면 셸이 칸을 당겨 읽어, 주문이 リレミト 로 바뀌어 돌았습니다.
- 배에 탄 채 시작하는 `21BF.4` 는 `7E:21CD`~ 의 배 자리가 아니라 다른 자리(284,159)에 섰습니다. 산 쪽 장면은 그 자리에서 찾았습니다.

## 남은 것

- 필드 줄의 `$19AE` bit7 이 켜지는 장면
