# 2026-10-25-52: 마차를 데려가는 맵($194A bit7)

장면 이동 도구에 마차(`WAGON=1`)가 들어와, 코드만 읽고 「마차 쪽」으로 적어 둔 `$194A` bit7 을 실제로 확인했습니다. 결과는 [dq5-field-format.md](../docs/dq5-field-format.md) 의 「마을 입장」 아래 `$194A` 설명에 있습니다.

## 1. 마차를 데리고 들어가기

`PARTY=02 WAGON=1`(スラリン 과 마차)로 필드에 서서 입구 셋을 밟았습니다. `02:C792` 의 갈래 끝 `02:C7AD`(`$1954` 쓰기)를 추적했습니다.

```sh
STATE=$PWD/work/state/ship.mss FIELD=403,401 PARTY=02 WAGON=1 TEST="up:20,wait:300" \
  TRACE="02C7AD" LOG="7E1954,7E194A" SHOT_DIR=$PWD/work/wgb0A "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5warptrace.lua"
```

```
0A/00 ($194A = 84)  02C7AD A=0001  $1954=01   마차가 주인공 뒤를 따라옴
13/00 ($194A = 84)  02C7AD A=0001  $1954=01
02/00 ($194A = 00)  02C7AD A=0000  $1954=00   スラリン 만 따라옴
```

bit7 이 켜진 그룹에서만 마차가 실내까지 따라옵니다. 0D 입구(385,399)는 마차를 데리고는 아래에서 들어가지지 않아 다른 두 그룹으로 확인했습니다.

## 남은 것

- 0D 입구에서 마차가 있으면 들어가지지 않는 까닭
