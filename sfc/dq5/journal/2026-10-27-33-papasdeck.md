# 2026-10-27-33: 배에서 내리는 장면을 거는 パパス 대화

[2026-10-27-30](2026-10-27-30-firstfield.md) 에서 17/01 의 내리는 장면(목록 `10:B135`)은 `21A1.7` 을 `WR` 로 켜서 시작했습니다. 원래 게임에서 그 비트를 켜는 곳을 찾았습니다. 결과는 [dq5-story.md](../docs/dq5-story.md) 순서 3·4 사이의 흐름입니다.

## 1. 정적으로 좁히기

`dq5flags.py rom/dq5.sfc 21A1` 의 `21A1.7` 켜는 곳 가운데 배(17)의 인물·이벤트 스크립트는 없었습니다. 목록 `10:B135` 의 パパス(슬롯 (49,53))는 대화 번호 `01A` 입니다. `dq5talk.py` 로 풀면 `2192.5` 가 꺼져 있을 때 「わすれものは　ないな？ タンスのなかも　調べたか？」(`751`)를 묻고, はい 면 `752`「じゃあ　船長！ …」 뒤 네이티브 `06:B3FC` 를 부릅니다. `06:B3FC` 는 `dq5flags.py` 목록의 `21A1.7` 켜는 곳(`BRK 0C`)입니다.

## 2. 원래 흐름으로 걷기

도착 장면이 끝난 17/01 (51,57) 세이브스테이트에서 시작해 입력만으로 갔습니다.

1. (60,66) 에서 위를 보고 とびら 로 선실 쪽 문을 열고 위로 걸어 17/02 (10,47).
2. (11,41) 출구로 17/00, 사다리 길을 거꾸로 걸어 (9,11) 에서 위의 パパス 에게 말 걸기: 메시지 `74F`「そうか　港に着いたか！」 뒤 480프레임 `2192` = `80`(`2192.7`).
3. 17/00 → 17/02 → 문 (10,48) 로 17/01 (60,66). 이때 17/01 은 `10:B135` 목록이고 난간 칸 (50,52) 의 `+1` 은 `01` 입니다. 갑판을 걷고 선장(대화 `38A`, 메시지 `750`)에게 말을 걸어도 `21A1` 은 바뀌지 않았습니다.
4. (51,53) 에서 왼쪽의 パパス 에게 말 걸기:

```

f391 06:B3FC
f392 21A1=80
f414 21A1=C0, 06:CC9E
f430~ 주인공이 X 50 → 38 로 다리를 건넘
```

`21A1.7` 은 갑판의 パパス 에게 말을 걸어 「わすれものは　ないな？」에 はい 로 답할 때 `06:B3FC` 가 켭니다. 그 뒤는 [2026-10-27-30](2026-10-27-30-firstfield.md) 의 내리는 장면과 같습니다.
