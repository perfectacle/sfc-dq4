# 2026-10-26-39: 옮긴 레코드 자리의 정적 전수, 창 종류별 캔버스, BG3 타일맵 후보 7800

한글 넣기에서 남은 셋을 쟀습니다. 옮긴 창 레코드 자리 `7E:1ABC`~`1BB1` 에 닿을 수 있는 롬의 모든 자리를 정적으로 세어 실측과 맞대었습니다. 창 2바이트 부호의 「캔버스 빌리기」 근거로 창 종류마다 캔버스 사용을 쟀고, BG3 타일맵을 옮길 다른 자리를 VRAM 쓰기 횟수로 찾았습니다. 결과는 [dq5-hangul-format.md](../docs/dq5-hangul-format.md)의 「옮긴 레코드를 둘 자리」·「VRAM 배치와 BG3 칸을 넓히는 길」·「창의 2바이트 부호: 두 길」에 있습니다.

## 1. 정적 전수

롬의 모든 바이트를 명령 시작으로 보고, 이 범위에 닿을 수 있는 모양을 셌습니다(`dq5wramrefs.py`). 절대·롱 피연산자가 범위 안이거나, 간접 포인터 자리가 범위 안이거나, 16비트 즉값이 범위 안인 곳입니다. D 를 알 수 없는 `TCD`·`PLD` 와 대상 범위를 알 수 없는 `MVN`·`MVP` 도 넣었습니다. 모두 12,786곳입니다.

이것을 실행 커버리지와 맞댔습니다. 접근 카운터만 쓰는 `lua/dq5execcov.lua` 로 장면 열셋을 돌렸습니다. 전원부터 셋, 타이틀 연출, 필드 전투, 선실 메뉴, 무기점, 전투, 주문 연출 여섯입니다. 앞 일지의 장면 여덟과 합쳐 실행된 롬 바이트는 85,676개입니다. 전원부터 켠 실행 말고는 범위에 읽기·쓰기가 없었습니다.

실행된 바이트에 걸린 후보는 352곳이었습니다. 그 자리에 실행 감시를 걸자, 실제 명령 시작으로 실행된 것은 14곳뿐이었습니다.

```
00:8923 PLD  222번, S1=0000(꺼내는 값)
00:866D MVN  대상 7E, Y=8000~   (전원 지우기)
22:8758 MVN  대상 7E, Y=6000~
25:84D3 MVN  대상 7E, Y=2001~
```

`PLD` 11곳은 모두 0 을 꺼내 D 가 0 이었고, `MVN` 셋은 대상이 범위 밖이었습니다. 나머지 338곳은 다른 명령의 중간 바이트였습니다.

실행되지 않은 후보 가운데 5,775곳은 실행된 바이트가 하나도 없는 뱅크 22개 안에 있습니다. 코드가 있는 뱅크의 미실행 6,659곳이 미확인으로 남았고, 그중 피연산자가 직접 범위를 가리키는 모양은 907곳입니다.

## 2. 창 종류별 캔버스

처음에는 필드 세이브스테이트에서 2프레임씩 눌러 메뉴를 열려 했는데, 명령 창이 열리지 않거나 방향이 먹지 않았습니다. 6프레임씩 누르자 열렸고, 메뉴를 옮겨 다니는 것은 선실 세이브스테이트에서 됐습니다.

명령 창·도구 목록과 どうする 창·장비 2단·つよさ 와 HP·MP 창·작전에서는 캔버스 칸 `96`~`17F` 를 하나도 쓰지 않았습니다. 문·조사·주문·まんたん 처럼 메시지가 함께 뜨면 233~234칸을 다 썼습니다.

## 3. BG3 타일맵의 다른 자리

같은 장면 열셋에서 VRAM 0x400워드 칸마다 쓰기 횟수를 셌습니다.

```
blk     boot  title  field  cabin  battle  shop   (주문 여섯, 타이틀 연출)
3400       0      0      0      0       0     0
7000       0      0      0      0       0     0   타이틀 연출만 2048
7800       0      0      0      0       0     0
```

전원 지우기 말고 한 번도 쓰이지 않은 칸은 `3400`·`3800`·`7800`·`7C00` 이었습니다. `3400`·`3800` 은 슬롯이 큰 맵의 BG 글자 자리라 빼고, `7800`·`7C00` 으로 즉값 열일곱을 바꾼 롬(`bg3move --base 78`·`7C`)을 만들어 앞의 비교를 다시 돌렸습니다.

`7800` 은 전원부터 넷과 필드 무작위 전투에서 화면이 모두 같았습니다. 타이틀 연출은 `dq5titlegif.py` 를 이 롬으로 돌리자 GIF 가 원래 것과 바이트째 같았습니다. `7C00` 은 로고·필드·전투에서 몇 장이 달랐습니다.
