# 2026-10-25-117: 회심 1/32, つうこん, 방어 상태 2, 주문 내성

[앞 일지](2026-10-25-109-damage2.md)에 남긴 전투 계산식을 마저 확인했습니다. 결과는 [dq5-data-format.md 「전투 계산식」](../docs/dq5-data-format.md#전투-계산식-20b030) 과 「주문과 행동」의 내성 문단에 있습니다.
실험은 같은 슬라임 한 마리 전투에서 값을 `POKE` 로 고정하고, 루틴 안의 PC 에서 A·X 와 `$10F5`(공격하는 쪽)·`$10F6`(맞는 쪽)을 기록했습니다.

## 1. 회심을 덮어도 절반만 회심이던 까닭

회심 판정을 늘 회심으로 덮은 판에서 PC 를 공격마다 차례로 찍었습니다.

```
20C3F6 (たたかう) → 20B030 (보통 피해) → 20C5F0 → 20C697 → 20C6B4 (난수) → 20C65C → 20AB04 (회심 피해)
```

일행의 たたかう 는 보통 피해를 먼저 셈하고 나서 회심을 가릅니다. 그래서 회심인 공격도 `20:B0C3`(보통 피해 끝)을 한 번 지나고, 앞 일지에서 `20:B0C3` 횟수를 「보통 공격 수」로 센 것이 틀렸습니다.
`20:B0C3` 은 공격 수 전체이고, 덮은 판의 주인공 공격 20번 중 회심이 19번(마지막 하나는 끝나기 전에 멈춤), 판정을 1/2 로 덮은 판은 31번 중 16번이었습니다.

원래 롬으로 입력 때를 달리한 여덟 판을 돌려 594번 공격(주인공 321·파파스 273)에서 회심이 24번(주인공 14·파파스 10)이었습니다. 4.0% 로 1/32(3.1%, 기대 18.6번)와 표준편차 1.3 안에서 맞습니다.

## 2. つうこん

`20:C40B` 는 `LDA #$42 / XBA / LDA $10F5 / BRK 8C 79` 로 공격하는 몬스터의 상태 비트 `42` 를 봅니다. `21:91F9` 표에서 `42` 는 몬스터 칸 `+A` 에서 3바이트 뒤(`+D`)의 bit6 입니다.
`7E:07CD` 를 `40` 으로 고정하자 슬라임의 공격 10번이 모두 `064`「つうこんの　いちげき！」 뒤 `20:B584` 로 갔고, 공격력 100 에서 100~105 였습니다(주인공 수비력 255). 이 비트를 켜는 곳은 찾지 못했습니다.

## 3. 방어 상태 2

ぼうぎょ 를 고른 턴에 쓰이는 RAM 을 찾으려고 일행 전투 칸 `7E:0760`~`077F` 쓰기를 보자 `21:91A8` 이 `7E:0766`(주인공 칸 `+6`)에 1 을 썼습니다. 이 칸을 2·3 으로 고정하면 피해가 1/5 였습니다.

```
+6 = 1   49 → 24, 52 → 26
+6 = 2   49 → 9,  52 → 10
+6 = 3   49 → 9,  52 → 10
```

처음에는 필드 표대로 `+5` 를 바꿔 보았지만 `$49` 는 늘 0 이었습니다.

## 4. 주문 내성

손님 파파스의 행동 여섯을 모두 メラ(`01`, 양 번호 1 = 바탕 12·폭 4)로 하고, 슬라임 레코드 바이트12 bit4-5(メラ 내성)를 0~3 으로 바꿨습니다. `20:AB98`(양)과 `20:ABD9`(내성 뒤)의 값을 짝지었습니다.

```
주인공 레벨 1    내성 0: 12~15 그대로   1: 12→9 13→10 14→11 15→12   2: 12→3 13→4 14→4 15→4   3: 0
주인공 레벨 20   내성 1: 그대로        2: 12→7 14→9                    3: 0
```

양은 12~15 가 고르게 나왔습니다. 레벨 1 은 `27:8055` = 255·205·84·0, 레벨 20 은 `27:8059` = 255·255·169·0 의 256분의 값이고, 255 는 곱하지 않고 그대로 둡니다.
`20:ABAB` 가 주인공 레벨(필드 27)에서 10 을 빼 무리 레벨 `$100F`(이 이벤트 전투는 0) 이상이면 둘째 표를 씁니다. 파파스는 빈 몬스터 칸(`81`~`83`)도 쳐서, 맞는 쪽이 `80` 인 것만 셌습니다.

## 틀렸던 것들

- 회심을 늘 일으켜도 절반만 회심이다: `20:B0C3` 은 회심인 공격도 지나므로 그 수를 보통 공격 수로 센 것이 틀렸다.
- 방어 상태는 일행 칸 `+5` 다: `+6` 이었다.

## 남은 것

- 일행이 맞을 때 갑옷의 주문 내성(`20:ABDC` 의 `27:80E3`·`27:80FC` 표).
- 일행 피하기(필드 `3D`)의 실측, つうこん 상태 비트 `42` 를 켜는 곳.
