# 2026-10-26-44: ポワン 의 부탁을 거절하면 22/00 의 징검돌이 가라앉음(06:C8EA·03:9747)

[2026-10-26-03](2026-10-26-03-exflag4.md) 의 「남은 것」 이던 `06:C8EA` 가 부르는 `03:9747` 을 풀었습니다. ポワン 의 부탁을 거절한 채 나가려 하면 요정 마을 남쪽 물 위의 징검돌을 가라앉혀 길을 막고, 부탁을 받아들이면 다시 올리는 루틴입니다. 결과는 [dq5-data-format.md](../docs/dq5-data-format.md) 의 `2199.3` 줄에 더했습니다.

## 1. 코드

22/00 의 숨은 인물 `05:C86E` 는 주인공이 (34~37,35) 에 들 때마다 `06:C8EA` 를 부릅니다(`21B5.0` 이 꺼져 있고 `2199.3` 이 켜져 있으면 부르지 않고 멈춤).

```
06:C8EA  21A2.7 꺼짐이면 21B5.0 끄고 21A2.7 켬        ; 맵에 들어온 뒤 처음 한 번
         21B5.0 꺼짐: 2199.3 꺼짐·219F.7 켜짐이면 03:9747, 21B5.0 켬
         21B5.0 켜짐: 2199.3 켜짐이면 03:9747, 21B5.0 끔
03:9747  (34,44) 부터 위로 다섯 줄씩, 21B5.0 에 따라 고른 타일로 셀을 다시 씀(00:D07D·00:D0AE)
```

`219F.7` 은 ポワン 장면 `06:C1B3` 이 메시지 `259` 앞에서 켭니다.

## 2. 실측

`219F.7` 만 써 넣고 장면을 돌리면, 272 프레임에 `06:C8EA` → `03:9747` 이 불려 317 프레임까지 돌이 아래 줄부터 사라졌고 `21B5` = `01` 이 되었습니다.

원래 흐름으로는 22/00 (35,55) 에서 A 로 장면을 넘기다 `259` 의 はい/いいえ 에서 B 를 눌렀습니다. 922 프레임에 `$E8` = `FF`, 메시지 `25A`「そうですか。 ざんねんですが しかたありませんわね……。」 뒤 아래로 걷자 1481 프레임에 `03:9747`, 1527 프레임 `21B5` = `01` 이었고, 주인공은 물가 (35,35) 에서 더 내려가지 못했습니다.

이어(동료를 둔 `PARTY=02` 세이브스테이트에서 같은 거절 뒤) 위로 걸어 ポワン 에게 다시 말을 걸자 `06:C180` → `06:C184` 가 `25B`·`25C`·`25D` 를 띄우고 `2199` = `18` 이 되었습니다. ベラ 가 일행에 든 뒤 아래로 걷자 232 프레임에 `03:9747`, 278 프레임 `21B5` = `00` 으로 돌이 다시 올라왔고 ベラ 와 함께 건넜습니다.
