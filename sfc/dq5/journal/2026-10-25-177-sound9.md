# 2026-10-25-177: 맵 곡 346곳 실측과 맵 곡을 바꾸는 조건

[곡 줄이기·키우기를 부르는 장면](2026-10-25-169-sound8.md) 까지 맵 곡 표(`23:FD6A` 레코드 `+5`)는 12곳만 들어가 보았습니다. 이번에는 들어갈 수 있는 모든 맵에 들어가 표와 견줬고, 밤과 이야기 플래그로 곡이 바뀌는지 보았습니다. 이야기 이벤트 안의 `04` 하나(이벤트 명령 `C6`)도 스크립트를 직접 걸어 확인했습니다. 결과는 [dq5-sound-format.md](../docs/dq5-sound-format.md) 「맵 곡」「곡 줄이기·키우기를 부르는 곳」에 있습니다.

## 1. 맵마다 들어갈 칸

장면 이동 도구의 `TO` 는 통행 가능한 칸을 줘야 합니다. 처음에는 모든 맵의 출구 표(`dq5exit.py`)에서 「다른 맵의 출구 → 도착 (x, y)」를 모았습니다. 첫 시도에서는 정규식을 「→ 맵」 순서로 잘못 써서 0곳이 나왔고, 「맵 의 출구 n → 도착」 순서로 고치자 250곳이 모였습니다. 나머지 96곳은 통행 격자(`attrgrid.py`)에서 가운데에 가장 가까운 `o` 칸을 골랐고, 92곳이 나왔습니다.

이 절차를 [dq5mapmusic.py](../tools/dq5mapmusic.py) 로 묶었습니다. 맵마다 MesenCE 를 띄워 `lua/dq5sndlog.lua` 가 적은 `00:CEA2` 의 `01` 인자를 표와 견줍니다.

## 2. 결과

| 시간 | 들어간 맵 | 표와 같음 | 다름 |
| --- | --- | --- | --- |
| 낮(세이브스테이트 그대로) | 342 | 342 | 0 |
| 밤(`SET 075E=90;075F=01`) | 250(출구 도착 칸) | 250 | 0 |

밤 실행에서는 21/00 화면이 어둡고 여관 주인이 없어 밤이 걸린 것을 확인했습니다. 들어가지 못한 맵은 통행 칸이 없는 `03/09`·`06/07`·`2B/02`·`32/04` 넷입니다. `17/00`(배)은 곡 `04` 가 나갔지만 장면 이동 도구의 도착 줄이 찍히지 않았습니다.

## 3. 표보다 먼저 보는 조건

곡을 고르는 `00:CE6B` 의 바이트는 `BRK 0B 40 15 / BNE / LDA 7E:21DF / BMI / LDA $BE / BMI / … BRK 0B 80 00 / … LDA #03 … LDA $1954 / CMP #03 … BRK 19 04 01` 이었습니다. 21/00 에 플래그를 넣고 들어가 보았습니다.

```
base           321 cmd=1A arg=06 / cmd=01 arg=06
SET 21DF=8C    321 cmd=1A arg=0C / cmd=01 arg=0C
SET 21A5|40    (곡 명령 없음)
```

`7E:21DF` bit7 은 이벤트 명령 `C8 v` 가 켜는 「이벤트 곡」 표시이고, 맵을 옮겨도 표 대신 그 곡을 틉니다. `7E:21A5` bit6 이 켜져 있으면 맵을 불러와도 곡 명령을 보내지 않습니다. 밤 곡은 따로 없고, 맵 곡을 바꾸는 것은 이 이야기 플래그들입니다.

## 4. 이벤트 명령 C6

`C6` 은 `23:FE69` 에서 지금 곡(`$1D8B`)을 `04` 로 줄입니다. 필드에서 이벤트 걷기 버퍼 `7E:1A0D` 에 `C6 FF` 를 쓰고 `$19B3` = `00:1A0D`, `$19AE` = `80` 으로 걸었습니다.

```
492 exec 23FE69
492 exec 23FE71
492 cmd=04 arg=01 from=23:FE71
```

이벤트 스크립트 전체(`dq5event.py --all`)에서 `C6` 을 쓰는 곳은 `15:F309` 하나였습니다. ヘンリー 를 쫓아간 パパス 가 「く！ カギが かかっている！」 하는 장면 바로 앞입니다.

나머지 여덟 곳 가운데 넷은 들어 있는 루틴의 포인터를 롬에서 찾았습니다(`02:AAE8`·`03:9833`·`06:E0EC`·`03:9964` 는 찾지 못함). `03:EC1C` 는 `02:F889` 가 부르고, 그 루틴 `02:F854` 의 포인터는 인물 자료 뱅크 `10:81AC` 에 있었습니다. `23:DE0A` 는 `02:866C` 의 장치 루틴이, `29:80A0` 은 `1A:85A7`, `0F:FC20` 은 `07:AA74`·`07:D070` 의 포인터가 가리켰습니다. 모든 맵의 인물 목록(`dq5npc.py`, 낮·밤)에서 이 주소들을 찾았지만 나오지 않아, 인물·장치를 찾아 거는 일은 남겼습니다.
