# 2026-10-26-47: 카지노·마차·탈것 장면에서도 롬 밖 뱅크는 실행되지 않음

여러 일지의 「남은 것」 에 남아 있던 「롬 밖 뱅크(`30`~) 감시를 카지노·동료·탈것 장면까지」 를 마쳤습니다. 결과는 [dq5-field-format.md 「롬 밖 뱅크 실행 감시」](../docs/dq5-field-format.md) 에 앞 일지들의 장면과 함께 표로 모았습니다.

## 1. 감시 방법

`dq5warp.lua` 로 장면의 세이브스테이트를 만들고, `sfc/dq5/tools/lua/dq5seqtrace.lua` 로 입력을 재생하며 실행 커버리지를 모았습니다. 한 장면을 `LO=300000 HI=7DFFFF` 와 `LO=B00000 HI=FFFFFF` 두 번 돌렸습니다. `80`~`AF` 는 롬 거울, `7E`·`7F` 는 WRAM 이라 뺐습니다. 테스트 러너가 100초쯤에서 끊기므로 장면마다 2,000~3,700 프레임으로 잡았습니다.

## 2. 장면

| 장면 | 확인한 것 | 뱅크 `30` 이상 실행 |
| --- | --- | --- |
| 카지노 슬롯 | 슬롯 본체 `11:BF71` 이 불리고 코인이 100 → 98 | 0 |
| 어른 주인공·마차·동료 셋 | 필드 걷기, 무작위 전투에서 주인공·スラリン 이 쓰러진 뒤 마차의 ボロンゴ 가 나와 명령 창 | 0 |
| 마법 융단 | どうぐ → つかう 로 펴고(`$1954` = `80`) 좌표가 145번 바뀜 | 0 |
| 天空城 | `$1954` = `81` 로 좌표가 249번 바뀜 | 0 |
| 배 | 해안의 배에 걸어 올라(30 프레임 `$1954` = `03`) 좌표가 127번 바뀜 | 0 |

`$1954` = `80` 을 `LATESET` 으로만 넣은 쪽은 산 위라 움직이지 않아, 융단은 실제로 펴서 탔습니다.

포커는 이 판에 없습니다. 메시지 `000`~`C7F` 에 「ポーカー」·「カード」·「トランプ」 가 하나도 없었습니다.
