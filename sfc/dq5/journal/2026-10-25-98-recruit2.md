# 2026-10-25-98: 동료 확률 표와 반드시 동료가 되는 가진 물건

동료가 되는 몬스터 41종의 확률을 뽑는 도구를 만들고, 판정 루틴을 다시 읽다가 가진 물건으로 판정을 건너뛰는 갈래를 찾아 실측했습니다. 결과는 [dq5-data-format.md 「동료가 되는 몬스터」](../docs/dq5-data-format.md#동료가-되는-몬스터) 에 있습니다.

## 1. 확률 표 도구

`sfc/dq5/tools/dq5recruit.py` 는 몬스터 레코드의 필드 76(확률 등급, 바이트9 bit0-2)과 77(동료 종류, 바이트24)로, 같은 종류를 이미 들인 수 0·1·2 일 때의 분모를 `27:8162`·`8172`·`8182`(등급마다 16비트)에서 찾아 적습니다.

```
00 スライム 등급7 종류02 1/2 1/32 1/16
03 ドラキー 등급4 종류03 1/16 1/64 1/64
12 まほうつかい 등급6 종류04 1/2 1/64 1/64
1E ホイミスライム 등급3 종류05 1/32 1/64 1/128
```

등급이 0 이 아닌 몬스터는 41종으로 동료 레코드(`23:AED1`) 종류 01~29 와 수가 같습니다.

## 2. 가진 물건 갈래

[2026-10-25-16](2026-10-25-16-recruit.md) 에서는 확률 판정 앞의 `JSL 26:8D0A` 를 「일행 자리 확인」 쯤으로 넘겼습니다. 읽어 보니 주인공 가진 물건 첫 7칸(`7E:2056`~`205C`)을 `26:8D33` 의 7바이트와 차례로 견주고, 모두 같으면 carry 를 켜 확률 판정 없이 `20:C2B9`(동료가 됨)로 갑니다.

```
26:8D33 = 00 0A 91 02 3C 64 FF
          ひのきのぼう とがったホネ しあわせのぼうし こんぼう のこぎりがたな みかわしのふく (빈칸)
```

필드 슬라임 셋 이벤트 전투에서 슬라임 등급을 1(바이트9 = `11`, 1/256)로 하고 동료 조건(`7E:21B1` = `40`, `$1010` = `80`)만 주었습니다.

| 가진 물건 | 결과 |
| --- | --- |
| 원래대로 | 승리 메시지로 끝 |
| 위 7칸을 전투 시작 때 넣음 | 「なかまに なりたそうに こちらをみている！」 → 「なかまに くわわった！」 |

## 3. 들인 수 셋·넷

`27:8153` 은 4비트 값의 켜진 비트 수를 돌려주는데 `0F`(넷) 칸만 0 입니다. 0 이면 들인 수 0 의 표를 쓰므로 넷째도 동료가 될 것처럼 보여, 확률 칸을 1 로 하고 `7E:29EC`(スライム 칸)을 `07`(셋)·`0F`(넷)으로 두고 이겼습니다. 둘 다 동료가 되지 않았습니다.

## 남은 것

- `0F`(넷) 에서 동료가 되지 않는 까닭(`27:8153` 이 0 이면 `20:C29E` 갈래로 가야 함)
