# 2026-10-26-21: ポワン 의 25D 창은 ベラ 가 다 걸어야 닫힘, 그 뒤의 ルーラ

[2026-10-26-15](2026-10-26-15-poanwin.md)·[2026-10-26-16](2026-10-26-16-poanwin2.md) 에서 22/00 장면 끝의 메시지 `25D` 창이 닫히지 않는다고 적었습니다. 창은 닫힙니다. 장면 루틴이 ベラ 를 일행 슬롯 1 쪽으로 걷게 하는데, 장면 이동한 세이브스테이트에는 슬롯 1 동료가 없어 ベラ 가 숨은 자리 (128,128) 까지 다녀오느라 오래 걸렸을 뿐입니다. 창이 닫힌 뒤의 ルーラ 도 쟀습니다. 결과는 [dq5-data-format.md](../docs/dq5-data-format.md) 의 `2199.3` 줄에 적었습니다.

실험에는 새 프로브 `sfc/dq5/tools/lua/dq5seqtrace.lua` 를 썼습니다. 세이브스테이트를 불러 입력을 재생하면서 정한 주소를 실행할 때의 레지스터·스택(`HOOK`), WRAM 값이 바뀐 프레임(`WLOG`), 정한 범위의 실행 순서와 커버리지(`LO`·`HI`·`FROM`·`TO`)를 남기고, `SAVEAT` 에서 세이브스테이트를 저장합니다.

## 1. 선실의 대화 04D 는 다음 A 로 닫힘

2026-10-26-16 의 실험(선실, `7E:36EB` = `4D`·`7E:2199` = `08`)을 같은 입력으로 다시 돌리고 대화 엔진(`06:8000`~`FFFF`)의 실행을 모두 적었습니다.

```sh
S="wait:10,up:3,wait:20"; for k in 1 2 3 4; do S="$S,a:4,wait:56"; done; S="$S,down:30,wait:40"
STATE=$PWD/work/state/ship.mss WR="7E36EB=4D;7E370B=00;7E2199=08" SEQ="$S" HOOK="248BAF,06AF32" \
  WLOG="hx=7E3020;hy=7E3080" MAXF=400 SHOT_DIR=$PWD/work/poan3 \
  "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5seqtrace.lua"
```

```
f168 hook 248BAF A=025D ...     메시지 25D
f220 hook 06AF32 ...            대화 스크립트 끝
f295 hy=0C                      주인공이 아래로 걸음
```

`25D` 를 띄운 뒤 다음 A 에서 끝 찾기 `06:B11A` 가 `068459`·`06845A`·`06845B`(`3E 3E 3F`)를 차례로 읽고 스크립트를 마쳤습니다(`Y` = `41`·`42`·`43`). 창이 닫히고 주인공이 걸었습니다. 앞 실험은 A 를 여덟 번 눌렀는데, 대화가 두 번 돌고 여덟째 A 에서 둘째 대화의 `25D` 가 막 떠 그 창에 멈춘 것이었습니다.

## 2. 22/00 의 25D 는 장면 루틴 06:C184 가 띄움

22/00 (35,55) 로 장면 이동한 세이브스테이트(`dq5warp.lua` `TO=22/00,35,55 SAVE=…`)에서 A 를 44 프레임마다 누르며 메시지 루틴 `24:8BAF` 과 대화 엔진 입구 `06:B0B1` 을 걸었습니다. 메시지 `258`·`259`·`25B`·`25C`·`25D` 는 나왔지만 `06:B0B1` 은 한 번도 돌지 않았습니다. 대화 스크립트가 아니라 장면 루틴이 띄운 것입니다. `25D` 프레임을 모두 적어 `24:8BAF` 앞을 보면 `00:8FA1` 이 멈춰 둔 루틴을 `06:C19F` 에서 이어 돌립니다.

`25B` 를 띄울 때의 스택에는 `06:C1E3`(`06:C1E1 JSR C184` 의 돌아올 자리)이 있습니다. 22/00 장면은 `06:C1B3` 에서 시작해 `2199.4` 를 켜고(`BRK 0C 10 09`, 434 프레임 `2199` = `10` 과 메시지 `259` 가 같은 프레임) はい/いいえ 에서 はい 면 `06:C184` 를 부릅니다. `06:C180` 은 `JSR C184 / RTS` 로, 대화 `04D` 의 `2199.3` 꺼짐 갈래(`0B 00 80 C1`, else 뒤 call `06:C180`)가 부르는 같은 몸통입니다. `dq5talk.py` 의 풀이가 맞습니다. 몸통은 `BRK` 명령으로 짜여 있습니다.

```
06:C184  BRK 95 00     대화 창
06:C187  BRK 99 5B     메시지 25B「じつは　私たちの宝 はるかぜの　フルートを…」
06:C18A  BRK 95 32     はい/いいえ
06:C18D  LDA $E8 / BEQ C199
06:C199  BRK 95 00 / BRK 99 5C「まあ！ 引き受けてくださるのですね！…」 / BRK 99 5D
06:C1A2  BRK 0C 08 09  2199.3 켬
06:C1A6  JSL 02:B088   ベラ 를 일행에
06:C1AA  BRK 0E
06:C1AC  BRK 95 FF     창 닫기
```

`02:B088` 에 들어가는 1563 프레임 뒤 2400 프레임을 적어 보면 `03:B0A1` ~ `03:B144` 고리가 한 프레임에 한 번 돕니다. `03:B079` 는 슬롯 X 를 목표 `7E:1EAE`·`1EAF` 까지 한 프레임에 1 픽셀씩 옮기고, 목표는 `03:B21E` 가 슬롯 Y 의 자리와 방향으로 두 칸 앞을 정합니다. `02:B088` 은 X = 9(ベラ), Y = 1 로 부릅니다.

| 프레임 | 일 |

| 1563 | `02:B088` |
| 1564 | `2199` = `18`, 목표 (128,128)(슬롯 1 이 숨은 자리) |
| 3237 | ベラ 도착, `02:B0A8` |

선실 세이브스테이트는 주인공 혼자(`$1967` = 1)라 슬롯 1 이 (128,128) 에 숨어 있습니다. 같은 장면 이동에 `PARTY=02` 를 주어 슬롯 1 에 동료를 두자 목표가 (36,18)·(36,20) 이 되고 2384 프레임에 창이 닫혔습니다. 2026-10-26-15 는 5000 프레임에서 멈춰 닫히기 전이었습니다.

## 3. 창이 닫힌 뒤의 ルーラ

창이 닫히고 `$1967` = 3(주인공·빈 슬롯 1·ベラ) 인 세이브스테이트에서, 처음 3 프레임에 `7E:2063` = `FF`·`2044` = `63`·`2050` = `63` 을 쓰고 じゅもん → 주인공 → ルーラ → ラインハット 를 골랐습니다.

```sh
S="wait:20,a:6,wait:40,right:6,wait:30,a:6,wait:50,a:6,wait:50"
for k in 1 2 3 4 5 6; do S="$S,down:6,wait:20"; done; S="$S,a:6,wait:60,a:6,wait:300"
STATE=<창이 닫힌 세이브스테이트> WR="7E2063=FF;7E2044=63;7E2050=63" SEQ="$S" HOOK="1180AC" \
  WLOG="bc=7E00BC;be=7E00BE" MAXF=1300 SHOT_DIR=… "$MESENCE" --testrunner "$PWD/rom/dq5.sfc" "$PWD/sfc/dq5/tools/lua/dq5seqtrace.lua"
```

두 세이브스테이트 모두 `1F:F8D3` 의 결과(`11:80AC` 의 A)는 0 이었습니다. [위 예외 표](../docs/dq5-data-format.md)의 「그룹 22: `2190.6` 꺼짐·`2199.3` 켜짐이면 허용」 과 같습니다.

- 슬롯 1 에 동료를 둔 쪽: 503 프레임 결과 0, 557 프레임 `$BC` = `01`, 594 프레임 `$BE` = `00`(그룹 01 필드).
- 혼자였던 쪽: 일행이 날아올라 사라진 뒤 그대로 22/00 에 머물러, 18,000 프레임에서 세이브스테이트로 끊고 이어 돌렸습니다. 날아오르는 `05:EA2F` 는 그릴 슬롯 셋이 모두 목표 높이 `$CF` 까지 오를 때까지 슬롯마다 y 를 줄이는데, 빈 슬롯 1 의 y 위 바이트(`7E:30A1`)가 `80` 이라 256 프레임에 1씩 `7F`·`7E`… 로 내려갔습니다. `30A1` = `00` 이 되고 33,322 프레임에 그룹 01 필드에 내렸습니다.

## 틀렸던 것들

- 「선실에서 대화 `04D` 만 걸어도 `25D` 창이 닫히지 않는다」(2026-10-26-16): A 를 여덟 번 누른 뒤 오른쪽을 눌렀는데, 여덟째 A 가 둘째 대화의 `25D` 를 띄운 직후였습니다. 다음 A 로 닫힙니다.
- 「`06845A`·`06845B` 는 읽지 않는다」(2026-10-26-16): 끝 찾기는 A 를 누른 뒤 `3E 3E 3F` 를 모두 읽습니다. 앞 실험의 800 프레임 안에는 그 A 가 없었습니다.
- 「22/00 의 `25D` 는 대화 `04D` 가 띄운다」: 22/00 에서는 장면 루틴 `06:C1B3` → `06:C184` 가 띄우고, 창을 닫는 것도 그 루틴의 `BRK 95 FF` 입니다. `21A6.6` 을 켜 본 것(2026-10-26-15)은 이 루틴과 관계가 없습니다.
- 「창이 닫히지 않는다」(2026-10-26-15): 5000 프레임까지만 보았습니다. 장면 이동 세이브스테이트에서는 5596 프레임에 닫힙니다.
