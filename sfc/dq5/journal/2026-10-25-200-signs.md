# 2026-10-25-200: 필드 앞 칸 표는 팻말

[앞 일지](2026-10-25-184-hidden-items.md)에 남긴 필드 앞 칸 표 `1E:F4BF` 를 열어 보았습니다. 결과는 [dq5-map-format.md](../docs/dq5-map-format.md) 의 「필드」에 있습니다.

항목 0 의 칸은 (183,197) 입니다. 장면 이동 도구로 (182,198) 에 내려 위를 보고 しらべる 했습니다. 처음에는 도구가 한 칸 오른쪽 (184,198) 에 내려 주어 12B·12C(발밑, 아무것도 없음)만 나왔습니다.

```
12:FCD3   $1E73 = 0181
메시지    169「…は 立て札を 読もうとした…」 → 181 “怪物に　注意！ 　ここより南　カボチの村”
```

값은 물건이 아니라 메시지 번호이고, 다섯 항목이 모두 팻말 글(`17F`~`185`)입니다.

필드에서 しらべる 로 물건이 나오는 곳은 `12:E5F2` 의 ルラムーンそう 한 곳뿐입니다.
