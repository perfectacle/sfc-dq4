# 2026-10-25-54: 보통 독과 キアリー, 마차 명령 창, がったい

막혔다고 적어 둔 것들을 다시 시도했습니다. 보통 독 비트와 キアリー, 상태 주문 값, 마차가 있을 때의 명령 창, スライム 합체, 이름 없는 몬스터 행동, 피하기의 상태 조건을 확인했습니다.
결과는 [dq5-data-format.md 「주문과 행동」](../docs/dq5-data-format.md#주문과-행동-268765) 에 있습니다.

## 1. 보통 독

[2026-10-25-49](2026-10-25-49-monster4.md) 에서는 `+1` 비트를 하나씩 켜 보는 방법으로 독을 가리지 못했습니다. 이번에는 독을 거는 쪽을 읽었습니다. どくこうげき(`77`)의 실행 루틴 `20:CE6D` 는 대상이 일행이면 피해를 준 뒤 `20:CE90` 에서 필드 `3E` 의 비트 3(`+1` bit5)을 보고, 꺼져 있으면 켜고 메시지 `041` 을 띄웁니다.

슬라임 행동을 どくこうげき 로 하고, 슬롯 공격력을 `POKE`(`7E:07C6` 등)로 올렸습니다. 처리 루틴 `20:B5E1` 의 `LDA #03` 이 성공 값이라 두 번 맞아도 안 걸려서, 이것을 8 로 덮었습니다.

```
05E 06A 041 「どくに おかされた！」   주인공 +1: 80 → A0
```

전투 중에는 보통 독 피해 메시지가 없었습니다. 필드에서 `+1` = `A0` 으로 좌우로 걸었을 때도 HP 가 그대로여서, 필드 피해가 드는 조건은 남았습니다.

## 2. キアリー

주인공 주문 칸에 넣으면 멈추므로 파파스에게 쓰게 했습니다. 파파스 합류 뒤 주인공 `+1` 을 `A0` 으로 한 번 쓰고, 파파스 행동을 キアリー(`2C`)로 했습니다.

```
070 07B  대상 00(파파스)  しかし なにも おこらなかった！
070 0CA  대상 01(주인공)  …の からだに まわっている どくが きえた！   +1: A0 → 80
```

`20:AEC6`·`AEFF` 는 대상이 일행이면 `20:AE41` 과 같은 `20:AEA4` 로 가서 난수(0~7) < 값으로 가립니다. 위의 3 → 8 이 이 값입니다.

## 3. 마차가 있을 때의 명령 창

dq5-warp 세션이 넣은 `ADULT=2`·`WAGON=1` 로 동료 하나(`PARTY=02`) 전투를 셋 만들었습니다.

| 옵션 | 명령 창 |
| --- | --- |
| `PARTY=02` | たたかう·さくせん·にげる(`19`) |
| `PARTY=02 ADULT=2` | たたかう·さくせん·にげる(`19`) |
| `PARTY=02 ADULT=2 WAGON=1` | たたかう·いれかえ·さくせん·にげる(`1A`) |

`21:8014` 가 고르는 것은 어른인지가 아니라 마차가 있어 いれかえ 를 할 수 있는지였습니다.

## 4. がったい 와 이름 없는 행동

장면 이동 도구로 슬라임 8마리 전투(`BATTLE="00:8"`)를 만들고 슬라임 행동을 모두 がったいだ(`6F`)로 했습니다. 첫 슬라임 차례에 「な なんと スライムたちが」「どんどん がったいしていく！」「なんと キングスライムに なってしまった！」가 나오고 무리가 キングスライム 한 마리(`7E:1001` = `6B`, `7E:1005` = 1)가 되었습니다.

행동 `98`·`99`·`A0`·`A7` 을 슬라임·ドラキー 의 행동 6개에 넣자, `99` 는 「どこからともなく …を よぶ こえがする」 뒤 「どこかへ いってしまった」로 그 몬스터가 빠졌고, 나머지 셋은 몬스터가 고르지 않고 たたかう 를 썼습니다.

## 5. 피하기의 상태 조건

피하기 표를 「늘」로(`6E` = 3, `27:8054` = 1) 하고, [2026-10-25-46](2026-10-25-46-monster3.md) 에서 만든 「처음부터 잠든 슬라임」 전투와 「깨어 있는 슬라임」 전투를 비교했습니다.

```
잠든 슬라임   : 05E 069 014(ねむっている) … 05E 069 099(めをさました) … 05E 0A3 05E 0A3
깨어 있는 슬라임: 05E 0A3 …
```

잠(상태 `30`) 동안은 피하지 않는다는 코드 읽기와 맞았습니다.

## 남은 것

- 필드에서 보통 독 피해가 드는 조건
- 행동 `98`·`A0`·`A7` 을 몬스터가 고르지 않는 까닭
- 동료 조건의 필드 A6, `23:AED1 +8` bit4-7, 물건 표 k1 bit2·4·5·6·7·k3·k4 (이번에 손대지 못함)
