# 2026-10-25-126: 스태프 롤 올리기와 07/02 ゲマ 장면 물체 실측

코드만 읽어 두었던 둘을 실측했습니다. 결과는 [dq5-graphics-format.md](../docs/dq5-graphics-format.md) 의 스태프 롤과 「맵 OBJ 물체」 에 있습니다.

## 1. 스태프 롤 올리기

엔딩 장면에서 `lua/dq5pokeonce.lua` 로 `7E:21EA` 를 `84` 로 한 번 두고, 800~1100프레임의 VRAM DMA 를 `lua/dq5vramlog.lua` 로 기록했습니다. BG3 `vscroll` 은 그대로 두고, 8프레임마다 타일맵 두 줄과 글자 그림 한 띠를 고리처럼 돌려 씁니다.

```
f00804 1C80 f00812 1CC0 f00820 1D00 … f00909 1FC0 f00917 1C00 f00925 1C40 …
f00802 4408 f00810 4608 f00818 4808 … f00907 5E08 f00915 4008 f00923 4208 …
```

코드 읽기로는 16프레임마다로 보았는데, 실제 간격은 8프레임이었습니다.

## 2. 07/02 의 물체 자리

`SET=219C|04` 장면을 6,000프레임 돌리며 30프레임마다 덤프하고, 탈것 슬롯의 칸 목록을 `16:F862` 항목과 견주어 슬롯마다 어느 물체인지 가렸습니다. 장면 중간에 인물 목록이 바뀌어 물체 첫 슬롯이 `11` 에서 `13` 으로 옮겨 가므로, 슬롯 번호가 아니라 칸 목록으로 따라가야 했습니다.

```
w2970 '03': (10,18)  '04'~'07': (11,16)
w3000 '04': (11,13) '05': (11,14) '06': (11,15) '07': (11,16)
w3060 '00': (11,14)
w4080 '01': (9,18) → w4440 (9,14) → 화면 위로
```

ゲマ 는 물체 `02`·`03`·`01` 세 그림으로 바뀌어 가며 놓이고, `04`~`07` 은 세로로 펼쳐지는 줄기, `00` 은 그 끝의 3x3 그림입니다. 여덟 물체 모두 OAM 묶음 142개가 그림과 같았습니다.

## 틀렸던 것들

- `02:9D8C` 가 놓는 슬롯 `11` 을 물체로 보았습니다. 그때 슬롯 `11` 은 그림 `78` 의 인물이었습니다.
- 스태프 롤 올리기를 16프레임마다로 적었습니다. 8프레임마다였습니다.
