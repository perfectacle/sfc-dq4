# 2026-10-25-139: 그룹 54·배·미닫이 방에서 원래대로 걸기

[2026-10-25-132](2026-10-25-132-event7.md) 에서 원래 맵에서 걸지 못한 직접 호출들을 다시 갔습니다. 결과는 [dq5-event-format.md 「원래 맵에서 걸기」](../docs/dq5-event-format.md#원래-맵에서-걸기) 에 있습니다.

## 1. 그룹 54

dq5-field2 가 `dq5warp.lua` 를 고쳐(그룹 50 이상에서 `2A:F769` 덮기) 그룹 54 에도 순간이동이 됩니다. 새 워크트리의 도구로 54/50·54/53 에 섰습니다. warp.txt 의 「arrived」 줄은 (7,23) 으로 찍혔지만, 인물 표의 주인공 자리와 화면은 요청한 칸이었습니다.

- 이벤트 9(54/50): 바위산 꼭대기의 불 놓인 제단 앞 (31,11) 에서 아래 6칸·위 4칸 걷고 `21A1.6` 을 켭니다. 54/50 (31,11) 로는 바로 서지 못해 (31,24) 에 선 뒤 스크립트 앞에 「위 13칸」을 붙였습니다.
- `02:F84F`(54/53): 어두운 기둥 방에서 위로 9칸 걸어 날개 달린 큰 인물 앞에 섭니다.

## 2. 배가 닿는 장면

17/01 은 배(17/00)와 같은 그룹이라 `TO` 가 「배를 떠났다」 를 알아채지 못합니다. dq5-sprite 가 [2026-10-25-91](2026-10-25-91-sprite4.md) 에서 쓴 대로 필드 입구로 걸어 들어갔습니다. 처음에는 `04:FD97` 의 항목을 고쳤지만, `FIELD` 가 쓰는 항목의 그룹을 바꾸면 필드 (0,0) 에 서고, 다른 항목을 고치면 밟아도 들어가지 않았습니다. 걸어서 들어가는 입구는 `04:FE83` 을 읽으므로 그 첫 항목을 「그룹 17, (342,56)」으로 덮자 17/01 (20,27) 에 들어갔습니다. 그룹 17 의 도착 항목이 처음부터 17/01 이었습니다.

조건을 다시 읽으니 Y ≥ 57 이 아니라 「걷는 중이고 아래로 가며 Y+1 ≥ 57」 이었습니다. 도착 칸을 (60,56) 으로 덮고 `SET 2191|06` 을 준 뒤 아래를 누르자 `02:A3D8` 이 불렸습니다. 주인공이 갑판을 위로 걸어 올라가고 「港に着いたぞー！」가 뜹니다. 메시지는 `1DE` 이고, 스크립트에 적힌 `1DF`「どうやら　着いたようだな。」는 그 뒤 `21A1.0` 을 기다리는 쪽에 있습니다.

## 3. 15/01 의 미닫이 방

POKE 로 주인공 칸 속성 `7E:3780` 을 `E3` 으로 고정해도 걸리지 않았습니다. 걷기 처리 `00:C85C` 가 걸음마다 `2B:8209` 로 그 값을 다시 구하기 때문입니다. 대신 걸을 때 값을 찍어 보니 15/01 (12,77) 의 별 칸이 바로 `E3` 이었습니다.

밟으면 `02:E3FA` 까지 가지만 곧 빠졌습니다. 방 배열 `7E:21EF`~`21F7` 이 `00 01 … 08` 이고, 주인공 방의 이웃 중 `07`(빈 자리)이 없었기 때문입니다. `SET` 으로 넣어서는 그대로 빠졌고, 도착 뒤 `LATESET` 으로 1번과 7번을 바꾸자 별 칸을 밟는 순간 방이 주인공을 태운 채 오른쪽의 갈색 빈 자리로 미끄러졌습니다. 그 끝에서 `15:F630` 의 `02:E463` 이 소리를 내고 마무리합니다. 3번과 7번을 바꾸면 아래로 미끄러졌습니다.

## 4. 1A/02 의 パパス

`SET 2195|0C` 로 들어가면 パパス 가 슬롯 `0A` (12,11) 에 그림 `2C` 로 놓입니다. 그런데 (11,11) 에서 오른쪽을 보고 말을 걸면 「その方向には　誰もいない。」였습니다. `06:BD94` 의 길은 지난번 선실에서 확인한 데까지입니다.

## 5. 셋째 바이트와 비트 6개

`C4`·`C5` 셋째 바이트는 dq5-npc2 가 [2026-10-25-129](2026-10-25-129-door2.md) 에서 밝힌 대로 층 값입니다. 문 표 종류 `C4` 인 문에서만 칸 `+1` 에 OR 됩니다. 01/00 성문은 그 종류가 아니어서 값을 바꿔도 같았습니다. 켜는 곳이 없던 비트 6개는 롬 전체를 다시 훑어도 켜는 꼴이 없어 「쓰지 않는 비트」 로 닫았습니다.
