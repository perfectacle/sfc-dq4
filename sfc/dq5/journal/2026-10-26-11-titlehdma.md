# 2026-10-26-11: 타이틀 바다 물결·BG4 HDMA 표와 링 반짝이 자리

오프닝 타이틀에서 프레임마다 바뀌는 것 가운데 남아 있던 셋, 바다 물결 HDMA 표(`7E:A000` 간접), BG4 가로 HDMA 표(`7E:A4DC`), 링 반짝이 OBJ 를 만드는 곳을 찾아 롬만으로 계산하는 `sfc/dq5/tools/dq5titlefx.py` 를 만들었습니다. 결과는 [dq5-graphics-format.md 「오프닝 타이틀 로고」](../docs/dq5-graphics-format.md#오프닝-타이틀-로고-02e840)에 있습니다.

## 1. 타이틀 세이브스테이트

전원부터 5,000프레임 넘게 입력을 재생하면 실험 한 번이 깁니다. `dq5titlegif.py` 와 같은 입력을 `dq5savestate.lua` 로 재생해 5,560프레임(타이틀 앞 검은 화면 끝 무렵)에 세이브스테이트를 만들고, 그 뒤로는 거기서 1,300프레임씩 돌렸습니다. 프레임 건너뛰기를 끄는 인자([2026-10-26-04](2026-10-26-04-frameskip.md))도 함께 줍니다.

## 2. 표를 쓰는 곳

`7E:A000`~`A6FF` 쓰기를 (PC, 주소)마다 처음 한 번씩 남겼습니다. 프레임마다 쓰는 곳은 `02:EC67`~(`A4DC`~`A4EB`)과 `03:998E`·`03:99B7`(`A007`~`A1E6`)이었습니다. `0F:EC4E`·`EC79`(132프레임)과 `02:EA80`(228프레임)은 같은 자리를 다른 그림을 풀 때 잠깐 쓴 것이고, `03:99C6`·`99DA`(361프레임)가 물결 표를 0 으로 채우고 간접 표 머리를 씁니다.

처음에 `$71`·`$75` 쓰기 감시를 `7E:0071` 로 걸자 아무것도 잡히지 않았습니다. 직접 페이지 쓰기는 뱅크 00 주소(`00:0071`)로 들어오기 때문이고, 감시 주소를 바꾸자 `03:AA73 INC $75`(프레임마다)와 `03:AAA4 STA $71` 이 나왔습니다. `$71` 에 더하는 `$075B` 는 NMI 쪽 `00:8897 INC $075B` 가 프레임마다 올리는 수였습니다.

부르는 곳은 문서에 적었던 「NMI 쪽」 이 아니라 타이틀 기다리는 고리 `02:ED3E` 였습니다. `7E:21EA` bit1 이 켜져 있으면 `03:AA67` 과 `02:EC67` 을 부릅니다.

## 3. 물결 표를 롬만으로

`03:AA92` 를 그대로 옮겨 처음 돌렸을 때는 939프레임이 모두 달랐습니다. 두 가지를 잘못 생각했습니다.

- 준비(`03:AA3C`)의 240번 고리가 한 프레임에 끝난다고 보았습니다. 실제로는 한 번에 `MVP` 로 478바이트를 옮겨 한 프레임에 11~12번씩, 21프레임에 걸쳐 돕니다. 그 사이 프레임 끝 덤프에는 옮기던 중간 모양(`FF0F` 같은 반쪽 낱말)이 보입니다.
- 표를 한 낱말 미는 것으로 보았지만, `MVP` 는 `A006`~`A1E3` 을 `A008`~`A1E5` 로 옮겨 끝 낱말의 높은 바이트(`A1E6`)는 그대로 둡니다.

이 둘을 고치고, 준비가 끝난 383프레임 상태에서 `$75`·`$075B` 만으로 진행하자 917프레임 내내 물결 표와 `$71` 이 덤프와 같았습니다. BG4 표는 `$75` 만으로 정해지고 918프레임 모두 같았습니다.

```
물결 표: 프레임 383 부터 917프레임 중 다름 0
BG4 표($75>0): 918프레임 중 다름 0
```

## 4. 링 반짝이

OAM 을 프레임마다 덤프하자 타일 `143`·`144`·`147`·`148` 같은 반짝이가 링 열을 따라 X 8점씩 늘어서 있었습니다. `02:EB22` 는 열을 하나 그릴 때마다 `02:EB96` 을 세 번(줄 k = 2, 1, 0) 부르고, 그 안에서 `02:EC00` 이 열 `$08` 의 자리(`02:EDFE` 의 X + 3, Y + `02:EE5A[열]` + `02:EE57[k]`)를 고릅니다. `$08` 은 머리 열 + 1 에서 OBJ 마다 하나씩 줄어 반짝이가 머리 뒤 네 열에 걸칩니다.

이 계산으로 1,081~1,300프레임의 OAM 0~11 을 맞추자 220프레임 모두 어떤 머리 열 하나와 같았습니다.

```
머리 열: 0~21 한 프레임씩 → 숨김 66프레임 → 0~21 두 프레임씩 → 숨김 88프레임
```

## 틀렸던 것들

- 「HDMA 표를 매 프레임 만드는 곳은 NMI 쪽」: 타이틀 고리 `02:ED3E` 가 부릅니다.
- 물결 준비가 한 프레임에 끝난다는 것과 표를 낱말째 민다는 것(3절).

## 남은 것

- 층을 모두 겹쳐 타이틀 연출 전체를 롬만으로 그리기(로고 밝히기·성 올리기·V 내려오기·링·반짝이·물결의 차례를 한 타임라인으로). 준비 21프레임 동안의 물결 표는 `MVP` 가 끊기는 자리에 따라 달라 롬만으로는 그리지 않습니다.
