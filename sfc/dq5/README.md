# dq5: SFC DQ5 엔진

SFC 「드래곤 퀘스트 V」(일본판) 엔진을 분석하는 트랙입니다. 맵·필드·인물·스크립트·게임 데이터의 형식을 풀어, DQ4 데이터를 어디에 어떻게 넣을지 정할 근거를 만듭니다. 규칙은 [AGENTS.md](../../AGENTS.md), 롬 준비는 [저장소 README](../../README.md#원본-롬) 를 봅니다.

## 문서

- [handoff.md](handoff.md): dq5 트랙 시작점(지금 상태, 실험 출발점, 다음 할 일)
- [docs/dq5-map-format.md](docs/dq5-map-format.md): DQ5 실내 맵 형식(지형·팔레트·인물·출구·영역 이동·보물상자)
- [docs/dq5-field-format.md](docs/dq5-field-format.md): DQ5 필드(세계 지도) 형식
- [docs/dq5-text-format.md](docs/dq5-text-format.md): DQ5 메시지(허프만 부호)·제어 코드·폰트·대화 스크립트·이름 문자열·메뉴 창 문자열
- [docs/dq5-data-format.md](docs/dq5-data-format.md): DQ5 게임 데이터(상점 품목·물건 가격·물건 표·몬스터·전투 조우)
- [docs/dq5-flags.md](docs/dq5-flags.md): DQ5 이야기 플래그(`7E:2190`~)를 켜고 끄고 보는 곳
- [docs/dq5-graphics-format.md](docs/dq5-graphics-format.md): DQ5 전투 몬스터 그림(레코드·머리·조각·타일 압축·팔레트·배치·그림자)과 전투 배경, 필드 인물 스프라이트(세트·레코드·타일 압축·프레임 배치·맵 OBJ 타일)
- [docs/dq5-hangul-format.md](docs/dq5-hangul-format.md): 한글 넣기 실현성(롬 확장, 메시지 옮기기와 트리 다시 만들기, 새 글자, 1바이트 부호)
- [docs/dq5-event-format.md](docs/dq5-event-format.md): DQ5 이벤트 스크립트(주인공을 조종하는 표와 명령)
- [docs/dq5-sound-format.md](docs/dq5-sound-format.md): DQ5 소리 명령(명령 입구·대기열·BRK 0F~19·효과음·맵 곡)
