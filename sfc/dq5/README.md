SFC 「드래곤 퀘스트 V」(일본판) 엔진을 분석하는 트랙입니다. 맵·필드·인물·스크립트·게임 데이터의 형식을 풀어, DQ4 데이터를 어디에 어떻게 넣을지 정할 근거를 만듭니다. 규칙은 [AGENTS.md](../../AGENTS.md), 롬 준비는 [저장소 README](../../README.md#원본-롬) 를 봅니다.

- [handoff.md](handoff.md): dq5 트랙 시작점(지금 상태, 실험 출발점, 다음 할 일)
